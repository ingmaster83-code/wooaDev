PostgreSQL 배열 · interval 파서

{1,2,3}, {"a b",NULL}, {{1,2},{3,4}} 같은 PostgreSQL 배열 리터럴을 JSON 으로 바꾸고, '1 year 2 mons 3 days 04:05:06' 같은 interval 값을 필드별로 분석해 ISO 8601 로 변환합니다.

사용 예시

✅ 배열 4개를 변환했습니다

입력 — PostgreSQL 배열 리터럴 (한 줄에 하나)

{1,2,3}
{"hello world",NULL,"with \"quote\"","a,b"}
{{1,2},{3,4}}
{apple,banana}

입력 — interval 값 (한 줄에 하나)

1 year 2 mons 3 days 04:05:06.5
-1 days +02:00:00
P1Y2M3DT4H5M6S
@ 2 hours 30 mins
00:90:00

결과 — 결과

입력 | 상태 | 차원 | 요소 수 | 참고
{1,2,3} | ✅ | 1D | 3 | 
{"hello world",NULL,"with \"quote\"",… | ✅ | 1D | 4 | 
{{1,2},{3,4}} | ✅ | 2D | 4 | 
{apple,banana} | ✅ | 1D | 2 |

결과 — JSON / 정규화

[1,2,3]
["hello world",null,"with \"quote\"","a,b"]
[[1,2],[3,4]]
["apple","banana"]

이 도구로 할 수 있는 일

psql 이나 CSV 로 내보낸 배열·interval 컬럼은 텍스트로 나와 코드에서 쓰기 번거롭습니다. 붙여 넣어 바로 구조화된 값으로 바꾸세요.

  • 배열: 따옴표 요소와 이스케이프, NULL 과 "NULL" 구분, 다차원, 빈 배열, [0:2]= 차원 접두사
  • 요소 타입 추정: 따옴표 없는 숫자·t/f 는 JSON 숫자·불리언, 나머지는 문자열
  • 다차원 배열의 하위 배열 길이가 다르면 PostgreSQL 이 거부한다고 알려 줌
  • interval: postgres 형식, SQL 표준(@ 2 hours), ISO 8601(P1Y2M3DT4H5M6S), 시:분:초 정규화, ago, 소수 단위
  • 연·월·일·시간·분·초와 ISO 8601, 근사 초 환산 출력

함께 쓰면 좋은 도구

📅ISO 8601 / RFC 날짜 변환기 ⏱️시간 단위·기간 변환기 📋JSON 포맷터 🗃️SQL INSERT 변환기

💡 Tips

  • interval 은 월(30일로 근사)·일·시간을 따로 저장하므로 단순 초 환산은 근사값입니다.
  • 실제 애플리케이션에서는 드라이버(pg 등)가 배열을 자동 변환하니 직접 파싱은 CSV·로그 분석에 쓰세요.
  • 문자열 배열은 쉼표·공백·따옴표가 있으면 PostgreSQL 이 따옴표로 감쌉니다.

자주 묻는 질문

NULL 과 "NULL" 은 다른가요?

따옴표 없는 NULL 은 값 없음(null), 따옴표가 있는 "NULL" 은 글자 NULL 이 든 문자열입니다.

interval 의 mons 는 무엇인가요?

month 의 약자입니다. 12 mons 는 1 year 로 표시되며 연 단위는 12개월로 환산됩니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
