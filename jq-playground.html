jq 플레이그라운드 (온라인 jq 실행기)

JSON과 jq 필터를 넣으면 결과를 바로 보여 줍니다. 파이프, select, map, group_by, reduce/foreach, 변수와 구조 분해, def 함수, 정규식(test·match·sub), @csv·@base64 같은 포맷, 경로 갱신(|=, +=), 여러 입력과 -n·-s·-r·-c·-S 옵션을 지원하는 jq 1.7 호환 해석기입니다.

사용 예시

✅ 출력 1개

입력 — jq 필터

.users | map(select(.age >= 30) | {name, city: .address.city}) | sort_by(.name)

입력 — JSON 입력 (여러 값을 이어 붙여도 됩니다)

{"users":[{"name":"Mina","age":34,"address":{"city":"Seoul"}},{"name":"Joon","age":28,"address":{"city":"Busan"}},{"name":"Ara","age":41,"address":{"city":"Daegu"}}]}

결과 — 결과

[
  {
    "name": "Ara",
    "city": "Daegu"
  },
  {
    "name": "Mina",
    "city": "Seoul"
  }
]

이 도구로 할 수 있는 일

jq 를 설치하지 않고도 필터를 만들고 테스트합니다. JSON 과 필터는 서버로 전송되지 않습니다.

  • 문법: 파이프, 쉼표, 대체(//), 경로(.a.b[0], .[1:3], .[]?, ..), 객체·배열 구성, 문자열 보간 "\(…)", 포맷(@csv @tsv @json @html @uri @sh @base64 @base32)
  • 제어: if/elif/else, try/catch, reduce, foreach, label/break, as 변수와 구조 분해(?// 포함), def 함수(재귀·클로저 인자)
  • 내장 함수 200여 개: map, select, sort_by, group_by, unique_by, to_entries, with_entries, paths, walk, limit, first/last, range, test/match/capture/sub/gsub, split/join, tojson, todate 등
  • 갱신: =, |=, +=, -=, *=, /=, //=, del, delpaths, setpath, pick
  • 옵션: -c -r -j -S -n -s -R --tab --indent, --argjson 변수, 여러 JSON 값 연속 입력

💡 Tips

  • 필터가 길어지면 단계별로 | 로 나눠 가며 결과를 확인하세요. 오류 메시지는 실제 jq 와 같은 형식입니다.
  • 문자열 값을 따옴표 없이 쓰려면 -r 옵션을 고르세요. 한 줄에 하나씩 파이프할 때 유용합니다.
  • 키가 많은 객체는 to_entries / with_entries 로 키와 값을 함께 다루면 편합니다.

자주 묻는 질문

실제 jq 와 결과가 똑같나요?

jq 1.7 의 문법과 주요 내장 함수를 구현했고 매뉴얼 예제로 검증했지만 100% 같지는 않습니다. JavaScript 객체 특성상 정수 형태의 키는 항상 앞쪽에 정렬되고, 큰 정수의 정밀도는 JavaScript 숫자 범위로 제한됩니다.

무한 루프를 돌리면 어떻게 되나요?

실행 단계 수와 출력 개수에 상한이 있어 일정 한도를 넘으면 오류로 중단합니다. 브라우저가 멈추지 않도록 한 안전장치입니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
