.NET Ticks 변환기 — DateTime.Ticks ↔ 날짜

.NET의 DateTime.Ticks(0001-01-01 이후 100나노초 수)를 날짜로, 날짜를 Ticks로 정밀하게 바꿉니다. 소수 7자리까지 잘리지 않습니다.

사용 예시

✅ 5개 변환

입력 — Ticks 또는 날짜 (한 줄에 하나)

639119646151234567
2026-10-16T09:30:15.1234567Z
0
621355968000000000
3155378975999999999

결과 — 변환 결과

입력 | Ticks | UTC (ISO 8601, 100ns) | Unix ms
639119646151234567 | 639119646151234567 | 2026-04-16T19:30:15.1234567Z | 1776367815123
2026-10-16T09:30:15.1234567Z | 639277398151234567 | 2026-10-16T09:30:15.1234567Z | 1792143015123
0 | 0 | 0001-01-01T00:00:00.0000000Z | -62135596800000
621355968000000000 | 621355968000000000 | 1970-01-01T00:00:00.0000000Z | 0
3155378975999999999 | 3155378975999999999 | 9999-12-31T23:59:59.9999999Z | 253402300799999

이 도구로 할 수 있는 일

C#의 DateTime.Ticks는 0001-01-01부터 지난 100나노초의 개수입니다. 로그, DB, 직렬화된 값에서 63xxxxxxxxxxxxxxxxx 같은 18~19자리 숫자를 만났을 때 날짜로 바꿔 보세요.

  • Ticks → UTC ISO 8601(소수 7자리), Unix 초·밀리초, 16진수
  • 날짜 → Ticks: 100ns 단위 정밀도를 그대로 유지 (double로는 불가능한 정밀도를 BigInt로 계산)
  • DateTime.Kind=Utc일 때의 ToBinary() 값도 함께 표시
  • 유효 범위(0 ~ 3155378975999999999)를 벗어나면 이유를 알려 줌
  • 한 줄에 하나씩 여러 값을 섞어 입력하면 숫자는 날짜로, 날짜는 Ticks로 자동 변환

💡 Tips

  • Unix 에포크(1970-01-01)의 Ticks는 621355968000000000 입니다. 이 값을 빼고 10,000으로 나누면 Unix 밀리초입니다.
  • JavaScript Number로 Ticks를 읽으면 끝자리가 틀립니다. 이 도구는 BigInt를 씁니다.
  • DateTimeOffset의 Ticks는 UTC가 아니라 현지 시각 기준이므로 오프셋을 따로 확인하세요.

자주 묻는 질문

Ticks 한 칸은 얼마인가요?

1 tick = 100나노초 = 0.0000001초입니다. 1초는 10,000,000 ticks, 1밀리초는 10,000 ticks입니다.

DateTime.MaxValue의 Ticks는?

3155378975999999999 로 9999-12-31T23:59:59.9999999 입니다. 이 도구의 범위 검사와 같은 값입니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
