Postman ↔ OpenAPI 변환기

Postman 컬렉션(v2.1)을 OpenAPI 3.0 문서로, 또는 OpenAPI 문서를 Postman 컬렉션으로 변환합니다. 경로·쿼리·헤더·본문·응답 예시를 옮기고 폴더는 태그로, baseUrl 은 컬렉션 변수로 매핑합니다. 변환 방향은 자동 판별됩니다.

사용 예시

✅ 요청 3개를 OpenAPI 3.0 으로 변환했습니다

입력 — Postman 컬렉션(v2.x JSON) 또는 OpenAPI 문서

{
  "info": {
    "name": "Pet API",
    "schema": "https://schema.getpostman.com/json/collection/v2.1.0/collection.json"
  },
  "variable": [
    {
      "key": "baseUrl",
      "value": "https://api.example.com/v1"
    }
  ],
  "auth": {
    "type": "bearer",
    "bearer": [

        "key": "token",
        "value": "{{token}}",
        "type": "string"
      }

이 도구로 할 수 있는 일

API 문서와 테스트 컬렉션을 한 곳에서 서로 바꿔 줍니다. 파일은 서버로 전송되지 않습니다.

  • Postman → OpenAPI: 경로 변수(:id), 쿼리, 헤더, JSON 본문 스키마 추론, 응답 예시, 폴더 → 태그
  • OpenAPI → Postman: baseUrl 변수, 경로·쿼리 파라미터(선택은 비활성), 요청 본문 예시, 응답 예시
  • 출력 형식 YAML 또는 JSON, 변환 방향 자동 판별
  • 변환 결과는 OpenAPI 검사기를 통과하도록 구성
  • 변환 요약 표와 주의 사항

💡 Tips

  • Postman 의 {{변수}} 는 OpenAPI 서버 URL 이나 값 자리표시자로 옮겨집니다. 변환 후 servers 를 확인하세요.
  • 스키마는 예시 본문에서 추론하므로 required·format 은 변환 후 직접 다듬는 것이 좋습니다.
  • 변환한 OpenAPI 는 OpenAPI 검사기에 붙여 넣어 바로 오류를 확인하세요.

자주 묻는 질문

인증 설정도 변환되나요?

OAuth2 같은 복잡한 인증은 변환하지 않습니다. 필요한 보안 스킴은 변환 후 직접 추가하세요.

Postman v2.0 도 되나요?

v2.1 컬렉션을 기준으로 합니다. v2.0 은 대부분 읽히지만 일부 필드는 무시될 수 있습니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
