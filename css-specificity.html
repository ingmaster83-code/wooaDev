CSS 명시도(Specificity) 계산기

여러 선택자를 입력하면 명시도를 계산하고 어떤 규칙이 이기는지 비교해줍니다.

💡 Tips

  • ID(#)는 클래스(.)보다, 클래스는 태그(div, a 등)보다 명시도가 높습니다.
  • 같은 명시도라면 CSS 파일에서 나중에 선언된 규칙이 이깁니다.
  • 명시도 전쟁을 피하려면 !important 대신 선택자를 단순하게 유지하세요.

자주 묻는 질문

명시도는 어떻게 계산되나요?

(인라인 style, ID 개수, 클래스·속성·가상클래스 개수, 태그·가상요소 개수) 네 자리 값으로 계산되며, 앞자리가 클수록 우선순위가 높습니다.

!important는 명시도에 포함되나요?

아니요. !important는 명시도 계산과 별개로 다른 모든 규칙보다 우선 적용됩니다. 명시도 비교는 !important가 없는 경우에만 의미가 있습니다.

파일이 서버에 저장되나요?

아니요. 모든 계산은 브라우저 안에서만 이루어지며 입력값은 서버로 전송되지 않습니다.
