XML → 표 · CSV 변환기

<catalog><book>…</book><book>…</book></catalog> 처럼 반복되는 요소를 레코드로 인식해 한 행씩의 표와 CSV·TSV 로 바꿉니다. 속성은 @속성 열로, 중첩 요소는 a.b 열로, 같은 이름의 반복 요소는 구분자로 합쳐 줍니다.

사용 예시

✅ 2행 × 7열

입력 — XML

<?xml version="1.0"?>
<catalog>
  <book id="b1" lang="en">
    <title>XML Basics</title>
    <author>Kim</author>
    <price currency="USD">29.99</price>
    <tags><tag>xml</tag><tag>intro</tag></tags>
  </book>
  <book id="b2">
    <title>Data, "Quoted" &amp; More</title>
    <author>Lee</author>
    <price currency="KRW">35000</price>
  </book>
</catalog>

결과 — 미리보기

@id | @lang | title | author | price@currency | price | tags.tag
b1 | en | XML Basics | Kim | USD | 29.99 | xml|intro
b2 |  | Data, "Quoted" & More | Lee | KRW | 35000 |

결과 — CSV

@id,@lang,title,author,price@currency,price,tags.tag
b1,en,XML Basics,Kim,USD,29.99,xml|intro
b2,,"Data, ""Quoted"" & More",Lee,KRW,35000,

이 도구로 할 수 있는 일

API 응답이나 내보내기 XML 을 스프레드시트에서 열 수 있게 만듭니다. 파일은 서버로 보내지 않습니다.

  • 레코드 감지: 가장 많이 반복되는 요소를 자동 선택하거나 경로(catalog/book)를 직접 지정
  • 열 만들기: 자식 요소는 열, 속성은 @이름, 중첩은 a.b, 반복 요소는 지정한 구분자(|)로 합침
  • 출력: 미리보기 표, CSV / TSV / 세미콜론, 엑셀용 UTF-8 BOM 선택
  • 보안: =, +, -, @ 로 시작하는 셀은 CSV 수식 주입 위험으로 알림
  • 네임스페이스 접두사와 CDATA, 엔티티 처리

💡 Tips

  • 엑셀에서 한글이 깨지면 UTF-8 BOM 옵션을 켜세요.
  • 레코드 구조가 서로 다르면 열이 합쳐져 빈 칸이 생길 수 있습니다.
  • 개인정보가 든 XML 은 변환 후 CSV 를 공유하기 전에 열을 확인하세요.

자주 묻는 질문

레코드가 하나뿐이면요?

반복 요소가 없으면 루트의 자식들을 한 행으로 변환합니다. 필요하면 레코드 경로를 지정하세요.

대용량 XML 도 되나요?

브라우저 메모리 한도 안에서 처리합니다. 수십 MB 이상은 서버 도구나 스트리밍 파서를 권장합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
