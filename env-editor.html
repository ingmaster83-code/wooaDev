.env 편집기 — 표로 편집하고 결과 미리보기

.env 파일을 변수·값 표로 바꿔 보여 주고, 셀을 직접 고치거나 변수를 추가·삭제하면 완성된 .env를 바로 만들어 줍니다.

사용 예시

✅ 변수 5개

입력 — .env 붙여넣기

# app
NODE_ENV=development
PORT=3000
DATABASE_URL=postgres://user:pass@localhost/db
JWT_SECRET=changeme
DEBUG=true

결과 — 편집 결과 .env

# app
NODE_ENV=development
PORT=3000
DATABASE_URL=postgres://user:pass@localhost/db
JWT_SECRET=changeme
DEBUG=true

이 도구로 할 수 있는 일

긴 .env 파일에서 한 줄 값을 바꾸거나 키를 추가할 때, 텍스트에서 따옴표나 공백을 신경 쓰다 실수하기 쉽습니다. 표로 보면서 편집하면 형식은 도구가 맞춰 줍니다.

  • 변수 이름과 값을 표의 셀에서 직접 수정, 행 추가·삭제
  • 주석과 빈 줄은 원래 위치에 그대로 유지하고 export 접두사도 보존
  • 값에 공백·#·따옴표가 있으면 자동으로 올바르게 따옴표 처리
  • 값 숨기기(•)로 화면 공유 중에도 안전하게 확인

편집이 끝나면 결과 .env를 복사하거나 다운로드하세요.

함께 쓰면 좋은 도구

🔍ENV 비교·누락 확인 📄.env.example 생성기 🔄ENV ↔ JSON 변환기 🔒비밀번호 생성기

💡 Tips

  • JWT_SECRET 같은 값을 새로 만들어야 하면 비밀번호 생성기로 만든 문자열을 붙여 넣으세요.
  • 결과를 입력으로 되돌리는 버튼으로 편집한 내용을 다시 불러 이어서 수정할 수 있습니다.
  • 키를 비우면 해당 행은 결과에서 제외됩니다.

자주 묻는 질문

편집한 내용이 저장되나요?

저장되지 않습니다. 페이지를 닫으면 사라지므로 결과를 복사하거나 다운로드해서 사용하세요. 모든 처리는 브라우저 안에서만 이루어집니다.

여러 줄 값도 편집할 수 있나요?

여러 줄 값은 표에서는 한 칸에 표시되며 저장 시 \n 이스케이프가 포함된 큰따옴표 문자열로 출력됩니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
