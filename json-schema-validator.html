JSON 스키마 검증기 — Schema로 JSON 데이터 검증

JSON 데이터가 JSON Schema를 만족하는지 검증하고, 어떤 경로의 어떤 규칙이 깨졌는지 모든 오류를 표로 보여 줍니다.

사용 예시

❌ 검증 실패 — 오류 5건 (Draft 07)

입력 — JSON Schema

{
  "type": "object",
  "required": ["id", "email"],
  "properties": {
    "id": { "type": "integer", "minimum": 1 },
    "email": { "type": "string", "format": "email" },
    "role": { "enum": ["admin", "user"] },
    "tags": { "type": "array", "items": { "type": "string" }, "uniqueItems": true }
  },
  "additionalProperties": false
}

입력 — 검증할 JSON 데이터

{
  "id": 0,
  "email": "not-an-email",
  "role": "guest",
  "tags": ["a", "a"],
  "extra": true
}

결과 — 검증 오류

데이터 위치 | 키워드 | 메시지 | 세부 | 스키마 위치
(root) | additionalProperties | must NOT have additional properties | additionalProperty="extra" | #/additionalProperties
/id | minimum | must be >= 1 | comparison=">=", limit=1 | #/properties/id/minimum
/email | format | must match format "email" | format="email" | #/properties/email/format
/role | enum | must be equal to one of the allowed values | allowedValues=["admin","user"] | #/properties/role/enum
/tags | uniqueItems | must NOT have duplicate items (items ## 1 and 0 are identical) | i=0, j=1 | #/properties/tags/uniqueItems

이 도구로 할 수 있는 일

API 요청 본문, 설정 파일, 데이터 파일이 약속한 형식을 지키는지 확인하는 표준 방법이 JSON Schema입니다. 스키마와 데이터를 붙여 넣으면 모든 위반을 한 번에 보여 줍니다.

  • 사용 라이브러리: Ajv v8 (가장 널리 쓰이는 JSON Schema 검증기)
  • Draft-07 / 2019-09 / 2020-12 지원, $schema로 자동 선택하거나 직접 지정
  • 모든 오류 수집: 데이터 경로(/items/1/price), 키워드(type, required, enum…), 메시지, 스키마 위치
  • format 검사(email, uri, date-time 등) 켜기/끄기, 엄격 모드(알 수 없는 키워드를 오류로)
  • 스키마 자체가 잘못된 경우에는 그 사실을 따로 알려 줌

스키마를 직접 쓰기 어렵다면 JSON 스키마 생성기로 초안을 만든 뒤 사용하세요.

💡 Tips

  • 오류가 많을 때는 데이터 위치 열이 같은 것끼리 묶어 읽으면 원인이 보입니다.
  • format은 기본 검증 대상이 아닐 수 있으므로 이메일·날짜 형식 검사가 필요하면 format 옵션을 켜 두세요.
  • additionalProperties:false가 있으면 오타 난 키가 additionalProperties 오류로 표시됩니다.

자주 묻는 질문

스키마의 $schema 값이 지원하지 않는 버전이면?

$schema는 버전 선택 용도로만 읽고 검증에서는 제외하므로, Draft-04 같은 구버전 문법만 쓰지 않는다면 대부분 동작합니다. 확실하지 않으면 버전을 직접 지정하세요.

데이터가 서버에 전송되나요?

아니요. 스키마와 데이터 모두 브라우저에서 처리되며 외부로 전송되지 않습니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
