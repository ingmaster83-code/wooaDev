CSS 포맷터 · 검사기

한 줄로 압축된 CSS 를 읽기 쉽게 정리하거나 최소화하고, 같은 규칙 안의 중복 속성, 빈 규칙, !important 남용, 불필요한 벤더 접두사, 닫히지 않은 괄호를 찾아 줍니다.

사용 예시

✅ 정리 완료

입력 — CSS

/* 카드 */
.card{color:#FFF;background:url("a.png") no-repeat;margin:0 auto;color:red!important}
.card:hover,.card:focus{transform:translateY(-2px)}
@media (max-width:600px){.card{margin:0;-webkit-transition:all .3s;transition:all .3s}.empty{}}
.btn{padding:4px 8px;&:hover{opacity:.8}}

결과 — 결과

/* 카드 */

.card {
  color: #FFF;
  background: url("a.png") no-repeat;
  margin: 0 auto;
  color: red !important;
}

.card:hover,
.card:focus {
  transform: translateY(-2px);
}

@media (max-width: 600px) {
  .card {
    margin: 0;
    -webkit-transition: all .3s;
    transition: all .3s;
  }

  .empty {}
}

.btn {
  padding: 4px 8px;
  &:hover {
    opacity: .8;
  }
}

결과 — 검사 결과

같은 규칙에서 속성이 중복되었습니다: color (.card) — 뒤의 값이 이깁니다 (폴백 의도가 아니면 제거)
빈 규칙: .empty
벤더 접두사 -webkit-transition — 현대 브라우저는 접두사 없이도 지원합니다 (Autoprefixer 사용 권장)

이 도구로 할 수 있는 일

압축된 스타일시트를 분석하거나 직접 짠 CSS 를 정리할 때 씁니다. 모든 처리는 브라우저 안에서만 이루어집니다.

  • 정리: 선택자 쉼표 줄바꿈, 속성 정리, 값의 쉼표·공백 정규화, !important 표기, @media 조건 공백
  • 문자열·url() 안의 ; { } 는 건드리지 않음, 중첩 규칙(&:hover)과 @규칙 지원
  • 선택: 선언 알파벳순 정렬, 주석 유지/삭제, 2칸·4칸·탭
  • 검사: 중복 속성, 빈 규칙, !important 4번 이상, 불필요한 -webkit- 접두사, 속성:값 형식 오류, 괄호·주석·문자열 미종료
  • 최소화: 공백·주석 제거, 마지막 세미콜론 제거, 0.5 → .5

💡 Tips

  • 정렬은 의도적인 폴백(color 를 두 번 쓰는 경우)의 순서를 바꿀 수 있어 주의하세요.
  • !important 가 많다면 선택자 명시도를 정리하는 편이 장기적으로 낫습니다.
  • 벤더 접두사는 Autoprefixer 같은 빌드 도구에 맡기는 것이 안전합니다.

자주 묻는 질문

중복 속성이 항상 잘못인가요?

아닙니다. 오래된 브라우저용 폴백을 위해 의도적으로 반복하기도 합니다. 의도하지 않은 중복인지 확인하라는 알림입니다.

SCSS/Less 도 되나요?

일반 CSS 와 CSS 중첩 문법을 대상으로 합니다. 변수·믹스인 같은 전처리기 기능은 지원하지 않습니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
