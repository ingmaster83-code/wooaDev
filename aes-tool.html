AES 암호화 · 복호화 (GCM · CBC · CTR)

AES-128/192/256 의 GCM, CBC, CTR 모드로 텍스트를 암호화하고 복호화합니다. 키, IV, 인증 태그, AAD 를 따로 다룰 수 있어 서버 구현과 결과를 맞춰 볼 때 편합니다. 키와 IV 를 비우면 무작위로 만들어 줍니다.

사용 예시

✅ 암호화 완료 (47바이트)

입력 — 입력 데이터 (암호화: 평문, 복호화: 암호문)

Hello, WooaDev! 안녕하세요

입력 — 키 (비우면 무작위 생성 — 암호화에서만)

000102030405060708090a0b0c0d0e0f

입력 — IV / Nonce / 카운터 (비우면 무작위 — 암호화에서만)

0102030405060708090a0b0c

결과 — 결과 요약

항목 | 값
AES-128-GCM | 
키 (hex) | 000102030405060708090a0b0c0d0e0f
IV | 0102030405060708090a0b0c
암호문 길이 | 31바이트
인증 태그 (16바이트) | MsEsyVxiDHg2ewX29M4HIA==
암호문 (태그 제외) | TmAESlzZf5JXM2wByK5MFS1eb7ZrNAH5xUm/7wgT+A==
결과 (암호문‖태그) | TmAESlzZf5JXM2wByK5MFS1eb7ZrNAH5xUm/7wgT+DLBLMlcYgx4NnsF9vTOByA=

결과 — 출력

TmAESlzZf5JXM2wByK5MFS1eb7ZrNAH5xUm/7wgT+DLBLMlcYgx4NnsF9vTOByA=

이 도구로 할 수 있는 일

다른 언어·서버가 만든 AES 암호문을 직접 풀어 보거나 구현이 같은 결과를 내는지 확인할 때 씁니다. 키와 데이터는 브라우저 밖으로 나가지 않습니다.

  • 모드: AES-GCM(인증 태그 16바이트, AAD 지원), AES-CBC(PKCS#7 패딩), AES-CTR(64비트 카운터)
  • 키: 16·24·32바이트, 16진수·Base64·UTF-8 / 키·IV 를 비우면 무작위 생성(암호화 때)
  • 결과: 암호문, 분리된 인증 태그, IV‖암호문‖태그 한 덩어리, 16진수 또는 Base64
  • 복호화: 태그가 붙어 있거나 따로 있는 GCM, IV 를 앞에서 떼어내는 옵션, 태그 불일치(변조·키·IV·AAD 오류) 진단
  • NIST 테스트 벡터와 일치, 모드별 보안 주의사항(nonce 재사용, CBC 무결성)

💡 Tips

  • GCM 에서 같은 키로 같은 nonce 를 두 번 쓰면 보안이 완전히 무너집니다. 메시지마다 새로 만드세요.
  • 복호화 실패는 대부분 키·IV·AAD 중 하나가 다르거나 Base64/16진수 해석이 달라서 생깁니다.
  • CBC·CTR 은 변조를 감지하지 못합니다. 무결성이 필요하면 GCM 을 쓰세요.

자주 묻는 질문

태그가 암호문 뒤에 붙어 있나요, 따로 있나요?

Web Crypto 와 Java 는 암호문 뒤에 태그를 붙이고, OpenSSL·일부 라이브러리는 따로 줍니다. 도구는 둘 다 지원합니다.

실제 비밀을 넣어도 되나요?

입력은 서버로 가지 않지만 이 도구는 테스트와 학습용입니다. 실제 운영 비밀은 서버나 KMS 에서 다루세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
