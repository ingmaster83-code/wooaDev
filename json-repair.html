JSON 복구 도구 — 깨진 JSON 자동 수정

따옴표·쉼표·괄호가 틀렸거나 중간에 잘린 JSON을 올바른 JSON으로 고치고, 무엇을 고쳤는지 알려 줍니다.

사용 예시

🔧 7종류의 문제를 고쳤습니다.

입력 — 깨진 JSON 입력

{
  // user info
  name: 'Wooa',
  "age": 30,
  tags: ['a', 'b',],
  active: True,
  "memo": "line1
line2",
  "nested": {"x": 1, "y": [1, 2

결과 — 복구된 JSON

{
  "name": "Wooa",
  "age": 30,
  "tags": [
    "a",
    "b"
  ],
  "active": true,
  "memo": "line1\nline2",
  "nested": {
    "x": 1,
    "y": [
      1,
      2
    ]
  }
}

결과 — 수정 내역

수정 내용 | 횟수
주석 제거 | 1회
따옴표 없는 키에 큰따옴표 추가 | 3회
작은따옴표 문자열을 큰따옴표로 변환 | 3회
후행 쉼표 제거 | 1회
Python/대문자 불리언을 JSON 형식으로 변환 | 1회
문자열 안의 줄바꿈을 \n 으로 변환 | 1회
닫히지 않은 괄호를 닫음 | 3회

이 도구로 할 수 있는 일

로그에서 복사한 JSON, ChatGPT 같은 AI가 만든 JSON, Python 딕셔너리 출력, 길이 제한으로 끝이 잘린 응답 등은 JSON.parse로 읽을 수 없는 경우가 많습니다. 이 도구는 느슨한 파서로 구조를 읽어 낸 뒤 표준 JSON으로 다시 써 줍니다.

  • 주석(//, /* */, #) 제거, 후행 쉼표 제거, 빠진 쉼표·콜론 채우기
  • 작은따옴표·스마트 따옴표 문자열과 따옴표 없는 키·값을 큰따옴표로 변환
  • True/False/None, undefined, NaN, Infinity, 16진수 숫자를 JSON 값으로 변환
  • 닫히지 않은 괄호와 문자열을 닫고, ```json 코드 블록이나 앞뒤 설명 문장은 제거

수정한 항목이 표로 정리되므로, 의도와 다르게 고쳐진 부분이 없는지 확인한 뒤 사용하세요.

💡 Tips

  • AI가 만든 응답에서 코드 블록(```)과 앞뒤 설명을 한 번에 걷어낼 수 있습니다.
  • 끝이 잘린 JSON은 마지막 값이 불완전할 수 있으니 복구 결과의 끝부분을 꼭 확인하세요.
  • 복구된 결과를 입력으로 되돌리는 버튼으로 다른 옵션(들여쓰기 등)을 이어서 적용할 수 있습니다.

자주 묻는 질문

복구하면 데이터가 바뀌지는 않나요?

문법만 고칩니다. 다만 잘린 문자열을 닫거나 값이 빠진 키를 null로 채우는 등 추정이 필요한 수정은 수정 내역에 모두 표시되니 확인해 주세요.

중복된 키는 어떻게 처리되나요?

같은 객체에 같은 키가 여러 번 있으면 JSON.parse와 같이 마지막 값만 남기고, 수정 내역에 알려 드립니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
