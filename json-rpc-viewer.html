JSON-RPC 2.0 메시지 뷰어 · 검증기

요청, 알림, 성공 응답, 오류 응답, 배치를 종류별로 분류하고 id 로 요청과 응답을 짝지어 줍니다. jsonrpc 버전 누락, 응답이 없는 요청, result 와 error 동시 존재 같은 규격 위반과 -32700 · -32601 같은 표준 오류 코드를 설명합니다.

사용 예시

🔍 메시지 7개 중 확인할 항목 1개

입력 — JSON-RPC 메시지 (객체, 배열(배치), 또는 줄마다 하나)

[
  {"jsonrpc":"2.0","method":"subtract","params":{"minuend":42,"subtrahend":23},"id":1},
  {"jsonrpc":"2.0","method":"notify_hello","params":[7]},
  {"jsonrpc":"2.0","result":19,"id":1},
  {"jsonrpc":"2.0","method":"foo.get","params":{"name":"x"},"id":"abc"},
  {"jsonrpc":"2.0","error":{"code":-32601,"message":"Method not found"},"id":"abc"},
  {"method":"legacy","id":3},
  {"jsonrpc":"2.0","method":"ping","id":4}
]

결과 — 메시지

위치 | 상태 | 종류 | 내용 | 문제
배치 1 | ✅ | 요청 | subtract({"minuend":42,"subtrahend":23}) | 
배치 2 | ✅ | 알림(Notification) | notify_hello(7) | 
배치 3 | ✅ | 성공 응답 | 19 | 
배치 4 | ✅ | 요청 | foo.get({"name":"x"}) | 
배치 5 | ✅ | 오류 응답 | -32601 Method not found — Method not found | 
배치 6 | ⚠️ | 요청 | legacy() | jsonrpc: "2.0" 이 없습니다 (JSON-RPC 1.0 이거나 오류)
배치 7 | ✅ | 요청 | ping() |

결과 — 요청 ↔ 응답 짝

id | 메서드 | 요청 | 응답 | 상태
1 | subtract | 배치 1 | 배치 3 | ✅
"abc" | foo.get | 배치 4 | 배치 5 | ❌ 오류
3 | legacy | 배치 6 | — | ⏳ 응답 없음
4 | ping | 배치 7 | — | ⏳ 응답 없음

이 도구로 할 수 있는 일

이더리움 노드, LSP, MCP, 각종 RPC API 의 통신 로그를 읽기 쉽게 정리합니다. 입력은 브라우저에서만 처리됩니다.

  • 입력: 단일 객체, 배치 배열, 또는 한 줄에 하나씩(로그 형식)
  • 분류: request(id 있음), notification(id 없음), result 응답, error 응답
  • 짝 맞추기: id 로 요청 ↔ 응답 연결, 응답 없는 요청과 요청 없는 응답 표시, 중복 id
  • 검증: jsonrpc "2.0", method 문자열, params 는 배열 또는 객체, result 와 error 는 정확히 하나
  • 표준 오류 코드 설명: -32700 파싱 오류, -32600 잘못된 요청, -32601 메서드 없음, -32602 잘못된 파라미터, -32603 내부 오류, -32000~-32099 서버 오류

💡 Tips

  • 알림(notification)은 id 가 없어 서버가 응답하지 않습니다. 응답을 기대하면 id 를 넣으세요.
  • 배치 응답은 요청과 순서가 같지 않을 수 있으므로 id 로 짝지어야 합니다.
  • id 는 문자열, 숫자, null 이 가능하지만 null 은 권장되지 않습니다.

자주 묻는 질문

id 가 0 이어도 요청인가요?

네. 0 도 유효한 id 입니다. id 키가 아예 없을 때만 알림입니다.

HTTP 상태 코드와는 어떻게 다른가요?

JSON-RPC 는 전송 방식과 무관한 프로토콜이라 오류도 본문의 error 로 전달합니다. HTTP 로 쓸 때도 보통 상태는 200 입니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
