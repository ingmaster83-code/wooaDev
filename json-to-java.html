JSON → Java 클래스 변환기

API 응답 샘플로 Java 모델 클래스를 만들어 줍니다. POJO(getter/setter), record, Lombok @Data 중 선택할 수 있습니다.

사용 예시

✅ 클래스 2개를 만들었습니다 (샘플 2개 분석)

입력 — JSON 샘플 (API 응답 등)

[
  {
    "id": 1,
    "name": "Kim",
    "email": "kim@example.com",
    "is_active": true,
    "score": 4.5,
    "tags": ["admin", "dev"],
    "address": { "city": "Seoul", "zip": "04524" },
    "created_at": "2026-01-02T03:04:05Z"
  },
  {
    "id": 2,
    "name": "Lee",
    "is_active": false,
    "score": 3,
    "tags": [],
    "address": { "city": "Busan", "zip": null },
    "created_at": "2026-02-03T04:05:06Z",
    "nickname": null
  }
]

결과 — Java 코드

import com.fasterxml.jackson.annotation.JsonProperty;
import java.util.List;

public class Root {
    private Long id;
    private String name;
    private String email;
    @JsonProperty("is_active")
    private Boolean isActive;
    private Double score;
    private List<String> tags;
    private Address address;
    @JsonProperty("created_at")
    private String createdAt;
    private Object nickname;

    public Long getId() { return id; }
    public void setId(Long id) { this.id = id; }

    public String getName() { return name; }
    public void setName(String name) { this.name = name; }

    public String getEmail() { return email; }
    public void setEmail(String email) { this.email = email; }

    public Boolean getIsActive() { return isActive; }
    public void setIsActive(Boolean isActive) { this.isActive = isActive; }

    public Double getScore() { return score; }
    public void setScore(Double score) { this.score = score; }

    public List<String> getTags() { return tags; }
    public void setTags(List<String> tags) { this.tags = tags; }

    public Address getAddress() { return address; }
    public void setAddress(Address address) { this.address = address; }

    public String getCreatedAt() { return createdAt; }
    public void setCreatedAt(String createdAt) { this.createdAt = createdAt; }

    public Object getNickname() { return nickname; }

이 도구로 할 수 있는 일

Spring 등에서 JSON 요청·응답을 받으려면 DTO 클래스가 필요합니다. 샘플 JSON만 있으면 초안을 바로 만들 수 있습니다.

  • 스타일: POJO(private 필드 + getter/setter), record(Java 16+), Lombok @Data
  • snake_case 키는 camelCase 필드로 바꾸고 Jackson @JsonProperty("is_active")를 자동으로 붙임
  • 배열은 List<T>, 정수는 Long(또는 Integer), 실수는 Double, 불리언은 Boolean, 타입이 섞이면 Object
  • 중첩 객체는 별도 클래스로 분리하고, 같은 구조는 재사용
  • 예약어(class, new 등)는 이름 뒤에 _를 붙여 컴파일 오류 방지

여러 응답 샘플을 이어 붙이면 필드 타입을 더 정확히 추론합니다.

💡 Tips

  • Jackson을 쓰지 않는다면 @JsonProperty 옵션을 끄고 필드 이름만 사용하세요.
  • record는 불변 DTO에 적합하고, 직렬화 라이브러리가 record를 지원하는 버전인지 확인하세요 (Jackson 2.12+).
  • package를 입력하면 파일 맨 위에 선언이 붙습니다.

자주 묻는 질문

Boolean 필드의 getter 이름은 isXxx가 아닌가요?

래퍼 타입(Boolean)의 getter는 JavaBeans 규칙상 getXxx를 사용합니다. 기본형 boolean이 필요하면 생성 후 타입만 바꿔 isXxx로 수정하세요.

null이나 누락 필드는 어떻게 되나요?

Java 참조 타입은 null이 가능하므로 별도 처리 없이 래퍼 타입으로 생성합니다. 값이 없을 때 기본값이 필요하면 직접 초기화하세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
