Chmod 계산기

파일 권한을 체크박스로 설정하거나 8진수를 직접 입력하세요. 심볼릭 표기와 chmod 명령이 자동 생성됩니다.

빠른 프리셋
8진수 직접 입력
권한 체크박스
구분 읽기 (r=4) 쓰기 (w=2) 실행 (x=1) 값
Owner (소유자) 0
Group (그룹) 0
Others (기타) 0
결과
8진수
000
심볼릭
----------
명령어
chmod 000 filename

이 포스팅은 쿠팡 파트너스 활동의 일환으로,
이에 따른 일정액의 수수료를 제공받습니다.

자주 묻는 질문

chmod 755와 chmod 644의 차이는 무엇인가요?

755는 소유자 읽기/쓰기/실행, 그룹·기타 읽기/실행 권한입니다. 644는 소유자 읽기/쓰기, 그룹·기타 읽기만 허용합니다.

실행 파일 권한은 어떻게 설정하나요?

실행 권한은 숫자 1 또는 기호 x에 해당합니다. 예: 755(rwxr-xr-x)로 설정하면 소유자와 그룹·기타 사용자 모두 실행 가능합니다.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.

💡 Tips

  • Linux/Unix 파일 권한을 숫자(755)↔기호(rwxr-xr-x) 형식으로 변환합니다.
  • chmod 755는 소유자 전체 권한, 그룹·기타 읽기·실행 권한입니다.
  • 웹 서버 파일은 644(파일) / 755(디렉토리)가 일반적입니다.
