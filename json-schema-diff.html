JSON 스키마 비교 도구 — 변경 사항과 호환성 위험도

두 JSON Schema를 비교해 속성 추가·삭제, 필수 여부, 타입, enum, 제약 변경을 찾고 요청/응답 관점에서 호환성이 깨지는지 알려 줍니다.

사용 예시

⚠️ 호환성 깨짐 4 · 주의 0 · 안전 1

입력 — 이전 스키마 (A)

{
  "type": "object",
  "required": ["id", "name"],
  "properties": {
    "id": { "type": "integer" },
    "name": { "type": "string", "maxLength": 50 },
    "status": { "enum": ["active", "inactive"] },
    "age": { "type": "integer", "minimum": 0 }
  }
}

입력 — 새 스키마 (B)

{
  "type": "object",
  "required": ["id", "name", "email"],
  "properties": {
    "id": { "type": "string" },
    "name": { "type": "string", "maxLength": 30 },
    "email": { "type": "string", "format": "email" },
    "status": { "enum": ["active", "inactive", "banned"] },
    "age": { "type": "integer", "minimum": 18 }
  }
}

결과 — 변경과 위험도

위험도 | 경로 | 변경 내용 | 이전 | 이후
🔴 호환성 깨짐 | id | 타입 변경 | integer | string
🔴 호환성 깨짐 | name | maxLength 제한이 엄격해짐 | 50 | 30
🔴 호환성 깨짐 | age | minimum 제한이 엄격해짐 | 0 | 18
🔴 호환성 깨짐 | email | 필수 속성이 추가됨 |  | string
🟢 안전 | status | enum 값 추가 |  | banned

이 도구로 할 수 있는 일

API 스키마를 바꿀 때 가장 두려운 것은 기존 클라이언트가 갑자기 깨지는 것입니다. 두 버전의 스키마를 넣으면 무엇이 어떻게 바뀌었고 그 변경이 위험한지 알려 줍니다.

  • 속성 추가/삭제, 필수 ↔ 선택, 타입 변경(넓어짐/좁아짐), enum 값 추가/제거
  • 제약 변경: minimum·maximum, minLength·maxLength, pattern, format, minItems·maxItems, additionalProperties 등
  • 스키마의 용도를 선택: 요청(클라이언트가 보내는 데이터) 또는 응답(클라이언트가 받는 데이터)에 따라 같은 변경도 위험도가 달라짐
  • 🔴 호환성 깨짐 / 🟡 주의 / 🟢 안전으로 구분해 위험한 순서로 정렬
  • $ref, allOf를 펼쳐 비교, oneOf/anyOf 변경은 직접 확인하도록 표시

단순 값 비교는 JSON 비교 도구를 사용하세요.

💡 Tips

  • 요청 스키마는 "필수 속성 추가"나 "제약 강화"가, 응답 스키마는 "필수 속성 제거"나 "타입 변경"이 가장 위험합니다.
  • enum 값을 추가하면 요청 스키마에는 안전하지만 응답 스키마에서는 클라이언트가 처리하지 못할 수 있어 주의로 표시됩니다.
  • 결과는 휴리스틱입니다. 릴리스 전 계약 테스트와 함께 사용하세요.

자주 묻는 질문

요청과 응답에서 위험도가 다른 이유가 무엇인가요?

요청 스키마가 엄격해지면 기존 클라이언트가 보내던 데이터가 거부될 수 있고, 응답 스키마가 느슨해지면 클라이언트가 예상하지 못한 데이터를 받을 수 있기 때문에 반대 방향으로 위험이 생깁니다.

OpenAPI 문서를 바로 비교할 수 있나요?

OpenAPI 전체가 아니라 비교할 스키마 조각(components.schemas.X의 내용)을 각각 붙여 넣으세요. 내부 $ref는 해당 조각 안에서만 해석됩니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
