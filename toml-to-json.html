TOML → JSON 변환기

TOML 설정 파일을 JSON으로 바꿉니다. 날짜·시간은 ISO 문자열로, 큰 정수는 정밀도 손실 없이 변환합니다.

사용 예시

✅ 변환 완료 — 키 15개, 최대 깊이 4

입력 — TOML 입력

# This is a TOML document
title = "TOML Example"

[owner]
name = "Kim"
dob = 1979-05-27T07:32:00-08:00

[database]
enabled = true
ports = [ 8000, 8001, 8002 ]
temp_targets = { cpu = 79.5, case = 72.0 }

[[servers]]
name = "alpha"
ip = "10.0.0.1"

[[servers]]
name = "beta"
ip = "10.0.0.2"

결과 — JSON 결과

{
  "title": "TOML Example",
  "owner": {
    "name": "Kim",
    "dob": "1979-05-27T07:32:00.000-08:00"
  },
  "database": {
    "enabled": true,
    "ports": [
      8000,
      8001,
      8002
    ],
    "temp_targets": {
      "cpu": 79.5,
      "case": 72
    }
  },
  "servers": [
    {
      "name": "alpha",
      "ip": "10.0.0.1"
    },
    {
      "name": "beta",
      "ip": "10.0.0.2"
    }
  ]
}

이 도구로 할 수 있는 일

TOML로 작성된 설정(pyproject.toml, Cargo.toml, netlify.toml 등)을 스크립트나 API에서 쓰려면 JSON이 가장 다루기 쉽습니다.

  • TOML 1.0 전체 문법: 테이블, 인라인 테이블, 테이블 배열, 다중행 문자열, 날짜·시간
  • 날짜/시간 값은 ISO 8601 문자열로 변환
  • 9007199254740993처럼 JavaScript 숫자로는 표현이 깨지는 큰 정수도 원래 자릿수 그대로 출력
  • 문법 오류가 있으면 줄·열 위치와 원인을 표시

JSON을 TOML로 만들려면 JSON → TOML 변환기를 사용하세요.

💡 Tips

  • 변환 전후 값이 같은지 확인하려면 키 정렬 옵션으로 양쪽을 같은 순서로 맞춰 비교하세요.
  • TOML의 주석은 JSON에 담을 수 없어 결과에서 사라집니다.
  • inf, nan 같은 특수 부동소수점은 JSON에서 표현할 수 없어 null로 출력될 수 있습니다.

자주 묻는 질문

TOML의 날짜는 JSON에서 어떻게 표현되나요?

JSON에는 날짜 타입이 없어 ISO 8601 문자열로 바뀝니다. 날짜만(2024-01-02), 시간만(03:04:05), 오프셋 포함 날짜시간 모두 원래 형식을 따릅니다.

매우 큰 정수도 변환되나요?

네. 2^53을 넘는 정수는 BigInt로 읽어 JSON 숫자 그대로 출력합니다. 다만 이후 JavaScript의 JSON.parse로 읽으면 정밀도가 손실될 수 있다는 점에 유의하세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
