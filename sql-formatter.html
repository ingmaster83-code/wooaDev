어떤 SQL 방언을 지원하나요?

MySQL, PostgreSQL, SQLite, Oracle, SQL Server 등 주요 SQL 방언을 지원합니다.

압축된 SQL을 포맷하면 어떤 점이 좋나요?

들여쓰기와 줄바꿈이 적용되어 쿼리 구조를 쉽게 파악하고 디버깅할 수 있습니다.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
