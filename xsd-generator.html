XML 샘플 → XSD 스키마 생성기

XML 샘플을 넣으면 요소 계층, 자식 순서(sequence/choice/all), minOccurs·maxOccurs, 속성의 필수 여부, 값에서 추론한 타입(정수·소수·날짜·불리언·URI)과 enumeration 을 담은 XSD 를 만들어 줍니다. 중첩형과 이름 있는 타입 스타일을 고를 수 있습니다.

사용 예시

✅ 요소 7종에서 XSD 를 만들었습니다

입력 — XML 샘플 (같은 요소가 여러 번 나올수록 정확합니다)

<?xml version="1.0"?>
<catalog>
  <book id="b1" lang="en" inStock="true">
    <title>XML Basics</title>
    <author>Kim</author>
    <price currency="USD">29.99</price>
    <pages>320</pages>
    <published>2024-03-01</published>
  </book>
  <book id="b2" lang="ko" inStock="false">
    <title>XPath 입문</title>
    <author>Lee</author>
    <author>Park</author>
    <price currency="KRW">18000</price>
    <pages>256</pages>
  </book>
  <book id="b3" lang="en" inStock="true">
    <title>Advanced XSLT</title>
    <author>Kim</author>
    <price currency="USD">45.00</price>
    <pages>512</pages>
    <published>2023-11-20</published>
  </book>
</catalog>

결과 — 생성된 XSD

<?xml version="1.0" encoding="UTF-8"?>
<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema" elementFormDefault="qualified">
  <xs:element name="catalog">
    <xs:complexType>
      <xs:sequence>
        <xs:element name="book" maxOccurs="unbounded">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="title" type="xs:string"/>
              <xs:element name="author" type="xs:string" maxOccurs="unbounded"/>
              <xs:element name="price">
                <xs:complexType>
                  <xs:simpleContent>
                    <xs:extension base="xs:decimal">
                      <xs:attribute name="currency" use="required">
                        <xs:simpleType>
                          <xs:restriction base="xs:string">
                            <xs:enumeration value="USD"/>
                            <xs:enumeration value="KRW"/>
                          </xs:restriction>
                        </xs:simpleType>
                      </xs:attribute>
                    </xs:extension>
                  </xs:simpleContent>
                </xs:complexType>
              </xs:element>
              <xs:element name="pages" type="xs:int"/>
              <xs:element name="published" type="xs:date" minOccurs="0"/>
            </xs:sequence>
            <xs:attribute name="id" type="xs:string" use="required"/>
…

이 도구로 할 수 있는 일

연동 문서의 스키마가 없을 때 샘플 XML 로 초안을 만들고 검증 도구로 확인합니다. 데이터는 브라우저 밖으로 나가지 않습니다.

  • 구조 추론: 같은 경로의 요소를 모아 자식 순서가 일관되면 xs:sequence, 순서가 다르면 xs:all, 섞여 나오면 무제한 xs:choice
  • 출현 횟수: 모든 부모에 있으면 필수, 없는 경우가 있으면 minOccurs=0, 여러 번 나오면 maxOccurs=unbounded
  • 타입 추론: boolean, int/long/integer, decimal, date, dateTime, time, anyURI, 그 외 string / 텍스트+속성 요소는 simpleContent 확장
  • 속성: 모든 인스턴스에 있으면 use=required, 값이 몇 가지로 반복되면 enumeration
  • 스타일: 중첩형(Russian Doll), 이름 있는 타입(Venetian Blind), xs/xsd 접두사, 들여쓰기

💡 Tips

  • 같은 요소가 여러 번 나오는 샘플일수록 minOccurs/maxOccurs 가 정확해집니다.
  • 생성된 XSD 는 "XSD 검증" 도구에서 원본 XML 을 검증해 왕복 확인할 수 있습니다.
  • 추론은 샘플에 보이는 값만 기준이므로 날짜·숫자 타입과 enumeration 은 사람이 검토해 다듬으세요.

자주 묻는 질문

완벽한 스키마를 만들어 주나요?

아니요. 샘플에서 추론한 초안입니다. 보이지 않은 변형(선택 요소, 다른 값)은 반영되지 않으니 검토가 필요합니다.

여러 XML 샘플을 합칠 수 있나요?

한 문서 안에서 반복되는 요소를 합쳐 추론합니다. 여러 파일은 공통 루트 아래에 모아 하나의 샘플로 만들어 넣으세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
