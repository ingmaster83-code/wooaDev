DNS 레코드 조회 (DoH)

도메인이나 IP 를 입력하면 Cloudflare 또는 Google 의 DoH 리졸버로 A·AAAA·CNAME·MX·TXT·NS·SOA·CAA 같은 레코드를 조회합니다. TTL, RCODE, DNSSEC(AD) 플래그와 원본 JSON 을 보여 주고 두 리졸버의 응답을 비교할 수도 있습니다.

사용 예시

✅ 1건 조회 · 응답 레코드 2개

입력 — 도메인 또는 IP (한 줄에 하나, 최대 5개)

example.com

결과 — 응답 레코드

이름 | 유형 | TTL(초) | 값 | 리졸버
example.com. | A | 300 | 93.184.216.34 | cloudflare
example.com. | A | 300 | 93.184.216.35 | cloudflare

결과 — 응답 상태

조회 | 유형 | 리졸버 | RCODE | 플래그 | 응답 | 권한 | 설명
example.com | A | cloudflare | NOERROR | RA RD | 2 | 0 | 정상

이 도구로 할 수 있는 일

dig 없이 브라우저에서 DNS 를 확인합니다. 질의는 우아하우스가 아니라 선택한 공개 DoH 리졸버로 직접 갑니다.

  • 유형: A, AAAA, CNAME, MX, TXT, NS, SOA, CAA, SRV, PTR, DS, DNSKEY, HTTPS, SVCB, TLSA, NAPTR, 주요 유형 일괄
  • 리졸버: Cloudflare(1.1.1.1), Google(8.8.8.8), 두 곳 비교(응답이 다르면 알림)
  • 응답: 이름·유형·TTL·값 표, RCODE(NXDOMAIN, SERVFAIL 등)와 AD/RD/RA 플래그, 원본 JSON
  • DNSSEC: DO 비트 요청, 검증 끄기(CD), AD 플래그 확인
  • IP 입력은 자동으로 in-addr.arpa / ip6.arpa 의 PTR 역조회로 처리

💡 Tips

  • SERVFAIL 이 나오면 'DNSSEC 검증 끄기'로 다시 조회해 서명 문제인지 리졸버 문제인지 구분해 보세요.
  • TXT 가 여러 문자열로 나뉘어 있으면 하나로 이어 붙여 보여 줍니다. SPF·DKIM 확인에 편합니다.
  • DNS 변경 직후에는 캐시 때문에 두 리졸버의 결과가 다를 수 있습니다. TTL 만큼 기다린 뒤 다시 확인하세요.

자주 묻는 질문

dig 와 결과가 다른 이유는요?

dig 는 로컬 리졸버를 쓰지만 이 도구는 공개 DoH 리졸버를 씁니다. 캐시와 지역별 응답이 달라 결과가 다를 수 있습니다.

조회가 실패하면 어떻게 하나요?

회사망이나 확장 프로그램이 DoH 도메인을 막으면 실패할 수 있습니다. 다른 리졸버를 고르거나 네트워크 정책을 확인하세요.

조회한 도메인이 서버로 전송되나요?

이 도구는 우아하우스 서버가 아니라 선택한 공개 DoH 리졸버(Cloudflare 또는 Google)에 브라우저가 직접 질의합니다. 조회한 도메인 이름은 해당 리졸버로 전달되므로 비공개 사내 도메인은 입력하지 마세요. 우아하우스는 입력값을 저장하지 않습니다.
