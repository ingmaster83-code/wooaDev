자주 묻는 질문

어떤 프로그래밍 언어를 지원하나요?

JavaScript, TypeScript, Python, HTML, CSS, JSON, Bash 등 주요 언어의 문법 강조를 지원합니다.

다운로드한 이미지를 어디에 쓸 수 있나요?

트위터·인스타그램 등 SNS 공유, 블로그 포스트, 발표자료(PPT) 삽입 등 코드를 시각적으로 보여줄 때 자유롭게 사용할 수 있습니다.

입력한 코드가 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 코드는 서버로 전송되지 않습니다.
