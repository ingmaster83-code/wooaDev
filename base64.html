Base64 인코더/디코더

텍스트 또는 파일을 Base64로 인코딩하거나, Base64 문자열을 원본으로 디코딩합니다.

출력

함께 쓰면 좋은 도구

🔗URL 인코더 🖼️이미지 → Base64 🔤HTML Entity 인코더 🔷JSON → TypeScript

💡 Tips

  • 텍스트를 Base64로 인코딩하거나 디코딩합니다.
  • URL Safe 옵션은 +/를 -_로 대체해 URL에서도 안전합니다.
  • 이미지 Base64 변환은 ImageKit의 이미지→Base64 도구를 사용하세요.

자주 묻는 질문

인코딩과 디코딩의 차이는 무엇인가요?

인코딩은 텍스트 → Base64 변환, 디코딩은 Base64 → 원래 텍스트 복원입니다.

URL Safe Base64란 무엇인가요?

+와 /를 -와 _로 대체해 URL 경로나 쿼리 파라미터에 안전하게 사용할 수 있는 변형입니다.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 개인정보와 민감한 데이터가 외부로 유출될 걱정이 없으며, 기업 보안 환경에서도 안심하고 사용할 수 있습니다.
