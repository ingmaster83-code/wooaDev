GitHub Actions 표현식 평가기

if: 에 쓰는 표현식을 github, env, matrix, steps, needs 같은 컨텍스트 JSON 으로 직접 평가합니다. 부분식마다 값과 타입을 보여 주고 GitHub 규칙(대소문자 무시 비교, 숫자 강제 변환, falsy 값)을 그대로 따릅니다.

사용 예시

✅ 결과: true (boolean)

입력 — 표현식 (${{ … }} 로 감싸도 되고, ${{ }} 가 섞인 문장도 됩니다)

github.ref == 'refs/heads/main' && contains(github.event.head_commit.message, '[deploy]') && !cancelled()

입력 — 컨텍스트 (JSON: github, env, vars, steps, needs, matrix, inputs, runner, job, secrets …)

{
  "github": {
    "ref": "refs/heads/main",
    "event_name": "push",
    "actor": "octocat",
    "event": { "head_commit": { "message": "Fix bug [deploy]" }, "commits": [ { "message": "a" }, { "message": "b" } ] }
  },
  "env": { "NODE_ENV": "production" },
  "matrix": { "os": "ubuntu-latest", "node": 20 },
  "steps": { "build": { "outcome": "success", "outputs": { "version": "1.2.3" } } },
  "needs": { "test": { "result": "success" } }
}

부분식 | 값 | 타입
github.ref | "refs/heads/main" | string
github.ref == 'refs/heads/main' | true | boolean

이 도구로 할 수 있는 일

커밋해서 돌려 보지 않고도 if 조건이 참이 되는지 확인합니다. 입력은 브라우저 밖으로 나가지 않습니다.

  • 문법: 리터럴(null, 불리언, 숫자, 0x16진수, '문자열' 과 '' 이스케이프), 프로퍼티 .a.b, ['키'], 인덱스, 객체 필터 .*, ! < <= > >= == != && ||, 괄호
  • 함수: contains, startsWith, endsWith, format({0} 과 {{ }}), join, toJSON, fromJSON, hashFiles(자리표시자), success, failure, always, cancelled
  • 규칙: 문자열 비교는 대소문자 무시, 형이 다르면 숫자로 변환(null→0, true→1, ''→0, 숫자 아닌 문자열→NaN), NaN 비교는 거짓, && 와 || 는 피연산자 값을 반환
  • ${{ }} 가 섞인 문장도 각 조각을 평가해 이어 붙임, 컨텍스트 이름·함수 이름은 대소문자 무시
  • 부분식별 평가 표(값·타입), 잡 상태(success/failure/cancelled) 선택

💡 Tips

  • inputs.dry == 'false' 처럼 불리언과 문자열을 == 로 비교하면 둘 다 숫자로 바뀌어 예상과 다를 수 있습니다.
  • if: 에서 ${{ }} 뒤에 글자를 붙이면 전체가 문자열이 되어 항상 참입니다.
  • github.event.commits.*.message 처럼 .* 를 쓰면 배열 요소의 속성만 모아 join 으로 합칠 수 있습니다.

자주 묻는 질문

실제 러너와 결과가 다를 수 있나요?

컨텍스트 값은 직접 넣은 JSON 이라 실제 실행 때의 값과 다를 수 있습니다. 평가 규칙 자체는 GitHub 문서의 규칙을 따릅니다.

hashFiles 는 왜 값이 안 나오나요?

러너의 실제 파일이 필요해서 계산할 수 없습니다. 자리표시 문자열을 반환하고 안내를 표시합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
