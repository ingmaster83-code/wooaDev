2의 보수 계산기 — 정수의 이진 표현

정수나 비트열을 넣으면 2의 보수, 1의 보수, 부호-크기 표현과 16진수, 부호 있는/없는 해석을 4~64비트에서 보여 줍니다.

사용 예시

✅ 8비트 — 부호 있는 범위 -128 ~ 127, 부호 없는 범위 0 ~ 255

입력 — 정수 또는 이진수 (한 줄에 하나)

-42
127
-128
0b11010110
0xFFD6

결과 — 표현 방식별 결과

입력 | 부호 있는 값 | 2의 보수 (2진) | 16진수 | 1의 보수 | 부호-크기 | 부호 없는 해석
-42 | -42 | 1101 0110 | 0xD6 | 1101 0101 | 1010 1010 | 214
127 | 127 | 0111 1111 | 0x7F | 0111 1111 | 0111 1111 | 127
-128 | -128 | 1000 0000 | 0x80 | 표현 불가 | 표현 불가 | 128
0b11010110 | -42 | 1101 0110 | 0xD6 | 1101 0101 | 1010 1010 | 214
0xFFD6 | 8비트를 넘는 비트열 |  |  |  |  |

이 도구로 할 수 있는 일

컴퓨터는 음수를 대부분 2의 보수로 저장합니다. 교과서의 -42 → 1101 0110 변환을 손으로 하지 않아도 됩니다.

  • 정수 → 비트열: 선택한 폭(4~64비트)에서의 2의 보수, 1의 보수, 부호-크기 표현과 16진수
  • 비트열 → 정수: 0b…/0x… 입력을 부호 있는 값과 부호 없는 값 두 가지로 해석
  • 표현 가능한 범위(예: 8비트 -128 ~ 127, 0 ~ 255)를 표시하고 범위를 넘으면 안내
  • 가장 작은 음수(-128)는 1의 보수·부호-크기로 표현할 수 없다는 점도 표시
  • 비트 연산 계산기와 함께 쓰면 마스크 연산 확인에 편리

💡 Tips

  • 2의 보수 만드는 법: 모든 비트를 뒤집고(1의 보수) 1을 더합니다.
  • -1은 모든 비트가 1인 값입니다 (8비트에서 1111 1111, 0xFF).
  • 0과 1만 쓴 문자열을 10진수가 아니라 비트열로 읽으려면 "비트열" 옵션을 선택하세요.

자주 묻는 질문

왜 2의 보수를 쓰나요?

덧셈·뺄셈 회로를 부호와 무관하게 똑같이 쓸 수 있고, 0이 하나뿐이며(+0과 -0 구분 없음) 표현 범위를 하나 더 확보할 수 있기 때문입니다.

1의 보수와 부호-크기는 지금도 쓰이나요?

정수 표현으로는 거의 쓰이지 않지만 체크섬(인터넷 체크섬은 1의 보수 합)과 부동소수점의 부호 비트에서 개념이 남아 있습니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
