현대적인 ID 생성기 — Nano ID · KSUID · UUID v7 · TypeID

짧고 URL에 안전한 Nano ID, 시간순 정렬되는 KSUID·UUID v7·TypeID를 만들고, KSUID에서 생성 시각을 읽어 냅니다.

사용 예시

✅ 2개 분석

입력 — 디코딩할 KSUID (한 줄에 하나)

0ujtsYcgvSTl8PAuAdqWYSMnLOv
0ujsswThIGTUYm2K8FjOOfXtY1K

결과 — 분석 결과

KSUID | 생성 시각 (UTC) | Unix 초 | 페이로드 128비트 (hex)
0ujtsYcgvSTl8PAuAdqWYSMnLOv | 2017-10-10T04:00:47Z | 1507608047 | b5a1cd34b5f99d1154fb6853345c9735
0ujsswThIGTUYm2K8FjOOfXtY1K | 2017-10-10T03:52:37Z | 1507607557 | 67ad536455c1813d788f57ca54679412

이 도구로 할 수 있는 일

UUID v4는 36자로 길고 정렬되지 않습니다. 용도에 따라 더 나은 대안이 여럿 있습니다.

  • Nano ID: 기본 21자, A-Za-z0-9_- 64문자. 길이와 문자 집합을 바꿀 수 있고 충돌 확률을 가늠할 수 있게 엔트로피(비트)를 표시. 편향 없는 선택(rejection sampling)
  • KSUID: 4바이트 시각(초) + 16바이트 난수를 Base62 27자로 표현, 시간순 정렬. 생성과 해독 지원
  • UUID v7: 48비트 Unix 밀리초 시각 + 난수, 표준 UUID 형식 / TypeID: 접두어_Base32(UUIDv7), 예: user_01h455vb4pex5vsknk084sn02q
  • 모두 crypto.getRandomValues 기반이라 Math.random처럼 예측 가능하지 않음

💡 Tips

  • 짧은 공개 URL에는 Nano ID 10~12자면 충분한 경우가 많습니다. 엔트로피 표시로 충돌 위험을 확인하세요.
  • 헷갈리는 문자를 피하려면 문자 집합에서 0O1lI를 빼면 됩니다.
  • KSUID 시각은 초 단위, UUID v7·ULID는 밀리초 단위입니다.

자주 묻는 질문

Nano ID는 얼마나 안전한가요?

기본 21자·64문자면 약 126비트의 엔트로피로 UUID v4(122비트)와 비슷한 수준입니다. 길이나 문자 집합을 줄이면 엔트로피도 줄어드니 표시된 값을 확인하세요.

CUID2는 왜 없나요?

CUID2는 SHA-3 해시가 필요한 규격인데 브라우저 표준 API에 SHA-3가 없어 규격과 다른 결과가 나올 수 있어 제공하지 않습니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
