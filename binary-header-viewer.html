ELF · PE · Mach-O 헤더 뷰어

이 도구로 할 수 있는 일

readelf·dumpbin·otool 없이 브라우저에서 실행 파일 구조를 봅니다. 파일은 서버로 전송되지 않으며 실행되지도 않습니다.

  • ELF: 32/64비트, 엔디언, 종류, 머신, 프로그램 헤더, 섹션, NEEDED·SONAME·RUNPATH, 인터프리터
  • PE: PE32/PE32+, 컴파일 시각, 서브시스템, 섹션(권한·엔트로피), 데이터 디렉터리, 임포트·익스포트, PDB 경로, .NET·서명 여부
  • Mach-O: 단일·fat(universal), CPU, 파일 종류, 세그먼트·섹션, 로드 명령(dylib, rpath, UUID, 빌드 버전, 코드 서명)
  • 보안: PIE/ASLR, NX/DEP, RELRO, CFG, W^X 위반, 스택 실행, 패킹이 의심되는 높은 엔트로피
  • Java class 버전과 WebAssembly 섹션도 식별

💡 Tips

  • 헤더는 보통 처음 수 KB 안에 있습니다. 임포트와 섹션까지 보려면 파일 전체를 선택하는 것이 좋습니다.
  • 섹션의 엔트로피가 7.2 이상이면 압축·암호화(패킹)된 코드일 가능성이 있습니다.
  • Mach-O fat 파일은 아키텍처별 오프셋부터 잘라 넣으면 슬라이스의 상세 헤더를 볼 수 있습니다.

자주 묻는 질문

악성코드 분석에 쓸 수 있나요?

헤더 구조를 읽기만 하며 파일을 실행하지 않습니다. 다만 서명 검증이나 백신 판정은 하지 않으므로 보조 정보로만 쓰세요.

서명이 유효한지도 확인하나요?

서명 테이블이나 로드 명령의 존재만 알려 주고 유효성은 검증하지 않습니다. 검증은 signtool·codesign 을 사용하세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
