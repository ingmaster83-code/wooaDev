CSS Border Radius 생성기

슬라이더로 모서리 둥글기를 조절하고 CSS border-radius 코드를 바로 복사하세요. 단순·상세 모드, px·% 단위 지원.

💡 Tips

  • 단순 모드: 4개 모서리에 동일한 값을 한 번에 적용합니다.
  • 상세 모드: 각 모서리(TL, TR, BL, BR)를 개별 설정할 수 있습니다.
  • % 단위: 요소 크기에 비례한 비율로 적용. 50%로 설정하면 완전한 원/타원이 됩니다.
  • px 단위: 고정 픽셀 값. 해상도와 무관하게 일정한 둥글기를 유지합니다.
  • 4개 값이 모두 같으면 border-radius: 12px처럼 단일 값으로 출력됩니다.
4개 값을 각각 다르게 설정하면 어떻게 되나요?

CSS는 border-radius: TL TR BR BL 순서로 시계 방향으로 각 모서리를 지정합니다. 상세 모드에서 개별 설정 시 이 형식으로 코드가 생성됩니다.

50%로 설정하면 원이 되나요?

정사각형 요소에 border-radius: 50%를 적용하면 완전한 원이 됩니다. 직사각형에 적용하면 타원이 됩니다.

border-radius와 border-top-left-radius 차이는?

border-radius는 단축 속성(shorthand)으로 최대 4개 값을 한 번에 설정합니다. border-top-left-radius 등 개별 속성으로도 설정 가능하며, 이 도구는 단축 속성 형식의 코드를 생성합니다.
