💡 Tips

  • 단순 모드: 4개 모서리에 동일한 값을 한 번에 적용합니다.
  • 상세 모드: 각 모서리(TL, TR, BL, BR)를 개별 설정할 수 있습니다.
  • % 단위: 요소 크기에 비례한 비율로 적용. 50%로 설정하면 완전한 원/타원이 됩니다.
  • px 단위: 고정 픽셀 값. 해상도와 무관하게 일정한 둥글기를 유지합니다.
  • 4개 값이 모두 같으면 border-radius: 12px처럼 단일 값으로 출력됩니다.

자주 묻는 질문

px와 % 단위 중 어느 것을 써야 하나요?

px는 고정 값, %는 요소 크기에 비례해 적용됩니다. 반응형 디자인에는 % 또는 rem을 권장합니다.

border-radius를 원형으로 만들려면?

width와 height가 같은 요소에 border-radius: 50%를 적용하면 완전한 원이 됩니다.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
