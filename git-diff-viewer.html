Git diff 뷰어 — 패치를 읽기 쉽게

git diff, git show, .patch/.diff 파일 내용을 붙여 넣으면 파일별 추가·삭제 줄 수, 이름 변경·신규·삭제 여부를 요약하고 줄 번호가 붙은 색상 diff로 보여 줍니다.

사용 예시

✅ 3개 파일 · +4 −2

입력 — git diff / 패치 (unified diff)

diff --git a/src/app.js b/src/app.js
index 3b18e51..a9c2d4f 100644
--- a/src/app.js
+++ b/src/app.js
@@ -1,5 +1,7 @@
 const express = require('express');
+const helmet = require('helmet');
 const app = express();
-app.listen(3000);
+app.use(helmet());
+app.listen(process.env.PORT || 3000);
 
 module.exports = app;
diff --git a/old-name.txt b/docs/new-name.txt
similarity index 92%
rename from old-name.txt
rename to docs/new-name.txt
index 1111111..2222222 100644
--- a/old-name.txt
+++ b/docs/new-name.txt
@@ -1,2 +1,2 @@
 hello
-world
+WooaDev
diff --git a/logo.png b/logo.png
new file mode 100644
Binary files /dev/null and b/logo.png differ

결과 — 파일별 요약

파일 | 상태 | 추가 | 삭제 | 헝크
src/app.js | M 수정 | +3 | −1 | 1
old-name.txt → docs/new-name.txt | R 이름 변경 (92%) | +1 | −1 | 1
logo.png | A 추가 | 바이너리 |  | 0

이 도구로 할 수 있는 일

이메일이나 PR 설명에 붙은 긴 패치를 열어 볼 편한 도구가 없을 때 쓰세요. 입력한 패치는 브라우저에서만 처리됩니다.

  • 파일별 요약: 상태(수정/추가/삭제/이름 변경 %/권한 변경/바이너리), 추가·삭제 줄 수, 헝크 수
  • 변경 내용: 원본·수정본 줄 번호가 붙은 색상 diff, 변경된 줄만 보기, 파일 이름 필터
  • git diff --stat 과 같은 형식의 요약 출력
  • 헝크 헤더의 줄 수와 실제 줄 수가 다르면(패치가 잘렸거나 수정됨) 경고
  • .env·키·credentials 같은 비밀 파일 포함, 줄 끝 공백, 1,000줄이 넘는 큰 변경을 경고

💡 Tips

  • git diff 대신 git diff --no-color 로 복사하세요. 색상 코드가 섞이면 해석이 어려워집니다.
  • 큰 PR은 파일 이름 필터로 관심 있는 부분만 먼저 보세요.
  • 패치를 적용하기 전에는 git apply --check 로 충돌 여부를 확인할 수 있습니다.

자주 묻는 질문

두 파일 내용을 직접 비교할 수도 있나요?

이 도구는 이미 만들어진 diff를 읽는 용도입니다. 두 텍스트를 직접 비교하려면 diff 뷰어 도구를 쓰세요.

바이너리 파일 변경은 어떻게 보이나요?

내용은 표시되지 않고 파일 목록에 '바이너리'로 나타납니다. 크기 변화는 git diff --stat 로 확인하세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
