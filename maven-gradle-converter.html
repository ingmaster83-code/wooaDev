Maven ↔ Gradle 의존성 변환기

pom.xml 의 <dependency> 블록을 Gradle Groovy·Kotlin DSL 로, Gradle 의 implementation "그룹:아티팩트:버전" 선언을 Maven XML 로 바꿉니다. scope 를 구성(configuration)으로 매핑하고 변환이 불가능한 부분은 알려 줍니다.

사용 예시

✅ 의존성 3개를 Gradle(Groovy) 로 변환

입력 — Maven <dependency> 또는 Gradle 의존성 선언

<dependency>
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-starter-web</artifactId>
  <version>3.3.4</version>
</dependency>
<dependency>
  <groupId>org.projectlombok</groupId>
  <artifactId>lombok</artifactId>
  <version>1.18.34</version>
  <scope>provided</scope>
</dependency>
<dependency>
  <groupId>org.junit.jupiter</groupId>
  <artifactId>junit-jupiter</artifactId>
  <version>5.10.3</version>
  <scope>test</scope>
</dependency>

결과 — 변환 결과

dependencies {
    implementation 'org.springframework.boot:spring-boot-starter-web:3.3.4'
    compileOnly 'org.projectlombok:lombok:1.18.34'
    testImplementation 'org.junit.jupiter:junit-jupiter:5.10.3'
}

결과 — 의존성

groupId | artifactId | 버전 | 범위/구성
org.springframework.boot | spring-boot-starter-web | 3.3.4 | compile → implementation
org.projectlombok | lombok | 1.18.34 | provided → compileOnly
org.junit.jupiter | junit-jupiter | 5.10.3 | test → testImplementation

이 도구로 할 수 있는 일

프로젝트를 Maven 에서 Gradle(또는 반대)로 옮길 때 의존성 선언을 한꺼번에 변환합니다. 입력은 브라우저에서만 처리됩니다.

  • 입력 자동 판별: Maven <dependency> XML 또는 Gradle 선언("g:a:v", group:/name:/version: 맵 형식)
  • scope 매핑: compile → implementation, provided → compileOnly, runtime → runtimeOnly, test → testImplementation
  • classifier, type(@aar 등), exclusions, optional 처리
  • 출력: Gradle Groovy, Gradle Kotlin, Maven XML 중 선택
  • 변환이 정확하지 않은 부분(버전 변수 ${…}, BOM, import scope)을 안내

💡 Tips

  • Maven 의 compile 은 Gradle 에서 api 가 아니라 implementation 이 일반적입니다. 라이브러리 API 에 노출될 때만 api 를 쓰세요.
  • 버전이 ${spring.version} 처럼 속성이면 Gradle 의 extra 속성이나 version catalog 로 옮겨야 합니다.
  • Spring Boot 같은 BOM 은 Gradle 의 platform() 으로 바꿉니다.

자주 묻는 질문

import scope 의존성은 어떻게 되나요?

dependencyManagement 의 import 는 Gradle 의 platform("g:a:v") 로 표현해야 하므로 변환 대상에서 안내만 표시합니다.

전체 pom.xml 을 넣어도 되나요?

<dependency> 블록만 추출해 처리하지만, 부모 POM·플러그인·프로파일은 변환하지 않습니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
