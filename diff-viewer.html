💡 Tips

  • 두 텍스트(코드, 문서 등)를 줄 단위로 비교합니다.
  • 추가된 줄은 녹색, 삭제된 줄은 빨간색으로 표시됩니다.
  • Pull Request 리뷰나 문서 변경 이력 확인에 유용합니다.

자주 묻는 질문

어떤 형식의 텍스트를 비교할 수 있나요?

코드, 문서, JSON 등 모든 텍스트 형식을 줄 단위로 비교할 수 있습니다.

색상 표시 의미는 무엇인가요?

녹색은 추가된 줄, 빨간색은 삭제된 줄입니다. Pull Request 리뷰나 문서 변경 이력 확인에 유용합니다.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 개인정보와 민감한 데이터가 외부로 유출될 걱정이 없으며, 기업 보안 환경에서도 안심하고 사용할 수 있습니다.
