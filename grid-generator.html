💡 Tips

  • fr 단위: 남은 공간을 비율로 나눕니다. 1fr 2fr은 1:2 비율로 분할.
  • repeat(): Column Template에 repeat(3, 1fr) 형식도 사용 가능합니다.
  • justify-items: 각 셀 내에서 아이템을 수평 정렬합니다.
  • align-items: 각 셀 내에서 아이템을 수직 정렬합니다.

자주 묻는 질문

복잡한 grid-template-areas도 생성할 수 있나요?

네. 시각적으로 영역을 나눠 grid-template-areas 코드를 자동 생성합니다.

반응형 그리드(auto-fill, auto-fit)도 지원하나요?

네. 반응형 옵션을 선택하면 auto-fill, auto-fit 코드가 생성됩니다.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
