이 도구로 할 수 있는 일

단순 치환 암호는 보안용이 아니라 스포일러 가리기, 퍼즐, CTF 입문, 이스터에그에 쓰입니다. 대표적인 방식을 한 번에 다룹니다.

  • ROT13: 알파벳 13칸 이동(같은 연산으로 암호화=복호화). ROT47: 출력 가능한 ASCII 94자 전체를 이동
  • ROT5: 숫자만, ROT18: ROT13+ROT5
  • 시저 암호: 1–25칸 이동으로 암호화/복호화, "25가지 전체 보기"로 이동값을 모를 때 해독
  • 아트배시: 알파벳을 뒤집어 대응(A↔Z)
  • 모스 부호: 영문·숫자·기호 인코딩과 디코딩 (단어 구분은 /)

이런 방식은 암호학적으로 안전하지 않으므로 비밀 보호에는 쓰지 마세요.

💡 Tips

  • 이동값을 모르는 시저 암호는 "25가지 전체 보기"에서 읽히는 줄을 찾으면 됩니다.
  • 모스 부호 디코딩에서는 글자 사이를 공백, 단어 사이를 / 또는 공백 3칸으로 구분하세요.
  • ROT13은 두 번 적용하면 원문으로 돌아옵니다.

자주 묻는 질문

ROT13은 안전한 암호인가요?

아니요. 누구나 즉시 풀 수 있는 가벼운 가림용입니다. 민감한 정보는 AES 같은 현대 암호를 쓰세요.

한글도 변환되나요?

ROT13·시저·아트배시는 영문 알파벳만, ROT5는 숫자만 바꾸고 한글은 그대로 둡니다. ROT47은 ASCII 기호까지 바꾸고 한글은 유지합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
