MAC 주소 검증 · 변환기

MAC 주소를 콜론·하이픈·Cisco 점 표기로 바꾸고, 유효성·유니캐스트/멀티캐스트·로컬 관리 여부와 EUI-64 링크 로컬 IPv6 주소를 알려 줍니다.

사용 예시

✅ 5개 변환, 1개 오류

입력 — MAC 주소 (한 줄에 하나)

00:1A:2B:3C:4D:5E
3c-22-fb-12-34-56
001a.2b3c.4d5e
FF:FF:FF:FF:FF:FF
02:42:ac:11:00:02
zz:00:11:22:33:44

결과 — 검증·변환 결과

3c-22-fb-12-34-56 | 3C:22:FB:12:34:56 | 유니캐스트 · 범용 관리(UAA) — 제조사 할당 | OUI 3C-22-FB | fe80::3e22:fbff:fe12:3456

이 도구로 할 수 있는 일

장비마다 MAC 주소 표기법이 달라 복사해서 붙여 넣을 때마다 형식을 고쳐야 합니다. Linux/Windows는 콜론·하이픈, Cisco는 점으로 쓰기 때문입니다.

  • 입력: 00:1A:2B:3C:4D:5E, 00-1a-2b-3c-4d-5e, 001a.2b3c.4d5e, 001A2B3C4D5E, 0x1a2b3c4d5e
  • 출력 형식 선택(콜론/하이픈/Cisco/구분자 없음)과 대소문자 선택, 여러 줄 한꺼번에 처리
  • 첫 바이트 비트로 유니캐스트/멀티캐스트와 범용(UAA)/로컬(LAA) 관리 주소를 판별 — 가상 머신·컨테이너·무작위 MAC은 LAA
  • 앞 3바이트 OUI(제조사 식별자)와 EUI-64 방식으로 만든 링크 로컬 IPv6(fe80::) 주소 계산
  • 브로드캐스트(FF:FF:FF:FF:FF:FF)와 모두 0 주소 구분

💡 Tips

  • 스마트폰의 "비공개 Wi-Fi 주소"는 무작위 LAA MAC을 씁니다. 2번째 16진수 자리가 2·6·A·E이면 LAA입니다.
  • 제조사 이름 조회는 최신 IEEE OUI 목록이 필요해 이 도구에서는 OUI 값만 보여 줍니다.
  • Docker 기본 MAC은 02:42:로 시작합니다.

자주 묻는 질문

LAA와 UAA는 무엇인가요?

첫 바이트의 두 번째 비트가 0이면 제조사가 부여한 범용 관리 주소(UAA), 1이면 소프트웨어나 관리자가 임의로 지정한 로컬 관리 주소(LAA)입니다.

EUI-64 링크 로컬 주소는 어떻게 만드나요?

MAC 가운데에 FF:FE를 끼워 넣고 첫 바이트의 U/L 비트를 뒤집은 64비트 값을 fe80::/64 뒤에 붙입니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
