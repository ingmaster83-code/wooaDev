JSON → XML 변환기

JSON 객체를 XML 요소로 바꿉니다. 속성(@), 텍스트(#text), 배열 반복, 특수문자 이스케이프를 지원합니다.

사용 예시

✅ 변환 완료

입력 — JSON 입력

{
  "order": {
    "@id": "A-1024",
    "customer": "Kim & Co.",
    "items": [
      { "sku": "P-1", "qty": 2, "price": 9.5 },
      { "sku": "P-2", "qty": 1, "price": 20 }
    ],
    "note": null,
    "paid": true
  }
}

결과 — XML 결과

<?xml version="1.0" encoding="UTF-8"?>
<order id="A-1024">
  <customer>Kim &amp; Co.</customer>
  <items>
    <sku>P-1</sku>
    <qty>2</qty>
    <price>9.5</price>
  </items>
  <items>
    <sku>P-2</sku>
    <qty>1</qty>
    <price>20</price>
  </items>
  <note/>
  <paid>true</paid>
</order>

이 도구로 할 수 있는 일

REST API(JSON)와 SOAP·레거시 시스템(XML)을 연결할 때 구조를 어떻게 옮길지가 가장 헷갈립니다. 이 변환기는 널리 쓰이는 규칙을 그대로 따릅니다.

  • 키가 @로 시작하면 XML 속성, "#text"는 요소의 텍스트, "#cdata"는 CDATA 영역
  • 배열은 같은 이름의 요소를 반복해서 출력 (최상위 배열은 지정한 이름으로 감쌈)
  • null과 빈 문자열은 빈 요소(<a/> 또는 <a></a>)로, &·<·>·" 는 자동으로 이스케이프
  • 숫자로 시작하거나 공백이 있는 키처럼 XML 태그로 쓸 수 없는 이름은 안전한 이름으로 바꾸고 알려 줌

반대 방향 변환은 XML → JSON 변환기를 사용하세요.

💡 Tips

  • 속성 접두사는 다른 문자(예: _)로 바꿀 수 있습니다. XML → JSON 변환기와 같은 접두사를 쓰면 왕복 변환이 됩니다.
  • 최상위가 키 하나뿐인 객체면 그 키가 루트 요소가 됩니다. 아니면 "루트 요소 이름"으로 감쌉니다.
  • 한 줄 출력은 SOAP 본문처럼 공백이 의미를 갖는 곳에 쓰기 좋습니다.

자주 묻는 질문

JSON 배열은 XML에서 어떻게 표현되나요?

XML에는 배열이 없으므로 같은 이름의 요소를 여러 번 반복해 표현합니다. 예: {"item":[1,2]} → <item>1</item><item>2</item>.

숫자·불리언 타입은 유지되나요?

XML은 모두 텍스트라 타입 정보가 사라집니다. 되돌릴 때는 XML → JSON 변환기의 "숫자·불리언 변환" 옵션을 쓰면 됩니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
