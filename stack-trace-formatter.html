스택 트레이스 정리기 — 언어 자동 판별

오류 로그의 긴 스택 트레이스를 언어를 자동으로 알아내 프레임(함수·파일·줄)으로 나누고, 내 코드 패키지에 해당하는 프레임을 강조해 가장 먼저 볼 위치를 알려 줍니다.

이 도구로 할 수 있는 일

수십 줄의 스택에서 라이브러리 프레임을 걷어내고 내 코드가 어디인지 바로 찾습니다. 로그는 브라우저에서만 처리됩니다.

  • 언어 자동 판별: Java/Kotlin, Python, JavaScript(V8·Firefox 형식), .NET, Go, Ruby, PHP
  • 표: 프레임 번호, 원인 단계(최상위/Caused by), 함수, 파일:줄(:열), 분류(내 코드/라이브러리/기타)
  • 내 코드 접두사(com.shop, /app/src 등)를 지정하면 해당 프레임을 ⭐ 로 강조하고 첫 위치를 안내
  • Caused by 체인(근본 원인은 보통 마지막)과 "... 12 more" 생략 프레임 처리
  • 압축된 번들(.min.js)이면 소스맵이 필요하다고 안내

💡 Tips

  • 가장 아래의 Caused by 가 보통 근본 원인이므로 그 위쪽의 내 코드 프레임을 먼저 보세요.
  • 스택에는 파일 경로·내부 클래스명·값이 들어 있을 수 있으니 공유 전에 확인하세요.
  • 프로덕션 JS 는 소스맵으로 원본 위치를 복원해야 합니다 (이 도구는 소스맵을 읽지 않습니다).

자주 묻는 질문

왜 언어를 판별하지 못하나요?

각 줄이 'at … (파일:줄)', 'File "…", line N' 같은 프레임 형식인지 확인하세요. 로그 접두사(타임스탬프)가 붙어 있으면 제거하면 더 잘 인식합니다.

비동기 프레임은 어떻게 보이나요?

파일과 줄이 없는 async 프레임은 표에서 제외되고 파일 정보가 있는 프레임만 나옵니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
