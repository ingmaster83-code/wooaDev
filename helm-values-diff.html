Helm values.yaml 비교기

이전과 새 values.yaml 을 붙여 넣으면 키 순서와 주석을 무시하고 경로(a.b.c)별로 추가, 삭제, 변경, 타입 변경을 보여 줍니다. 스칼라 변경은 helm --set 인자로도 만들어 주고 리스트 병합과 비밀 값 같은 주의점을 알려 줍니다.

사용 예시

➕ 3 · ➖ 2 · ✏️ 5 · ⚠️ 타입 1

입력 — 이전 values.yaml

replicaCount: 2
image:
  repository: nginx
  tag: "1.25"
  pullPolicy: IfNotPresent
service:
  type: ClusterIP
  port: 80
ingress:
  enabled: false
  hosts:
    - host: a.example.com
resources:
  limits:
    cpu: 500m
    memory: 256Mi
nodeSelector: {}

입력 — 새 values.yaml

replicaCount: 3
image:
  repository: nginx
  tag: "1.27"
  pullPolicy: IfNotPresent
service:
  type: LoadBalancer
  port: "80"
ingress:
  enabled: true
  hosts:
    - host: a.example.com
    - host: b.example.com
resources:
  limits:
    memory: 512Mi
autoscaling:
  enabled: true
  maxReplicas: 10

결과 — 차이

 | 경로 | 이전 | 새 값 | 비고
➕ | autoscaling.enabled |  | true | 
➕ | autoscaling.maxReplicas |  | 10 | 
✏️ | image.tag | "1.25" | "1.27" | 
✏️ | ingress.enabled | false | true | 
➕ | ingress.hosts[1].host |  | "b.example.com" | 
➖ | nodeSelector | {} |  | 
✏️ | replicaCount | 2 | 3 | 
➖ | resources.limits.cpu | "500m" |  | 
✏️ | resources.limits.memory | "256Mi" | "512Mi" | 
⚠️ | service.port | 80 | "80" | number → string
✏️ | service.type | "ClusterIP" | "LoadBalancer" |

결과 — helm --set 인자 (스칼라 변경·추가)

--set autoscaling.enabled=true \
  --set autoscaling.maxReplicas=10 \
  --set-string image.tag=1.27 \
  --set ingress.enabled=true \
  --set replicaCount=3 \
  --set resources.limits.memory=512Mi \
  --set service.type=LoadBalancer

이 도구로 할 수 있는 일

차트를 올리기 전에 values 파일의 무엇이 달라졌는지 한눈에 확인합니다. 파일은 서버로 전송되지 않습니다.

  • 비교: 중첩 매핑을 a.b.c 경로로 펼쳐 추가(➕), 삭제(➖), 변경(✏️), 타입 변경(⚠️)을 표시, 같은 값 포함 보기 선택
  • 타입 변경: "80" 과 80 처럼 텍스트는 같고 타입만 다른 경우도 표시(끌 수 있음)
  • 리스트: Helm 은 values 병합 때 리스트를 합치지 않고 통째로 바꾸므로 안내하고 인덱스 변경은 --set 에서 제외
  • --set 인자: 변경·추가된 스칼라 값을 helm --set 또는 --set-string(숫자처럼 보이는 문자열)으로 생성
  • 점검: 삭제된 키는 차트 기본값으로 돌아감, 값에 평문 비밀(password, token …)이 바뀐 경우 경고, 중복 키

💡 Tips

  • image.tag: "1.27" 처럼 숫자로 보이는 태그는 따옴표를 유지해야 1.270 같은 변환을 피합니다.
  • helm get values RELEASE -o yaml 의 출력과 새 파일을 비교하면 실제 릴리스와의 차이를 알 수 있습니다.
  • 리스트 항목을 바꿀 때는 --set 이 아니라 -f values.yaml 로 전체 리스트를 전달하세요.

자주 묻는 질문

키 순서가 달라도 같은 파일로 보나요?

네. 매핑은 키 순서를 무시하고 값만 비교합니다. 리스트는 순서가 의미 있으므로 순서가 바뀌면 변경으로 봅니다.

주석이나 앵커는요?

주석은 무시하고 앵커와 병합 키는 풀어서 비교합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
