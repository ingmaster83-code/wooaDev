TOML 포맷터·검증기

TOML 파일의 문법을 검증하고 들여쓰기·공백·테이블 구성을 일정한 형식으로 정리합니다.

사용 예시

✅ 올바른 TOML입니다

입력 — TOML 입력

title="TOML Example"
[owner]
name =   "Kim"
[database]
ports=[8000,8001,8002]
enabled=true
[servers.alpha]
ip="10.0.0.1"
[servers.beta]
ip="10.0.0.2"

결과 — 정리된 TOML

title = "TOML Example"

[owner]
name = "Kim"

[database]
ports = [ 8000, 8001, 8002 ]
enabled = true

[servers.alpha]
ip = "10.0.0.1"

[servers.beta]
ip = "10.0.0.2"

결과 — 검증 정보

문법: 유효함 ✅
키: 11
테이블(객체): 6
배열: 1
최대 깊이: 4

이 도구로 할 수 있는 일

손으로 편집하다 보면 TOML의 공백과 표기 방식이 제각각이 되기 쉽습니다. 이 도구는 문서를 읽어 문법을 검증한 뒤 같은 내용을 일관된 모양으로 다시 씁니다.

  • TOML 1.0 문법 검증과 오류 위치(줄·열) 안내
  • key=value, key = value 같은 공백 차이와 배열·인라인 테이블 표기를 통일
  • 키 정렬 옵션으로 diff를 줄이고 병합 충돌을 방지
  • 키 개수, 테이블 수, 배열 수, 최대 깊이 요약

주의: 다시 쓰는 과정에서 주석은 유지되지 않습니다. 주석이 중요한 파일은 검증 용도로만 쓰세요.

  • pyproject.toml처럼 여러 사람이 편집하는 파일은 키 정렬 후 커밋하면 diff가 깔끔해집니다.
  • 주석을 보존해야 한다면 이 도구로 검증만 하고 직접 수정하세요.
  • 결과를 JSON으로 확인하고 싶으면 TOML → JSON 변환기를 이용하세요.

자주 묻는 질문

정리하면 값이 바뀌나요?

아니요. 문서를 읽어 같은 값을 다시 쓰는 방식이라 값은 그대로이고 표기만 통일됩니다. 다만 주석과 원래의 줄바꿈 스타일은 사라집니다.

TOML 1.1이나 확장 문법도 지원하나요?

TOML 1.0 규격을 기준으로 합니다. 1.0에 없는 문법은 오류로 표시될 수 있습니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
