JSON → Go 구조체 변환기

API 응답 JSON을 붙여 넣으면 json 태그가 달린 Go struct를 만들어 줍니다. 배열의 모든 요소를 분석해 누락 필드까지 반영합니다.

사용 예시

✅ 구조체 2개를 만들었습니다 (샘플 2개 분석)

입력 — JSON 샘플 (API 응답 등)

[
  {
    "id": 1,
    "name": "Kim",
    "email": "kim@example.com",
    "is_active": true,
    "score": 4.5,
    "tags": ["admin", "dev"],
    "address": { "city": "Seoul", "zip": "04524" },
    "created_at": "2026-01-02T03:04:05Z"
  },
  {
    "id": 2,
    "name": "Lee",
    "is_active": false,
    "score": 3,
    "tags": [],
    "address": { "city": "Busan", "zip": null },
    "created_at": "2026-02-03T04:05:06Z",
    "nickname": null
  }
]

결과 — Go 구조체

package model

type Root struct {
	ID        int64       `json:"id"`
	Name      string      `json:"name"`
	Email     *string     `json:"email,omitempty"`
	IsActive  bool        `json:"is_active"`
	Score     float64     `json:"score"`
	Tags      []string    `json:"tags"`
	Address   Address     `json:"address"`
	CreatedAt string      `json:"created_at"`
	Nickname  interface{} `json:"nickname,omitempty"`
}

type Address struct {
	City string  `json:"city"`
	Zip  *string `json:"zip"`
}

결과 — 분석 정보

분석한 샘플: 2
생성된 타입: Address, Root

이 도구로 할 수 있는 일

Go에서 JSON API를 호출하려면 응답에 맞는 struct를 손으로 작성해야 합니다. 샘플 하나만 보고 만들면 어떤 응답에서는 없는 필드나 null인 필드를 놓치기 쉬워, 이 도구는 여러 샘플을 모두 분석합니다.

  • 배열의 모든 요소(또는 이어 붙인 여러 JSON)를 합쳐 분석: 일부에만 있는 필드는 omitempty와 포인터로
  • null이 섞인 필드는 포인터(*string 등), 정수와 실수가 섞이면 float64, 타입이 제각각이면 interface{}/any
  • user_id → UserID, api_url → APIURL처럼 Go의 약어 관례(ID, URL, HTTP…)를 적용
  • 중첩 객체는 별도 struct로 분리하고, 구조가 같은 객체는 하나로 재사용
  • int/int64, time.Time, any 사용 여부를 옵션으로 선택

생성된 코드는 초안입니다. 필드 이름과 타입을 프로젝트 규칙에 맞게 다듬어 사용하세요.

💡 Tips

  • 가능하면 서로 다른 응답 2–3개를 이어 붙여 넣으세요. 선택 필드를 훨씬 정확히 찾아냅니다.
  • ID나 개수처럼 큰 숫자는 int64 옵션을 켜 두는 것이 안전합니다.
  • RFC 3339 날짜 문자열은 "날짜-시간은 time.Time" 옵션으로 time.Time 필드가 됩니다.

자주 묻는 질문

왜 일부 필드에 포인터가 붙나요?

Go에서는 값이 없는 것(null)과 0/빈 문자열을 구분하려면 포인터가 필요합니다. 포인터 옵션을 끄면 일반 타입으로 생성됩니다.

최상위가 배열이면 어떻게 하나요?

배열 요소의 구조로 struct를 만들고, 주석으로 "JSON 최상위가 배열이므로 []타입으로 디코딩"하라고 안내합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
