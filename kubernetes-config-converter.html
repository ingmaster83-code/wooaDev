Kubernetes ConfigMap · Secret ↔ .env 변환기

.env 파일의 KEY=VALUE를 ConfigMap과 Secret YAML로 자동 분리하고(Base64 인코딩 포함), 반대로 Secret/ConfigMap YAML을 .env 로 되돌립니다. Deployment 에 연결하는 envFrom 예시도 만들어 줍니다.

사용 예시

✅ ConfigMap 3개 키 · Secret 2개 키

입력 — .env 내용 (KEY=VALUE)

# 앱 설정
LOG_LEVEL=info
API_URL=https://api.example.com
DB_HOST=db.internal
DB_PASSWORD=s3cr3t!
JWT_SECRET="a long secret value"

입력 — ConfigMap / Secret YAML

apiVersion: v1
kind: Secret
metadata:
  name: app-secret
data:
  DB_PASSWORD: czNjcjN0IQ==
  JWT_SECRET: YSBsb25nIHNlY3JldCB2YWx1ZQ==
stringData:
  EXTRA: plain value

결과 — 결과

apiVersion: v1
kind: ConfigMap
metadata:
  name: app-config
data:
  LOG_LEVEL: info
  API_URL: "https://api.example.com"
  DB_HOST: db.internal
---
apiVersion: v1
kind: Secret
metadata:
  name: app-config-secret
type: Opaque
data:
  DB_PASSWORD: czNjcjN0IQ==
  JWT_SECRET: YSBsb25nIHNlY3JldCB2YWx1ZQ==

결과 — Deployment 에서 사용하기

# Deployment > spec.template.spec.containers[]
        envFrom:
          - configMapRef:
              name: app-config
          - secretRef:
              name: app-config-secret

# 또는 키 하나씩
        env:
          - name: LOG_LEVEL
            valueFrom:
              configMapKeyRef:
                name: app-config
                key: LOG_LEVEL

이 도구로 할 수 있는 일

배포 설정을 .env 에서 쿠버네티스로 옮길 때 값마다 Base64를 계산하고 ConfigMap/Secret 을 나누는 일을 자동화합니다. 모든 처리는 브라우저에서만 일어납니다.

  • .env → YAML: 키 이름에 PASSWORD·SECRET·TOKEN·KEY 등이 있으면 Secret, 나머지는 ConfigMap 으로 자동 분류(수동 선택도 가능)
  • Secret 은 data(Base64) 또는 stringData(평문) 선택, 네임스페이스 지정
  • 이름(DNS 서브도메인)과 키 문자 규칙, 중복 키, 숫자·불리언의 문자열 인용 처리
  • Deployment 에 붙일 envFrom / valueFrom 예시 생성
  • 반대 방향: ConfigMap·Secret YAML 의 data/stringData 를 풀어 .env 로 출력

💡 Tips

  • Base64 는 암호화가 아닙니다. Secret YAML 을 Git 에 올리지 말고 Sealed Secrets, External Secrets, SOPS 를 쓰세요.
  • ConfigMap 의 값은 문자열이어야 하므로 포트 같은 숫자도 "8080" 처럼 따옴표로 감싸 출력합니다.
  • ConfigMap/Secret 하나는 1MiB 한도가 있습니다. 큰 파일은 볼륨이나 별도 저장소를 고려하세요.

자주 묻는 질문

data 와 stringData 의 차이는요?

data 는 Base64 로 인코딩한 값을, stringData 는 평문을 적으면 API 서버가 저장 시 Base64 로 바꿔 줍니다. 읽기 쉬운 매니페스트에는 stringData 가 편합니다.

Secret 값을 바꾸면 파드에 바로 반영되나요?

환경 변수로 주입한 값은 파드를 재시작해야 바뀝니다. 볼륨으로 마운트한 경우에는 잠시 후 파일이 갱신됩니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
