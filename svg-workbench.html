SVG 최적화 · 점검 · Data URI

SVG 코드를 붙여 넣으면 편집기 메타데이터, 주석, 사용하지 않는 id, 기본값 속성을 지우고 좌표 자릿수와 색상 표기를 줄여 용량을 줄입니다. script, on* 이벤트, foreignObject, 외부 링크 같은 XSS 위험을 찾아 제거하고, 스크립트가 실행되지 않는 미리보기와 CSS 용 Data URI 도 만들어 줍니다.

사용 예시

⛔ 문제 2건 — 정리 후 496 B (−64.3%)

입력 — SVG 코드

<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<!-- Created with Inkscape (http://www.inkscape.org/) -->
<svg xmlns="http://www.w3.org/2000/svg" xmlns:inkscape="http://www.inkscape.org/namespaces/inkscape" xmlns:sodipodi="http://sodipodi.sourceforge.net/DTD/sodipodi-0.dtd" version="1.1" id="svg8" width="48mm" height="48mm" viewBox="0 0 48 48" onload="alert(1)">
  <metadata id="metadata5"><rdf:RDF xmlns:rdf="http://www.w3.org/1999/02/22-rdf-syntax-ns#"><cc:Work xmlns:cc="http://creativecommons.org/ns#"/></rdf:RDF></metadata>
  <sodipodi:namedview id="base" pagecolor="#ffffff" inkscape:zoom="1.4"/>
  <title id="title1">Wooa icon</title>
  <defs id="defs2">
    <linearGradient id="grad" x1="0" y1="0" x2="1" y2="1">
      <stop offset="0" stop-color="rgb(255, 0, 0)"/>
      <stop offset="1" stop-color="#0000ff"/>
    </linearGradient>
  </defs>

결과 — 점검 결과

⛔ <script> 가 포함되어 있습니다. 웹페이지에 인라인으로 넣으면 XSS 위험입니다 (<img> 로 불러오면 실행되지 않음)
⛔ on* 이벤트 핸들러 속성이 1개 있습니다 (XSS 위험)
ℹ️ 편집기(Inkscape 등) 메타데이터가 있습니다. 정리하면 크기가 줄어듭니다
ℹ️ 소수점 4자리 이상 숫자가 10개 있습니다. 자릿수를 줄이면 용량이 크게 줄어듭니다

이 도구로 할 수 있는 일

svgo 설치 없이 브라우저에서 SVG 를 정리합니다. 코드는 서버로 전송되지 않습니다.

  • 정리: 주석·메타데이터·Inkscape/Sodipodi 속성, 빈 그룹, 미사용 id, 기본값 속성 제거, 좌표 자릿수 조절
  • 경로 최소화: path 데이터 재작성(아크 플래그, 음수·소수 구분자 절약), 색상 이름·rgb()·#aabbcc 단축
  • 점검: viewBox·xmlns 누락, script, on* 핸들러, foreignObject, 외부/javascript: 링크, 내장 래스터, 접근성 title
  • 출력: 정리된 SVG(최소화/들여쓰기), 용량 변화와 gzip 추정, 스크립트 차단 미리보기, URL 인코딩·Base64 CSS Data URI
  • 옵션: 소수 자릿수, title/desc 유지, width/height 제거, 위험 요소 제거

💡 Tips

  • 아이콘은 소수 자릿수 1~2 면 충분한 경우가 많습니다. 줄이면 크기가 크게 줄지만 큰 도형에서는 어긋나 보일 수 있습니다.
  • 신뢰할 수 없는 SVG 는 인라인(<svg>)으로 삽입하지 말고 <img> 로 불러오세요. <img> 안에서는 스크립트가 실행되지 않습니다.
  • CSS 배경 용 SVG 는 URL 인코딩 Data URI 가 Base64 보다 보통 작습니다.

자주 묻는 질문

모양이 바뀔 수 있나요?

좌표 자릿수를 낮추면 미세한 차이가 생길 수 있습니다. 미리보기로 확인하고 필요하면 자릿수를 올리세요. 스타일 시트(<style>) 규칙은 건드리지 않습니다.

svgo 와 같은가요?

자주 쓰는 정리 규칙만 구현했습니다. path 병합이나 변환 적용 같은 고급 최적화는 하지 않으므로 대형 일러스트는 svgo 를 사용하세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
