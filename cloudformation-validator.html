CloudFormation 템플릿 검증기

YAML 또는 JSON 템플릿(!Ref 같은 단축 함수 지원)을 붙여 넣으면 없는 리소스·파라미터 참조, 순환 의존성, 조건·매핑 참조, 필수 속성 누락, 중복 Export, 열린 보안 그룹, 공개 S3, 평문 비밀번호, 지원이 끝난 Lambda 런타임을 줄 번호로 알려 줍니다.

사용 예시

⛔ 오류 9건 · 경고 2건 — 리소스 5개

입력 — CloudFormation 템플릿 (YAML 또는 JSON, !Ref 같은 단축 함수 지원)

AWSTemplateFormatVersion: "2010-09-09"
Parameters:
  Env:
    Type: String
    Default: staging
    AllowedValues: [dev, prod]
  DbPassword:
    Type: String
Conditions:
  IsProd: !Equals [!Ref Env, prod]
  Unused: !Equals [!Ref Env, test]
Resources:
  Bucket:
    Type: AWS::S3::Bucket
    Properties:
      AccessControl: PublicRead
      BucketName: !Sub "${Env}-${AWS::Region}-${Missing}"
  Function:
    Type: AWS::Lambda::Function
    DependsOn: Role
    Properties:
      Runtime: python3.8
      Handler: index.handler
      Role: !GetAtt Role.Arn
  Role:
    Type: AWS::IAM::Role
    DependsOn: Function
    Properties:
      ManagedPolicyArns: [!Ref Policy2]
  Sg:
    Type: AWS::EC2::SecurityGroup
    Properties:
      GroupDescription: web
      SecurityGroupIngress:
        - IpProtocol: tcp
          FromPort: 22
          ToPort: 22
          CidrIp: 0.0.0.0/0
  Db:
…

결과 — 리소스

논리 ID | 타입 | 줄 | 의존 리소스 | Condition
Bucket | AWS::S3::Bucket | 13 | — | 
Function | AWS::Lambda::Function | 18 | Role | 
Role | AWS::IAM::Role | 25 | Function | 
Sg | AWS::EC2::SecurityGroup | 30 | — | 
Db | AWS::RDS::DBInstance | 39 | — |

결과 — 점검 결과

ℹ️ 줄 1: Description 이 없습니다
⛔ 줄 5: 파라미터 "Env" 의 Default(staging)가 AllowedValues 에 없습니다
⚠️ 줄 7: 파라미터 "DbPassword" 는 비밀 값처럼 보이는데 NoEcho: true 가 없어 콘솔·API 에 값이 노출됩니다
ℹ️ 줄 10: 조건 "IsProd" 을 쓰는 곳이 없습니다
ℹ️ 줄 11: 조건 "Unused" 을 쓰는 곳이 없습니다
ℹ️ 줄 13: 버킷 "Bucket" 에 PublicAccessBlockConfiguration 이 없습니다
ℹ️ 줄 13: 버킷 "Bucket" 에 BucketEncryption 이 없습니다 (기본 SSE-S3 는 적용됨)
⛔ 줄 16: 버킷 "Bucket" 의 AccessControl 이 PublicRead 라 공개됩니다
⛔ 줄 17: Fn::Sub 안의 ${Missing} 가 리소스·파라미터에 없습니다
⛔ 줄 18: 리소스 순환 의존성: Function → Role → Function (스택 생성이 실패합니다)
⛔ 줄 21: 리소스 "Function" (AWS::Lambda::Function) 에 필수 속성 Code 가 없습니다
⚠️ 줄 22: Lambda 런타임 python3.8 은(는) 지원이 종료되었거나 종료 예정입니다. 최신 런타임으로 올리세요
⛔ 줄 28: 리소스 "Role" (AWS::IAM::Role) 에 필수 속성 AssumeRolePolicyDocument 가 없습니다
⛔ 줄 29: Ref "Policy2" 가 리소스·파라미터에 없습니다
⛔ 줄 32: 보안 그룹 "Sg" 이 SSH/RDP 를 전 세계(0.0.0.0/0)에 엽니다
ℹ️ 줄 39: DB "Db" 에 StorageEncrypted: true 가 없습니다
ℹ️ 줄 39: 상태가 있는 리소스 "Db" 에 DeletionPolicy(Snapshot/Retain)가 없어 스택 삭제 시 데이터가 사라집니다
⛔ 줄 50: Export 이름 "shared" 이 줄 46 와 중복됩니다 (리전 안에서 고유해야 함)
이 검사는 구조·참조·흔한 속성만 확인합니다. 실제 배포 전에는 cfn-lint 와 aws cloudformation validate-template, 변경 세트로 한 번 더 확인하세요

이 도구로 할 수 있는 일

스택을 만들다 롤백되기 전에 템플릿의 구조·참조 오류와 흔한 보안 문제를 찾습니다. 템플릿은 서버로 전송되지 않습니다.

  • 형식: YAML/JSON, !Ref·!GetAtt·!Sub·!If 같은 단축 함수 지원, 섹션 이름, 논리 ID 규칙, 리소스 타입 형식, 알 수 없는 속성
  • 참조: Ref·Fn::GetAtt·Fn::Sub(${}) 대상이 리소스·파라미터·의사 파라미터에 있는지, DependsOn, Fn::FindInMap 의 매핑, Condition·Fn::If 조건
  • 순환: Ref/GetAtt/DependsOn 그래프의 순환 의존성 감지
  • 속성: 파라미터 Type·Default↔AllowedValues·NoEcho, 자주 쓰는 리소스(Lambda, IAM Role, EC2, RDS, SQS/SNS 정책 등)의 필수 속성
  • 보안·운영: 공개 S3, SSH/RDP 전세계 오픈, IAM Action:*·Resource:*, 평문 DB 비밀번호, 종료된 Lambda 런타임, 상태 있는 리소스의 DeletionPolicy, Export 이름 중복

💡 Tips

  • 비밀번호는 NoEcho 파라미터나 Secrets Manager 동적 참조 {{resolve:secretsmanager:...}} 로 받으세요.
  • 논리 ID 에는 하이픈과 밑줄을 쓸 수 없습니다. 영문자와 숫자만 허용됩니다.
  • 순환 의존성은 Ref 로 서로를 가리키는 보안 그룹 규칙에서 자주 생깁니다. 규칙을 별도 리소스로 분리하세요.

자주 묻는 질문

cfn-lint 를 대체하나요?

아닙니다. 리소스 타입별 전체 스키마를 검사하지 않고 구조·참조·흔한 속성만 봅니다. 배포 전에는 cfn-lint 와 변경 세트로 한 번 더 확인하세요.

SAM 템플릿도 되나요?

Transform 이 있는 SAM 템플릿은 기본 구조와 참조만 확인하고 AWS::Serverless::* 속성은 SAM 이 변환하므로 상세 검사를 하지 않습니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
