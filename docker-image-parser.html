Docker 이미지 이름 분석기 — 레지스트리 · 태그 · digest

nginx, ubuntu:22.04, ghcr.io/owner/app:v1@sha256:… 같은 이미지 참조를 레지스트리, 저장소, 태그, digest로 나누고 Docker가 실제로 받는 전체 이름으로 정규화합니다.

사용 예시

✅ 6개 이미지 참조를 분석했습니다

입력 — Docker 이미지 참조 (한 줄에 하나)

nginx
ubuntu:22.04
bitnami/redis:7.2
ghcr.io/owner/app:v1.4.2
localhost:5000/my/app@sha256:3d6d3a1c5f0b9c4d5b3c1e2f7a8b9c0d1e2f3a4b5c6d7e8f9a0b1c2d3e4f5a6b
123456789012.dkr.ecr.ap-northeast-2.amazonaws.com/web:latest

결과 — 구성 요소

입력 | 레지스트리 | 저장소 | 태그 | Digest
nginx | docker.io (Docker Hub) | library/nginx  ← 공식 이미지 | latest (기본값) | —
ubuntu:22.04 | docker.io (Docker Hub) | library/ubuntu  ← 공식 이미지 | 22.04 | —
bitnami/redis:7.2 | docker.io (Docker Hub) | bitnami/redis | 7.2 | —
ghcr.io/owner/app:v1.4.2 | ghcr.io (GitHub Container Registry) | owner/app | v1.4.2 | —
localhost:5000/my/app@sha256:3d6d3a1c5f0b9c4d5b3c1e2f7a8b9c0d1e2f3a4b5c6d7e8f9a0b1c2d3e4f5a6b | localhost:5000 (local) | my/app | — | sha256:3d6d3a1c5f0b…
123456789012.dkr.ecr.ap-northeast-2.amazonaws.com/web:latest | 123456789012.dkr.ecr.ap-northeast-2.amazonaws.com (Amazon ECR) | web | latest | —

결과 — 정규화된 참조

docker.io/library/nginx:latest
docker.io/library/ubuntu:22.04
docker.io/bitnami/redis:7.2
ghcr.io/owner/app:v1.4.2
localhost:5000/my/app@sha256:3d6d3a1c5f0b9c4d5b3c1e2f7a8b9c0d1e2f3a4b5c6d7e8f9a0b1c2d3e4f5a6b
123456789012.dkr.ecr.ap-northeast-2.amazonaws.com/web:latest

이 도구로 할 수 있는 일

이미지 이름은 생략 규칙이 많아서(레지스트리 docker.io, 공식 이미지 library/, 태그 latest) 실제로 어디서 무엇을 받는지 헷갈립니다. 여러 줄을 한꺼번에 분석할 수 있습니다.

  • 분해: 레지스트리(포트 포함), 저장소 경로, 태그, @digest
  • 정규화: nginx → docker.io/library/nginx:latest, index.docker.io 별칭 통일, 기본 레지스트리 변경 가능
  • 레지스트리 식별: Docker Hub, GHCR, Quay, Amazon ECR, Google GCR/Artifact Registry, MCR, Azure ACR, GitLab, localhost
  • 검증: 저장소 이름은 소문자·숫자·구분자만, 태그는 128자·허용 문자, digest 는 sha256:64자
  • 점검: latest/태그 없음 사용, digest 고정 권장, 첫 구성 요소가 레지스트리인지 사용자 이름인지 규칙 설명

💡 Tips

  • 운영 배포에는 latest 대신 버전 태그를, 가장 엄격하게는 @sha256:… digest 로 고정하세요.
  • 첫 구성 요소에 . 이나 : 가 있거나 localhost 면 레지스트리, 아니면 Docker Hub 의 사용자 이름입니다.
  • 태그는 대문자를 쓸 수 있지만 저장소 이름은 소문자만 가능합니다.

자주 묻는 질문

태그와 digest 를 같이 쓰면 어떻게 되나요?

digest 가 우선하고 태그는 사람이 읽기 위한 표시로만 남습니다. 태그가 나중에 다른 이미지를 가리켜도 digest 로 받은 이미지는 변하지 않습니다.

library/ 는 무엇인가요?

Docker Hub 의 공식 이미지(nginx, ubuntu 등)가 속한 네임스페이스입니다. nginx 는 내부적으로 docker.io/library/nginx 입니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
