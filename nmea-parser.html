NMEA 0183 GPS 문장 파서

$GPGGA, $GPRMC 같은 NMEA 0183 문장을 위도·경도(십진 도), 시각, 속도, 방위, 위성 수, HDOP, 고도로 풀고 XOR 체크섬이 맞는지 확인합니다. 지도 링크도 만들어 줍니다.

사용 예시

✅ 문장 5개 해석

입력 — NMEA 0183 문장 (한 줄에 하나)

$GPGGA,092750.000,5321.6802,N,00630.3372,W,1,8,1.03,61.7,M,55.2,M,,*76
$GPRMC,092750.000,A,5321.6802,N,00630.3372,W,0.02,31.66,280511,,,A*43
$GPGLL,5321.6802,N,00630.3372,W,092750.000,A,A*4B
$GPVTG,31.66,T,,M,0.02,N,0.04,K,A*09
$GPGSA,A,3,10,07,05,02,29,04,08,13,,,,,1.72,1.03,1.38*0A

결과 — 참고

NMEA 위도·경도는 ddmm.mmmm 형식이라 도(°) = dd + mm.mmmm/60 으로 변환합니다. S, W 는 음수입니다
체크섬은 $ 와 * 사이 문자의 XOR 입니다

이 도구로 할 수 있는 일

GPS 수신기 시리얼 출력이나 로그를 사람이 읽을 수 있게 풀어 줍니다. 처리는 모두 브라우저에서 이루어집니다.

  • 문장: GGA(고정 정보), RMC(권장 최소), GLL, VTG, GSA(DOP·사용 위성)와 그 외 문장은 필드 나열
  • 좌표: ddmm.mmmm → 십진 도, N/S/E/W 부호 처리, 지도 링크
  • 값: UTC 시각·날짜, 속도 노트→km/h, 진행 방향(도), 위성 수, HDOP, 고도, 고정 품질(RTK 등)
  • 체크섬: $ 와 * 사이 문자의 XOR 과 * 뒤 16진수 비교
  • 토커 ID(GP·GN·GL·GA·BD) 구분, 한 줄에 한 문장

💡 Tips

  • RMC 의 상태 V(void)는 위치가 유효하지 않다는 뜻입니다. 좌표를 믿지 마세요.
  • 고정 품질 0 이면 위치 고정이 안 된 상태이고, 4(RTK 고정)나 5(RTK 부동)는 정밀 측위입니다.
  • GN 으로 시작하는 문장은 여러 위성 시스템(GPS+GLONASS 등)을 합친 해입니다.

자주 묻는 질문

체크섬이 맞지 않으면요?

전송 중 비트 오류일 가능성이 높으니 해당 문장은 버리는 것이 일반적입니다. $ 와 * 는 계산에서 제외됩니다.

속도 단위가 노트인 이유는요?

NMEA 는 항해용 표준에서 출발해 속도를 노트(해리/시), 거리를 해리로 씁니다. 1노트는 1.852 km/h 입니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
