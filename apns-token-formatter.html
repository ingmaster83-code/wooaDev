APNs 디바이스 토큰 변환기

Xcode 로그의 <740f4707 bebcf74f …> 형식, 공백 없는 16진수, Base64 로 된 APNs 디바이스 토큰을 서버가 쓰는 소문자 16진수로 통일하고 길이를 검증합니다. Swift·Node·Python 변환 코드도 제공합니다.

이 도구로 할 수 있는 일

iOS 푸시 알림 서버에 등록하는 디바이스 토큰이 로그·데이터베이스·라이브러리마다 다른 형식이라 맞지 않을 때 사용합니다.

  • 입력: <공백이 있는 16진수>, 연속 16진수(대소문자 무관), Base64/Base64URL, 한 줄에 하나
  • 출력: 서버로 보낼 소문자 16진수, 8자 단위로 읽기 쉬운 표기, Base64
  • 검증: 보통 32바이트(64자리), 너무 짧거나(32 미만) 긴 경우(100 초과) 경고
  • 앱 코드 예시: Swift 의 Data → 16진수, Node 의 Base64 → 16진수, Python
  • 길이가 바뀔 수 있으니 저장 컬럼을 넉넉히 잡도록 안내

💡 Tips

  • 개발(sandbox)과 운영 토큰은 서로 호환되지 않습니다. 환경별 APNs 엔드포인트를 맞추세요.
  • 앱을 재설치하거나 복원하면 토큰이 바뀔 수 있으니 실행할 때마다 서버에 등록하세요.
  • Android 의 FCM 등록 토큰은 APNs 토큰과 다른 값입니다.

자주 묻는 질문

토큰을 서버에서 대문자로 저장해도 되나요?

APNs 는 16진수 대소문자를 구분하지 않지만 일관되게 소문자로 저장하면 중복 비교가 쉽습니다.

토큰이 64자가 아닌데 정상인가요?

과거에는 32바이트였지만 길이가 늘어날 수 있다고 Apple 이 안내합니다. 최대 100바이트까지 허용되니 64자로 고정하지 마세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
