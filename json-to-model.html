JSON → Rust · C# · Dart · Kotlin 모델 변환기

JSON 샘플 하나로 Rust(serde), C#(System.Text.Json), Dart(fromJson/toJson), Kotlin(data class) 모델 코드를 만들어 줍니다.

사용 예시

✅ 타입 2개를 만들었습니다 (샘플 2개 분석)

입력 — JSON 샘플 (API 응답 등)

[
  {
    "id": 1,
    "name": "Kim",
    "email": "kim@example.com",
    "is_active": true,
    "score": 4.5,
    "tags": ["admin", "dev"],
    "address": { "city": "Seoul", "zip": "04524" },
    "created_at": "2026-01-02T03:04:05Z"
  },
  {
    "id": 2,
    "name": "Lee",
    "is_active": false,
    "score": 3,
    "tags": [],
    "address": { "city": "Busan", "zip": null },
    "created_at": "2026-02-03T04:05:06Z",
    "nickname": null
  }
]

결과 — 생성된 코드

use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Root {
    pub id: i64,
    pub name: String,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub email: Option<String>,
    pub is_active: bool,
    pub score: f64,
    pub tags: Vec<String>,
    pub address: Address,
    pub created_at: String,
    #[serde(default)]
    pub nickname: serde_json::Value,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Address {
    pub city: String,
    pub zip: Option<String>,
}

이 도구로 할 수 있는 일

모바일(Flutter·Kotlin)과 백엔드(Rust·C#) 개발에서는 같은 JSON 스키마를 언어별 모델로 반복해서 옮겨 적게 됩니다. 한 번 붙여 넣고 언어만 바꿔 보세요.

  • Rust: #[derive(Serialize, Deserialize)], 선택 필드는 Option<T>, 이름이 다르면 #[serde(rename)], 예약어는 r#type
  • C#: System.Text.Json의 [JsonPropertyName], 클래스 또는 record, nullable 참조 타입(?) 옵션
  • Dart: final 필드, required/nullable 생성자, fromJson/toJson (캐스팅 포함, double 변환 처리)
  • Kotlin: kotlinx.serialization의 @Serializable·@SerialName, 선택 필드는 = null
  • 모든 언어에서 중첩 객체 분리, 배열 → List/Vec, 같은 구조 재사용

Go·Java·Python·Swift는 각각 전용 변환기가 있습니다.

함께 쓰면 좋은 도구

💡 Tips

  • Flutter 모델은 Dart를 선택하면 fromJson/toJson까지 한 번에 생성됩니다.
  • C#에서 nullable reference types를 쓰는 프로젝트라면 nullable 옵션을 켜 두세요 (경고를 줄이도록 = default!; 추가).
  • Rust의 camelCase API는 rename_all 옵션으로 필드마다 rename을 붙이지 않아도 됩니다.

자주 묻는 질문

타입이 불확실한 필드는 어떻게 되나요?

샘플에서 타입이 하나로 정해지지 않으면(null만 있거나 타입이 섞임) 각 언어의 동적 타입(serde_json::Value, object, dynamic, JsonElement)으로 생성합니다.

Dart 코드는 json_serializable 없이도 동작하나요?

네. 생성된 클래스가 fromJson/toJson을 직접 구현하므로 build_runner 없이 바로 사용할 수 있습니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
