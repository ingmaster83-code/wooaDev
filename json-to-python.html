JSON → Python 모델 변환기 — dataclass · Pydantic · TypedDict

JSON 샘플에서 dataclass, Pydantic v2 BaseModel, TypedDict 코드를 만들어 줍니다. Optional 필드와 별칭(alias)까지 처리합니다.

사용 예시

✅ 클래스 2개를 만들었습니다 (샘플 2개 분석)

입력 — JSON 샘플 (API 응답 등)

[
  {
    "id": 1,
    "name": "Kim",
    "email": "kim@example.com",
    "is_active": true,
    "score": 4.5,
    "tags": ["admin", "dev"],
    "address": { "city": "Seoul", "zip": "04524" },
    "created_at": "2026-01-02T03:04:05Z"
  },
  {
    "id": 2,
    "name": "Lee",
    "is_active": false,
    "score": 3,
    "tags": [],
    "address": { "city": "Busan", "zip": null },
    "created_at": "2026-02-03T04:05:06Z",
    "nickname": null
  }
]

결과 — Python 코드

from dataclasses import dataclass
from typing import Any, List, Optional


@dataclass
class Address:
    city: str
    zip: Optional[str] = None


@dataclass
class Root:
    id: int
    name: str
    is_active: bool
    score: float
    tags: List[str]
    address: Address
    created_at: str
    email: Optional[str] = None
    nickname: Any = None

이 도구로 할 수 있는 일

FastAPI, 데이터 파이프라인, 외부 API 클라이언트를 만들 때 JSON 응답을 타입이 있는 모델로 받으면 편리합니다.

  • dataclass: 필수 필드를 먼저, 선택 필드는 = None으로 정렬해 dataclass 규칙에 맞게 생성
  • Pydantic v2: camelCase 같은 원본 키는 snake_case 필드 + Field(alias="createdAt"), ISO 날짜는 datetime/date, UUID 지원
  • TypedDict: 일부 샘플에만 있는 키는 NotRequired로, 파이썬 식별자가 아닌 키는 함수형 문법으로
  • 최신 표기(list[str], str | None, Python 3.10+) 또는 typing.List/Optional 선택
  • 중첩 객체는 별도 클래스로 먼저 정의해 순서 오류를 방지

예약어(from, class 등)는 이름 뒤에 _를 붙입니다.

💡 Tips

  • 외부 API 응답은 Pydantic 모델로 받으면 타입 검증과 날짜 자동 변환까지 한 번에 됩니다.
  • Python 3.9 이하라면 "최신 타입 표기" 옵션을 끄세요.
  • 여러 응답을 이어 붙이면 선택 필드를 더 정확히 찾습니다.

자주 묻는 질문

dataclass와 Pydantic은 어떻게 고르나요?

단순한 데이터 묶음이면 dataclass, 입력 검증·형 변환·JSON 직렬화가 필요하면 Pydantic이 적합합니다. FastAPI는 Pydantic을 기본으로 씁니다.

null 값은 어떻게 처리되나요?

null이 있는 필드는 Optional[T] (또는 T | None)로 만들고 기본값을 None으로 지정합니다. 타입이 하나도 확인되지 않는 필드는 Any입니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
