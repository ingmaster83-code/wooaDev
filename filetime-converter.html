Windows FILETIME 변환기

Windows FILETIME(1601-01-01 이후 100ns 수)을 날짜로, 날짜를 FILETIME으로 바꿉니다. 10진수·16진수·상위/하위 DWORD 입력을 모두 받습니다.

사용 예시

✅ 5개 변환

입력 — FILETIME 또는 날짜 (한 줄에 하나)

134052684151234567
0x01DC4B3A12345678
0x01DC4B3A 0x12345678
2026-10-16T09:30:15.1234567Z
116444736000000000

결과 — 변환 결과

입력 | FILETIME | 16진수 | UTC (ISO 8601, 100ns)
134052684151234567 | 134052684151234567 | 0x01DC4034BC05A007 | 2025-10-18T13:40:15.1234567Z
0x01DC4B3A12345678 | 134064801699878520 | 0x01DC4B3A12345678 | 2025-11-01T14:16:09.9878520Z
0x01DC4B3A 0x12345678 | 134064801699878520 | 0x01DC4B3A12345678 | 2025-11-01T14:16:09.9878520Z
2026-10-16T09:30:15.1234567Z | 134366166151234567 | 0x01DD5D50F3468407 | 2026-10-16T09:30:15.1234567Z
116444736000000000 | 116444736000000000 | 0x019DB1DED53E8000 | 1970-01-01T00:00:00.0000000Z

이 도구로 할 수 있는 일

NTFS 파일 시간, Active Directory의 lastLogon·pwdLastSet, Windows 레지스트리와 이벤트 로그는 FILETIME으로 시각을 저장합니다. 1601-01-01부터 지난 100나노초 수라서 사람이 읽을 수 없습니다.

  • 입력: 133700000000000000 같은 10진수, 0x01DB… 16진수, "0x01DB1234 0x5678ABCD"(상위 DWORD 하위 DWORD) 쌍
  • 출력: UTC ISO 8601(100ns), Unix 초·밀리초, 10진/16진, dwHigh/dwLow
  • 날짜를 넣으면 FILETIME 값으로 역변환
  • 64비트 부호 없는 정수 범위와 표시 가능한 날짜 범위를 검사

💡 Tips

  • Active Directory 속성 값이 9223372036854775807 이면 "만료 없음"을 뜻하는 특수값이라 날짜가 아닙니다.
  • 0은 1601-01-01입니다. lastLogon이 0이면 "한 번도 로그온하지 않음"이라는 뜻이 많습니다.
  • FILETIME은 항상 UTC 기준입니다. 로컬 시각은 시간대 변환기로 바꾸세요.

자주 묻는 질문

왜 1601년인가요?

1601년은 400년 주기 그레고리력의 시작 해로, 윤년 규칙이 한 주기 단위로 깔끔하게 반복되어 Windows가 기준으로 삼았습니다.

FILETIME과 .NET Ticks는 어떻게 다른가요?

둘 다 100ns 단위지만 기준이 다릅니다. FILETIME은 1601-01-01, .NET Ticks는 0001-01-01입니다. 차이는 504911232000000000 ticks 입니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
