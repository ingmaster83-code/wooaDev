OpenAPI Mock 데이터 생성기

OpenAPI 문서에서 엔드포인트를 골라 응답 또는 요청 본문 Mock JSON 을 만듭니다. example 이 있으면 우선 쓰고, 없으면 스키마(type·format·enum·min/max)에서 결정적으로 값을 만들며 같은 입력이면 항상 같은 결과가 나옵니다. curl 명령도 함께 제공합니다.

사용 예시

✅ GET /pets → 200 의 Mock 데이터를 만들었습니다

입력 — OpenAPI 문서 (YAML 또는 JSON)

openapi: 3.0.3
info: { title: Pets, version: 1.0.0 }
servers: [{ url: https://api.example.com/v1 }]
paths:
  /pets:
    get:
      summary: List pets
      parameters: [{ name: limit, in: query, schema: { type: integer } }]
      responses:
        "200":
          description: OK
          content:
            application/json:
              schema: { type: array, items: { $ref: "#/components/schemas/Pet" } }
    post:
      summary: Add a pet
      requestBody:
        content: { application/json: { schema: { $ref: "#/components/schemas/NewPet" } } }
      responses:
        "201":
          description: Created
          content: { application/json: { schema: { $ref: "#/components/schemas/Pet" } } }
        "400": { description: Bad request, content: { application/json: { schema: { $ref: "#/components/schemas/Error" } } } }
components:
  schemas:
    Pet:
      type: object
…

결과 — 엔드포인트 목록

메서드 | 경로 | operationId | 응답 코드 | 
GET | /pets | — | 200 | ◀
POST | /pets | — | 201, 400 |

이 도구로 할 수 있는 일

API 서버가 없어도 프런트엔드와 테스트에 쓸 응답 데이터를 바로 만듭니다. 문서는 서버로 전송되지 않습니다.

  • 대상: 'GET /pets/{id}' 처럼 메서드와 경로를 적거나 operationId 로 선택
  • 값 생성: example · default · enum 우선, string format(date-time, email, uuid, uri 등)과 숫자 범위를 반영
  • 스키마: $ref, allOf 병합, oneOf/anyOf(첫 항목), additionalProperties 맵
  • readOnly 는 응답에만, writeOnly 는 요청에만 포함
  • 상태 코드·배열 길이 선택, 경로 변수를 채운 curl 명령 출력

💡 Tips

  • 같은 문서면 항상 같은 값이 나오므로 스냅샷 테스트와 문서 예시에 그대로 쓸 수 있습니다.
  • 스키마에 example 을 적어 두면 Mock 값이 그 예시로 고정됩니다.
  • 요청 본문 Mock 은 POST·PUT 테스트 데이터로, 응답 Mock 은 프런트엔드 개발용 목 서버 응답으로 쓰세요.

자주 묻는 질문

랜덤 값인가요?

아니요. 스키마의 이름과 위치에서 결정적으로 계산하므로 같은 입력이면 같은 결과가 나옵니다.

oneOf 는 어떻게 처리하나요?

첫 번째 항목을 기준으로 만듭니다. 다른 항목이 필요하면 해당 스키마에 example 을 지정하세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
