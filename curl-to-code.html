자주 묻는 질문

어디서 cURL 명령어를 얻나요?

브라우저 개발자도구 Network 탭에서 요청을 우클릭 → Copy → Copy as cURL을 선택하면 얻을 수 있습니다.

복잡한 cURL 옵션도 다 지원하나요?

메서드(-X), 헤더(-H), 바디(-d/--data), 기본인증(-u)까지 지원합니다. 매우 특수한 옵션(--cookie-jar 등)은 인식하지 못할 수 있습니다.

입력한 cURL이 서버에 저장되나요?

아니요. 모든 변환은 브라우저 안에서만 이루어지며 입력값은 서버로 전송되지 않습니다.
