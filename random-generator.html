랜덤 문자열 · 난수 생성기

토큰·코드용 랜덤 문자열, 범위 안의 정수·실수, 목록에서 무작위 추첨과 섞기를 브라우저의 암호학적 난수로 만듭니다.

사용 예시

✅ 5개 생성 — 문자열당 약 95비트 엔트로피 (암호학적 난수)

입력 — 목록 (한 줄에 하나)

김민준
이서연
박지호
최유나
정현우

결과 — 결과

5T503r5l6WjAczCd
QWMRwSmat51cqAL6
21heEYIwo54EFOSH
j2GgK5lqWe3ptXaF
KVxWCpGUEOsP9c7h

이 도구로 할 수 있는 일

API 키 예시, 초대 코드, 테스트 데이터, 경품 추첨까지 "무작위"가 필요한 일은 많습니다. 이 도구는 예측할 수 없는 암호학적 난수(crypto.getRandomValues)만 사용합니다.

  • 랜덤 문자열: 영문+숫자, 소문자, 대문자, 숫자, 16진수, Base64url, 헷갈리는 문자 제외, 직접 입력한 문자 집합. 문자열당 엔트로피(비트) 표시
  • 랜덤 정수·실수: 범위와 개수 지정, 중복 없이 뽑기, 소수 자릿수
  • 목록 추첨: 한 줄에 하나씩 넣은 항목에서 n개를 뽑기(중복 허용/불허), 목록 전체 섞기(Fisher–Yates)
  • 모듈로 편향이 없도록 균일 분포로 뽑음

자주 묻는 질문

Math.random과 무엇이 다른가요?

Math.random은 예측 가능한 의사 난수라 보안 용도에 적합하지 않습니다. crypto.getRandomValues는 운영체제의 보안 난수원을 사용해 예측할 수 없습니다.

결과를 같은 값으로 재현할 수 있나요?

재현 가능한 시드 난수는 제공하지 않습니다. 재현이 필요한 테스트 데이터는 JSON 모의 데이터 생성기의 시드 기능을 이용하세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
