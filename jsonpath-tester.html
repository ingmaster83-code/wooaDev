JSONPath 테스터 — 값과 경로를 함께 확인

$.store.book[?(@.price < 10)].title 같은 JSONPath 식을 실행해 일치한 값과 그 경로를 바로 확인합니다.

사용 예시

✅ 2개 일치

입력 — JSON 데이터

{
  "store": {
    "book": [
      { "category": "reference", "author": "Nigel Rees", "title": "Sayings of the Century", "price": 8.95 },
      { "category": "fiction", "author": "Evelyn Waugh", "title": "Sword of Honour", "price": 12.99 },
      { "category": "fiction", "author": "Herman Melville", "title": "Moby Dick", "isbn": "0-553-21311-3", "price": 8.99 },
      { "category": "fiction", "author": "J. R. R. Tolkien", "title": "The Lord of the Rings", "isbn": "0-395-19395-8", "price": 22.99 }
    ],
    "bicycle": { "color": "red", "price": 399 }
  }
}

입력 — JSONPath 식

$.store.book[?(@.price < 10)].title

결과 — 일치 항목 (경로 + 값)

# | 경로 | 값
1 | $['store']['book'][0]['title'] | "Sayings of the Century"
2 | $['store']['book'][2]['title'] | "Moby Dick"

결과 — 값만 모은 JSON

[
  "Sayings of the Century",
  "Moby Dick"
]

이 도구로 할 수 있는 일

JSONPath는 JSON을 위한 쿼리 언어(RFC 9535)로, 설정 도구·API 게이트웨이·테스트 프레임워크에서 널리 쓰입니다. 식을 코드에 넣기 전에 실제 데이터로 확인해 보세요.

  • 기본: $.a.b, $['a'], $[0], $[-1], $.*, 합집합 $['a','b']
  • 재귀 탐색 $..price, 슬라이스 $[1:5:2], 역순 $[::-1]
  • 필터 [?(@.price < 10 && @.category == 'fiction')], 존재 검사 [?(@.isbn)], 정규식 [?(@.name =~ /^a/)]
  • 함수 length(), count(), match(), search() 지원
  • 일치한 항목마다 정규화된 경로($['store']['book'][0])를 함께 표시

자바스크립트 eval을 쓰지 않고 직접 해석하므로 입력한 식이 코드로 실행되지 않습니다.

💡 Tips

  • 필터에서 문자열은 작은따옴표나 큰따옴표로 감싸고, 숫자는 그대로 씁니다.
  • 결과 경로를 복사해서 JSON 포인터 도구나 코드의 접근 경로로 활용하세요.
  • $ 없이 a.b 만 입력해도 루트부터의 경로로 해석합니다.

자주 묻는 질문

JSONPath 구현마다 결과가 다르다던데요?

표준(RFC 9535)이 나오기 전의 구현들이 서로 달라서 필터 문법이나 .length 같은 부분이 다를 수 있습니다. 이 도구는 RFC 9535와 가장 널리 쓰이는 Goessner 문법을 함께 지원합니다.

입력한 식이 서버에서 실행되나요?

아니요. 브라우저 안에서 식을 직접 해석하며 서버로 전송하거나 자바스크립트 eval로 실행하지 않습니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
