💡 Tips

  • URL에 포함된 한글·특수문자를 %XX 형식으로 인코딩합니다.
  • query string의 값 부분만 인코딩하고 전체 URL은 인코딩하지 마세요.
  • 디코딩으로 %XX 형식의 URL을 읽기 쉽게 변환합니다.

자주 묻는 질문

URL 인코딩이 필요한 경우는 어떤 때인가요?

URL에 한글, 공백, 특수문자를 포함할 때 %XX 형식으로 인코딩해야 브라우저와 서버가 올바르게 처리합니다.

전체 URL을 인코딩하면 안 되는 이유는 무엇인가요?

/, ?, & 등 URL 구조 문자도 인코딩되어 URL이 깨집니다. 쿼리 파라미터 값 부분만 인코딩하세요.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 개인정보와 민감한 데이터가 외부로 유출될 걱정이 없으며, 기업 보안 환경에서도 안심하고 사용할 수 있습니다.
