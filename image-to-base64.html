💡 Tips

  • Base64로 변환하면 별도 파일 없이 HTML/CSS에 이미지를 직접 삽입할 수 있습니다.
  • 파일 크기가 클수록 Base64 문자열도 길어집니다 (원본 대비 약 33% 증가).
  • 작은 아이콘·로고에 적합하며, 큰 이미지는 일반 URL 방식을 권장합니다.
  • SVG는 Base64 외에도 url-encoded 방식으로 CSS에 넣을 수 있습니다.
  • 모든 변환은 브라우저 안에서만 처리됩니다. 파일이 서버로 전송되지 않습니다.
Data URL과 Base64만의 차이는?

Data URL은 data:image/png;base64,AAA... 형식으로 HTML img src나 CSS url()에 바로 사용할 수 있습니다. Base64만은 순수한 인코딩 문자열로, 별도 처리가 필요한 경우 사용합니다.

어떤 이미지 형식을 지원하나요?

PNG, JPG/JPEG, GIF, SVG, WebP, BMP, ICO 등 브라우저가 지원하는 모든 이미지 형식을 변환할 수 있습니다.

이미지가 서버에 업로드되나요?

아니요. 모든 처리는 브라우저 내 JavaScript로만 실행됩니다. 파일은 외부로 전송되지 않아 개인정보가 보호됩니다.

큰 이미지도 변환할 수 있나요?

기술적으로는 가능하지만, 대용량 이미지는 Base64 문자열이 매우 길어져 HTML/CSS 파일 크기가 크게 증가합니다. 일반적으로 10KB 미만의 이미지에 사용하는 것을 권장합니다.
