SQL INSERT 변환기 — INSERT에서 JSON · CSV로

mysqldump 나 SQL 파일의 INSERT INTO … VALUES (…),(…) 문을 읽어 열 이름이 붙은 JSON, CSV, JSON Lines 로 바꿉니다. 문자열 이스케이프, NULL, 숫자, 여러 문장을 처리합니다.

사용 예시

✅ users: 3행 · 6열

입력 — SQL INSERT 문

INSERT INTO users (id, name, email, active, score, note) VALUES
  (1, 'Kim', 'kim@example.com', true, 3.5, NULL),
  (2, 'O''Brien', 'ob@example.com', false, 10, 'says "hi", ok'),
  (3, '이영희', NULL, 1, -2, 'line1\nline2');
INSERT INTO `orders` (`id`, `user_id`) VALUES (10, 1), (11, 2);

결과 — 변환 결과

[
  {
    "id": 1,
    "name": "Kim",

결과 — 문장별 요약

테이블 | 행 | 열
users | 3 | id, name, email, active, score, note
orders | 2 | id, user_id

이 도구로 할 수 있는 일

덤프 파일의 INSERT 문을 스프레드시트나 코드에서 쓰고 싶을 때, DB 에 넣어 보지 않고 바로 변환합니다. 입력은 브라우저 밖으로 나가지 않습니다.

  • 다중 행 VALUES (…),(…) 와 여러 INSERT 문, 주석(-- , /* */) 처리
  • 값: 문자열('O''Brien', 백슬래시 이스케이프), 숫자(음수·지수), NULL, TRUE/FALSE, 함수 호출은 «…» 로 표시
  • 식별자: 백틱·큰따옴표·대괄호, db.table 형식에서 테이블 이름만 사용
  • 열 목록이 없으면 col1, col2 … 로 이름 부여, 열·값 개수가 다르면 오류
  • 테이블 이름 필터와 숫자·불리언을 JSON 타입으로 바꿀지 선택

💡 Tips

  • 대용량 덤프는 INSERT 한 문장에 수천 행이 들어 있을 수 있습니다. 필요한 테이블만 필터로 고르세요.
  • CSV 로 엑셀에서 열 때 한글이 깨지면 UTF-8 BOM 이 필요할 수 있습니다.
  • SELECT 결과를 INSERT 로 내보낸 파일이면 열 이름이 정확해 가장 변환이 잘 됩니다.

자주 묻는 질문

INSERT … SELECT 도 변환되나요?

아닙니다. VALUES 로 값이 직접 적힌 문장만 변환하고 SELECT 형태는 건너뜁니다.

ON DUPLICATE KEY UPDATE 가 있으면요?

해당 절은 무시하고 VALUES 의 행만 추출합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
