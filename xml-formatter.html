💡 XML 포맷터 사용법

  • 들여쓰기: 압축된 XML을 보기 좋게 정리합니다. 2칸/4칸 선택 가능.
  • 압축: 불필요한 공백을 제거해 파일 크기를 줄입니다.
  • 검증만: 포맷을 바꾸지 않고 XML 문법 오류만 확인합니다.
  • 모든 처리는 브라우저에서만 이루어지며 서버로 전송되지 않습니다.
  • XML 선언(<?xml version="1.0"?>)이 있으면 그대로 유지됩니다.

자주 묻는 질문

JSON 포맷터와 XML 포맷터의 차이는?

JSON은 자바스크립트 객체 표기법이고 XML은 태그 기반 마크업 언어입니다. XML은 속성, 네임스페이스, CDATA 등 JSON에 없는 개념이 있어 별도 파서가 필요합니다.

유효성 검사 오류가 발생하면?

태그 이름, 속성 따옴표, 닫힘 태그 누락 등을 확인하세요. 오류 메시지에 구체적인 위치가 표시됩니다.

대용량 XML도 처리되나요?

브라우저 메모리 내에서 처리되므로 수 MB 규모의 XML도 처리 가능합니다. 다만 매우 큰 파일은 처리 속도가 느려질 수 있습니다.
