XML 이스케이프 · 이스케이프 해제

& < > " ' 를 XML 엔티티로 바꾸거나 되돌립니다. 요소 텍스트, 큰따옴표/작은따옴표 속성, CDATA 중 사용 위치에 맞는 규칙으로 처리하고 XML 1.0 에서 허용되지 않는 제어 문자를 찾아 줍니다.

사용 예시

🔍 이스케이프 완료 · 금지 문자 제거됨

입력 — 텍스트

Tom & Jerry <"Cartoon"> it's 100% fun — 안녕 😀

결과 — 결과

Tom &amp; Jerry &lt;"Cartoon"&gt; it's 100% fun — 안녕 😀

결과 — 변환된 문자

원본 | 변환 | 설명 | 횟수
& | &amp; |  | 1
< | &lt; |  | 1
> | &gt; |  | 1

이 도구로 할 수 있는 일

XML·RSS·SVG·설정 파일에 텍스트를 넣을 때 깨지지 않도록 올바르게 이스케이프합니다. 처리는 브라우저 안에서 이루어집니다.

  • 위치별 규칙: 요소 텍스트(& < >), 속성(& < " 또는 '), CDATA(]]> 분할)
  • 비ASCII 문자를 &#10진수; 또는 &#x16진수; 로 변환하는 옵션
  • 해제: &amp; &lt; &gt; &quot; &apos; 와 숫자 문자 참조 &#65; &#x41;, 정의되지 않은 엔티티는 그대로 두고 알림
  • XML 1.0 에서 쓸 수 없는 제어 문자(0x00–0x08 등)를 감지
  • 변환된 문자 표

💡 Tips

  • XML 에는 &nbsp; 같은 HTML 엔티티가 없습니다. &#160; 처럼 숫자 참조를 쓰세요.
  • 속성 값은 쓰는 따옴표 종류에 맞춰 큰따옴표 또는 작은따옴표를 이스케이프합니다.
  • 제어 문자는 이스케이프로도 표현할 수 없으니 제거해야 합니다.

자주 묻는 질문

HTML 이스케이프와 같은가요?

기본 5개 엔티티는 같지만 XML 은 &nbsp; 등 HTML 이름 엔티티를 정의하지 않습니다.

CDATA 안에는 이스케이프가 필요 없나요?

내용은 그대로 두되 종료 표시 ]]> 만 ]]]]><![CDATA[> 로 분할해야 합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
