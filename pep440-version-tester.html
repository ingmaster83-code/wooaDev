PEP 440 파이썬 버전 비교 · 지정자 테스터

1.0rc1, 1.0.post1, 1!2.0 같은 파이썬 버전 문자열을 PEP 440 규칙으로 정규화·정렬하고, >=1.0,<2.0 · ~=1.4.2 · ==1.* 같은 지정자와 일치하는지, 일치하는 가장 높은 버전은 무엇인지 알려 줍니다.

사용 예시

🔍 11개 중 1개가 PEP 440 형식이 아닙니다

1.0

1.0rc1
1.0.dev3
1.1
1!0.5
2.0a1
2.0
2.0.1+ubuntu.1
1.0.0
not.a.version

입력 — 버전 지정자 (선택, 예: >=1.0,<2.0 · ~=1.0 · ==1.*)

>=1.0,<2.0

1.1

이 도구로 할 수 있는 일

pip 가 어떤 버전을 설치할지, 버전 문자열 순서가 어떻게 되는지 확인할 때 씁니다. 처리는 모두 브라우저 안에서 이루어집니다.

  • 정규화: 1.0-rc1 → 1.0rc1, 1.0.POST1 → 1.0.post1, 1.0.0 은 1.0 과 동일 비교
  • 정렬: dev < a < b < rc < 정식 < post, epoch(1!) 우선, 로컬 버전(+ubuntu.1) 처리
  • 지정자: ==, !=, <=, >=, <, >, ~=, ==1.*, ===, 콤마로 AND 결합
  • 프리릴리스는 지정자에 명시되지 않으면 기본 제외 (옵션으로 포함)
  • 형식이 잘못된 줄은 표에서 구분하고 일치하는 가장 높은 버전 출력

💡 Tips

  • ~=1.4.2 는 >=1.4.2,==1.4.* 와 같아서 1.5.0 은 허용하지 않습니다.
  • 1.0 과 1.0.0 은 같은 버전입니다. 문자열 정렬로 비교하면 1.10 이 1.9 보다 앞에 오는 실수가 생깁니다.
  • 프리릴리스를 받고 싶으면 pip install --pre 또는 지정자에 rc 를 명시하세요.

자주 묻는 질문

SemVer 와 PEP 440 은 같은가요?

비슷하지만 다릅니다. PEP 440 은 a, b, rc, dev, post 와 epoch, 로컬 버전을 지원하고 -beta.1 같은 표기는 정규화됩니다.

== 1.* 와 ~= 1.0 의 차이는요?

==1.* 는 1.x 전체, ~=1.0 은 >=1.0,==1.* 로 같지만 ~=1.0.0 은 1.0.x 로 더 좁아집니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
