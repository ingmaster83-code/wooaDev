AndroidManifest.xml 뷰어 · 보안 점검

AndroidManifest.xml 텍스트나 APK 에서 꺼낸 바이너리 매니페스트(AXML)를 16진수·Base64·파일로 넣으면 XML 로 복원하고, 패키지·SDK 버전, 권한, 액티비티·서비스·리시버·프로바이더와 인텐트 필터를 표로 정리합니다. exported 누락, debuggable, 평문 HTTP 같은 문제도 찾아 줍니다.

사용 예시

⛔ 오류 2건 · 경고 6건 — com.wooahouse.demo

입력 — AndroidManifest.xml (텍스트) 또는 APK 안의 바이너리 매니페스트 (16진수 / Base64)

<?xml version="1.0" encoding="utf-8"?>
<manifest xmlns:android="http://schemas.android.com/apk/res/android"
    package="com.wooahouse.demo"
    android:versionCode="12"
    android:versionName="1.2.0">

    <uses-sdk android:minSdkVersion="24" android:targetSdkVersion="34" />

    <uses-permission android:name="android.permission.INTERNET" />
    <uses-permission android:name="android.permission.CAMERA" />
    <uses-permission android:name="android.permission.ACCESS_BACKGROUND_LOCATION" />
    <uses-permission android:name="android.permission.READ_SMS" />
    <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />

    <application
        android:name=".App"
        android:label="Wooa Demo"
        android:debuggable="true"
        android:usesCleartextTraffic="true">

        <activity android:name=".MainActivity">
            <intent-filter>
…

이 도구로 할 수 있는 일

APK 를 디컴파일하지 않고도 매니페스트를 읽고 보안 설정을 점검합니다. 파일은 서버로 전송되지 않습니다.

  • 입력: 텍스트 XML, APK 안의 바이너리 AXML(UTF-8/UTF-16 문자열 풀), 16진수·Base64·파일
  • 정보: 패키지, versionName/Code, minSdk·targetSdk·compileSdk, 앱 라벨, Application 클래스
  • 권한: 일반·위험(런타임)·민감 분류, 중복, 사용자 정의 권한의 보호 수준
  • 컴포넌트: 종류, 이름, exported, 보호 권한, 인텐트 필터(action·category·data), 딥 링크 autoVerify
  • 점검: targetSdk 31+ exported 누락(설치 실패), debuggable, allowBackup, cleartext, 공개 provider·service, 낮은 targetSdk

💡 Tips

  • targetSdk 31 이상에서는 intent-filter 가 있는 모든 컴포넌트에 android:exported 를 명시해야 설치됩니다.
  • 릴리스 APK 의 debuggable 이 true 이면 누구나 앱 데이터에 접근할 수 있습니다. 빌드 변형을 확인하세요.
  • Gradle 병합 후 최종 매니페스트는 app/build/intermediates 또는 APK Analyzer 에서 꺼내 확인하세요.

자주 묻는 질문

리소스 참조(@0x7f…)는 이름으로 바뀌나요?

resources.arsc 는 읽지 않으므로 @0x7f… 숫자 그대로 표시됩니다. 라벨 등 문자열 리소스의 실제 값은 알 수 없습니다.

AAB 나 APK 파일을 통째로 넣어도 되나요?

아니요. APK 는 zip 이라 AndroidManifest.xml 파일만 꺼내서 넣어야 합니다. 이 도구는 zip 을 풀지 않습니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
