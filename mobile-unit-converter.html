모바일 단위 · 색상 변환기 (dp · sp · px · pt)

화면 밀도(mdpi~xxxhdpi)에 따라 dp·sp·px·pt 를 변환하고 밀도별 에셋 크기를 계산합니다. 색상은 #AARRGGBB, CSS rgba, Flutter Color, iOS UIColor, SwiftUI, Android XML 표기를 한 번에 보여 줍니다.

사용 예시

✅ 16 dp = 48 px (480 dpi)

입력 — 값

16

입력 — 색상 (#RRGGBB, #AARRGGBB, rgba(), 0xAARRGGBB)

#80FF5722

결과 — 변환 결과

단위 | 값
px | 48 px
dp (Android) | 16 dp
sp (Android) | 16 sp
pt (iOS) | 16 pt
물리 크기 | 2.54 mm (0.1 in)
밀도 배율 | 3× (480 dpi)
ldpi (120) | 12 px  → drawable-ldpi
mdpi (160) | 16 px  → drawable-mdpi
hdpi (240) | 24 px  → drawable-hdpi
xhdpi (320) | 32 px  → drawable-xhdpi
xxhdpi (480) | 48 px  → drawable-xxhdpi
xxxhdpi (640) | 64 px  → drawable-xxxhdpi

결과 — 코드

Android XML : 16dp  /  16sp
Compose     : 16.dp  /  16.sp
Flutter     : 16  (logical pixels)
SwiftUI/UIKit: 16 pt
CSS (1x web): 16px

이 도구로 할 수 있는 일

안드로이드·iOS·플러터 디자인 값을 옮길 때 단위와 색상 표기를 일일이 계산하지 않아도 됩니다.

  • 단위: px = dp × (dpi ÷ 160), sp 는 글꼴 배율 반영, pt 는 iOS 논리 단위(1pt = 1dp 로 취급)
  • 밀도 표: ldpi~xxxhdpi 별 픽셀 크기와 drawable-밀도 폴더, iOS @1x~@3x
  • 물리 크기(mm·inch)와 터치 대상 최소 크기(Android 48dp, iOS 44pt) 안내
  • 색상: #RRGGBB, #RRGGBBAA(CSS), #AARRGGBB(Android), rgba(), 0xAARRGGBB 입력 → 모든 표기와 HSL
  • 출력: Flutter Color, UIColor, SwiftUI Color, Color.argb, Android XML, Compose

💡 Tips

  • 8자리 색상은 CSS 는 #RRGGBBAA, Android/Flutter 는 #AARRGGBB 로 알파 위치가 반대입니다.
  • 아이콘은 xxhdpi 기준으로 만들고 나머지 밀도는 자동 축소하는 방식이 흔합니다.
  • sp 는 사용자의 글꼴 크기 설정을 따르므로 텍스트에만 쓰고 레이아웃 크기에는 dp 를 쓰세요.

자주 묻는 질문

dp 와 sp 의 차이는요?

dp 는 화면 밀도에 독립적인 길이이고, sp 는 거기에 사용자의 글꼴 크기 설정까지 곱한 값입니다.

iOS 의 pt 는 px 인가요?

아닙니다. pt 는 논리 단위이고 기기 배율(@2x, @3x)에 따라 픽셀이 됩니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
