JSON 키 추출기 — 특정 키의 값 모아보기·필터링

JSON 어디에 있든 지정한 키의 값을 찾아 경로와 함께 모으고, 특정 키만 남기거나 제거하거나 사용된 모든 키를 나열합니다.

사용 예시

✅ 7곳에서 찾았습니다

입력 — JSON 입력

{
  "id": 1,
  "name": "Kim",
  "email": "kim@example.com",
  "orders": [
    { "id": 10, "total": 3200, "items": [{ "id": 1, "name": "pen" }] },
    { "id": 11, "total": 900, "items": [] }
  ],
  "profile": { "id": "p-1", "email": "k@work.com" }
}

입력 — 키 이름 (쉼표·공백으로 여러 개)

id, email

결과 — 결과 목록

경로 | 키 | 값
$.id | id | 1
$.email | email | "kim@example.com"
$.orders[0].id | id | 10
$.orders[0].items[0].id | id | 1
$.orders[1].id | id | 11
$.profile.id | id | "p-1"
$.profile.email | email | "k@work.com"

결과 — JSON 결과

[
  1,
  "kim@example.com",
  10,
  1,
  11,
  "p-1",
  "k@work.com"
]

이 도구로 할 수 있는 일

큰 API 응답에서 id 값만 모으거나, 민감한 키(password, token)를 지우고 공유하고 싶을 때가 있습니다. 경로를 일일이 쓰지 않고 키 이름만 입력하면 됩니다.

  • 찾기(재귀): 어느 깊이에 있든 그 이름의 키를 모두 찾아 경로·값을 표로 표시
  • 남기기: 지정한 키만 남기고 나머지는 제거 (구조는 유지)
  • 제거하기: 지정한 키를 모든 깊이에서 삭제
  • 키 목록: 사용된 모든 키를 등장 횟수와 값 타입과 함께 나열

정확한 경로로 값을 뽑아야 한다면 JSONPath 테스터나 JMESPath 테스트기를 사용하세요.

함께 쓰면 좋은 도구

💡 Tips

  • 공유 전 민감 정보를 지울 때는 "제거하기"에 password, token, secret 등을 쉼표로 넣으세요.
  • "키 목록"은 처음 보는 API 응답의 전체 필드를 빠르게 파악할 때 좋습니다.
  • 대소문자 무시 옵션으로 userId / userid 같은 표기 차이를 한꺼번에 찾을 수 있습니다.

자주 묻는 질문

키 이름이 같지만 위치가 다른 값도 모두 나오나요?

네. 객체와 배열을 끝까지 탐색해 일치하는 모든 키를 경로와 함께 보여 줍니다.

"남기기"에서 부모 객체는 어떻게 되나요?

지정한 키를 가진 항목까지의 경로는 유지하고, 해당 키가 하나도 없는 가지는 결과에서 빠집니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
