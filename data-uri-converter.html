Data URI 변환기 — data: URL 만들기·해석

텍스트나 파일을 data:URL(Base64 또는 퍼센트 인코딩)로 만들고, 기존 Data URI를 해석해 내용과 MIME 타입을 확인합니다.

사용 예시

✅ 변환 완료

입력 — 입력

<svg xmlns="http://www.w3.org/2000/svg" width="40" height="40"><circle cx="20" cy="20" r="18" fill="#C4956A"/></svg>

결과 — 결과

data:image/svg+xml;charset=utf-8,%3Csvg%20xmlns=%22http://www.w3.org/2000/svg%22%20width=%2240%22%20height=%2240%22%3E%3Ccircle%20cx=%2220%22%20cy=%2220%22%20r=%2218%22%20fill=%22%23C4956A%22/%3E%3C/svg%3E

결과 — 정보

MIME: image/svg+xml
원본: 116 bytes
Data URI 길이: 205자
CSS에서: url("data:image/svg+xml;charset=utf-8,%3Csvg%20xmlns=%22http://www.w3.org/2000/svg%22%20width=%2240%22%20height=%2240%22%3E%3Ccircle%20cx=%2220%22%20cy=%2220%22%20r=%2218%22%20fill=%22%23C4956A%22/%3E%3C/s…")

이 도구로 할 수 있는 일

작은 이미지나 SVG, CSS·JS 조각을 별도 요청 없이 HTML·CSS에 직접 넣을 때 Data URI를 씁니다. 반대로 코드에서 발견한 긴 data: 문자열의 정체를 확인할 때도 필요합니다.

  • 텍스트 → Data URI: MIME 타입 선택(svg, html, json, css, js 등), Base64 또는 퍼센트 인코딩 선택
  • 파일 → Data URI: 이미지·폰트·PDF 등 어떤 파일이든 Base64 Data URI로 변환
  • Data URI → 내용: MIME, charset, 인코딩 방식, 디코딩된 크기를 표시하고 텍스트면 내용을, 바이너리면 16진수를 출력
  • 이미지 Data URI는 투명 배경 위에 미리보기

SVG처럼 텍스트 기반 파일은 퍼센트 인코딩이 Base64보다 짧고 gzip에도 유리합니다.

함께 쓰면 좋은 도구

🖼️이미지 → Base64 🔐Base64 🔗URL 인코더 🔤HTML Entity 인코더

💡 Tips

  • CSS에서는 url("data:image/svg+xml,...") 형태로 퍼센트 인코딩 SVG를 바로 쓸 수 있습니다.
  • Base64 Data URI는 원본보다 약 33% 커지므로 수 KB 이상의 파일에는 권장하지 않습니다.
  • 이미지 파일만 변환한다면 이미지 → Base64 변환기도 있습니다.

자주 묻는 질문

Data URI는 크기 제한이 있나요?

브라우저마다 다르지만 대부분 수 MB까지 처리합니다. 다만 HTML·CSS 파일이 커지고 캐시를 활용할 수 없으므로 작은 리소스에만 사용하는 것이 좋습니다.

charset=utf-8은 꼭 필요한가요?

텍스트(HTML, JSON 등)에서 한글 같은 비ASCII 문자가 있다면 지정하는 것이 안전합니다. SVG는 XML 선언으로 인코딩이 정해져 생략해도 됩니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
