.gitignore 테스터 — 어떤 규칙이 적용되는가

.gitignore 내용과 확인할 경로를 넣으면 각 경로가 무시되는지, 어떤 줄의 규칙 때문인지, 부정(!) 규칙이 왜 먹히지 않는지를 Git과 같은 규칙으로 판정해 보여 줍니다.

사용 예시

✅ 10개 중 6개가 무시됩니다

입력 — .gitignore 내용

# 빌드 산출물
node_modules/
dist/
*.log
.env
!.env.example
/config/*.local
build/**/*.map
!important.log

입력 — 확인할 경로 (한 줄에 하나, 폴더는 끝에 /)

node_modules/express/index.js
dist/app.js
src/debug.log
important.log
.env
.env.example
config/db.local
config/sub/db.local
build/js/main.js.map
src/index.js

결과 — 판정 결과

경로 | 결과 | 근거 규칙 | 설명
node_modules/express/index.js | 🚫 무시됨 | 2: node_modules/ | 상위 폴더 node_modules/ 가 무시되어 안의 파일은 모두 무시됩니다 (줄 2)
dist/app.js | 🚫 무시됨 | 3: dist/ | 상위 폴더 dist/ 가 무시되어 안의 파일은 모두 무시됩니다 (줄 3)
src/debug.log | 🚫 무시됨 | 4: *.log | 줄 4 규칙과 일치
important.log | ✅ 추적됨 | 9: !important.log | 줄 9 의 ! 규칙이 다시 포함시킴
.env | 🚫 무시됨 | 5: .env | 줄 5 규칙과 일치
.env.example | ✅ 추적됨 | 6: !.env.example | 줄 6 의 ! 규칙이 다시 포함시킴
config/db.local | 🚫 무시됨 | 7: /config/*.local | 줄 7 규칙과 일치
config/sub/db.local | ✅ 추적됨 | — | 일치하는 규칙 없음 → 추적됨
build/js/main.js.map | 🚫 무시됨 | 8: build/**/*.map | 줄 8 규칙과 일치
src/index.js | ✅ 추적됨 | — | 일치하는 규칙 없음 → 추적됨

결과 — git check-ignore -v 형식

.gitignore:2:node_modules/	node_modules/express/index.js
.gitignore:3:dist/	dist/app.js
.gitignore:4:*.log	src/debug.log
.gitignore:9:!important.log	important.log

::	config/sub/db.local

이 도구로 할 수 있는 일

'분명히 .gitignore에 넣었는데 계속 추적돼요', '!로 다시 포함했는데 안 돼요' 같은 문제를 규칙별로 추적합니다. 모든 판정은 브라우저에서 이뤄집니다.

  • 각 경로의 결과: 무시됨/추적됨, 근거가 된 줄 번호와 규칙, 이유 설명
  • git check-ignore -v 와 같은 형식의 출력 제공
  • 지원 문법: *, ?, [abc], [!abc], **/, /**/, 끝의 /**, 앞의 / (루트 고정), 끝의 / (폴더 전용), \# 와 \! 이스케이프
  • 상위 폴더가 무시되면 안의 파일을 ! 로 다시 포함할 수 없다는 Git 규칙을 경고
  • core.ignorecase(대소문자 구분 안 함) 옵션

💡 Tips

  • 이미 커밋된 파일은 .gitignore에 추가해도 계속 추적됩니다. git rm --cached 파일 로 추적을 해제하세요.
  • 폴더 안의 일부만 남기려면 dir/ 대신 dir/* 로 무시하고 !dir/keep.txt 로 되살립니다.
  • 하위 폴더의 .gitignore, .git/info/exclude, 전역 ignore 는 이 도구가 반영하지 않으니 한 파일씩 테스트하세요.

자주 묻는 질문

왜 !로 다시 포함해도 무시되나요?

상위 폴더 자체가 무시되면 Git은 그 폴더 안을 아예 보지 않아서입니다. dir/ 대신 dir/* 로 쓰면 폴더는 열어 두고 내용만 무시할 수 있습니다.

build 와 build/ 는 다른가요?

build/ 는 폴더에만 적용되고, build 는 같은 이름의 파일과 폴더 모두에 적용됩니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
