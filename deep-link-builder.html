모바일 딥 링크 · Intent URI 생성기

myapp://product/42 같은 커스텀 스킴, https 유니버설 링크/앱 링크, 앱이 없을 때 대체 URL 이 있는 Android intent:// URI 를 한 번에 만들고, AndroidManifest·assetlinks.json·AASA 설정 예시와 테스트 명령을 제공합니다.

사용 예시

✅ 딥 링크를 만들었습니다

입력 — 쿼리 파라미터 (한 줄에 key=value)

id=42
ref=email campaign
utm_source=news

입력 — 분석할 링크 (URL 또는 intent:// URI)

intent://product/42?ref=mail#Intent;scheme=myapp;package=com.example.shop;S.browser_fallback_url=https%3A%2F%2Fshop.example.com%2Fproduct%2F42;end

결과 — 링크

# 커스텀 스킴 (iOS/Android)
myapp://product/42?id=42&ref=email%20campaign&utm_source=news

# 유니버설 링크(iOS) / 앱 링크(Android)
https://shop.example.com/product/42?id=42&ref=email%20campaign&utm_source=news

# Android Intent URI (Chrome 에서 앱 열기 + 대체 URL)
intent://product/42?id=42&ref=email%20campaign&utm_source=news#Intent;scheme=myapp;package=com.example.shop;S.browser_fallback_url=https%3A%2F%2Fplay.google.com%2Fstore%2Fapps%2Fdetails%3Fid%3Dcom.example.shop;end

# 테스트 명령
adb shell am start -a android.intent.action.VIEW -d "myapp://product/42?id=42&ref=email%20campaign&utm_source=news" com.example.shop
xcrun simctl openurl booted "myapp://product/42?id=42&ref=email%20campaign&utm_source=news"
adb shell am start -a android.intent.action.VIEW -d "https://shop.example.com/product/42?id=42&ref=email%20campaign&utm_source=news"
xcrun simctl openurl booted "https://shop.example.com/product/42?id=42&ref=email%20campaign&utm_source=news"

결과 — 구성 요소

항목 | 값
scheme | myapp
host | product
path | /42
query | id, ref, utm_source
web | shop.example.com
package | com.example.shop

이 도구로 할 수 있는 일

앱 안의 특정 화면을 여는 링크를 플랫폼마다 따로 만들 때 쓰입니다.

  • 만들기: 스킴·호스트·경로·쿼리(자동 퍼센트 인코딩)·웹 도메인·Android 패키지·대체 URL
  • 출력: 커스텀 스킴 URL, 유니버설/앱 링크 https URL, intent://…#Intent;scheme=…;package=…;S.browser_fallback_url=…;end
  • 설정 예시: AndroidManifest intent-filter(autoVerify), assetlinks.json, apple-app-site-association, iOS Associated Domains
  • 테스트: adb shell am start -a VIEW -d, xcrun simctl openurl booted
  • 분석 모드: URL 또는 intent URI 를 구성 요소로 분해하고 package·fallback 누락 점검

💡 Tips

  • 로그인 토큰 같은 민감한 값은 커스텀 스킴으로 전달하지 마세요. 다른 앱이 같은 스킴을 가로챌 수 있습니다.
  • Android 12+ 에서는 앱 링크 도메인 검증(assetlinks.json)을 통과해야 웹 링크가 앱으로 열립니다.
  • iOS 의 apple-app-site-association 파일은 확장자 없이 application/json 으로 서비스해야 합니다.

자주 묻는 질문

커스텀 스킴과 유니버설 링크 중 무엇을 써야 하나요?

유니버설/앱 링크가 안전하고 앱이 없으면 웹으로 연결됩니다. 커스텀 스킴은 설정이 간단하지만 앱이 없으면 열리지 않습니다.

intent:// 는 어디서 쓰나요?

Android Chrome 같은 브라우저에서 앱을 열고 실패 시 대체 URL 로 보내는 용도입니다. iOS 에서는 동작하지 않습니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
