벡터 유사도 · 거리 계산기 (임베딩 비교)

임베딩 벡터 A 와 B 를 붙여 넣으면 코사인 유사도, 코사인 거리, 내적, 사잇각, L1·L2·L∞ 거리와 크기를 계산합니다. 비교할 벡터를 더 넣으면 A 와 가까운 순서로 순위를 매겨 줍니다.

사용 예시

✅ cosine = 0.991798 · L2 = 0.160935

입력 — 벡터 A (쉼표·공백·JSON 배열)

[0.12, -0.53, 0.91, 0.07, 0.44]

입력 — 벡터 B

0.10, -0.48, 0.85, 0.20, 0.39

입력 — 비교할 다른 벡터들 (한 줄에 하나, 선택)

0.9 0.1 -0.2 0.5 0.0
-0.12, 0.53, -0.91, -0.07, -0.44

결과 — 유사도 · 거리

지표 | 값
차원 | 5
|A| (L2) | 1.149739
|B| (L2) | 1.074709
내적 A·B | 1.2255
코사인 유사도 | 0.991798
코사인 거리 (1 − cos) | 0.008202
사잇각 | 7.343571°
유클리드 거리 (L2) | 0.160935
맨해튼 거리 (L1) | 0.31
체비쇼프 거리 (L∞) | 0.13
정규화된 A·B 의 유클리드 거리 | 0.128082

결과 — A 와 비교한 순위

순위 | 벡터 | 코사인 | 유클리드 | 값
1 | B | 0.991798 | 0.160935 | 벡터 B
2 | #1 | -0.07595 | 1.617374 | 0.9 0.1 -0.2 0.5 0.0
3 | #2 | -1 | 2.299478 | -0.12, 0.53, -0.91, -0.07, -0.44

이 도구로 할 수 있는 일

임베딩 값 두 개가 얼마나 비슷한지 눈으로 확인하고 싶을 때 씁니다. 벡터는 브라우저에서만 처리됩니다.

  • 입력: 쉼표·공백으로 구분한 숫자나 [0.1, -0.2] 같은 JSON 배열, 소수 자릿수 선택
  • 지표: 코사인 유사도·거리(1 − cos), 내적, 사잇각(도), L2·L1·L∞ 거리, 각 벡터의 크기
  • 순위: 비교할 벡터를 한 줄에 하나씩 넣으면 A 와의 코사인 유사도 순서로 정렬 (차원이 다르면 제외 표시)
  • 단위 벡터면 내적이 코사인 유사도와 같다는 안내, 영벡터는 코사인이 정의되지 않음
  • 차원이 다르거나 숫자가 아닌 값은 오류

💡 Tips

  • 임베딩 API 는 보통 정규화된 벡터를 줍니다. 이때는 내적과 코사인 유사도가 같습니다.
  • 거리 지표는 작을수록, 유사도는 클수록 비슷합니다.
  • 서로 다른 모델의 임베딩은 비교할 수 없습니다. 같은 모델의 같은 차원만 비교하세요.

자주 묻는 질문

코사인 유사도와 유클리드 거리 중 무엇을 써야 하나요?

텍스트 임베딩은 방향이 의미를 나타내므로 코사인 유사도가 일반적입니다. 크기가 중요하면 L2 도 함께 보세요.

1536차원 벡터도 되나요?

붙여 넣을 수 있는 한 계산됩니다. 숫자 수천 개는 브라우저에서 즉시 처리됩니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
