JSON Lines (NDJSON) 뷰어 · 변환기

한 줄에 JSON 하나씩인 JSONL/NDJSON 로그를 붙여 넣으면 표로 펼쳐 보여 주고, 필터링하고, JSON 배열·CSV·들여쓰기한 형식으로 변환합니다. 깨진 줄은 줄 번호와 이유를 알려 줍니다.

사용 예시

🔍 유효 4줄 · 오류 1줄

입력 — JSON Lines / NDJSON (한 줄에 JSON 하나)

{"ts":"2026-10-16T09:00:01Z","level":"info","msg":"server started","port":8080}
{"ts":"2026-10-16T09:00:05Z","level":"warn","msg":"slow query","ms":1450,"tags":["db","orders"]}
{"ts":"2026-10-16T09:00:09Z","level":"error","msg":"payment failed","order":{"id":42,"amount":19.9}}
{"ts":"2026-10-16T09:00:10Z","level":"info","msg":"retry" 

{"ts":"2026-10-16T09:00:12Z","level":"info","msg":"done"}

이 도구로 할 수 있는 일

구조화 로그나 AI 학습 데이터(JSONL)를 편집기 없이 바로 훑어볼 때 씁니다. 데이터는 브라우저 안에서만 처리됩니다.

  • 표: 모든 줄의 키 합집합을 열로, 중첩 객체는 a.b 열로 펼치기(선택)
  • 필터: 줄에 포함된 텍스트로 걸러 보기
  • 변환: JSON 배열, CSV, 들여쓰기 JSON Lines, 유효한 줄만 다시 JSONL
  • 오류: 줄 번호별 파싱 오류, 빈 줄, 최상위가 객체가 아닌 값, 열 불일치
  • 줄 수·열 수 등 통계

💡 Tips

  • 한 줄이 두 줄로 나뉘면 JSON 이 깨집니다. JSONL 은 각 줄이 독립된 완전한 JSON 이어야 합니다.
  • AI 파인튜닝용 JSONL 은 각 줄의 구조가 같은지 열 불일치를 확인하세요.
  • 대용량 로그는 jq 나 DuckDB 가 더 효율적입니다.

자주 묻는 질문

NDJSON 과 JSON Lines 는 같은가요?

사실상 같은 형식입니다. 한 줄에 JSON 값 하나, 줄 구분은 \n 입니다.

JSON 배열 하나를 넣으면요?

배열 전체를 한 줄로 보지 않고, JSONL 이 아니라는 안내와 함께 배열 요소를 줄로 처리하는지 확인하세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
