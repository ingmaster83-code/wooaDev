RSA · EC · Ed25519 키 쌍 생성기

Web Crypto 로 RSA(2048~4096), ECDSA(P-256·384·521), Ed25519 키 쌍을 브라우저 안에서 만들고 PKCS#8 개인키 PEM, SPKI 공개키 PEM, JWK, SSH authorized_keys 한 줄과 지문을 한 번에 보여 줍니다.

사용 예시

✅ ECDSA P-256 키 쌍을 만들었습니다

입력 — SSH 공개키 주석 (선택, 예: you@host)

test@wooadev

결과 — 키 정보

항목 | 값
종류 | ECDSA P-256
SSH 지문 | SHA256:ws/d956/pXhZ832xMXnKyyHYD00pa/WTr+bDLg0ZhPs
JWK 지문 (RFC 7638) | 0OoiuxTc-ST93Ie5jOTGVKwfYXCg8QPEqyfeaftuqWg
개인키 형식 | PKCS#8 (-----BEGIN PRIVATE KEY-----)
공개키 형식 | SubjectPublicKeyInfo (-----BEGIN PUBLIC KEY-----)

결과 — SSH 공개키 (authorized_keys 한 줄)

ecdsa-sha2-nistp256 AAAAE2VjZHNhLXNoYTItbmlzdHAyNTYAAAAIbmlzdHAyNTYAAABBBIB/RjQIXC4Y19FkBwFKibghnSNIEQqwJOvvbRA1A1epjO6eOVA/QBICgFxg/wpyD9Y87sE9E9i4vo6EoBv/YVE= test@wooadev

이 도구로 할 수 있는 일

개발·테스트에 필요한 키 쌍을 설치 없이 만들 때 씁니다. 키는 브라우저 안에서만 만들어지고 전송되지 않습니다.

  • 키 종류: ECDSA P-256·P-384·P-521, Ed25519, RSA 2048·3072·4096
  • 출력: 개인키(PKCS#8 PEM), 공개키(SPKI PEM), JWK(개인키·공개키 구분), SSH authorized_keys 한 줄
  • 지문: SSH SHA256 지문(ssh-keygen -lf 와 동일), JWK RFC 7638 지문
  • 생성된 공개키는 openssl pkey -pubout 과 일치하는 표준 형식
  • 화면에 나온 키는 운영에 쓰지 말라는 안내와 Ed25519 지원 브라우저 안내

함께 쓰면 좋은 도구

📝CSR 생성·해석기 🗝️SSH 공개키 검사기 🧷JWK ↔ PEM 변환기 🧂비밀번호 해시 생성·검증 (bcrypt·Argon2·scrypt)

💡 Tips

  • JWT 서명 테스트에는 ECDSA P-256(ES256)이나 Ed25519 가 짧고 빠릅니다.
  • SSH 공개키 한 줄은 ~/.ssh/authorized_keys 에 그대로 붙이고, 개인키 PEM 은 chmod 600 으로 저장하세요.
  • RSA 4096 은 생성에 몇 초가 걸릴 수 있습니다.

자주 묻는 질문

여기서 만든 키를 운영에 써도 되나요?

권장하지 않습니다. 운영 키는 서버나 HSM·KMS 에서 직접 만드세요. 이 도구는 테스트와 학습용입니다.

개인키는 서버로 전송되나요?

아니요. 모든 것이 브라우저의 Web Crypto 로 처리되며 페이지를 닫으면 사라집니다. 필요하면 바로 복사해 두세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
