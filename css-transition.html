CSS Transition 생성기

transition 속성을 슬라이더로 조정하고 실시간 미리보기로 확인하세요

적용 속성

Easing (Timing Function)

클릭

박스를 클릭하면 효과를 미리볼 수 있습니다

복사됨!

💡 Tips

  • ease-in-out: 자연스러운 UI 전환에 가장 많이 사용됩니다
  • cubic-bezier: 직접 입력해 완전히 커스텀한 곡선을 만들 수 있습니다
  • all 대신 특정 속성만 지정하면 성능 최적화에 도움이 됩니다
  • 여러 속성을 쉼표로 연결: transition: opacity 0.3s, transform 0.5s;

자주 묻는 질문

transition과 animation의 차이는?
transition은 두 상태 사이의 전환을 정의하고, animation은 keyframe을 사용해 복잡한 여러 단계 애니메이션을 정의합니다. 간단한 hover 효과에는 transition이 적합합니다.
will-change 속성을 함께 사용해야 하나요?
transform, opacity에는 will-change: transform을 추가하면 GPU 가속으로 성능이 향상됩니다. 단, 남용하면 메모리 소비가 늘어납니다.
