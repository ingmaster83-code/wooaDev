IP 범위 → CIDR 변환기

192.168.1.5 - 192.168.1.200 처럼 시작과 끝 IP로 주어진 범위를 가장 적은 수의 CIDR 블록으로 나눕니다. IPv6도 지원합니다.

사용 예시

✅ 4줄 처리 — CIDR 18개

입력 — IP 범위 (시작 - 끝) 또는 CIDR (한 줄에 하나)

192.168.1.5 - 192.168.1.200
10.0.0.0 - 10.0.3.255
203.0.113.0/28
2001:db8::1 - 2001:db8::ff

결과 — 변환 결과

192.168.1.5 - 192.168.1.200 | 9개 | 192.168.1.5/32, 192.168.1.6/31, 192.168.1.8/29, 192.168.1.16/28, 192.168.1.32/27, 192.168.1.64/26, 192.168.1.128/26, 192.168.1.192/29, 192.168.1.200/32 | 196

이 도구로 할 수 있는 일

WHOIS나 ISP가 알려 주는 IP 대역은 "1.2.3.0 - 1.2.3.255" 같은 범위인데, 방화벽·클라우드 설정은 CIDR만 받는 경우가 많습니다.

  • 범위를 정렬 규칙에 맞는 가장 큰 블록부터 잘라 최소 개수의 CIDR로 표현
  • 딱 맞는 대역이면 하나(10.0.0.0 - 10.0.3.255 → 10.0.0.0/22), 어긋나면 여러 개로 분해
  • CIDR을 넣으면 시작·끝 주소와 주소 수를 확인, IPv6 범위도 가능
  • 오류(시작>끝, IPv4/IPv6 혼합, 형식 오류)는 줄마다 이유를 표시

💡 Tips

  • 결과 CIDR 모음을 복사해 방화벽 규칙에 한 줄씩 붙여 넣으세요.
  • 범위를 여러 개 합쳐서 정리하려면 CIDR 집합 계산기의 병합 기능을 쓰세요.
  • 시작 주소가 블록 경계에 맞지 않으면 작은 블록이 앞뒤로 생기는 것이 정상입니다.

자주 묻는 질문

결과가 왜 하나가 아니라 여러 개인가요?

CIDR은 크기가 2의 거듭제곱이고 시작 주소가 그 크기의 배수여야 합니다. 범위가 이 규칙에 맞지 않으면 여러 블록으로 나눠야 같은 범위를 정확히 표현할 수 있습니다.

0.0.0.0 - 255.255.255.255는요?

0.0.0.0/0 하나로 표현됩니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
