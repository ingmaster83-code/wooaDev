Base 인코딩 변환기 — Base16 · Base32 · Base58 · Base85

텍스트나 16진수 바이트를 Base16, Base32, Base58, Base85(Ascii85·Z85)로 인코딩하고 다시 디코딩합니다.

이 도구로 할 수 있는 일

Base64 말고도 용도에 따라 여러 Base 인코딩이 쓰입니다. 이 도구 하나로 모두 변환할 수 있습니다.

  • Base16(Hex): 바이트를 16진수로. 대소문자 선택
  • Base32: RFC 4648 표준, base32hex, Crockford(헷갈리는 문자 제외). TOTP 비밀키가 이 형식, = 패딩 선택
  • Base58: 비트코인 알파벳(0·O·I·l 제외), Flickr, Ripple. 선행 0 바이트도 보존
  • Base85: Ascii85(Adobe, PDF·PostScript)와 Z85(ZeroMQ, 4바이트 배수)
  • 입력은 UTF-8 텍스트 또는 16진수 바이트, 디코딩 결과는 텍스트 또는 16진수로 확인

Base64는 Base64 인코더, 2진수는 텍스트 ↔ 바이너리 변환기를 사용하세요.

💡 Tips

  • 구글 OTP 같은 2단계 인증 비밀키는 Base32입니다. 공백·소문자도 그대로 붙여 넣어도 디코딩됩니다.
  • 디코딩 결과가 텍스트가 아니면(이진 데이터) 자동으로 16진수로 표시합니다.
  • Z85는 입력 길이가 4바이트의 배수여야 합니다.

자주 묻는 질문

Base58은 왜 쓰나요?

0, O, I, l처럼 헷갈리는 문자와 +, / 를 뺀 알파벳이라 사람이 옮겨 적기 쉽고 URL에도 안전합니다. 비트코인 주소와 IPFS 해시 등에 쓰입니다.

Base32와 Base64의 차이는 무엇인가요?

Base32는 영문 대문자와 숫자 2–7만 써서 대소문자 구분이 없는 환경에 안전하지만 결과가 원본보다 약 60% 길어집니다(Base64는 약 33%). Base64는 더 짧고 대소문자를 구분합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
