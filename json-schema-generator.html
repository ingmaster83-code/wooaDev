JSON 스키마 생성기 — 샘플에서 JSON Schema 만들기

JSON 샘플(여러 개 가능)에서 타입, required, format을 추론해 JSON Schema 초안을 만들어 줍니다.

사용 예시

✅ 샘플 2개를 분석해 스키마를 만들었습니다 (속성 정의 14개)

입력 — JSON 샘플

[
  {
    "id": 1,
    "name": "Kim",
    "email": "kim@example.com",
    "is_active": true,
    "score": 4.5,
    "tags": ["admin", "dev"],
    "address": { "city": "Seoul", "zip": "04524" },
    "created_at": "2026-01-02T03:04:05Z"
  },
  {
    "id": 2,
    "name": "Lee",
    "is_active": false,
    "score": 3,
    "tags": [],
    "address": { "city": "Busan", "zip": null },
    "created_at": "2026-02-03T04:05:06Z"
  }
]

결과 — JSON Schema

{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "properties": {
    "id": {
      "type": "integer"
    },
    "name": {
      "type": "string"
    },
    "email": {
      "type": "string",
      "format": "email"
    },
    "is_active": {
      "type": "boolean"
    },
    "score": {
      "type": "number"
    },
    "tags": {
      "type": "array",
      "items": {
        "type": "string"
      }
    },
    "address": {
      "type": "object",
      "properties": {
        "city": {
          "type": "string"
        },
        "zip": {
          "type": [
            "string",
            "null"
          ]
        }
      },
      "required": [
        "city",
        "zip"
      ]
    },
    "created_at": {
      "type": "string",
      "format": "date-time"
    }
  },
  "required": [
    "id",
    "name",
    "is_active",
    "score",
    "tags",
    "address",
    "created_at"
  ]
}

이 도구로 할 수 있는 일

API 문서화, 입력 검증, 설정 파일 검증에는 JSON Schema가 필요하지만 처음부터 쓰기는 번거롭습니다. 대표 JSON 샘플을 주면 기본 골격을 만들어 줍니다.

  • 타입 추론: string/integer/number/boolean/array/object, null이 섞이면 ["string","null"]
  • 여러 샘플을 분석해 모든 샘플에 있는 키만 required로 지정
  • 문자열 형식 추정: date-time, date, email, uuid, uri, ipv4 (옵션)
  • additionalProperties:false, title, 스키마 버전(2020-12 / 2019-09 / Draft-07) 선택

생성된 스키마는 출발점입니다. 최소/최대값, enum, pattern 같은 제약은 직접 추가하세요.

💡 Tips

  • 가능한 한 다양한 샘플을 이어 붙이세요. 선택 필드와 타입 혼합을 더 정확히 찾아냅니다.
  • 만든 스키마는 JSON 스키마 검증기에서 실제 데이터로 바로 시험해 볼 수 있습니다.
  • OpenAPI 3.1은 JSON Schema 2020-12를, 3.0은 변형 문법을 사용합니다.

자주 묻는 질문

샘플이 하나뿐이면 required가 전부 지정되나요?

네. 샘플에 있는 모든 키가 필수로 처리됩니다. 선택 필드가 있다면 필드가 없는 샘플을 함께 넣거나 required 옵션을 끄세요.

enum이나 최솟값 같은 제약도 추론하나요?

아니요. 샘플만으로 의도를 알 수 없으므로 타입·required·format까지만 추론합니다. 나머지 제약은 직접 추가해 주세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
