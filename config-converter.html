설정 파일 변환기 — INI · .properties · plist ↔ JSON

INI, Java .properties, Apple plist(XML) 설정을 JSON으로, JSON을 다시 해당 형식으로 변환합니다.

사용 예시

✅ JSON으로 변환했습니다 — 키 9개

입력 — 입력

; server settings
host = example.com
port = 8080
debug = true

[database]
user = admin
password = "p@ss word"
hosts[] = db1
hosts[] = db2

[database.pool]
max = 10

결과 — 변환 결과

{
  "host": "example.com",
  "port": 8080,
  "debug": true,
  "database": {
    "user": "admin",
    "password": "p@ss word",
    "hosts": [
      "db1",
      "db2"
    ],
    "pool": {
      "max": 10
    }
  }
}

이 도구로 할 수 있는 일

Python의 configparser(INI), Java/Spring의 application.properties, macOS·iOS의 Info.plist는 서로 다른 설정 형식입니다. JSON으로 바꾸면 한눈에 구조를 보고 다른 도구로 옮기기 쉽습니다.

  • INI: [section], key=value, ; # 주석, key[]=값 배열, [a.b] 중첩 섹션
  • .properties: key=value, key:value, 줄 이어쓰기(\), \uXXXX 유니코드, a.b.c 점 표기를 중첩 객체로(선택)
  • plist(XML): dict/array/string/integer/real/true/false/date/data 변환 (null은 plist에 없어 빈 문자열)
  • JSON → INI/.properties/plist 방향 변환도 지원, 결과를 입력으로 되돌려 왕복 확인

TOML·YAML은 각각 전용 변환기를, .env는 ENV 변환기를 이용하세요.

함께 쓰면 좋은 도구

🧾JSON → TOML 변환기 🔄ENV ↔ JSON 변환기 🔄JSON ↔ YAML 🔍설정 파일 비교 도구

💡 Tips

  • Spring의 application.properties는 "점(.) 표기를 중첩 객체로"를 켜면 application.yml과 비슷한 구조로 볼 수 있습니다.
  • INI 값이 숫자·불리언이어야 한다면 "숫자·불리언 자동 변환"을 켜세요.
  • .properties의 한글은 \uXXXX로 이스케이프되어 있어도 변환 시 원래 글자로 복원됩니다.

자주 묻는 질문

plist는 바이너리 형식도 되나요?

XML 형식만 지원합니다. 바이너리 plist는 먼저 `plutil -convert xml1`으로 XML로 바꾼 뒤 사용하세요.

INI 형식에는 표준이 있나요?

표준 명세가 없어 구현마다 조금씩 다릅니다. 이 도구는 가장 흔한 규칙(섹션, = 또는 :, ; # 주석, 따옴표 값)을 지원합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
