ADB 명령어 생성기 — 실행 전에 뜻 확인

앱 설치·삭제·실행, logcat 필터, 스크린샷·녹화, 파일 복사, 탭·스와이프 입력, 포트 연결, 무선 연결, 권한, 인텐트, dumpsys 까지 자주 쓰는 adb 명령을 선택지로 만들고 각 부분의 뜻과 주의사항을 알려 줍니다.

사용 예시

✅ 명령어를 만들었습니다

결과 — ADB 명령어

adb shell am start -n com.example.app/.MainActivity

결과 — 각 부분의 뜻

부분 | 뜻
adb | Android Debug Bridge
shell am start | 액티비티 매니저로 액티비티 시작
-n com.example.app/.MainActivity | 패키지/액티비티 (.MainActivity 는 패키지 기준 상대 경로)

이 도구로 할 수 있는 일

외우기 어려운 adb 옵션을 고르기만 하면 명령 한 줄과 설명 표가 나옵니다.

  • 작업: devices, install, uninstall, start, force-stop, pm clear, logcat, screencap, screenrecord, push/pull, input, forward/reverse, connect, pm grant/revoke, am start/broadcast, dumpsys, pm list packages, reboot
  • logcat: 최소 레벨, 태그 필터(+ *:S), 앱 프로세스만(--pid=$(pidof …))
  • 안전 안내: pm clear 로 데이터 삭제, .aab 는 직접 설치 불가, 5555 포트 공개 위험, 한글 input text 한계
  • 여러 기기일 때 -s 시리얼 접두사
  • 각 부분의 뜻 표와 주의 사항

💡 Tips

  • 여러 기기가 연결되어 있으면 -s 시리얼을 꼭 지정하세요. adb devices -l 로 목록을 볼 수 있습니다.
  • React Native 개발에서 Metro 서버 연결은 adb reverse tcp:8081 tcp:8081 로 해결됩니다.
  • 스크린샷은 exec-out 을 쓰면 줄바꿈 변환 없이 PNG 가 그대로 저장됩니다.

자주 묻는 질문

adb 가 'unauthorized' 로 나오면요?

기기에서 USB 디버깅 허용 팝업을 승인해야 합니다. 안 보이면 adb kill-server 후 다시 연결하세요.

무선 디버깅은 어떻게 연결하나요?

Android 11 이상은 개발자 옵션의 무선 디버깅에서 페어링 코드로 adb pair IP:포트 를 먼저 한 뒤 adb connect 합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
