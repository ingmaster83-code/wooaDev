SQLite 파일 뷰어 (읽기 전용)

SQLite 3 데이터베이스 파일을 선택하거나 Base64·16진수로 붙여 넣으면 헤더 정보, sqlite_master 의 테이블·인덱스·뷰·트리거, 스키마 SQL 과 테이블 행을 보여 줍니다. 순수 JavaScript 로 b-트리를 직접 읽어서 설치나 WebAssembly 없이 동작합니다.

사용 예시

✅ SQLite 3 파일 — 페이지 6개 · UTF-8 · 테이블 2개 · users 표시

이 도구로 할 수 있는 일

앱이 만든 .db 파일을 설치 없이 열어 구조와 데이터를 확인합니다. 파일은 서버로 전송되지 않으며 수정하지도 않습니다.

  • 헤더: 페이지 크기·개수, 텍스트 인코딩(UTF-8/UTF-16), 저널 모드(WAL), user_version, application_id, freelist, SQLite 버전
  • 스키마: sqlite_master 의 테이블·인덱스·뷰·트리거와 CREATE 문, 루트 페이지, 행 수
  • 행: 테이블 선택, 건너뛰기·개수, 값 검색, INTEGER PRIMARY KEY 별칭 복원, 큰 값은 오버플로 페이지까지 조립
  • BLOB 은 16진수와 길이로 표시, WITHOUT ROWID·가상 테이블은 스키마만
  • WAL 파일의 미반영 변경은 보이지 않음을 안내

💡 Tips

  • 앱의 .db 파일이 작다면 Base64 로 붙여 넣는 것보다 '파일 선택'이 편합니다.
  • WAL 모드 DB 는 -wal 파일의 최근 변경이 반영되지 않았을 수 있습니다. 필요하면 체크포인트 후 복사하세요.
  • 행 수가 많은 테이블은 '값 검색'과 '건너뛸 행 수'로 원하는 부분만 확인하세요.

자주 묻는 질문

파일이 수정되거나 업로드되나요?

아니요. 브라우저가 파일을 메모리로 읽어 해석할 뿐이며 서버로 전송되지 않고 원본도 바꾸지 않습니다.

암호화된 DB 도 열리나요?

SQLCipher 같은 암호화 DB 는 헤더가 일반 SQLite 가 아니라서 열 수 없습니다. 아주 큰 파일은 브라우저 메모리에 따라 느려질 수 있습니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
