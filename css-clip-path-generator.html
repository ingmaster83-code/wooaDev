CSS clip-path 생성기 — 다각형 · 원 · 도형

삼각형·육각형·별 같은 프리셋이나 직접 입력한 꼭짓점으로 clip-path: polygon() 을 만들고, circle(), ellipse(), inset() 도 생성해 바로 미리보기로 확인합니다.

사용 예시

✅ clip-path 를 만들었습니다

입력 — 다각형 꼭짓점 (한 줄에 x% y% 또는 x y)

50% 0%
100% 38%
82% 100%
18% 100%
0% 38%

결과 — CSS

.element {
  clip-path: polygon(50% 0%, 100% 38%, 82% 100%, 18% 100%, 0% 38%);
  /* Safari 구버전 */
  -webkit-clip-path: polygon(50% 0%, 100% 38%, 82% 100%, 18% 100%, 0% 38%);
}

결과 — 꼭짓점

# | x | y
1 | 50% | 0%
2 | 100% | 38%
3 | 82% | 100%
4 | 18% | 100%
5 | 0% | 38%

이 도구로 할 수 있는 일

이미지나 박스를 사각형이 아닌 모양으로 자르는 clip-path 값을 좌표로 쉽게 만듭니다.

  • 프리셋: 삼각형, 사다리꼴, 마름모, 오각형, 육각형, 별, 화살표
  • 직접 입력: 한 줄에 x% y% (px 도 가능), 3개 이상, 일직선 점·영역 밖 점 경고
  • circle(반지름 at 중심), ellipse, inset(안쪽 여백 round 반경)
  • 점 목록 표와 -webkit-clip-path 포함 CSS
  • 그라디언트 또는 단색 배경으로 미리보기

💡 Tips

  • clip-path 는 그림자도 같이 잘라 버립니다. 그림자가 필요하면 부모에 filter: drop-shadow() 를 쓰세요.
  • 점 개수가 같은 두 polygon 사이에서는 transition 으로 모양이 부드럽게 변합니다.
  • 클릭 영역도 잘린 모양을 따릅니다.

자주 묻는 질문

점을 마우스로 끌어 조절할 수 있나요?

이 도구는 좌표 입력 방식입니다. 퍼센트 좌표를 수정하면서 미리보기로 확인하세요.

%와 px 를 섞어도 되나요?

가능하지만 반응형이려면 % 를 권장합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
