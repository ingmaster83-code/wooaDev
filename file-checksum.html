파일 체크섬 계산기 — MD5 · SHA · CRC-32

내려받은 파일이 손상되거나 바뀌지 않았는지 확인하세요. 파일을 선택하면 MD5, SHA-1, SHA-256, SHA-384, SHA-512, CRC-32를 한꺼번에 계산하고 공식 해시값과 비교합니다.

사용 예시

✅ 계산 완료 — 텍스트 15 bytes

입력 — 텍스트

Hello, WooaDev!

이 도구로 할 수 있는 일

ISO·설치 파일·백업을 내려받은 뒤 배포처가 공개한 해시와 비교하는 것은 가장 기본적인 무결성 확인입니다. 파일은 브라우저 안에서만 처리됩니다.

  • 한 번에 MD5, SHA-1, SHA-256, SHA-384, SHA-512, CRC-32 계산
  • 공식 해시값을 붙여 넣으면 어느 알고리즘과 일치하는지 자동으로 찾아 표시 (공백·대소문자 무시)
  • 텍스트 모드로 문자열의 해시도 확인, 16진수 대소문자 선택
  • 결과를 표 그대로 복사

💡 Tips

  • 보안 목적이라면 SHA-256 이상을 비교하세요. MD5·SHA-1은 의도적 충돌이 가능해 무결성 확인용으로만 적합합니다.
  • 해시값은 반드시 파일을 내려받은 사이트와 다른 경로(공식 문서, 서명 파일)에서 확인하는 것이 안전합니다.
  • Windows는 certutil -hashfile 파일 SHA256, macOS/Linux는 shasum -a 256 파일 로 같은 값을 확인할 수 있습니다.

자주 묻는 질문

해시가 같으면 파일이 안전한가요?

내용이 공식 배포본과 같다는 뜻이지 악성코드가 없다는 보장은 아닙니다. 해시를 공개한 출처가 믿을 만한지가 중요합니다.

체크섬과 해시는 같은 건가요?

넓게는 같은 용도입니다. CRC-32 같은 체크섬은 전송 오류 감지용이고, SHA-256 같은 암호학적 해시는 위·변조 방지까지 목적에 둡니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
