이 도구로 할 수 있는 일

접속 로그나 오류 리포트에 남은 긴 User-Agent를 사람이 읽을 수 있는 정보로 풀어 줍니다. 한 줄에 하나씩 여러 개를 넣으면 표로 비교합니다.

  • 브라우저: Chrome, Edge, Safari, Firefox, Opera, Samsung Internet, 네이버 웨일, Vivaldi, Brave, IE 등과 버전
  • 렌더링 엔진(Blink·WebKit·Gecko·Trident)과 운영체제(Windows 버전 매핑, macOS, iOS/iPadOS, Android, Linux, ChromeOS)
  • 기기: 데스크톱·모바일·태블릿·TV, 모델명(삼성 갤럭시 SM-… 등)
  • 인앱 브라우저: 카카오톡, 네이버 앱, 다음 앱, Facebook, Instagram, LINE, Android WebView
  • 봇: Googlebot, Bingbot, 네이버 Yeti, Daum, OpenAI·Anthropic·Perplexity 크롤러, curl·requests 등 HTTP 클라이언트

💡 Tips

  • Chrome·Edge·Safari의 UA는 호환성 때문에 서로 비슷한 토큰을 포함합니다. 순서가 중요해 이 도구는 Edge→Opera→웨일→…→Chrome→Safari 순으로 판별합니다.
  • 최신 브라우저는 UA를 줄이는(UA reduction) 추세라 macOS는 항상 10.15.7, Windows는 10으로 보일 수 있습니다.
  • 봇 판별은 UA만으로 하면 위조가 쉽습니다. 중요한 차단은 역방향 DNS 검증을 병행하세요.

자주 묻는 질문

UA 문자열만으로 정확한 기기를 알 수 있나요?

대략적인 정보만 알 수 있습니다. 브라우저의 UA 축소와 위장 때문에 정확한 OS 버전·모델은 User-Agent Client Hints(Sec-CH-UA-*)를 함께 확인해야 합니다.

Googlebot을 진짜인지 어떻게 확인하나요?

UA는 누구나 흉내 낼 수 있으므로 접속 IP의 역방향 DNS가 googlebot.com 또는 google.com으로 끝나고 정방향 조회가 같은 IP인지 확인하세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
