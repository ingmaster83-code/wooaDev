JSON 평탄화·복원 도구

중첩된 JSON을 user.address.city 같은 한 단계 키로 펼치거나, 평탄화된 JSON을 다시 중첩 구조로 복원합니다.

사용 예시

✅ 평탄화 완료 — 값 8개

입력 — JSON 입력

{
  "user": {
    "name": "Kim",
    "emails": ["a@x.com", "b@x.com"],
    "address": { "city": "Seoul", "geo": { "lat": 37.5, "lng": 127 } }
  },
  "active": true,
  "meta": {}
}

결과 — 결과

{
  "user.name": "Kim",
  "user.emails[0]": "a@x.com",
  "user.emails[1]": "b@x.com",
  "user.address.city": "Seoul",
  "user.address.geo.lat": 37.5,
  "user.address.geo.lng": 127,
  "active": true,
  "meta": {}
}

이 도구로 할 수 있는 일

다국어(i18n) 번역 파일, 환경 변수, 엑셀·CSV 변환처럼 한 단계 키-값 구조가 필요한 곳에서는 중첩 JSON을 펼쳐야 합니다. 반대로 평탄한 키를 다시 중첩 구조로 되돌릴 수도 있습니다.

  • 평탄화: {"a":{"b":[1,2]}} → {"a.b[0]":1,"a.b[1]":2}
  • 구분자(., /, _ 등)와 배열 표기(a[0] 또는 a.0)를 선택
  • 빈 객체·배열을 값으로 유지하거나 제거
  • 복원: 연속된 숫자 키(0,1,2…)는 배열로, 나머지는 객체로 재구성

경로만 필요하면 JSON 키 추출기나 JSON 포인터 도구가 더 편합니다.

💡 Tips

  • 평탄화 후 키를 정렬하거나 필터링하고, 결과를 입력으로 되돌려 복원할 수 있습니다.
  • 구분자가 키 이름에도 쓰이면 복원 시 구조가 달라질 수 있으니 키에 없는 문자(예: /)를 구분자로 고르세요.
  • 숫자로만 된 객체 키("0","1")는 복원 시 배열로 해석될 수 있습니다.

자주 묻는 질문

평탄화한 뒤 완전히 원래대로 복원되나요?

대부분 그렇습니다. 다만 키 이름 안에 구분자가 있거나 숫자로만 이루어진 객체 키가 있으면 구조가 달라질 수 있어 구분자를 바꿔서 쓰는 것이 안전합니다.

배열은 어떻게 표기되나요?

기본값은 a[0].b 형태의 대괄호 표기이고, a.0.b처럼 점 표기로도 바꿀 수 있습니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
