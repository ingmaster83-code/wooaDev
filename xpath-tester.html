XPath 테스터 (XPath 1.0)

XML 과 XPath 식을 넣으면 일치한 노드를 경로, 값, XML 조각으로 보여 주고 count(), sum(), contains() 같은 함수 결과도 계산합니다. 모든 축과 술어를 지원하며 브라우저 지원과 상관없이 자체 엔진으로 동작합니다.

사용 예시

✅ 노드 1개 일치

입력 — XML

<?xml version="1.0"?>
<catalog>
  <book id="b1" lang="en">
    <title>XML Basics</title>
    <author>Kim</author>
    <price currency="USD">29.99</price>
  </book>
  <book id="b2" lang="ko">
    <title>XPath 입문</title>
    <author>Lee</author>
    <price currency="KRW">18000</price>
  </book>
  <book id="b3" lang="en">
    <title>Advanced XSLT</title>
    <author>Kim</author>
    <price currency="USD">45.00</price>
  </book>
</catalog>

입력 — XPath 식

//book[author="Kim" and price > 30]/title

결과 — 일치한 노드

# | 종류 | 경로 | 값
1 | element | /catalog/book[3]/title | Advanced XSLT

결과 — 결과

<title>Advanced XSLT</title>

이 도구로 할 수 있는 일

SOAP 응답, RSS, 설정 XML 에서 원하는 값을 고르는 식을 만들면서 결과를 바로 확인합니다. 데이터는 브라우저 밖으로 나가지 않습니다.

  • 경로: 절대·상대, //, ., .., @속성, 와일드카드 *, text(), comment(), node()
  • 축: child, descendant(-or-self), parent, ancestor(-or-self), following(-sibling), preceding(-sibling), attribute, self
  • 술어와 연산자: [위치], [조건], and, or, not(), = != < <= > >=, + - * div mod, 노드 집합 비교(하나라도 일치), 합집합 |
  • 함수: count, sum, position, last, name, local-name, string, concat, contains, starts-with, substring*, normalize-space, translate, number, floor, ceiling, round, boolean … (ends-with, lower-case, upper-case, matches, replace, abs 등 2.0 함수 일부 확장)
  • 결과: 노드 집합(경로·값·XML 조각), 문자열, 숫자, 불리언

💡 Tips

  • //book[price > 30] 처럼 숫자 비교는 텍스트를 숫자로 바꿔 비교합니다.
  • 기본 네임스페이스(xmlns=...)가 있으면 //item 은 일치하지 않습니다. //*[local-name()="item"] 을 쓰세요.
  • (//book)[1] 과 //book[1] 은 다릅니다. 앞은 전체 중 첫 번째, 뒤는 각 부모의 첫 번째 book 입니다.

자주 묻는 질문

XPath 2.0/3.1 도 되나요?

핵심은 XPath 1.0 이며, 자주 쓰는 2.0 함수 일부만 확장으로 지원합니다. 시퀀스, for/let 식은 지원하지 않습니다.

브라우저의 document.evaluate 와 같은가요?

표준 XPath 1.0 규칙을 따라 같은 결과가 나오도록 만들었습니다. 네임스페이스 해석만 문서에 쓰인 접두사 이름 비교로 단순화했습니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
