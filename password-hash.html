비밀번호 해시 생성기 · 검증기

bcrypt, Argon2id(i, d), scrypt 로 비밀번호 해시를 만들고, 이미 있는 해시가 비밀번호와 맞는지 검증합니다. 비용 매개변수와 걸린 시간을 보여 주고 OWASP 권장보다 약하면 알려 줍니다.

사용 예시

✅ argon2id 해시를 만들었습니다 (31 ms)

입력 — 비밀번호

correct horse battery staple

결과 — 결과

항목 | 값
알고리즘 | argon2id
매개변수 | m=19456, t=2, p=1
솔트 (16진수) | a932b84a58849180ab89f0229ef8d613
걸린 시간 | 31 ms
해시 길이 | 97자

결과 — 해시

$argon2id$v=19$m=19456,t=2,p=1$qTK4SliEkYCrifAinvjWEw$u3ogHGkI9pCHucHO15NuyV/RGg51bzwU/AziTZVDZpY

이 도구로 할 수 있는 일

서버 코드가 만든 해시가 올바른지 확인하거나 테스트 데이터를 만들 때 씁니다. 입력은 브라우저 밖으로 나가지 않습니다(WebAssembly 로 계산).

  • 알고리즘: bcrypt($2a$, 비용 4~15), Argon2id·Argon2i·Argon2d(메모리·반복·병렬도), scrypt(N=2^ln, r, p)
  • 해시 만들기: 무작위 솔트 또는 16진수 솔트 지정(재현용), 인코딩된 해시 문자열($argon2id$v=19$…)과 걸린 시간
  • 검증: $2b$·$argon2id$·$scrypt$ 접두사로 알고리즘 자동 판별, 일치/불일치 표시
  • 점검: OWASP 최소 권장(Argon2id m=19 MiB, t=2, p=1 · scrypt N=2^17 · bcrypt 비용 10 이상)과 비교, bcrypt 72바이트 제한
  • Node 의 crypto.argon2·scrypt, crypt_blowfish 테스트 벡터와 일치

함께 쓰면 좋은 도구

🔑Hash 생성기 🔏HMAC 생성기 🔑키 쌍 생성기 (RSA·EC·Ed25519) 🔒AES 암호화·복호화 도구

💡 Tips

  • 새 시스템에는 Argon2id 를 권장합니다. 불가능하면 비용 12 이상의 bcrypt 나 scrypt 를 쓰세요.
  • 로그인 1회에 서버에서 100~500 ms 걸리도록 비용을 조정하세요. 브라우저와 서버 속도는 다릅니다.
  • 솔트는 해시 문자열에 함께 들어 있으므로 따로 저장할 필요가 없습니다.

자주 묻는 질문

bcrypt 는 왜 72바이트가 넘으면 안 되나요?

bcrypt 알고리즘이 비밀번호의 처음 72바이트만 사용합니다. 긴 비밀번호는 먼저 SHA-256 으로 해시하거나 Argon2id 를 쓰세요.

같은 비밀번호인데 해시가 매번 달라요.

솔트가 무작위이기 때문에 정상입니다. 검증 기능으로 일치 여부를 확인하세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
