파일 형식 판별기 — 매직 바이트로 진짜 형식 확인

파일 이름이 아니라 파일 앞부분의 시그니처(매직 바이트)로 실제 형식을 알아냅니다. 파일을 선택하거나 16진수 바이트를 붙여 넣으면 PNG·PDF·ZIP·EXE 등 60여 형식을 판별하고 확장자와 대조합니다.

사용 예시

🚨 확장자와 실제 형식이 다릅니다

입력 — 파일 앞부분의 16진수 바이트

89 50 4E 47 0D 0A 1A 0A 00 00 00 0D 49 48 44 52 00 00 01 00 00 00 01 00 08 06 00 00 00

입력 — 파일 이름 (확장자 대조용, 선택)

photo.jpg

결과 — 판별 결과

형식 | 대표 확장자 | MIME | 이름 대조 | 분류
PNG | png | image/png | ⚠️ .jpg | image

결과 — 앞부분 16진수 덤프

0000  89 50 4e 47 0d 0a 1a 0a 00 00 00 0d 49 48 44 52  .PNG........IHDR
0010  00 00 01 00 00 00 01 00 08 06 00 00 00           .............

이 도구로 할 수 있는 일

확장자는 이름일 뿐이라 바꾸면 그만입니다. 업로드 검증이나 출처를 알 수 없는 파일 점검에는 내용을 직접 보는 것이 확실합니다.

  • 입력: 파일 선택(앞 4KB만 읽음) 또는 16진수 바이트 붙여 넣기
  • 판별: 이미지(PNG·JPEG·GIF·WebP·BMP·TIFF·ICO·AVIF), 문서(PDF·RTF·OLE2), 압축(ZIP·GZIP·7z·RAR·TAR·XZ), 오디오·비디오, 실행 파일(ELF·PE·Mach-O·class·wasm), DB·폰트·인증서 등
  • 파일 이름의 확장자와 대조해 불일치, 실행 파일인데 문서 확장자 같은 위장 경고
  • 텍스트(UTF-8, BOM), JSON·XML·HTML·SVG 휴리스틱 판별
  • 앞 64바이트 16진수 덤프 제공

💡 Tips

  • docx·xlsx·pptx·jar·apk·epub 는 모두 ZIP 으로 시작합니다. 정확한 종류는 내부 파일 이름으로 구분합니다.
  • 업로드 검증은 확장자, Content-Type, 매직 바이트를 모두 확인하고 파일을 웹 루트 밖에 저장하세요.
  • 매직 바이트가 맞아도 악성 내용이 없다는 뜻은 아닙니다.

자주 묻는 질문

파일이 서버로 올라가나요?

아니요. 브라우저에서 파일 앞부분만 읽어 판별하며 어디에도 전송하지 않습니다.

왜 'MZ'로 시작하면 exe 인가요?

DOS 실행 파일 헤더의 시그니처(Mark Zbikowski의 머리글자)로 Windows PE 실행 파일(exe, dll)이 이 헤더로 시작합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
