Azure 리소스 ID · SAS · 연결 문자열 분석기

/subscriptions/…/providers/Microsoft.Compute/virtualMachines/vm1 같은 리소스 ID와 Blob URL(SAS 토큰), 스토리지 연결 문자열을 구성 요소로 나누고, 만료·과도한 권한·키 노출을 점검합니다.

사용 예시

🔍 위험 항목이 있습니다

입력 — Azure 리소스 ID, Blob URL 또는 연결 문자열

/subscriptions/00000000-1111-2222-3333-444444444444/resourceGroups/rg-prod/providers/Microsoft.Compute/virtualMachines/web-01/extensions/AzureMonitorAgent
https://mystorageacct.blob.core.windows.net/container/folder/file.txt?sv=2022-11-02&sp=r&sig=abc
DefaultEndpointsProtocol=https;AccountName=mystorageacct;AccountKey=Eby8vdM02xNOcqFlqUwJPLlmEtlCDXJ1OUzFT50uSRZ6IFsuFq2UVErCz4I6tq/K1SZFPTOtr/KBHBeksoGMGw==;EndpointSuffix=core.windows.net

결과 — 점검 사항

리소스 ID 는 대소문자를 구분하지 않습니다. 비교할 때는 소문자로 바꿔 비교하세요
SAS 에 만료 시각(se)이 없습니다 — 저장된 액세스 정책을 쓰는 경우가 아니면 이상합니다
🚨 AccountKey 는 계정 전체 권한입니다 — 코드·로그에 두지 말고 Key Vault 나 관리 ID 를 쓰세요

이 도구로 할 수 있는 일

Azure 포털·ARM 템플릿·CLI 에서 보는 긴 리소스 ID와 SAS URL, 연결 문자열을 사람이 읽을 수 있게 풀어 줍니다. 비밀 값은 화면에 그대로 보이지 않도록 마스킹합니다.

  • 리소스 ID: subscriptionId(GUID 검증), resourceGroup, provider, 리소스 종류, 이름 계층(부모/자식)
  • Blob URL: 스토리지 계정, 컨테이너, 경로, SAS 필드(sv, sp, se, st, spr, sr)
  • SAS 점검: 만료 시각 지남, 만료 없음, 쓰기·삭제 권한, HTTP 허용
  • 연결 문자열: AccountName·EndpointSuffix 표시, AccountKey·SharedAccessSignature 마스킹
  • 리소스 ID는 대소문자를 구분하지 않으므로 비교 시 소문자 변환 권장

💡 Tips

  • SAS는 가능하면 짧은 만료와 최소 권한(읽기 전용)으로 만들고, 장기 접근에는 관리 ID를 쓰세요.
  • AccountKey가 든 연결 문자열은 코드·로그에 두지 말고 Key Vault에 보관하세요.
  • ARM 템플릿에서 같은 리소스를 비교할 때는 ID 전체를 소문자로 맞춘 뒤 비교합니다.

자주 묻는 질문

SAS 토큰의 sig는 무엇인가요?

토큰 내용에 대한 HMAC 서명입니다. 이 값이 노출되면 만료 전까지 누구나 같은 권한을 가지므로 공유에 주의하세요.

관리 ID와 SAS 중 무엇이 안전한가요?

관리 ID는 비밀을 코드에 두지 않아 더 안전합니다. SAS는 외부에 임시 접근을 줄 때 유용합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
