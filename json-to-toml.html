JSON → TOML 변환기

JSON을 사람이 읽기 쉬운 TOML 설정으로 바꿉니다. 테이블([table])과 테이블 배열([[array]]) 구조를 자동으로 만듭니다.

사용 예시

✅ 변환 완료

입력 — JSON 입력

{
  "title": "Example",
  "owner": { "name": "Kim", "active": true },
  "database": { "ports": [8000, 8001], "connection_max": 5000 },
  "servers": [
    { "name": "alpha", "ip": "10.0.0.1" },
    { "name": "beta", "ip": "10.0.0.2" }
  ]
}

결과 — TOML 결과

title = "Example"

[owner]
name = "Kim"
active = true

[database]
ports = [ 8000, 8001 ]
connection_max = 5000

[[servers]]
name = "alpha"
ip = "10.0.0.1"

[[servers]]
name = "beta"
ip = "10.0.0.2"

이 도구로 할 수 있는 일

TOML은 Rust의 Cargo.toml, Python의 pyproject.toml, Hugo·Netlify 설정 등에서 쓰는 설정 파일 형식입니다. 이미 JSON으로 갖고 있는 설정을 TOML로 옮길 때 사용하세요.

  • 중첩 객체 → [section] 테이블, 객체 배열 → [[servers]] 테이블 배열로 자동 구성
  • 문자열 이스케이프, 숫자·불리언 표기, 배열 형식은 TOML 1.0 규격에 맞춰 생성
  • TOML에는 null이 없으므로 "항목 제거 / 빈 문자열 / 오류" 중 처리 방식을 선택
  • 최상위가 객체가 아니면(배열·값) TOML이 될 수 없다는 점을 안내

반대로 TOML을 JSON으로 바꾸려면 TOML → JSON 변환기를 사용하세요.

💡 Tips

  • JSON의 null이 많다면 "항목 제거"로 두고 선택값으로 취급하는 것이 일반적입니다.
  • 변환 결과를 TOML 포맷터에 넣으면 키 정렬 등 추가 정리를 할 수 있습니다.
  • 날짜·시간은 JSON에서 문자열이므로 TOML에서도 문자열로 변환됩니다.

자주 묻는 질문

TOML은 JSON과 무엇이 다른가요?

TOML은 주석을 쓸 수 있고 따옴표·쉼표 규칙이 단순해 사람이 직접 편집하는 설정 파일에 적합합니다. 대신 null이 없고 최상위는 반드시 테이블(객체)이어야 합니다.

배열 안에 서로 다른 타입이 섞여 있어도 되나요?

TOML 1.0부터 허용됩니다. 이 도구는 TOML 1.0 규격으로 출력합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
