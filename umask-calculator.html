umask 계산기 — 새 파일·디렉터리 기본 권한

umask 022 이면 새 파일은 644, 디렉터리는 755 가 됩니다. umask 에서 권한을 계산하거나, 원하는 권한(예: 640/750)에서 필요한 umask 를 거꾸로 구하고 자주 쓰는 값 표를 보여 줍니다.

사용 예시

✅ umask 027 → 파일 640 · 디렉터리 750

입력 — umask (8진수, 예: 022)

027

입력 — 원하는 파일 권한 (8진수 또는 rw-r--r--)

640

입력 — 원하는 디렉터리 권한 (8진수 또는 rwxr-x---)

750

결과 — 결과

항목 | 값 | 권한
umask | 027 | ----w-rwx (마스크로 빼는 권한)
새 파일 권한 | 640 | rw-r-----
새 디렉터리 권한 | 750 | rwxr-x---
umask 기호 표기 | u=rwx,g=rx,o= | umask -S 가 출력하는 형식

결과 — 명령어

umask 027
umask u=rwx,g=rx,o=

# 영구 적용 위치
echo 'umask 027' >> ~/.bashrc    # 사용자 셸
# /etc/login.defs → UMASK 027            # 로그인 기본값
# systemd 서비스: UMask=027
# Dockerfile: RUN umask 027 && …    # 해당 RUN 안에서만 유효

이 도구로 할 수 있는 일

새로 만들어지는 파일의 권한은 chmod 가 아니라 umask 가 결정합니다. 값을 뺀다는 개념이 헷갈릴 때 바로 계산해 보세요.

  • umask → 권한: 파일은 666, 디렉터리는 777 에서 umask 비트를 제거
  • 권한 → umask: 640/750 또는 rw-r----- 형식의 원하는 권한에서 필요한 umask 계산
  • rwx 기호 표기와 umask -S 형식(u=rwx,g=rx,o=) 표시
  • 자주 쓰는 umask(022, 002, 027, 077, 007) 비교표
  • ~/.bashrc, /etc/login.defs, systemd UMask=, Dockerfile 에서 영구 적용하는 방법 안내

💡 Tips

  • 서버 계정 기본값으로는 027(그룹 읽기, 기타 접근 불가)이나 077 이 안전합니다.
  • 파일에는 기본적으로 실행 권한이 붙지 않습니다. 스크립트는 chmod +x 로 따로 지정하세요.
  • systemd 서비스, cron, sshd 는 로그인 셸의 umask 를 물려받지 않으니 서비스 설정에서 UMask= 를 지정하세요.

자주 묻는 질문

umask 022 는 왜 644 가 되나요?

파일 기본 666(rw-rw-rw-)에서 umask 의 022(----w--w-)를 빼면 644(rw-r--r--)입니다. 디렉터리는 777 에서 같은 비트를 빼 755 가 됩니다.

umask 를 바꿨는데 기존 파일 권한은 그대로예요.

umask 는 앞으로 만들 파일에만 적용됩니다. 기존 파일은 chmod 로 바꿔야 합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
