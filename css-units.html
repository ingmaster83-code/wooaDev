자주 묻는 질문

px와 rem의 차이는 무엇인가요?

px는 절대 단위, rem은 루트 요소의 폰트 크기 기준 상대 단위입니다. 반응형 디자인에는 rem이 유용합니다.

vw와 vh는 어떤 단위인가요?

vw는 뷰포트 너비의 1%, vh는 뷰포트 높이의 1%입니다. 전체 화면 레이아웃에 활용됩니다.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.

💡 Tips

  • px, em, rem, vw, vh 등 CSS 단위 간 변환을 지원합니다.
  • rem은 루트 폰트 크기 기준으로 반응형 디자인에 유용합니다.
  • 화면 크기 기준 단위(vw, vh)는 전체 화면 레이아웃에 활용합니다.
