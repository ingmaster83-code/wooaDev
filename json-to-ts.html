JSON → TypeScript 변환기

JSON을 붙여넣으면 TypeScript interface를 자동 생성합니다. 중첩 객체·배열·선택적 필드를 지원합니다.

✅ 복사 완료!

함께 쓰면 좋은 도구

🔐Base64 🔗URL 인코더 🖼️이미지 → Base64 🔤HTML Entity 인코더

💡 Tips

  • 중첩 객체는 별도 interface로 자동 생성됩니다.
  • 배열은 요소 타입을 추론해 type[] 형식으로 생성됩니다.
  • 선택적 필드 옵션 체크 시 모든 필드에 ?가 추가됩니다.
  • null 값은 null 타입으로 처리됩니다.

자주 묻는 질문

중첩된 JSON도 TypeScript 타입으로 변환되나요?

네. 중첩 객체와 배열 모두 타입이 자동으로 추론됩니다.

optional 필드를 처리할 수 있나요?

null이나 undefined 값은 자동으로 ? 옵셔널 표시가 적용됩니다.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
