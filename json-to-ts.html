JSON → TypeScript 변환기

JSON을 붙여넣으면 TypeScript interface를 자동 생성합니다. 중첩 객체·배열·선택적 필드를 지원합니다.

✅ 복사 완료!

💡 Tips

  • 중첩 객체는 별도 interface로 자동 생성됩니다.
  • 배열은 요소 타입을 추론해 type[] 형식으로 생성됩니다.
  • 선택적 필드 옵션 체크 시 모든 필드에 ?가 추가됩니다.
  • null 값은 null 타입으로 처리됩니다.
혼합 타입 배열은 어떻게 처리되나요?

배열의 첫 번째 요소를 기준으로 타입을 추론합니다. 다양한 타입이 섞인 배열은 any[]로 표시되거나 수동으로 수정이 필요합니다.

생성된 코드를 바로 사용할 수 있나요?

대부분의 경우 바로 사용 가능하지만, API 응답에 따라 null 허용 여부(| null)나 선택적 필드 처리를 수동으로 조정하는 것을 권장합니다.
