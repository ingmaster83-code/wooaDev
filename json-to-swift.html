JSON → Swift Codable 변환기

여러 API 응답 샘플을 분석해 CodingKeys까지 갖춘 Swift Codable struct를 만들어 줍니다.

사용 예시

✅ 구조체 2개를 만들었습니다 (샘플 2개 분석)

입력 — JSON 샘플 (API 응답 등)

[
  {
    "id": 1,
    "name": "Kim",
    "email": "kim@example.com",
    "is_active": true,
    "score": 4.5,
    "tags": ["admin", "dev"],
    "address": { "city": "Seoul", "zip": "04524" },
    "created_at": "2026-01-02T03:04:05Z"
  },
  {
    "id": 2,
    "name": "Lee",
    "is_active": false,
    "score": 3,
    "tags": [],
    "address": { "city": "Busan", "zip": null },
    "created_at": "2026-02-03T04:05:06Z",
    "nickname": null
  }
]

결과 — Swift Codable

import Foundation

struct Root: Codable {
    let id: Int
    let name: String
    let email: String?
    let isActive: Bool
    let score: Double
    let tags: [String]
    let address: Address
    let createdAt: String
    let nickname: JSONValue?

    enum CodingKeys: String, CodingKey {
        case id
        case name
        case email
        case isActive = "is_active"
        case score
        case tags
        case address
        case createdAt = "created_at"
        case nickname
    }
}

struct Address: Codable {
    let city: String
    let zip: String?
}

이 도구로 할 수 있는 일

iOS 앱에서 JSONDecoder로 응답을 읽으려면 Codable을 채택한 struct가 필요합니다. 샘플 JSON만 있으면 초안을 바로 만들 수 있습니다.

  • 키 이름이 다르면(is_active → isActive) CodingKeys 열거형을 자동 생성
  • 일부 응답에만 있거나 null인 필드는 옵셔널(String?)로
  • 타입이 섞인 필드는 함께 제공되는 JSONValue 열거형으로 안전하게 디코딩
  • let 또는 var, Hashable 채택 여부 선택. 중첩 객체는 별도 struct로 분리하고 같은 구조는 재사용
  • Swift 예약어(class, default 등)는 백틱(`)으로 감쌈

여러 응답을 이어 붙이면 옵셔널 판단이 정확해집니다.

💡 Tips

  • JSONDecoder의 keyDecodingStrategy = .convertFromSnakeCase를 쓰면 CodingKeys 없이도 snake_case를 매핑할 수 있습니다.
  • 날짜 문자열은 String으로 생성됩니다. 필요하면 Date로 바꾸고 dateDecodingStrategy를 지정하세요.
  • 서버가 같은 필드를 때로는 숫자, 때로는 문자열로 보내면 JSONValue로 받은 뒤 변환하세요.

자주 묻는 질문

옵셔널을 줄이고 싶어요.

옵셔널은 샘플에서 누락·null이 확인된 필드에만 붙습니다. 서버 스펙상 항상 있는 필드라면 여러 응답을 함께 넣어 정확도를 높이거나 생성 후 직접 수정하세요.

JSONValue는 무엇인가요?

문자열·숫자·불리언·배열·객체·null 중 무엇이든 담을 수 있는 열거형입니다. 타입이 불확실한 필드에만 쓰이며 필요할 때만 파일 끝에 포함됩니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
