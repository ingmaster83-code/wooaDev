DynamoDB JSON ↔ 일반 JSON 변환기

DynamoDB 가 쓰는 타입 표기 JSON({"name":{"S":"Kim"},"age":{"N":"31"}})을 일반 JSON 으로, 또는 반대로 변환합니다. Item/Items 래퍼와 SS·NS·B·L·M 타입을 지원합니다.

사용 예시

✅ 변환했습니다

입력 — 입력 JSON

{
  "Item": {
    "pk": {"S": "USER#42"},
    "age": {"N": "31"},
    "active": {"BOOL": true},
    "nick": {"NULL": true},
    "tags": {"SS": ["a", "b"]},
    "scores": {"NS": ["1.5", "2"]},
    "addr": {"M": {"city": {"S": "Seoul"}, "zip": {"S": "04524"}}},
    "history": {"L": [{"S": "x"}, {"N": "7"}]},
    "avatar": {"B": "aGVsbG8="}
  }
}

결과 — 변환 결과

{
  "Item": {
    "pk": "USER#42",
    "age": 31,
    "active": true,
    "nick": null,
    "tags": [
      "a",
      "b"
    ],
    "scores": [
      1.5,
      2
    ],
    "addr": {
      "city": "Seoul",
      "zip": "04524"
    },
    "history": [
      "x",
      7
    ],
    "avatar": {
      "$binary": "aGVsbG8="
    }
  }
}

결과 — 참고

집합(SS/NS/BS)은 배열로 변환되어 집합이라는 정보가 사라집니다. 바이너리는 {"$binary": base64} 로 표시했습니다

이 도구로 할 수 있는 일

AWS CLI 의 dynamodb get-item/scan 결과나 콘솔 내보내기를 읽기 쉬운 JSON 으로 바꾸거나, 일반 JSON 을 put-item 에 쓸 수 있는 형식으로 바꿉니다.

  • 지원 타입: S, N, BOOL, NULL, L, M, SS, NS, B, BS
  • DynamoDB → 일반: Item, Items 래퍼, 배열, 단일 속성 값을 알아서 처리
  • 일반 → DynamoDB: 숫자는 문자열 N, 중첩 객체는 M, 배열은 L(옵션으로 중복 없는 문자열/숫자 배열을 SS/NS 집합으로)
  • 정밀도를 잃는 큰 숫자는 문자열로 유지
  • 알 수 없는 타입, 한 속성에 여러 타입 같은 오류를 경로와 함께 안내

💡 Tips

  • 집합(SS/NS)은 일반 JSON 으로 바꾸면 배열이 되어 집합 정보가 사라집니다.
  • 숫자는 항상 문자열로 전송됩니다. 38자리까지 정밀도를 가지므로 JavaScript 숫자로 변환하면 손실될 수 있습니다.
  • SDK 에서는 marshall / unmarshall 함수를 쓰면 같은 변환을 코드로 할 수 있습니다.

자주 묻는 질문

BOOL 과 NULL 은 어떻게 표기되나요?

{"BOOL": true}, {"NULL": true} 형태입니다. NULL 은 값이 항상 true 입니다.

바이너리(B)는 어떻게 되나요?

Base64 문자열을 {"$binary": …} 로 표시해 구분합니다. 다시 DynamoDB 로 되돌릴 때는 B 로 직접 지정하세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
