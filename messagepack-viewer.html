MessagePack 디코더 · 인코더

16진수나 Base64, 파일로 받은 MessagePack 바이트를 형식 이름과 바이트 오프셋이 붙은 구조 표와 JSON으로 풀어 줍니다. 반대로 JSON을 가장 짧은 MessagePack 으로 인코딩하는 기능도 있습니다.

사용 예시

✅ 해석 완료 — 42바이트, 요소 12개

입력 — MessagePack (16진수/Base64) 또는 인코딩할 JSON

84 a4 6e 61 6d 65 a5 57 6f 6f 61 21 a3 61 67 65 1e a6 73 63 6f 72 65 73 93 01 cb 40 09 1e b8 51 eb 85 1f d4 02 0a a2 6f 6b c3

결과 — 구조 (바이트 오프셋)

오프셋 | 바이트 | 경로 | 형식 | 값
0 | 0x84 | $ | fixmap | map(4)
6 | 0xa5 |   $.name | fixstr | "Wooa!"
16 | 0x1e |   $.age | positive fixint | 30
24 | 0x93 |   $.scores | fixarray | array(3)
25 | 0x01 |     $.scores[0] | positive fixint | 1
26 | 0xcb |     $.scores[1] | float 64 | 3.14
35 | 0xd4 |     $.scores[2] | fixext 1 | ext 2 h'0a'
41 | 0xc3 |   $.ok | true | true

결과 — JSON / 인코딩 결과

{
  "name": "Wooa!",
  "age": 30,
  "scores": [
    1,
    3.14,
    {
      "$ext": 2,
      "$data": "0a"
    }
  ],
  "ok": true
}

이 도구로 할 수 있는 일

서버 간 통신이나 캐시에 저장된 msgpack 데이터를 열어 볼 때 씁니다. 데이터는 브라우저 밖으로 나가지 않습니다.

  • 입력: 16진수(공백·0x 허용), Base64, 파일 — 형식은 자동 판별
  • 구조 표: 바이트 오프셋, 형식 바이트, 경로($.a.b[0]), 형식 이름(positive fixint, fixstr, map 16 …), 값
  • 지원 형식: 정수 8~64비트, float32/64, str·bin·array·map, ext·fixext, 타임스탬프 확장(-1)
  • 64비트 정수는 정밀도를 잃지 않고 표시, 문자열이 아닌 맵 키·중복 키·잘못된 UTF-8·뒤에 남은 바이트를 알림
  • 인코딩: JSON 을 가장 짧은 정수 형식으로 변환하고 16진수·Base64 로 출력

💡 Tips

  • msgpack 은 JSON 과 달리 바이너리와 정수·실수를 구분합니다. 실수 1.0 과 정수 1 은 다른 바이트입니다.
  • 맵 키가 문자열이 아닌 msgpack 은 JSON 으로 옮길 때 키가 문자열이 되어 충돌할 수 있습니다.
  • 스트림처럼 값이 이어져 있으면 뒤에 남은 바이트 알림을 보고 값별로 잘라 다시 해석하세요.

자주 묻는 질문

MessagePack 과 JSON 은 무엇이 다른가요?

MessagePack 은 JSON 과 비슷한 데이터 모델을 바이너리로 압축한 형식입니다. 작고 빠르며 바이너리(bin)와 확장 타입을 지원합니다.

c1 바이트는 왜 오류인가요?

0xc1 은 규격에서 사용하지 않기로 한 예약 바이트라서 정상 데이터에는 나올 수 없습니다. 데이터가 손상되었거나 다른 형식일 수 있습니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
