웹 서버 액세스 로그 분석기 (Nginx · Apache)

Nginx/Apache 의 combined·common 형식 로그를 붙여 넣으면 IP, 시각, 메서드, 경로, 상태, 바이트, UA 로 나눠 표와 CSV 로 만들고, 상태 코드 분포·상위 IP·경로·봇 비율·스캐닝 요청을 요약합니다.

이 도구로 할 수 있는 일

서버 장애나 이상 트래픽을 확인할 때 로그 몇 줄을 바로 구조화해 보는 도구입니다. 로그는 브라우저 밖으로 나가지 않습니다.

  • 형식: combined, common, 뒤에 추가 필드(응답 시간 등)가 붙은 변형
  • 표: 줄 번호, IP, 시각, 메서드, 경로, 상태, 바이트, User-Agent / CSV: 모든 필드 포함
  • 통계: 요청 수, 전송 바이트, 2xx~5xx 비율, 상위 IP·경로, 메서드, 5xx 목록, 봇·스크립트 추정
  • 탐지: wp-login·.env·../ 등 스캐닝 요청, 같은 경로의 401/403 반복(무차별 대입)
  • 파싱 실패한 줄 번호 알림

함께 쓰면 좋은 도구

💡 Tips

  • 프록시/CDN 뒤에서는 로그의 IP 가 프록시 주소일 수 있어 X-Forwarded-For 를 로그 형식에 추가하세요.
  • IP 는 개인정보가 될 수 있으니 공유하기 전에 마스킹하세요.
  • 응답 시간을 보려면 nginx 의 $request_time 을 로그 포맷에 넣으세요.

자주 묻는 질문

JSON 형식 로그도 되나요?

이 도구는 텍스트 combined/common 형식용입니다. JSON 로그는 JSON Lines 뷰어를 쓰세요.

combined 와 common 의 차이는요?

combined 는 common 에 Referer 와 User-Agent 가 더 붙은 형식입니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
