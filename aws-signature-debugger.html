AWS Signature V4 디버거

요청 URL·헤더·본문과 테스트 키를 넣으면 SigV4 의 정규 요청, 서명할 문자열, 날짜→리전→서비스→서명 키 파생, 최종 서명과 Authorization 헤더(또는 사전 서명 URL)를 단계별로 보여 줍니다. 기대 서명과 비교해 어디서 달라지는지도 진단합니다.

사용 예시

✅ 서명 계산 완료: 5fa00fa31553b73ebf1942676e86291e8372ff2a2260956d9b8aae1d763fbf31

입력 — 요청 URL

https://example.amazonaws.com/

입력 — 헤더 (한 줄에 이름: 값)

Host: example.amazonaws.com
X-Amz-Date: 20150830T123600Z

입력 — Access Key ID (테스트 키만)

AKIDEXAMPLE

입력 — Secret Access Key (테스트 키만)

wJalrXUtnFEMI/K7MDENG+bPxRfiCYEXAMPLEKEY

입력 — 비교할 Authorization 헤더 또는 서명 (선택)

AWS4-HMAC-SHA256 Credential=AKIDEXAMPLE/20150830/us-east-1/service/aws4_request, SignedHeaders=host;x-amz-date, Signature=5fa00fa31553b73ebf1942676e86291e8372ff2a2260956d9b8aae1d763fbf31

결과 — 서명 단계 요약

단계 | 값
정규 URI | /  (S3 이외 서비스는 경로를 한 번 더 인코딩)
정규 쿼리 | —
SignedHeaders | host;x-amz-date
페이로드 해시 | e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855
Credential scope | 20150830/us-east-1/service/aws4_request

결과 — ① 정규 요청 (Canonical Request)

GET
/

host:example.amazonaws.com
x-amz-date:20150830T123600Z

host;x-amz-date
e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855

이 도구로 할 수 있는 일

403 SignatureDoesNotMatch 가 날 때 어느 단계가 틀렸는지 비교해 봅니다. 키와 요청은 브라우저 밖으로 전송되지 않습니다.

  • 모드: Authorization 헤더 서명, 사전 서명 URL(쿼리 문자열)
  • 단계: 정규 URI(S3 외에는 이중 인코딩), 정규 쿼리, 서명 헤더, 페이로드 해시, 서명 문자열, kDate→kRegion→kService→kSigning, 최종 서명
  • 페이로드: 본문 SHA-256, UNSIGNED-PAYLOAD, STREAMING 모드
  • 기대 서명을 넣으면 어느 입력(헤더·쿼리·본문·시각)이 다른지 진단
  • AWS 공식 테스트 벡터(get-vanilla 등)로 검증됨

💡 Tips

  • Host 헤더와 X-Amz-Date 는 서명 헤더에 포함되어야 하고 실제 요청에 보낸 값과 같아야 합니다.
  • S3 가 아닌 서비스는 정규 URI 를 한 번 더 인코딩합니다. 경로에 특수문자가 있으면 이 차이로 자주 틀립니다.
  • 서명 시각이 서버와 15분 이상 어긋나면 서명이 맞아도 거부됩니다.

자주 묻는 질문

실제 Secret Access Key 를 넣어도 되나요?

계산은 브라우저 안에서만 이루어지고 전송되지 않지만, 안전을 위해 테스트용 키만 쓰세요. 실제 키를 입력했다면 교체(rotate)하세요.

AWS SDK 없이 서명이 필요한 경우는요?

직접 HTTP 로 AWS API 를 호출하거나 임베디드 기기·다른 언어에서 서명을 구현할 때, 이 도구의 중간값을 구현 결과와 비교해 디버깅하세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
