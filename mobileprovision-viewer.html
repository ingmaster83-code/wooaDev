iOS 프로비저닝 프로파일 뷰어

.mobileprovision(또는 security cms -D 로 꺼낸 plist)을 붙여 넣거나 파일로 선택하면 프로파일 이름, 앱 ID, 팀, 만료일, 종류(Development·Ad Hoc·App Store·Enterprise), 등록된 기기 UDID, Entitlements, 개발자 인증서(만료·SHA-1 지문)를 보여 주고 만료 임박과 기기 누락을 알려 줍니다.

사용 예시

✅ Wooa Demo Development — 개발 (Development), 151일 남음

이 도구로 할 수 있는 일

Xcode 없이 프로파일 내용을 브라우저에서 확인합니다. 파일은 서버로 전송되지 않습니다.

  • 입력: plist XML 텍스트, .mobileprovision 파일(CMS 래퍼에서 plist 추출), Base64/16진수
  • 정보: 이름, UUID, 번들 ID, 팀, 플랫폼, 생성·만료일과 남은 일수, 종류(개발·Ad Hoc·App Store·엔터프라이즈)
  • Entitlements: get-task-allow, aps-environment, keychain-access-groups, 앱 그룹 등 전체 목록
  • 기기: UDID 목록과 형식, 특정 UDID 등록 여부 확인
  • 인증서: 주체 CN, 발급자, 유효 기간, SHA-1 지문 (만료 검사)

💡 Tips

  • TestFlight·App Store 용 프로파일에는 기기 목록이 없습니다. 기기 UDID 가 보이면 개발 또는 Ad Hoc 입니다.
  • 프로파일 안의 인증서 SHA-1 지문은 키체인의 서명 인증서와 비교해 어떤 인증서로 서명 가능한지 확인하는 데 쓰입니다.
  • 만료된 프로파일은 설치·실행이 실패합니다. 만료 30일 전부터 경고를 표시합니다.

자주 묻는 질문

CMS 서명도 검증하나요?

아니요. 서명 래퍼에서 plist 를 꺼내 보여 줄 뿐 Apple 서명이 유효한지는 검증하지 않습니다.

macOS 의 .provisionprofile 도 되나요?

같은 plist 구조라 대부분 읽을 수 있습니다. 플랫폼과 Entitlements 는 macOS 용 값으로 표시됩니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
