💡 Tips

  • 헤더 행에서 정렬(왼쪽/가운데/오른쪽)을 선택할 수 있습니다
  • CSV 가져오기: 첫 번째 행이 자동으로 헤더가 됩니다
  • 열/행 오른쪽 × 버튼으로 삭제합니다
  • 생성된 마크다운은 GitHub, Notion, VS Code에서 바로 사용 가능합니다

자주 묻는 질문

마크다운 테이블은 어디서 사용하나요?

GitHub README, GitLab, Notion, Obsidian, VS Code, Discord 등 마크다운을 지원하는 모든 플랫폼에서 사용할 수 있습니다.

열 정렬 설정은 어떻게 동작하나요?

헤더 행의 정렬 선택기로 각 열의 정렬을 지정합니다. 구분선에 `:---`, `:---:`, `---:` 형식으로 반영됩니다.
