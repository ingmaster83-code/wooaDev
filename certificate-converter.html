이 도구로 할 수 있는 일

CA 가 준 여러 파일을 서버 설정에 맞는 한 파일로 합치거나 형식을 바꿀 때 씁니다. 인증서는 브라우저 밖으로 나가지 않습니다.

  • 입력: PEM 여러 개(openssl x509 -text 출력에 섞여 있어도 PEM 만 추출), DER 16진수·Base64, PKCS#7(.p7b/.p7c)
  • 변환: PEM(모두 추출), 체인 번들 PEM(중복 제거·리프→루트 정렬), DER(Base64·16진수)
  • 번들 옵션: 자체 서명 루트 제외(서버용), 각 인증서 앞에 주체·발급자·만료일 주석
  • PKCS#12(.pfx)는 암호화되어 있어 열 수 없다고 안내하고 openssl 변환 명령을 알려 줌
  • 입력에 개인키가 섞여 있으면 결과에서 제외하고 경고

💡 Tips

  • Nginx 는 ssl_certificate 에 리프 + 중간 CA 순서의 번들을 지정합니다. 루트는 보통 뺍니다.
  • Windows 에서 내보낸 .cer 는 DER 또는 Base64(PEM) 둘 중 하나입니다. 도구가 자동으로 판별합니다.
  • .p7b 는 인증서만 담은 PKCS#7 입니다. 개인키는 들어 있지 않습니다.

자주 묻는 질문

DER 파일 자체를 내려받을 수 있나요?

텍스트 도구라 Base64 로 보여 줍니다. Base64 를 디코드해(base64 -d) 저장하면 .der/.cer 파일이 됩니다.

PFX 는 왜 안 되나요?

비밀번호로 암호화된 컨테이너라 브라우저에서 다루지 않습니다. openssl pkcs12 로 PEM 으로 바꾼 뒤 사용하세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
