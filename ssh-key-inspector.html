SSH 공개키 검사기 · 지문 계산기

이 도구로 할 수 있는 일

서버나 GitHub 에 등록한 키가 맞는지, 로그에 찍힌 지문이 어떤 키의 것인지 확인할 때 씁니다. 키는 브라우저 밖으로 나가지 않습니다.

  • 입력: 공개키 여러 줄, authorized_keys 옵션(command=, from=, no-pty …), known_hosts 호스트 접두사, RFC 4716 형식
  • 계산: 키 종류·비트 수, SHA256:… 지문(ssh-keygen -lf 와 동일), MD5 지문
  • 점검: RSA 2048 미만, DSA(ssh-dss) 폐기, 중복 키, 주석 누락, 타입 불일치, 인증서(-cert-v01)·보안 키(sk-) 표시
  • 변환: RSA·Ed25519·ECDSA 를 PEM SubjectPublicKeyInfo 로 출력
  • 개인키(-----BEGIN OPENSSH PRIVATE KEY-----)를 붙여 넣으면 거부하고 경고

💡 Tips

  • 서버 로그나 GitHub 설정의 SHA256:… 값과 비교하면 어느 키인지 알 수 있습니다.
  • 새 키는 Ed25519 를 권장합니다. RSA 라면 3072비트 이상이 좋습니다.
  • authorized_keys 에 command= 옵션이 있으면 그 키로는 지정한 명령만 실행됩니다.

자주 묻는 질문

개인키를 붙여 넣어도 되나요?

안 됩니다. 개인키는 어디에도 붙여 넣지 마세요. 공개키(.pub)만 입력하세요. 개인키를 입력하면 도구가 거부합니다.

MD5 지문은 왜 따로 있나요?

OpenSSH 6.7 이전과 일부 장비는 MD5 지문을 보여 줍니다. 현재 표준은 SHA256 입니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
