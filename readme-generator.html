💡 Tips

  • 사용 예시 코드는 실제로 복사해서 바로 실행 가능한 형태로 작성하세요.
  • 주요 기능은 3~5개 정도로 간결하게 나열하는 것이 가독성이 좋습니다.
  • 완성 후 GitHub에서 미리보기로 렌더링 결과를 한 번 더 확인하세요.

자주 묻는 질문

생성된 README를 바로 GitHub에 올려도 되나요?

네, 표준 마크다운 형식으로 생성되므로 저장소 루트에 README.md로 저장하면 GitHub가 자동으로 프로젝트 페이지에 표시합니다.

뱃지(badge)는 어떻게 작동하나요?

shields.io 서비스를 이용한 이미지 링크로, 라이선스·버전 등의 정보를 뱃지 형태로 보여줍니다. GitHub 사용자명/저장소명을 입력하면 실제 저장소 정보에 맞게 자동 반영됩니다.

입력한 내용이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력값은 서버로 전송되지 않습니다.
