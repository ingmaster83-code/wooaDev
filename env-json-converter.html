ENV ↔ JSON 변환기

dotenv(.env) 형식을 JSON으로, JSON을 .env로 변환합니다. 숫자·불리언 자동 변환과 __ 중첩 규칙을 지원합니다.

사용 예시

✅ 변수 5개를 변환했습니다

입력 — 입력

# database
DB_HOST=localhost
DB_PORT=5432
DEBUG=true
API_KEY="abc def"
EMPTY=

결과 — 변환 결과

{
  "DB_HOST": "localhost",
  "DB_PORT": 5432,
  "DEBUG": true,
  "API_KEY": "abc def",
  "EMPTY": ""
}

이 도구로 할 수 있는 일

Docker, Kubernetes, CI 설정에서는 JSON을, 로컬 개발에서는 .env를 쓰는 경우가 많아 서로 옮겨야 할 때가 자주 있습니다.

  • .env → JSON: 주석·빈 줄 무시, 따옴표/export/인라인 주석 처리, 숫자·true/false·null 자동 변환(선택)
  • DB__HOST=h, DB__PORT=5432 → {"db":{"host":"h","port":5432}} 처럼 __ 로 중첩 객체 생성(선택)
  • JSON → .env: 중첩 키를 DB_HOST처럼 대문자 SNAKE_CASE로 펼치고, 공백·특수문자가 있는 값은 자동으로 따옴표 처리
  • 배열은 JSON 문자열로 저장하고 경고로 알려 줌

변환한 결과를 입력으로 되돌려 왕복 변환을 확인할 수 있습니다.

💡 Tips

  • secrets를 JSON으로 관리하는 도구에 옮길 때 "숫자·불리언 자동 변환"을 끄면 모든 값이 문자열로 유지됩니다.
  • 구분자를 __ 로 지정하면 DB__HOST 같은 계층형 환경 변수 규칙(.NET, Spring 등)과 맞출 수 있습니다.
  • 값에 공백이나 # 이 있으면 "항상 따옴표" 옵션이 없어도 자동으로 따옴표가 붙습니다.

자주 묻는 질문

모든 값이 문자열로 나오게 할 수 있나요?

"숫자·불리언 자동 변환" 옵션을 끄면 모든 값이 문자열로 유지됩니다. 포트 번호나 우편번호처럼 형태가 중요한 값에 적합합니다.

배열은 .env에서 어떻게 표현하나요?

.env에는 배열 표기가 없어 JSON 문자열(예: [1,2])로 저장하고 경고로 알려 드립니다. 애플리케이션에서 파싱해서 사용하세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
