Redis RESP 파서 · 명령 변환기

redis-cli --pipe 나 MONITOR, 패킷 캡처에서 얻은 RESP 텍스트·16진수를 타입(+, -, :, $, *, RESP3 확장), 길이, 값의 트리로 풀어 줍니다. SET key value 같은 명령을 RESP 바이트로 만드는 기능도 있습니다.

사용 예시

✅ 해석 완료 — 92바이트, 값 6개, 요소 11개

입력 — RESP 데이터 (또는 명령어)

*3

$3

SET

$5

hello

$5

Wooa!

:1000

+OK

-ERR unknown command

$-1

*2

$3

foo

:42

결과 — 구조 (바이트 오프셋)

오프셋 | 경로 | 타입 | 길이/수 | 값
0 | $ | Array | 3 | 요소 3개
4 |   $[0] | Bulk String | 3 | "SET"
13 |   $[1] | Bulk String | 5 | "hello"
24 |   $[2] | Bulk String | 5 | "Wooa!"
35 | $1 | Integer |  | 1000
42 | $2 | Simple String |  | "OK"
47 | $3 | Error |  | ERR unknown command
69 | $4 | Bulk String | -1 | null (없음)
74 | $5 | Array | 2 | 요소 2개
78 |   $5[0] | Bulk String | 3 | "foo"
87 |   $5[1] | Integer |  | 42

이 도구로 할 수 있는 일

Redis 서버와 주고받는 바이트가 어떤 명령과 응답인지 직접 읽을 때 씁니다. 데이터는 브라우저 밖으로 나가지 않습니다.

  • 입력: 실제 줄바꿈 텍스트, \r\n 이 글자로 적힌 텍스트, 16진수 바이트 / LF 만 있어도 CRLF 로 보정
  • 타입: + 단순 문자열, - 오류, : 정수, $ Bulk String(널 -1 포함), * 배열, RESP3 의 _ # , ( ! = % ~ > |
  • 트리 표(오프셋·경로·타입·길이·값)와 명령어처럼 보이는 배열은 "SET key value" 형태로 요약
  • Bulk String 길이가 실제와 다르면 위치와 함께 오류로 안내
  • 변환: 따옴표로 묶은 인자를 지원하는 명령어 → RESP 바이트(바이트 길이 기준), printf | nc 예시

💡 Tips

  • Bulk String 의 길이는 글자 수가 아니라 바이트 수입니다. 한글은 글자당 3바이트입니다.
  • 파이프라인 응답은 값이 여러 개 이어진 스트림이라 위에서부터 차례로 해석합니다.
  • redis-cli --pipe 로 대량 입력할 때는 이 도구로 만든 RESP 를 파일로 저장해 쓸 수 있습니다.

자주 묻는 질문

RESP2 와 RESP3 의 차이는요?

RESP3 는 널, 불리언, 실수, 맵, 셋, 푸시 같은 타입을 추가했습니다. HELLO 3 으로 협상한 연결에서 쓰입니다.

줄바꿈이 LF 뿐인 텍스트도 되나요?

네. RESP 는 CRLF 를 쓰므로 LF 를 CRLF 로 바꿔 해석하고 그 사실을 알립니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
