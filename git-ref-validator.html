Git 브랜치 · 태그 이름 검사기

브랜치나 태그 이름 목록을 넣으면 git check-ref-format 규칙을 어기는 이름을 찾아 이유를 알려 주고, 사용할 수 있는 이름으로 고쳐 제안합니다. 팀 규칙(소문자, 접두사) 점검도 선택할 수 있습니다.

사용 예시

❌ 12개 중 9개가 Git 규칙을 위반합니다

입력 — 브랜치·태그 이름 (한 줄에 하나)

feature/login-page
fix bug
release/v1.2.0
hotfix..urgent
.hidden
feature/new.lock
my-branch.
@
feat/add-@{x}
-bad
feature//double
USER/Mixed_Case

결과 — 검사 결과

이름 | 판정 | 사유 | 제안
feature/login-page | ✅ | git check-ref-format 규칙을 모두 통과 | 
fix bug | ❌ | 공백이나 제어 문자를 쓸 수 없습니다 | fix-bug
release/v1.2.0 | ✅ | git check-ref-format 규칙을 모두 통과 | 
hotfix..urgent | ❌ | 연속된 점(..)을 쓸 수 없습니다 | hotfix.urgent
.hidden | ❌ | 점(.)으로 시작하는 구성 요소가 있습니다 | hidden
feature/new.lock | ❌ | .lock 으로 끝나는 구성 요소가 있습니다 | feature/new-lock
my-branch. | ❌ | 점(.)으로 끝날 수 없습니다 | my-branch
@ | ❌ | @ 한 글자는 쓸 수 없습니다 (HEAD 의 별칭) | at
feat/add-@{x} | ❌ | @{ 시퀀스를 쓸 수 없습니다 | feat/add-x
-bad | ❌ | - 로 시작하면 명령어 옵션으로 오해됩니다 | bad
feature//double | ❌ | 연속된 슬래시(//)를 쓸 수 없습니다 | feature/double
USER/Mixed_Case | ⚠️ | 대문자 포함 — 대소문자 구분 안 하는 파일 시스템(Windows/macOS)에서 충돌할 수 있습니다 | user/mixed_case

결과 — 고친 이름 제안

fix bug  →  fix-bug
hotfix..urgent  →  hotfix.urgent
.hidden  →  hidden
feature/new.lock  →  feature/new-lock
my-branch.  →  my-branch
@  →  at
feat/add-@{x}  →  feat/add-x
-bad  →  bad
feature//double  →  feature/double
USER/Mixed_Case  →  user/mixed_case

이 도구로 할 수 있는 일

'not a valid branch name' 오류가 나거나, 브랜치 이름 규칙을 팀에 안내할 때 쓰는 도구입니다.

  • 검사 규칙: 연속된 점, 공백·제어 문자, ~ ^ : ? * [ \, @{ 시퀀스, 단독 @, 앞뒤 슬래시, // , 점으로 끝남, 점으로 시작하는 구성 요소, .lock 으로 끝남, 앞의 -
  • 종류 선택: 브랜치, 태그, 전체 참조(refs/…)
  • 위반 이유와 고친 이름 제안을 표로 제공 (여러 이름을 한꺼번에 검사)
  • 팀 규칙 점검: 대문자(대소문자 구분 없는 파일 시스템 충돌), _ 와 - 혼용, 접두사 없음, 60자 초과, 비ASCII
  • feature 브랜치와 feature/x 가 동시에 존재할 수 없는 경로 충돌 안내

💡 Tips

  • 브랜치 이름에 /가 있으면 폴더처럼 저장됩니다. feature 브랜치가 있으면 feature/x 를 만들 수 없습니다.
  • Windows·macOS 는 대소문자를 구분하지 않으므로 Feature 와 feature 가 충돌할 수 있습니다. 소문자만 쓰세요.
  • 이슈 번호를 넣은 feature/123-add-login 같은 형식은 추적에 유용합니다.

자주 묻는 질문

규칙을 통과했는데도 오류가 나요.

이미 같은 이름이나 상위 경로(feature 와 feature/x)가 있거나 원격 브랜치 이름이 겹치는 경우입니다. git branch -a 로 확인하세요.

한글 브랜치 이름도 되나요?

Git 규칙상 허용되지만 환경에 따라 인코딩 문제가 생길 수 있어 ASCII 를 권장합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
