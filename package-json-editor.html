package.json 검사 · 정리기

package.json 을 붙여 넣으면 name 규칙, version 형식, main/exports, 위험한 install 스크립트, 버전 범위(*·latest·git URL), 중복 의존성 같은 문제를 찾고, 키 순서와 의존성을 정렬한 깔끔한 JSON 을 만들어 줍니다.

사용 예시

❌ 오류 2건 · 의존성 8개

입력 — package.json

{
  "name": "My App",
  "version": "1.0",
  "main": "index.js",
  "scripts": { "start": "node index.js", "test": "echo \"Error: no test specified\" && exit 1", "postinstall": "node setup.js" },
  "dependencies": { "express": "^4.18.2", "lodash": "*", "left-pad": "latest", "react": "18.2.0", "mylib": "git+https://github.com/me/mylib.git" },
  "devDependencies": { "express": "^4.17.0", "jest": "~29.7.0", "typescript": ">=5 <6" },
  "engines": { "node": ">=18" },
  "license": "MIT License"
}

결과 — 의존성

패키지 | 범위 | 위치 | 설명
express | ^4.18.2 | dependencies | 마이너·패치 자동 업데이트
express | ^4.17.0 | devDependencies | 마이너·패치 자동 업데이트
jest | ~29.7.0 | devDependencies | 패치만 자동 업데이트
left-pad | latest | dependencies | ⚠️ 고정되지 않음 — 어떤 버전이든 설치됨
lodash | * | dependencies | ⚠️ 고정되지 않음 — 어떤 버전이든 설치됨
mylib | git+https://github.com/me/mylib.git | dependencies | Git/URL/로컬 경로
react | 18.2.0 | dependencies | 정확히 고정
typescript | >=5 <6 | devDependencies | 범위

결과 — 정리된 package.json

{
  "name": "My App",
  "version": "1.0",

}

이 도구로 할 수 있는 일

npm 패키지를 배포하거나 정리하기 전에 흔한 실수를 확인합니다. 파일은 서버로 보내지 않습니다.

  • 검사: name(소문자·214자·스코프), version(SemVer), private/license 누락, main/exports, engines
  • scripts: 기본 placeholder test, preinstall/postinstall 같은 설치 훅 경고
  • 의존성: 범위가 *·latest·빈 값·git/URL·file: 인 항목, 정확한 고정 버전, 두 곳에 중복된 패키지
  • 정리 모드: 표준 키 순서(name, version, scripts …)와 의존성 알파벳 정렬
  • 의존성 표: 종류별 이름과 범위

함께 쓰면 좋은 도구

💡 Tips

  • 라이브러리는 dependencies 에, 빌드·테스트 도구는 devDependencies 에 두세요.
  • postinstall 스크립트는 설치하는 사용자 환경에서 실행되므로 꼭 필요할 때만 사용하세요.
  • 배포하지 않을 앱 저장소라면 "private": true 로 실수 배포를 막을 수 있습니다.

자주 묻는 질문

정렬하면 scripts 순서도 바뀌나요?

정리 모드에서 의존성은 알파벳순으로 정렬되고 scripts 는 원래 순서를 유지합니다. 최상위 키만 관례 순서로 맞춥니다.

package-lock.json 도 되나요?

지원하지 않습니다. 이 도구는 package.json 전용입니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
