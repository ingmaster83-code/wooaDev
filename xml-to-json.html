XML → JSON 변환기

XML을 JSON으로 바꿉니다. 속성은 @키로, 반복 요소는 배열로, 숫자와 불리언은 값 타입으로 변환합니다.

사용 예시

✅ 변환 완료 — 루트 <order>

입력 — XML 입력

<?xml version="1.0" encoding="UTF-8"?>
<order id="A-1024" paid="true">
  <customer>Kim &amp; Co.</customer>
  <items>
    <item sku="P-1"><qty>2</qty><price>9.5</price></item>
    <item sku="P-2"><qty>1</qty><price>20</price></item>
  </items>
  <note/>
</order>

결과 — JSON 결과

{
  "order": {
    "@id": "A-1024",
    "@paid": true,
    "customer": "Kim & Co.",
    "items": {
      "item": [
        {
          "@sku": "P-1",
          "qty": 2,
          "price": 9.5
        },
        {
          "@sku": "P-2",
          "qty": 1,
          "price": 20
        }
      ]
    },
    "note": ""
  }
}

이 도구로 할 수 있는 일

SOAP 응답이나 RSS, 설정 XML을 JavaScript에서 다루려면 JSON으로 바꾸는 것이 가장 편합니다. 변환 규칙은 다음과 같습니다.

  • 속성은 "@속성명" 키로, 요소 안의 텍스트는 자식이 있을 때 "#text"로 저장
  • 같은 이름의 요소가 여러 번 나오면 배열로, "항상 배열로" 옵션을 켜면 하나뿐이어도 배열로 통일
  • 숫자·true/false는 값 타입으로 변환하되 007, 1.50처럼 되돌렸을 때 달라지는 값은 문자열로 유지
  • CDATA, &lt; 같은 엔티티, XML 선언은 자동으로 처리하고 태그가 맞지 않으면 줄·열 위치를 안내

JSON을 XML로 되돌리려면 JSON → XML 변환기를 이용하세요.

💡 Tips

  • 하위 요소 구조가 일정하지 않은 XML은 "항상 배열로"를 켜면 이후 코드에서 분기가 줄어듭니다.
  • 속성이 필요 없다면 "속성 무시"로 결과를 단순하게 만들 수 있습니다.
  • 숫자로 보이는 코드값(우편번호, 전화번호)은 선행 0이 있으면 자동으로 문자열로 남습니다.

자주 묻는 질문

XML 네임스페이스(접두사)는 어떻게 되나요?

태그 이름의 접두사(ns:tag)는 그대로 키 이름에 유지됩니다. 네임스페이스 URL을 해석하지는 않습니다.

DTD나 외부 엔티티도 처리하나요?

아니요. DOCTYPE은 무시하고 기본 엔티티(&lt; &gt; &amp; &quot; &apos;)와 숫자 문자 참조만 해석하므로 외부 엔티티를 통한 공격(XXE)과 무관하게 안전합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
