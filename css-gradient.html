💡 Tips

  • Linear: 한 방향으로 색이 변하는 기본 그라디언트. 배경·버튼·헤더에 많이 사용.
  • Radial: 중심에서 원형으로 퍼지는 그라디언트. 빛·하이라이트 효과에 적합.
  • Conic: 중심을 기준으로 각도 방향으로 색이 변함. 파이 차트·색상환 표현에 사용.
  • 색상 정지점 위치(%)를 조절해 색상 전환 구간을 세밀하게 제어할 수 있습니다.
  • background 속성 대신 background-image를 사용해도 동일하게 동작합니다.

자주 묻는 질문

CSS gradient 코드를 바로 복사할 수 있나요?

네. 생성된 CSS 코드를 클릭하면 클립보드에 복사됩니다.

방사형(radial) 그라디언트도 생성할 수 있나요?

네. 선형(linear)과 방사형(radial) 그라디언트 모두 지원합니다.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
