💡 Tips

  • 텍스트·이모지 모드로 1~2글자나 이모지 하나만 입력하면 빠르게 파비콘을 만들 수 있습니다.
  • ZIP 다운로드 후 파일들을 사이트 루트(/)에 업로드하고 포함된 HTML 코드만 붙여넣으면 끝입니다.
  • logo.svg나 logo.png를 파비콘으로 쓸 때는 이미지 모드로 업로드 후 즉시 변환하세요.

자주 묻는 질문

favicon.ico와 PNG 파일 중 어느 걸 써야 하나요?

둘 다 사용하는 것이 좋습니다. favicon.ico는 구형 브라우저 호환용이며, PNG 파일은 고해상도 디스플레이와 PWA에 사용됩니다. ZIP 다운로드 후 HTML 코드를 그대로 붙여넣으면 모든 브라우저에서 최적의 아이콘이 표시됩니다.

이미지를 어떤 크기로 준비해야 하나요?

최소 512×512px 이상의 정사각형 이미지를 권장합니다. PNG나 SVG 형식이면 화질이 가장 좋습니다. 업로드 후 자동으로 모든 크기로 변환됩니다.

파일이 서버에 업로드되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 개인정보와 민감한 데이터가 외부로 유출될 걱정이 없으며, 기업 보안 환경에서도 안심하고 사용할 수 있습니다.
