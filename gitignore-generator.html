.gitignore 생성기

사용하는 스택을 체크하면 조합된 .gitignore 파일을 바로 만들어줍니다.

💡 Tips

  • 운영체제(macOS/Windows)와 에디터(VSCode/IntelliJ) 항목은 언어와 상관없이 항상 함께 추가하는 것을 권장합니다.
  • .env 파일은 API 키 등 민감정보가 담기므로 반드시 무시 목록에 넣으세요.
  • 이미 커밋한 파일이 있다면 .gitignore 추가 후 git rm --cached -r . 로 캐시를 정리하세요.

자주 묻는 질문

여러 스택을 동시에 선택할 수 있나요?

네, 예를 들어 Node.js + macOS + VSCode처럼 여러 개를 체크하면 하나의 .gitignore 파일로 합쳐서 만들어줍니다.

이미 커밋된 파일은 .gitignore를 추가해도 계속 추적되나요?

네. .gitignore는 앞으로 새로 추가될 파일에만 적용됩니다. 이미 추적 중인 파일을 빼려면 git rm --cached 명령을 별도로 실행해야 합니다.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 선택값은 서버로 전송되지 않습니다.
