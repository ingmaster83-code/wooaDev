CSS 효과 생성기 — 그림자 · 테두리 · 변형 · 필터

값을 조절하면 box-shadow(겹친 그림자), text-shadow, border, transform, filter, 글래스모피즘(backdrop-filter) CSS 가 만들어지고 바로 미리보기로 확인됩니다.

사용 예시

✅ CSS 를 만들었습니다

결과 — CSS

.element {
  box-shadow:
    0px 8px 24px 0px rgba(0, 0, 0, 0.25),
    0px 4px 8px rgba(0, 0, 0, 0.15);
}

결과 — 참고

겹친 그림자(레이어)를 쓰면 한 겹보다 훨씬 자연스러운 깊이감이 납니다

이 도구로 할 수 있는 일

그림자의 offset·blur·spread 를 숫자로 조절하며 결과를 보고 CSS 를 복사합니다.

  • box-shadow: x, y, blur, spread, 색과 투명도, inset, 자연스러운 겹친 두 번째 그림자
  • text-shadow, border(두께·선 모양·색)·border-radius
  • transform: translate, rotate, scale, skewX 를 올바른 순서로 합성하고 transition 포함
  • filter: blur, brightness, contrast, grayscale, hue-rotate, saturate, sepia (기본값은 생략)
  • 글래스모피즘: 반투명 배경 + backdrop-filter(blur, saturate) + 접두사

💡 Tips

  • 부드러운 그림자는 한 겹보다 서로 다른 blur 두 겹을 겹쳐 쓰면 훨씬 자연스럽습니다.
  • transform 은 레이아웃을 바꾸지 않아 애니메이션에 유리합니다.
  • backdrop-filter 는 뒤에 이미지·그라디언트가 있어야 효과가 보입니다.

자주 묻는 질문

transform 함수의 순서가 왜 중요한가요?

여러 함수는 오른쪽부터 차례로 적용되어 회전한 뒤 이동하는 것과 이동한 뒤 회전하는 것의 결과가 다르기 때문입니다.

filter 와 backdrop-filter 의 차이는요?

filter 는 요소 자체(자식 포함)에, backdrop-filter 는 요소 뒤의 배경에 효과를 적용합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
