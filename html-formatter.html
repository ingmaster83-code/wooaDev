HTML 포맷터 · 구조 검사기

한 줄로 뭉쳐 있거나 들여쓰기가 엉킨 HTML을 읽기 쉽게 정리하고, 닫히지 않은 태그, 중복 id, alt 없는 이미지, lang·viewport 누락 같은 구조 문제를 찾아 줍니다. 최소화도 지원합니다.

사용 예시

🔍 구조 문제 2건

입력 — HTML

<!DOCTYPE html><html><head><meta charset="utf-8"><title>Demo</title><style>body{margin:0}</style></head><body><div class="wrap"><h1 id="t">Hello <em>world</em></h1><p>Short <b>bold</b> text.<img src="a.png"><ul><li>One<li>Two</ul><a href="#">link</a><script>if (a<b) { run(); }</script></div><div id="t"></body></html>

결과 — 결과

<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8">
    <title>Demo</title>
    <style>body{margin:0}</style>
  </head>
  <body>
    <div class="wrap">
      <h1 id="t">Hello <em>world</em></h1>
      <p>Short <b>bold</b> text.<img src="a.png"></p>
      <ul>
        <li>One</li>
        <li>Two</li>
      </ul>
      <a href="#">link</a>
      <script>if (a<b) { run(); }</script>
    </div>
    <div id="t"></div>
  </body>
</html>

결과 — 구조 검사

<img> 에 alt 속성이 없습니다 (접근성·SEO)
🚨 중복된 id="t"
🚨 </div> 가 없습니다 (<body> 이 닫힐 때까지 열려 있음)
<html> 에 lang 속성이 없습니다
모바일용 viewport 메타 태그가 없습니다

이 도구로 할 수 있는 일

복사해 온 마크업이나 템플릿 출력 결과를 읽기 쉽게 만들고 흔한 실수를 한 번에 확인합니다. 입력은 브라우저에서만 처리됩니다.

  • 정리: 블록 요소는 줄을 나누고 인라인 요소는 한 줄에 유지, void 요소(br, img)와 선택적 종료 태그(li, p) 처리
  • script·style·pre·textarea 내용은 원문 그대로 보존
  • 구조 검사: 닫히지 않은/짝 없는 태그, 중복 id, alt 없는 img, rel=noopener 없는 target=_blank, 인라인 on* 속성, 폐기 태그
  • 페이지 검사: DOCTYPE, html lang, title, meta charset, viewport
  • 최소화 모드와 줄 너비 설정

💡 Tips

  • pre·textarea 안의 공백은 의미가 있어 건드리지 않습니다.
  • 인라인 요소 사이의 공백 하나가 화면 간격을 만들 수 있어, 최소화 후에는 화면을 확인하세요.
  • 접근성을 위해 img 에는 항상 alt 를 쓰고 장식용이면 alt="" 로 두세요.

자주 묻는 질문

브라우저는 잘못된 HTML도 렌더링하는데 왜 검사하나요?

브라우저가 알아서 고친 결과가 의도와 다를 수 있고, 중복 id·누락된 속성은 스크립트·접근성·SEO 문제로 이어지기 때문입니다.

XHTML/JSX 도 되나요?

일반 HTML 규칙 기준입니다. 자체 종료 태그(<br />)는 인식하지만 JSX 전용 문법은 지원하지 않습니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
