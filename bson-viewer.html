BSON 디코더 · 확장 JSON 변환기

MongoDB 의 BSON 바이트를 16진수·Base64·.bson 파일로 받아 요소 표(바이트 오프셋)와 Relaxed·Canonical 확장 JSON 으로 풀어 줍니다. 확장 JSON 을 BSON 으로 인코딩할 수도 있습니다.

사용 예시

✅ 해석 완료 — 125바이트, 문서 1개, 요소 10개

이 도구로 할 수 있는 일

mongodump 로 받은 .bson 파일이나 네트워크로 잡은 문서를 열어 볼 때 씁니다. 파일은 서버로 전송되지 않습니다.

  • 입력: 16진수, Base64, .bson 파일(문서 여러 개가 이어진 mongodump 형식 포함)
  • 요소 표: 바이트 오프셋, 타입 바이트, 경로, 타입, 값 — double, string, document, array, binary, ObjectId, bool, datetime, null, regex, int32, timestamp, int64, decimal128, minKey·maxKey
  • 출력 표기: Relaxed 확장 JSON, Canonical 확장 JSON, 타입 정보를 뺀 단순 JSON
  • 문서 크기·종료 바이트 검증, 중복 키·폐기된 타입(undefined, symbol, DBPointer) 알림
  • 인코딩: 확장 JSON($oid, $date, $numberLong …)을 BSON 바이트로 변환

💡 Tips

  • Relaxed 는 사람이 읽기 좋고 Canonical 은 타입을 잃지 않습니다. 다른 도구로 옮길 때는 Canonical 이 안전합니다.
  • ObjectId 의 앞 4바이트는 생성 시각입니다. ObjectId 도구에서 날짜로 바꿔 볼 수 있습니다.
  • JSON 숫자는 int32 범위면 int32, 안전한 정수 범위면 int64, 아니면 double 로 인코딩됩니다.

자주 묻는 질문

BSON 과 JSON 의 차이는 무엇인가요?

BSON 은 MongoDB 가 쓰는 바이너리 JSON 이며 날짜, ObjectId, 바이너리, Int64, Decimal128 같은 JSON 에 없는 타입을 가집니다.

Relaxed 와 Canonical 확장 JSON 의 차이는요?

Canonical 은 모든 숫자에 $numberInt 같은 타입 표기를 붙여 정확히 왕복 변환되고, Relaxed 는 일반 숫자·ISO 날짜를 써서 읽기 쉽습니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
