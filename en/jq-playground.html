jq Playground (Online jq Runner)

Paste JSON and a jq filter to see the result immediately. A jq 1.7-compatible interpreter with pipes, select, map, group_by, reduce / foreach, variables and destructuring, def functions, regex (test, match, sub), formats such as @csv and @base64, path updates (|=, +=), multiple inputs and the -n -s -r -c -S options.

Example

✅ 1 output(s)

Input — jq filter

.users | map(select(.age >= 30) | {name, city: .address.city}) | sort_by(.name)

Input — JSON input (several concatenated values are allowed)

{"users":[{"name":"Mina","age":34,"address":{"city":"Seoul"}},{"name":"Joon","age":28,"address":{"city":"Busan"}},{"name":"Ara","age":41,"address":{"city":"Daegu"}}]}

Result — Output

[
  {
    "name": "Ara",
    "city": "Daegu"
  },
  {
    "name": "Mina",
    "city": "Seoul"
  }
]

What this tool does

Build and test jq filters without installing jq. Your JSON and filter are not uploaded.

  • Syntax: pipes, commas, alternative (//), paths (.a.b[0], .[1:3], .[]?, ..), object and array construction, string interpolation "\(…)", formats (@csv @tsv @json @html @uri @sh @base64 @base32)
  • Control: if / elif / else, try / catch, reduce, foreach, label / break, as-variables with destructuring (including ?//), def functions (recursion, closure arguments)
  • 200+ builtins: map, select, sort_by, group_by, unique_by, to_entries, with_entries, paths, walk, limit, first / last, range, test / match / capture / sub / gsub, split / join, tojson, todate and more
  • Updates: =, |=, +=, -=, *=, /=, //=, del, delpaths, setpath, pick
  • Options: -c -r -j -S -n -s -R --tab --indent, --argjson variables and consecutive JSON values as input

💡 Tips

  • For long filters, add one | step at a time and check the result as you go. Error messages follow real jq's wording.
  • Choose -r to print strings without quotes, which is handy when piping one value per line.
  • For objects with many keys, to_entries / with_entries lets you handle keys and values together.

Frequently Asked Questions

Is the output identical to real jq?

It implements jq 1.7 syntax and the main builtins and is verified against the manual's examples, but it is not 100% identical. As JavaScript objects, integer-like keys always sort first, and big integers are limited to JavaScript number precision.

What happens with an infinite loop?

There are limits on execution steps and output count; going past them stops the run with an error, so the browser does not freeze.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
