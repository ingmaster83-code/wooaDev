W3C Trace Context Tool — traceparent & tracestate

Analyses the distributed-tracing headers traceparent (00-trace-id-span-id-flags) and tracestate, validates them, starts a new trace or derives a child span from a parent, and shows curl, B3 and Datadog header examples.

Example

✅ Valid traceparent

Input — traceparent header value

00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01

Input — tracestate header value (optional)

congo=t61rcWkgMzE,rojo=00f067aa0ba902b7

Input — Parent traceparent (to create a child span)

00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01

Result — Fields

Field | Value
version | 00
trace-id | 4bf92f3577b34da6a3ce929d0e0e4736
parent-id (span) | 00f067aa0ba902b7
trace-flags | 01 (0b00000001)
sampled | yes — record / export this trace
random-trace-id | no / unknown
tracestate[1] | congo = t61rcWkgMzE
tracestate[2] | rojo = 00f067aa0ba902b7

Result — Headers

traceparent: 00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01
tracestate: congo=t61rcWkgMzE,rojo=00f067aa0ba902b7

What this tool does

Check that the traceparent crossing services in OpenTelemetry-style tracing is valid and whether it is sampled.

  • Parse: version, 32-char trace-id, 16-char span-id, flags (sampled = 01, random = 02) and tracestate entries
  • Validate: lowercase hex, lengths, no all-zero IDs, no version ff, no extra fields on version 00 and tracestate key, value, 32-entry and 512-char limits
  • Generate: a new trace from secure randomness, or a child span that keeps the parent's trace-id
  • Examples as a curl header, B3 (Zipkin) and Datadog
  • Notes that an invalid tracestate is dropped independently of the traceparent

💡 Tips

  • With the sampled flag at 00 the trace may not be recorded or exported.
  • A service must keep the received trace-id and create only a new span-id for the next call to keep the trace connected.
  • Logging the trace-id lets you link logs with traces.

Frequently Asked Questions

traceparent versus tracestate?

traceparent is the standard field every system understands; tracestate is optional and carries vendor-specific data.

Why are uppercase hex digits invalid?

The spec allows lowercase hex only, so a receiver ignores a header written in uppercase.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
