.gitignore Tester — Which Rule Applies?

Enter .gitignore content and paths to see whether each path is ignored, which line is responsible and why a negation (!) rule does not work, using the same rules as Git.

Example

✅ 6 of 10 path(s) are ignored

Input — .gitignore content

# 빌드 산출물
node_modules/
dist/
*.log
.env
!.env.example
/config/*.local
build/**/*.map
!important.log

Input — Paths to test (one per line, folders end with /)

node_modules/express/index.js
dist/app.js
src/debug.log
important.log
.env
.env.example
config/db.local
config/sub/db.local
build/js/main.js.map
src/index.js

What this tool does

Trace problems such as 'I added it to .gitignore but it is still tracked' or 'my ! rule does nothing' rule by rule. Everything is evaluated in your browser.

  • For each path: ignored or tracked, the responsible line number and rule, and an explanation
  • Output in the same shape as git check-ignore -v
  • Syntax: *, ?, [abc], [!abc], **/, /**/, trailing /**, leading / (anchored), trailing / (folders only), \# and \! escapes
  • Warns about Git's rule that files under an ignored folder cannot be re-included with !
  • core.ignorecase (case-insensitive) option

💡 Tips

  • Files that were already committed stay tracked after you add them to .gitignore. Run git rm --cached file.
  • To keep only part of a folder ignore dir/* instead of dir/ and re-include with !dir/keep.txt.
  • Nested .gitignore files, .git/info/exclude and the global ignore file are not applied, so test one file at a time.

Frequently Asked Questions

Why does ! not re-include my file?

When a parent folder is ignored Git never looks inside it. Writing dir/* instead of dir/ ignores the contents while leaving the folder open.

Are build and build/ different?

build/ only matches folders, while build matches both files and folders with that name.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
