What this tool does

Structure a few lines of log quickly when investigating an outage or odd traffic. Logs never leave your browser.

  • Formats: combined, common and variants with extra trailing fields such as response time
  • Table: line, IP, time, method, path, status, bytes, user agent; CSV with every field
  • Statistics: requests, bytes, 2xx–5xx share, top IPs and paths, methods, 5xx list and a bot / script estimate
  • Detection: scanning requests (wp-login, .env, ../) and repeated 401 / 403 on login paths
  • Reports the numbers of lines that failed to parse

💡 Tips

  • Behind a proxy or CDN the logged IP may be the proxy; add X-Forwarded-For to the log format.
  • IP addresses can be personal data; mask them before sharing.
  • To see response times add nginx's $request_time to the log format.

Frequently Asked Questions

Does it read JSON logs?

This tool is for text combined / common formats. Use the JSON Lines viewer for JSON logs.

Combined versus common?

Combined is common plus the Referer and User-Agent fields.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
