💡 Tips

  • Use 755 for directories and executable scripts; 644 for regular files in web server setups.
  • Read (r) = 4, Write (w) = 2, Execute (x) = 1. Add the values for each group to get the octal digit.
  • Avoid setting 777 permissions — it allows everyone to write and execute, creating a security risk.

Frequently Asked Questions

What does chmod 755 mean?

Owner can read, write, and execute (7); group and others can read and execute (5).

What is the difference between symbolic and numeric mode?

Numeric (octal) mode uses digits like 755; symbolic mode uses letters like u+x, g-w.

Is my data sent to a server?

No. All processing happens entirely within your browser — your files are never uploaded to any server. This zero-server architecture keeps your data 100% private, safe for sensitive documents and enterprise security environments.
