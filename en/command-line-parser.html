Command Line, PATH & Environment Variable Analyzer

Breaks a complex shell command line into the program, arguments, leading env vars, pipes and redirections, and audits the PATH variable and environment variable lists for duplicates, risky entries and mistakes.

What this tool does

Check the structure of a long command with mixed quotes before reading it closely or moving it into a script. Input is processed in the browser and never executed.

  • Command lines: POSIX quoting ('…', "…", $'…', \), env prefixes, pipes (|, |&), lists (&&, ||, ;, &), redirections (>, >>, <, 2>, 2>&1, &>) and subshells
  • Warnings: unquoted $variables (word splitting, globbing), command substitution, rm -rf, chmod 777, curl | sh, eval and a wrong 2>&1 order
  • Windows rules (CommandLineToArgvW) for argument splitting are available too
  • PATH: duplicates, empty entries (current directory), relative paths, ~ and trailing slashes, plus a tidied export line
  • Environment variables: tidy KEY=VALUE / export / .env, flag duplicates, bad names and secrets, and output export, .env, docker -e and JSON

💡 Tips

  • An empty PATH entry (::) or . means the current directory and risks running a malicious binary.
  • In scripts always quote variables as "$var" so values with spaces are not split into several arguments.
  • 2>&1 must come after the file redirect: command > out.log 2>&1.

Frequently Asked Questions

Does this tool run the command?

No. It only analyses the string. Variable expansion and command substitution are shown as written, not evaluated.

Which end of PATH has priority?

Earlier entries are searched first. If the same program exists in several places the first one runs; check with which -a.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
