What this tool does

Data URIs embed small images, SVGs and snippets directly in HTML or CSS with no extra request. You also need to decode them when you find a mysterious long data: string in code.

  • Text → Data URI: choose a MIME type (svg, html, json, css, js…) and Base64 or percent-encoding
  • File → Data URI: any image, font, PDF… as a Base64 Data URI
  • Data URI → content: shows MIME, charset, encoding and decoded size; text is displayed as text, binary as hex
  • Image Data URIs get a preview on a transparency grid

For text formats like SVG, percent-encoding is shorter than Base64 and compresses better with gzip.

💡 Tips

  • In CSS you can use percent-encoded SVG directly: url("data:image/svg+xml,…").
  • Base64 Data URIs are about 33% larger than the original, so avoid them for files beyond a few KB.
  • If you only convert images, the Image to Base64 tool is also available.

Frequently Asked Questions

Is there a size limit for Data URIs?

It varies by browser, but most handle several MB. They bloat HTML/CSS and can't be cached separately, so reserve them for small resources.

Is charset=utf-8 required?

For text such as HTML or JSON containing non-ASCII characters, specifying it is safest. SVG sets its encoding in the XML declaration, so it may be omitted.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
