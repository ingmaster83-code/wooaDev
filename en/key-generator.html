What this tool does

Create key pairs for development and tests without installing anything. Keys are generated only in your browser and never sent.

  • Key types: ECDSA P-256, P-384, P-521, Ed25519, RSA 2048, 3072, 4096
  • Output: private key (PKCS#8 PEM), public key (SPKI PEM), JWK (private and public separated) and an SSH authorized_keys line
  • Fingerprints: SSH SHA256 (same as ssh-keygen -lf) and JWK RFC 7638
  • The public key matches openssl pkey -pubout in standard format
  • Reminds you not to use on-screen keys in production and which browsers support Ed25519

💡 Tips

  • For JWT signing tests ECDSA P-256 (ES256) or Ed25519 is short and fast.
  • Paste the SSH line into ~/.ssh/authorized_keys as is and save the private PEM with chmod 600.
  • RSA 4096 can take a few seconds to generate.

Frequently Asked Questions

Can I use a key generated here in production?

Not recommended; create production keys on a server or in an HSM / KMS. This tool is for testing and learning.

Is the private key sent to a server?

No. Everything runs in the browser's Web Crypto and disappears when the page closes; copy what you need right away.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
