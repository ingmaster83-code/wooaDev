requirements.txt Analyser & Converter

Splits requirements.txt lines into package, extras, specifier, environment marker and options (-r, -e, --hash), flags unpinned dependencies and converts to pyproject.toml, Pipfile, Poetry or a tidied requirements.txt.

What this tool does

Use it to move an old requirements.txt to a modern pyproject or to find problems. Your file is not uploaded.

  • Analysis: package name (normalised: case and _ . → -), extras [security], specifier and marker ; python_version<"3.9"
  • Option lines: -r includes, -e editable installs, --index-url and --hash shown separately
  • Checks: no version, ranges instead of ==, duplicate packages, VCS / URL dependencies
  • Output: pyproject.toml [project] dependencies, Pipfile [packages], Poetry notation and a sorted requirements.txt
  • Invalid lines are reported with their position

💡 Tips

  • For reproducible builds create a lock file (==) with pip-tools or uv and keep direct dependencies in pyproject.
  • Django and django, python_dateutil and python-dateutil are treated as the same package.
  • Environment markers are kept in the converted output.

Frequently Asked Questions

Is the Poetry output the same as pip specifiers?

Poetry mostly uses ^ and ~, but this tool copies the original specifier so the meaning does not change.

How is -r other.txt handled?

The other file cannot be read, so it is shown only as an include; paste its contents as well.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
