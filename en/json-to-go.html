JSON to Go Struct Converter

Paste an API response and get Go structs with json tags. Every array element is analysed so missing fields are handled correctly.

What this tool does

Calling a JSON API from Go means hand-writing structs for the response. A single sample hides fields that are absent or null in other responses, so this tool analyses all your samples.

  • Merges every array element (or several concatenated JSON values): fields present in only some become omitempty pointers
  • Fields with null become pointers (*string…), int+float mixes become float64, inconsistent types become interface{}/any
  • Applies Go initialism conventions: user_id → UserID, api_url → APIURL
  • Nested objects get their own structs; identical shapes are reused
  • Options for int vs int64, time.Time and any

The output is a starting point — adjust names and types to your project's conventions.

💡 Tips

  • Paste 2–3 different responses together; optional fields are detected far more accurately.
  • Keep the int64 option on for IDs and counts that can grow large.
  • Enable "time.Time for date-time strings" to get time.Time fields for RFC 3339 dates.

Frequently Asked Questions

Why do some fields become pointers?

In Go you need a pointer to tell a missing value (null) from 0 or an empty string. Turn the pointer option off to get plain types.

What if the top level is an array?

A struct is generated from the item shape and a comment reminds you to decode into a slice of that type.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
