JSON Diff — Compare Two JSON Documents by Path

Compares two JSON documents semantically, lists added, removed and changed values with their paths, and generates a JSON Patch.

Example

🔍 Added 2 · Removed 1 · Changed 2

Input — Original JSON (A)

{
  "name": "WooaDev",
  "version": "1.0.0",
  "tags": ["json", "tool"],
  "author": { "name": "Kim", "email": "kim@example.com" },
  "legacy": true
}

Input — Changed JSON (B)

{
  "name": "WooaDev",
  "version": "1.1.0",
  "tags": ["json", "tool", "free"],
  "author": { "name": "Kim", "email": "kim@wooahouse.com" },
  "license": "MIT"
}

Result — Changes

Type | Path | Before (A) | After (B)
Changed | $.version | "1.0.0" | "1.1.0"
Added | $.tags[2] |  | "free"
Changed | $.author.email | "kim@example.com" | "kim@wooahouse.com"
Removed | $.legacy | true | 
Added | $.license |  | "MIT"

Result — JSON Patch (A → B)

[
  {
    "op": "replace",
    "path": "/version",
    "value": "1.1.0"
  },
  {
    "op": "add",
    "path": "/tags/2",
    "value": "free"
  },
  {
    "op": "replace",
    "path": "/author/email",
    "value": "kim@wooahouse.com"
  },
  {
    "op": "add",
    "path": "/license",
    "value": "MIT"
  },
  {
    "op": "remove",
    "path": "/legacy"
  }
]

What this tool does

A text diff flags every line when only indentation or key order changed. This tool parses both documents first and compares values, so only real changes show up.

  • Ignores key order, whitespace and line breaks; shows added/removed/changed values with paths such as $.user.tags[1]
  • Type changes (number 1 → string "1") are labelled separately
  • "Ignore array order" treats arrays with the same elements as equal
  • Also generates a JSON Patch (RFC 6902) that turns A into B — handy for PATCH requests or change logs

For line-by-line text comparison, use the Diff Viewer.

💡 Tips

  • To see how an API response changed between releases, just paste both responses.
  • Turn on "Ignore array order" for lists of tags or IDs where order doesn't matter.
  • The generated patch removes array tail items from the highest index down, so applying it in order turns A into B.

Frequently Asked Questions

Is JSON with a different key order considered different?

No. Key order in a JSON object has no meaning, so it is ignored. Arrays are compared in order by default.

Are 1 and 1.0 the same value?

JSON doesn't distinguish integers from floats, so they are equal. A number and a string (1 vs "1") are reported as a type change.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
