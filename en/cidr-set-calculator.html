CIDR Set Calculator — Merge · Intersect · Exclude

Aggregates CIDR blocks into fewer entries, computes intersection, union and difference of two lists, or checks whether IPs fall inside a range. IPv4 and IPv6 are supported.

What this tool does

Firewalls, security groups, nginx allow lists and cloud IP ranges grow long, and overlapping or adjacent entries should be consolidated.

  • Merge: aggregate overlapping or touching blocks into the fewest CIDRs (10.0.0.0/24 + 10.0.1.0/24 → 10.0.0.0/23)
  • Intersection (A∩B), difference (A−B), union (A∪B): remove a range from an allow list or find what two lists share
  • Containment: is each B entry fully inside A, partly overlapping, or outside?
  • Input: CIDRs, single IPs, "start - end" ranges and # comments, one per line
  • Reports total address and CIDR counts

💡 Tips

  • A difference (A−B) can split into several CIDRs because CIDR blocks are powers of two.
  • Paste a cloud provider's published IP list and merge it to shrink your rule count dramatically.
  • IPv4 and IPv6 can be mixed; each family is computed separately.

Frequently Asked Questions

Doesn't merging widen the allowed range?

No. The tool re-expresses exactly the same set of addresses with the fewest CIDRs; it never adds addresses.

How are ranges (start - end) handled?

They're decomposed into the minimal CIDRs and merged with the other entries.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
