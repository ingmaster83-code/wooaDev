JSON to XML Converter

Turns JSON objects into XML elements, with support for attributes (@), text (#text), repeated array items and proper escaping.

Example

✅ Converted

Input — JSON input

{
  "order": {
    "@id": "A-1024",
    "customer": "Kim & Co.",
    "items": [
      { "sku": "P-1", "qty": 2, "price": 9.5 },
      { "sku": "P-2", "qty": 1, "price": 20 }
    ],
    "note": null,
    "paid": true
  }
}

Result — XML output

<?xml version="1.0" encoding="UTF-8"?>
<order id="A-1024">
  <customer>Kim &amp; Co.</customer>
  <items>
    <sku>P-1</sku>
    <qty>2</qty>
    <price>9.5</price>
  </items>
  <items>
    <sku>P-2</sku>
    <qty>1</qty>
    <price>20</price>
  </items>
  <note/>
  <paid>true</paid>
</order>

What this tool does

Bridging a JSON REST API and an XML/SOAP system raises one question: how should the structure be mapped? This converter follows the widely used conventions.

  • A key starting with @ becomes an XML attribute, "#text" is the element's text and "#cdata" a CDATA section
  • Arrays are written as repeated elements with the same name (a top-level array is wrapped in the name you choose)
  • null and empty strings become empty elements (<a/> or <a></a>); &, <, > and " are escaped automatically
  • Names that cannot be XML tags (starting with a digit, containing spaces…) are renamed safely and reported

For the reverse direction use the XML to JSON converter.

💡 Tips

  • You can change the attribute prefix (for example to _). Use the same prefix in the XML to JSON tool for lossless round trips.
  • If the top level is an object with a single key, that key becomes the root element; otherwise the value is wrapped in the root name you set.
  • Single-line output suits places where whitespace is significant, such as SOAP bodies.

Frequently Asked Questions

How are JSON arrays represented in XML?

XML has no array type, so the same element name is repeated. For example {"item":[1,2]} becomes <item>1</item><item>2</item>.

Are number and boolean types preserved?

XML stores everything as text, so type information is lost. When converting back, enable "Convert numbers & booleans" in the XML to JSON tool.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
