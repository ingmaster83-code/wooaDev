FAQ

What is the difference between meta description and OG description?
Meta description is used by search engines for SERP snippets. OG (Open Graph) description is shown when sharing on social media platforms like Facebook or LinkedIn. Both should be compelling but can differ slightly.
Do meta keywords still matter for SEO?
Google officially ignores the meta keywords tag. However, some other search engines (like Yandex) still consider it. It doesn't hurt to include them but shouldn't be your main SEO focus.
