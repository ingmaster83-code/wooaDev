ADB Command Builder — Know the Command Before You Run It

Build common adb commands from options — install, uninstall and launch apps, logcat filters, screenshots and recording, file copy, tap and swipe input, port mapping, wireless connect, permissions, intents and dumpsys — with an explanation of each part and warnings.

Example

✅ Command built

Result — ADB command

adb shell am start -n com.example.app/.MainActivity

Result — What each part does

Part | Meaning
adb | Android Debug Bridge
shell am start | Start an activity via the activity manager
-n com.example.app/.MainActivity | package/activity (.MainActivity is relative to the package)

What this tool does

Pick options instead of memorising adb flags and get a one-line command with an explanation table.

  • Tasks: devices, install, uninstall, start, force-stop, pm clear, logcat, screencap, screenrecord, push / pull, input, forward / reverse, connect, pm grant / revoke, am start / broadcast, dumpsys, pm list packages, reboot
  • logcat: minimum level, tag filter (+ *:S) and app process only (--pid=$(pidof …))
  • Safety notes: pm clear wipes data, an .aab cannot be installed directly, an open port 5555 is risky, non-ASCII input text limits
  • -s serial prefix when several devices are attached
  • A table of what each part does

💡 Tips

  • With several devices attached always give -s serial; list them with adb devices -l.
  • For React Native, adb reverse tcp:8081 tcp:8081 connects the device to Metro.
  • exec-out screencap saves the PNG without newline conversion.

Frequently Asked Questions

adb shows 'unauthorized'.

Approve the USB debugging prompt on the device; if it does not appear run adb kill-server and reconnect.

How do I connect wirelessly?

On Android 11+ pair first with adb pair IP:port using the code from Wireless debugging, then adb connect.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
