XPath Tester (XPath 1.0)

Enter XML and an XPath expression to see matched nodes as paths, values and XML fragments, and the results of functions such as count(), sum() and contains(). All axes and predicates are supported through a built-in engine that does not depend on browser support.

Example

✅ 1 node(s) matched

Input — XML

<?xml version="1.0"?>
<catalog>
  <book id="b1" lang="en">
    <title>XML Basics</title>
    <author>Kim</author>
    <price currency="USD">29.99</price>
  </book>
  <book id="b2" lang="ko">
    <title>XPath 입문</title>
    <author>Lee</author>
    <price currency="KRW">18000</price>
  </book>
  <book id="b3" lang="en">
    <title>Advanced XSLT</title>
    <author>Kim</author>
    <price currency="USD">45.00</price>
  </book>
</catalog>

Input — XPath expression

//book[author="Kim" and price > 30]/title

Result — Matched nodes

# | Type | Path | String value
1 | element | /catalog/book[3]/title | Advanced XSLT

Result — Result

<title>Advanced XSLT</title>

What this tool does

Build an expression that picks values from SOAP responses, RSS or config XML and see the result immediately. Data never leaves your browser.

  • Paths: absolute and relative, //, ., .., @attribute, wildcard *, text(), comment(), node()
  • Axes: child, descendant (-or-self), parent, ancestor (-or-self), following (-sibling), preceding (-sibling), attribute, self
  • Predicates and operators: [position], [condition], and, or, not(), = != < <= > >=, + - * div mod, existential node-set comparison and union |
  • Functions: count, sum, position, last, name, local-name, string, concat, contains, starts-with, substring*, normalize-space, translate, number, floor, ceiling, round, boolean … (plus a few 2.0 functions: ends-with, lower-case, upper-case, matches, replace, abs)
  • Results: a node-set (path, value, XML fragment), string, number or boolean

💡 Tips

  • //book[price > 30] converts text to numbers before comparing.
  • With a default namespace (xmlns=...) //item will not match; use //*[local-name()="item"].
  • (//book)[1] differs from //book[1]: the first is the first of all, the second the first book of each parent.

Frequently Asked Questions

Does it support XPath 2.0 / 3.1?

The core is XPath 1.0 with a few common 2.0 functions as extensions; sequences and for / let expressions are not supported.

Is it the same as the browser's document.evaluate?

It follows standard XPath 1.0 rules and gives the same results; only namespace handling is simplified to comparing the prefixed names written in the document.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
