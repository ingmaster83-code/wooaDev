XML Schema (XSD) Validator

Paste XML and an XSD to check element order and occurrences, required attributes, simple types (integers, dates, booleans …), facets (enumeration, pattern, length, range) and ID / IDREF, with the location (XPath) and reason for each error.

Example

⛔ 5 error(s)

Input — XML to validate

<?xml version="1.0"?>
<catalog>
  <book id="b1" pages="320">
    <title>XML Basics</title>
    <author>Kim</author>
    <price currency="USD">29.99</price>
    <published>2024-02-30</published>
  </book>
  <book id="b1" pages="0">
    <title>XPath 입문</title>
    <price currency="EUR">18000</price>
    <isbn>123</isbn>
  </book>
</catalog>

Input — XSD schema

<?xml version="1.0"?>
<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema">
  <xs:element name="catalog">
    <xs:complexType>
      <xs:sequence>
        <xs:element name="book" maxOccurs="unbounded">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="title" type="xs:string"/>
              <xs:element name="author" type="xs:string" maxOccurs="3"/>
              <xs:element name="price">
                <xs:complexType>
                  <xs:simpleContent>
                    <xs:extension base="xs:decimal">
                      <xs:attribute name="currency" use="required">
                        <xs:simpleType>
                          <xs:restriction base="xs:string">
                            <xs:enumeration value="USD"/>
                            <xs:enumeration value="KRW"/>
                          </xs:restriction>
…

Result — Validation errors

# | Path | Error
1 | /catalog/book[1]/published | Value "2024-02-30" is not a real date
2 | /catalog/book[2] | Duplicate ID "b1"
3 | /catalog/book[2] | Attribute pages value "0" is outside the positiveInteger range (1 to inf)
4 | /catalog/book[2] | Child elements do not match the schema: at <price> expected <author>
5 | /catalog/book[2]/price | Attribute currency value "EUR" is not one of the allowed values (USD, KRW)

Result — Notes

Supported: elements, attributes, complexType (sequence, choice, all, group, extension / restriction), simpleType (facets, list, union), built-in types, occurrences and ID / IDREF. Namespaces are compared by local name only; key / unique / keyref, import / include and substitutionGroup are not checked

What this tool does

Check an integration XML against its schema in the browser without xmllint. Your files are not uploaded.

  • Structure: sequence, choice, all and group, minOccurs / maxOccurs, mixed, empty elements, extension and restriction (complexContent, simpleContent), named types and element ref
  • Error location: an XPath such as /catalog/book[2]/price and a reason like "child elements do not match: expected <author> at <price>"
  • Attributes: required, prohibited, fixed, default, undeclared attribute errors and anyAttribute
  • Types: string, the integer family (with ranges), decimal, boolean, date, dateTime, time, duration, anyURI, hexBinary, base64Binary, NMTOKEN, language, ID / IDREF and other built-ins
  • Facets: enumeration, pattern, length, minLength, maxLength, min / maxInclusive and Exclusive, totalDigits, fractionDigits, list and union

💡 Tips

  • The first ordering error can cause later cascading errors; fix from the top.
  • Dates are checked for real existence too (no February 30), not just format.
  • key / unique / keyref, substitutionGroup and import / include are not supported; use a dedicated tool for those.

Frequently Asked Questions

Does it handle namespaced XML?

Prefixes are ignored and names compared locally, so schemas that distinguish elements by targetNamespace may not be exact.

What about XSD 1.1 assertions?

Not supported; it targets the core of XSD 1.0.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
