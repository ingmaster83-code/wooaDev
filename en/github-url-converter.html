What this tool does

README images, script downloads and CDN usage each need a different URL form. Paste one and get them all.

  • Input: github.com blob / tree / raw URLs, raw.githubusercontent.com URLs, git@github.com:… ssh URLs, repository URLs and github.io
  • Output: repository, HTTPS / SSH clone, GitHub CLI, Blob, Raw (two forms), jsDelivr CDN, GitHub API contents, github.dev, Blame, History and ZIP
  • Keeps line anchors (#L10-L20) and encodes special characters in paths
  • For branch names with slashes (feature/x) set the number of ref parts; the ref (branch, tag or SHA) can be overridden
  • Branch-name links change over time, so a commit SHA permalink is recommended

💡 Tips

  • When quoting code in docs or issues use a commit SHA permalink (press y on GitHub) instead of a branch.
  • The jsDelivr CDN caches, so new commits may be slow to appear. Pin a tag or SHA.
  • Raw URLs of private repositories need a token; do not share them as they are.

Frequently Asked Questions

What is the difference between blob and raw?

blob is the GitHub web page (highlighting, buttons) while raw serves the plain file content. Use raw for running scripts or embedding images.

A feature/x branch URL is split wrongly.

A URL alone cannot tell where the branch ends and the path begins. Set the 'slash-separated parts in the branch name' option to 2.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
