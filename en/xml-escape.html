What this tool does

Escape text correctly so it does not break XML, RSS, SVG or config files. Everything runs in your browser.

  • Per-context rules: element text (& < >), attributes (& < " or '), CDATA (]]> split)
  • Option to turn non-ASCII characters into &#decimal; or &#xhex;
  • Unescape: &amp; &lt; &gt; &quot; &apos; and numeric references &#65; &#x41;; undefined entities are kept and reported
  • Detects control characters illegal in XML 1.0 (0x00–0x08 and others)
  • A table of converted characters

💡 Tips

  • XML has no &nbsp; or other HTML named entities; use a numeric reference such as &#160;.
  • Escape the quote type that matches the attribute's delimiter.
  • Control characters cannot be represented even by escaping; remove them.

Frequently Asked Questions

Is it the same as HTML escaping?

The five basic entities are the same, but XML does not define HTML named entities such as &nbsp;.

Does CDATA need escaping?

The content stays as is, but the terminator ]]> must be split as ]]]]><![CDATA[>.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
