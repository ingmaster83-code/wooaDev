💡 Tips

  • Secure: cookie only sent over HTTPS. HttpOnly: inaccessible to JavaScript (XSS protection)
  • SameSite=Strict: cookie not sent on cross-site requests (strongest CSRF protection)
  • Max-Age: expiry in seconds. Expires: absolute GMT date for expiry
  • Cookie max size is ~4KB. Browser limits vary on how many cookies per domain

Frequently Asked Questions

What is the difference between the Cookie and Set-Cookie headers?

The Cookie header is sent by the browser to the server and contains only name=value pairs. The Set-Cookie header is sent by the server to the browser and includes attributes like Expires, Domain, Path, Secure, and HttpOnly.

What are the requirements for SameSite=None?

When using SameSite=None, the Secure flag must also be present. Without Secure, modern browsers will reject the cookie. SameSite=None allows cross-site requests to carry the cookie, so use it only when necessary (e.g., embedded widgets, OAuth).
