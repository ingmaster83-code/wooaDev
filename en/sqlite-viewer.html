SQLite File Viewer (Read-only)

Choose a SQLite 3 database file, or paste it as Base64 / hex, to see the header, the tables, indexes, views and triggers from sqlite_master, the schema SQL and table rows. It reads the b-tree directly in plain JavaScript, with no install and no WebAssembly.

What this tool does

Open an app's .db file without installing anything to check its structure and data. The file is neither uploaded nor modified.

  • Header: page size and count, text encoding (UTF-8 / UTF-16), journal mode (WAL), user_version, application_id, freelist, SQLite version
  • Schema: tables, indexes, views and triggers from sqlite_master with CREATE statements, root pages and row counts
  • Rows: choose a table, skip / limit, value search, INTEGER PRIMARY KEY alias restored, large values reassembled from overflow pages
  • BLOBs shown as hex with length; WITHOUT ROWID and virtual tables show schema only
  • A note that uncommitted changes in a WAL file are not visible

💡 Tips

  • For small .db files, 'Choose a file' is easier than pasting Base64.
  • A WAL-mode database may be missing recent changes from the -wal file; checkpoint before copying if you need them.
  • For tables with many rows, use value search and skip to look at just the part you need.

Frequently Asked Questions

Is the file modified or uploaded?

No. The browser reads the file into memory and parses it; nothing is sent to a server and the original is never changed.

Can it open encrypted databases?

Encrypted databases such as SQLCipher do not have a plain SQLite header and cannot be opened. Very large files may be slow depending on browser memory.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
