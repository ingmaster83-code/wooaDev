What this tool does

Decoding a response with JSONDecoder in an iOS app needs a struct conforming to Codable. A sample JSON is enough for a first draft.

  • Generates a CodingKeys enum whenever key names differ (is_active → isActive)
  • Fields missing or null in some responses become optionals (String?)
  • Mixed-type fields decode safely through the bundled JSONValue enum
  • Choose let or var and optional Hashable; nested objects become separate structs, identical shapes are reused
  • Swift keywords (class, default…) are wrapped in backticks

Paste several responses together for accurate optional detection.

💡 Tips

  • With JSONDecoder's keyDecodingStrategy = .convertFromSnakeCase you can map snake_case without CodingKeys.
  • Date strings are generated as String. Change to Date and set dateDecodingStrategy if needed.
  • If a server sends a field sometimes as a number and sometimes as a string, receive it as JSONValue and convert.

Frequently Asked Questions

I want fewer optionals.

Optionals are only added for fields observed missing or null in your samples. If the API guarantees a field, add more samples or edit the output.

What is JSONValue?

An enum that can hold any JSON value — string, number, bool, array, object or null. It's used only for uncertain fields and included at the end only when needed.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
