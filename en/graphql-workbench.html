GraphQL Schema & Query Workbench

Paste GraphQL SDL to get a type table, schema errors (undefined types, missing interface fields, unused types) and tidy formatted output. Add a query to validate its fields, arguments, variables and fragments against the schema, with did-you-mean suggestions for typos.

Example

⛔ 6 error(s), 1 warning(s) — 8 type(s)

Input — Schema (SDL)

schema { query: Query mutation: Mutation }

"""사용자"""
type User implements Node {
  id: ID!
  name: String!
  email: String
  posts(first: Int = 10, after: String): [Post!]!
  role: Role!
}
type Post { id: ID! title: String! author: User! tags: [String!] }
interface Node { id: ID! }
enum Role { ADMIN EDITOR VIEWER }
union SearchResult = User | Post | Comment
input NewPost { title: String! body: String authorId: ID! }
type Query {
  user(id: ID!): User
  users(role: Role): [User!]!
  search(term: String!): [SearchResult!]!
}
type Mutation { createPost(input: NewPost!): Post! }

Input — Query / mutation (optional)

query GetUser($id: ID!, $unused: Int) {
  user(id: $id) {
    id
    nane
    role { name }
    posts(first: "5") { title author { email } }
    ...UserBits
  }
}
fragment UserBits on User { email, missing }
mutation { createPost(input: { title: "Hi" }) { id } }

What this tool does

Validate schemas and queries in the browser without a server. Your input is not uploaded.

  • Schema: undefined type references, missing interface implementations, duplicates, input / output type rules, unused types
  • Query: unknown fields (with suggestions), missing required arguments, variable types, fragments, selection-set rules
  • Type table: kind, field / value count, implements relations and line numbers
  • Re-printed, consistently formatted SDL and query
  • Hints that can be turned off

  • A misspelled field name gets a 'did you mean ...?' suggestion with the closest match.
  • extend type and directive definitions are understood, so you can paste part of a federated schema.
  • Use the formatted SDL to keep your team's .graphql files consistent.

Frequently Asked Questions

Does it implement every GraphQL validation rule?

It covers the common schema and query rules but not all of graphql-js. Verify with the official library before deploying.

Can I paste only a schema?

Yes. With an empty query box only the schema check and formatting run.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
