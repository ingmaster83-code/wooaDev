Postman ↔ OpenAPI Converter

Convert a Postman collection (v2.1) into an OpenAPI 3.0 document, or an OpenAPI document into a Postman collection. Paths, queries, headers, bodies and response examples are carried over; folders become tags and the base URL becomes a collection variable. The direction is detected automatically.

✅ Converted 3 request(s) to OpenAPI 3.0

What this tool does

Switch between API documentation and test collections in one place. Your files are not uploaded.

  • Postman → OpenAPI: path variables (:id), queries, headers, JSON body schema inference, response examples, folders → tags
  • OpenAPI → Postman: baseUrl variable, path and query parameters (optional ones disabled), request body examples, response examples
  • Output as YAML or JSON; direction auto-detected
  • Converted OpenAPI is built to pass the OpenAPI validator
  • Summary table and notes about what was not converted

💡 Tips

  • Postman {{variables}} become server URLs or value placeholders in OpenAPI; check servers after converting.
  • Schemas are inferred from example bodies, so refine required and format by hand afterwards.
  • Paste the converted OpenAPI into the OpenAPI validator to check it immediately.

Frequently Asked Questions

Is authentication converted?

Complex auth such as OAuth2 is not converted. Add the security schemes you need after converting.

Does it support Postman v2.0?

v2.1 collections are the target. v2.0 mostly reads fine, but some fields may be ignored.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
