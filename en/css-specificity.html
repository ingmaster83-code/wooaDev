💡 Tips

  • An ID (#) beats a class (.), and a class beats an element (div, a, etc.).
  • With equal specificity, the rule declared later in the CSS file wins.
  • Avoid specificity wars — keep selectors simple instead of reaching for !important.

Frequently Asked Questions

How is specificity calculated?

As a four-part value (inline style, ID count, class/attribute/pseudo-class count, element/pseudo-element count). Higher values in the leftmost position win.

Does !important count toward specificity?

No. !important overrides all other rules regardless of specificity. Specificity comparison only matters when !important isn't used.

Are inputs stored on a server?

No. All calculations happen entirely in your browser and inputs are never sent to a server.
