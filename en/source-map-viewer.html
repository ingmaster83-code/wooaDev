Source Map (.map) Viewer & Position Translator

Paste a source map JSON, data URI or sourceMappingURL comment to see the source file list and decoded VLQ mappings. Enter a line:column from a minified bundle to get the original file, line, column, symbol name and surrounding code, or look up where an original line ended up in the bundle.

Example

✅ Source map — 2 source(s), 14 mapping(s)

Input — Source map (.map JSON, data: URI or sourceMappingURL comment)

{
 "version": 3,
 "file": "bundle.js",
 "sourceRoot": "",
 "sources": [
  "src/util.ts",
  "src/app.ts"
 ],
 "sourcesContent": [
  "export function add(a: number, b: number) {\n  return a + b;\n}\n",
  "import { add } from './util';\nconst n = add(1, 2);\nconsole.log(n);\n"
 ],
 "names": [
  "add",
  "a",
  "b",
  "n",
  "console"
 ],
 "mappings": "AAAO,SAASA,IAAIC,EAAWC,GAC7B,OAAOD,CAAE,CAAEC,CACb;ACDA,IAAMC,EAAIH,SACVI,QAAQ"
}

Result — Summary

Version: 3
File: bundle.js
sourceRoot: —
Source files: 2
Names: 5
Mappings: 14
Generated lines (by mappings): 2
Map size: 432 B

        |                     ^

What this tool does

Find the original location of an error from minified production code in the browser. Your source map is not uploaded.

  • Input: .map JSON, data:application/json URI, //# sourceMappingURL=data:… comments, )]}' prefix and index maps (sections)
  • Translate: a stack-trace line:column (1-based) to original file, line, column and name, with the nearest earlier mapping and 5 lines of context
  • Reverse: 'file:line' to the list of bundle positions it produced
  • Tables: mappings and content size per source file, and the mapping list (generated to original)
  • Checks: version, out-of-range source / name indexes, missing or exposed sourcesContent

💡 Tips

  • Paste the line:column from a console stack trace such as 'bundle.js:1:15234'. Both numbers are 1-based.
  • Publishing a .map with sourcesContent exposes your original source; upload it only to your error-tracking service.
  • If the column does not match a mapping exactly, the previous mapping is used, as the specification says.

Frequently Asked Questions

What if the source map has no original code?

Without sourcesContent you get the file name, line and column only; open the original file separately to read that line.

What if I only have a path to an external .map file?

Open that file yourself and paste its contents; this tool does not fetch files from the network.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
