umask Calculator — Default Permissions for New Files

With umask 022 new files become 644 and directories 755. Calculate permissions from a umask, or work backwards from the permissions you want (such as 640 / 750), with a table of common values.

Example

✅ umask 027 → file 640 · directory 750

Input — umask (octal, e.g. 022)

027

Input — Desired file permission (octal or rw-r--r--)

640

Input — Desired directory permission (octal or rwxr-x---)

750

Result — Result

Item | Value | Permissions
umask | 027 | ----w-rwx (permissions removed)
New file | 640 | rw-r-----
New directory | 750 | rwxr-x---
Symbolic umask | u=rwx,g=rx,o= | the format of umask -S

Result — Commands

umask 027
umask u=rwx,g=rx,o=

# Where to make it permanent
echo 'umask 027' >> ~/.bashrc    # user shell
# /etc/login.defs → UMASK 027            # login default
# systemd 서비스: UMask=027
# Dockerfile: RUN umask 027 && …    # only within that RUN

What this tool does

Permissions of newly created files are set by umask, not chmod. When subtracting bits gets confusing, just calculate it.

  • umask → permissions: remove the umask bits from 666 for files and 777 for directories
  • permissions → umask: from wanted permissions such as 640 / 750 or rw-r----- find the required umask
  • rwx notation and the umask -S format (u=rwx,g=rx,o=)
  • Comparison table of common umasks (022, 002, 027, 077, 007)
  • How to make it permanent in ~/.bashrc, /etc/login.defs, systemd UMask= and Dockerfiles

💡 Tips

  • 027 (group read, no access for others) or 077 are safe defaults for server accounts.
  • Files never get execute permission by default; add it with chmod +x for scripts.
  • systemd services, cron and sshd do not inherit your login shell's umask, so set UMask= in the service.

Frequently Asked Questions

Why does umask 022 give 644?

Start from 666 (rw-rw-rw-) and remove 022 (----w--w-) to get 644 (rw-r--r--). Directories start at 777 and become 755.

I changed umask but existing files kept their permissions.

umask only affects files created afterwards. Change existing files with chmod.
