XSD → JSON Schema Converter

Converts a top-level XSD element to JSON Schema: complexType becomes object, maxOccurs>1 an array, attributes "@name" properties, simple types type / format, and facets enum, pattern, minimum and maxLength, with named types split into $defs.

Example

✅ Converted "library" to JSON Schema

Result — Rules and notes

xs:choice lists all properties and distinguishes the required combinations with oneOf / anyOf (approximation)
XML attributes became "@name" properties and repeated elements (maxOccurs>1) became arrays. XML→JSON converters differ (attribute prefix, single-item arrays), so confirm it matches your actual conversion
Element order (sequence) and key / unique constraints cannot be expressed in JSON Schema and were dropped

What this tool does

Use it when moving an XML-based API to JSON and converting the schema too. Your schema never leaves your browser.

  • Structure: element → property, required from minOccurs, maxOccurs>1 → array (minItems, maxItems), complexType → object, optional additionalProperties
  • Types: integer family (ranges → minimum / maximum), decimal / float / double → number, boolean, date, dateTime, time, duration, anyURI → format, hexBinary and base64Binary
  • Facets: enumeration → enum, pattern, length, minLength, maxLength, min / maxInclusive and Exclusive, fractionDigits → multipleOf, list → array, union → anyOf
  • Special: simpleContent with attributes uses a "#text" key, configurable attribute prefix (@ by default), choice → oneOf of required sets, nillable → null allowed and mixed
  • Named simpleType / complexType go to $defs (definitions in draft-07) with $ref; choose the root element and wrap in its name

💡 Tips

  • XML→JSON converters differ; adjust the attribute prefix and single-item array behaviour to match your real conversion.
  • XML element order (sequence) means nothing in a JSON object and is not expressed in JSON Schema.
  • 64-bit integers (long) can exceed JSON's safe number range; check whether they need string handling.

Frequently Asked Questions

Is xs:choice converted exactly?

It is an approximation: all alternatives are listed as properties and only the required combinations are distinguished with oneOf, so exclusivity may not be fully expressed.

What about imported schemas?

import / include are unsupported and references to those types become empty schemas; merge the definitions into one file.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
