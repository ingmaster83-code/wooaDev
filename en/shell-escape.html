Shell Escape Converter — POSIX, Bash, PowerShell & cmd

Escapes strings containing spaces, quotes, $, backticks or semicolons so a shell receives them as one safe argument, in POSIX sh / bash, Bash $'…', fish, PowerShell and cmd.exe styles at once.

Example

✅ Escaped 5 argument(s)

Input — Strings to escape (one argument per line; use the option below for a single multi-line argument)

It's a "quoted" $HOME `value`
plain-word
C:\Program Files\App
hello world; rm -rf /
single\backslash

Result — Escaped output

echo 'It'\''s a "quoted" $HOME `value`'

Result — Notes

Inside double quotes $ ` \ " ! are still special — prefer the single-quote form when you do not want expansion
Escaping makes a string a single safe argument. Never build shell command strings from user input — pass an argument array to an exec-style API (shell=False)
cmd.exe rules vary by program (CommandLineToArgvW). % and ^ behave differently inside and outside .bat files

What this tool does

Wrong quoting when putting user input or file names into a shell command breaks the command or opens a security hole. Rules differ per shell, so compare them side by side.

  • Targets: POSIX sh / bash / zsh single quotes ('It'\''s'), Bash $'…' (ANSI-C), POSIX double quotes, fish, PowerShell single and double quotes, cmd.exe and JSON
  • Handle many arguments one per line, or treat the whole text (with newlines) as a single argument
  • Prepend a command (for example echo or scp) to get something runnable
  • Safe characters stay bare and an empty string becomes ''
  • Notes on NUL bytes, newline limits and $ / backtick expansion inside double quotes

💡 Tips

  • Instead of building shell command strings from user input pass an argument array to an execve-style API (for example Python subprocess with shell=False).
  • If you do not want variable expansion, single quotes are safer than double quotes.
  • PowerShell writes a single quote inside single quotes as ''.

Frequently Asked Questions

How do I put a single quote inside single quotes?

No escaping works inside single quotes, so close the quote, write \' and reopen: 'It'\''s'.

Why is cmd.exe output so complicated?

cmd.exe's own rules (^, %) overlap with each program's argument parsing, so perfect quoting is hard. Prefer PowerShell or argument arrays.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
