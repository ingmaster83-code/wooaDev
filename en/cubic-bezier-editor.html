cubic-bezier Easing Editor & steps()

Enter cubic-bezier(x1, y1, x2, y2) or a name such as ease-out-back to see the curve, a progress-over-time table and transition, @keyframes and Web Animations code.

Example

✅ cubic-bezier(0.34, 1.56, 0.64, 1) (= ease-out-back)

Input — cubic-bezier(x1, y1, x2, y2) or keyword

cubic-bezier(0.34, 1.56, 0.64, 1)

Result — CSS

/* ease-out-back */
transition: transform 600ms cubic-bezier(0.34, 1.56, 0.64, 1);

@keyframes move {
  from { transform: translateX(0); }
  to   { transform: translateX(200px); }
}
.box { animation: move 600ms cubic-bezier(0.34, 1.56, 0.64, 1) forwards; }

/* JS (Web Animations API) */
el.animate([{ transform: "translateX(0)" }, { transform: "translateX(200px)" }], { duration: 600, easing: "cubic-bezier(0.34, 1.56, 0.64, 1)", fill: "forwards" });

What this tool does

The easing curve decides how an animation feels. See what four numbers mean as a curve and a table.

  • Input: cubic-bezier(…), four numbers, keywords (ease, ease-in-out), 18 easing names (ease-out-back, ease-in-expo …) and steps(n, jump)
  • Curve graph with control points and a progress table for the number of rows you choose
  • Detects overshoot (y beyond 0–1) and anticipation
  • Generates transition, @keyframes and Web Animations API code
  • x1 or x2 outside 0–1 is reported as a CSS spec violation

💡 Tips

  • A curve with overshoot (y > 1) passes the target and settles back for a springy feel.
  • 150–300 ms suits UI transitions and 300–500 ms larger moves.
  • Use steps() for sprite animation and typewriter effects.

Frequently Asked Questions

Why must x stay within 0–1?

x is the time axis; going back would give several values at one instant, so CSS restricts it. y is unrestricted.

How does it apply inside keyframes?

animation-timing-function restarts for every keyframe interval, so a single curve over the whole animation needs a single interval.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
