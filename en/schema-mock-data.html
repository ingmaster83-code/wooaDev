JSON Mock Data Generator — Test Data from a Schema

Paste a JSON Schema and get fake JSON that respects types, ranges, enums, formats, patterns and array lengths.

Example

✅ Generated 3 item(s) (seed 1)

Input — JSON Schema

{
  "type": "object",
  "required": ["id", "name", "email", "role"],
  "properties": {
    "id": { "type": "integer", "minimum": 1000, "maximum": 9999 },
    "name": { "type": "string", "minLength": 2 },
    "email": { "type": "string", "format": "email" },
    "role": { "enum": ["admin", "editor", "viewer"] },
    "code": { "type": "string", "pattern": "^[A-Z]{3}-[0-9]{4}$" },
    "score": { "type": "number", "minimum": 0, "maximum": 5, "multipleOf": 0.5 },
    "tags": { "type": "array", "items": { "type": "string" }, "minItems": 1, "maxItems": 3, "uniqueItems": true },
    "created": { "type": "string", "format": "date-time" }
  }

What this tool does

Front-end work and API tests often need believable data before the backend is ready. With a schema you can generate it right away.

  • Numbers: integers/floats honouring minimum/maximum, exclusive*, multipleOf
  • Strings: minLength/maxLength, formats (email, uuid, date, date-time, uri, ipv4…), pattern (generates strings matching the regex)
  • enum, const, default/examples (optional), array minItems/maxItems/uniqueItems and tuples (prefixItems)
  • $ref (#/definitions, #/$defs), allOf merging, oneOf/anyOf selection
  • Include optional properties or not, how many items, and a seed (same seed = same output)

💡 Tips

  • A fixed seed makes test fixtures reproducible.
  • Patterns support common regex features — classes, quantifiers, groups, alternation. Advanced syntax such as lookaheads is reported as unsupported.
  • Property names like name, city and title produce human-looking values.

Frequently Asked Questions

Does the generated data always pass the schema?

Within the supported keywords, yes — it was cross-checked against a validator with several schemas and seeds. Very complex conditions (if/then/else, not…) aren't guaranteed.

Does it produce real personal data?

No. Names come from a small list of examples and emails use example.com — all fake.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
