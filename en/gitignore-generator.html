💡 Tips

  • Always add your OS (macOS/Windows) and editor (VSCode/IntelliJ) entries regardless of language.
  • Always ignore .env files — they usually hold API keys and other secrets.
  • If files are already committed, add .gitignore then run git rm --cached -r . to clear the cache.

Frequently Asked Questions

Can I select multiple stacks at once?

Yes — check any combination, like Node.js + macOS + VSCode, and they'll be merged into one .gitignore file.

Do already-committed files stop being tracked once I add a .gitignore?

No. .gitignore only affects files not yet tracked. To untrack an already-committed file, run git rm --cached separately.

Are selections stored on a server?

No. All processing happens entirely in your browser and your selections are never sent to a server.
