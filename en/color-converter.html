💡 Color Format Tips

  • HEX: #RRGGBB format. Most common in CSS. 3-digit shorthand (#RGB) is also supported.
  • RGB: Red(0-255) · Green(0-255) · Blue(0-255). Additive color mixing.
  • HSL: Hue(0-360°) · Saturation(0-100%) · Lightness(0-100%). Great for intuitive color adjustments.
  • Click the color picker or type a HEX value to update all formats instantly.

Frequently Asked Questions

Does it support 3-digit HEX codes (#RGB)?
Yes. Entering a 3-digit HEX code like #F5A automatically expands it to #FF55AA before converting.
Which format should I use in CSS?
HEX is the most common and widely supported. HSL is great for intuitive adjustments, and RGB is preferred when you need to add transparency (rgba).
