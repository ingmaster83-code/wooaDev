💡 Tips

  • In HTML, <, >, and & are interpreted as tags/attributes and must be encoded as entities.
  • Always encode user input before rendering it in HTML to prevent XSS vulnerabilities.
  • Click any entity code in the table to select it for copying.
Named Entity vs Numeric Entity — what's the difference?

Named entities like &amp; are human-readable. Numeric entities like &#38; use Unicode code points and can represent any character, including those without named equivalents.

What happens if I put special characters in HTML without encoding?

The browser may interpret them as HTML tags or attributes, breaking your layout or creating XSS security vulnerabilities.
