What this tool does

Turns the long User-Agent left in access logs and error reports into readable facts. Put several in, one per line, to compare them in a table.

  • Browsers: Chrome, Edge, Safari, Firefox, Opera, Samsung Internet, Naver Whale, Vivaldi, Brave, IE and versions
  • Engine (Blink, WebKit, Gecko, Trident) and OS (Windows version mapping, macOS, iOS/iPadOS, Android, Linux, ChromeOS)
  • Device: desktop, mobile, tablet, TV and model names (Samsung Galaxy SM-…)
  • In-app browsers: KakaoTalk, NAVER app, Daum app, Facebook, Instagram, LINE, Android WebView
  • Bots: Googlebot, Bingbot, Naver Yeti, Daum, OpenAI / Anthropic / Perplexity crawlers, curl, requests and other HTTP clients

💡 Tips

  • Chrome, Edge and Safari UAs contain each other's tokens for compatibility, so order matters — this tool tests Edge → Opera → Whale → … → Chrome → Safari.
  • Browsers are reducing UA detail, so macOS may always read 10.15.7 and Windows 10.
  • UA alone is easy to forge for bot detection — pair important blocks with reverse DNS verification.

Frequently Asked Questions

Can the UA alone identify the exact device?

Only roughly. With UA reduction and spoofing, exact OS versions and models need User-Agent Client Hints (Sec-CH-UA-*).

How do I verify a real Googlebot?

Anyone can fake the UA, so check that the visiting IP's reverse DNS ends in googlebot.com or google.com and that the forward lookup returns the same IP.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
