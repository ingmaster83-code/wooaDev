Frequently Asked Questions

Can I push the generated README straight to GitHub?

Yes, it's standard Markdown — save it as README.md in your repo root and GitHub will render it automatically on the project page.

How do the badges work?

They're image links via shields.io that show license, stars, and issue counts. Enter your GitHub username/repo and they'll reflect your actual repository.

Is my input stored on a server?

No. All processing happens entirely in your browser and inputs are never sent to a server.
