JSON Lines (NDJSON) Viewer & Converter

Paste JSONL / NDJSON with one JSON value per line to view it as a table, filter it and convert it to a JSON array, CSV or pretty-printed lines. Broken lines are reported with their number and reason.

What this tool does

Skim structured logs or AI training data (JSONL) without an editor. Data is processed only in your browser.

  • Table: the union of all keys as columns, with optional a.b flattening of nested objects
  • Filter: show only lines containing some text
  • Convert: JSON array, CSV, pretty JSON Lines, or valid lines only back to JSONL
  • Errors: parse errors per line number, blank lines, non-object top-level values and column mismatches
  • Statistics such as line and column counts

💡 Tips

  • If one record is split over two lines the JSON breaks; each JSONL line must be complete on its own.
  • For fine-tuning JSONL check column mismatches to confirm every line has the same structure.
  • For huge logs jq or DuckDB is more efficient.

Frequently Asked Questions

Are NDJSON and JSON Lines the same?

Effectively yes: one JSON value per line separated by \n.

What if I paste one JSON array?

It is not JSONL; the tool reports the problem so you can convert the array to lines.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
