What this tool does

Besides Base64, other Base encodings are used for specific purposes. This one tool converts them all.

  • Base16 (hex): bytes as hex digits, upper or lower case
  • Base32: RFC 4648, base32hex and Crockford (no look-alike letters). TOTP secrets use it; = padding optional
  • Base58: Bitcoin alphabet (no 0, O, I, l), Flickr and Ripple variants; leading zero bytes are preserved
  • Base85: Ascii85 (Adobe, PDF/PostScript) and Z85 (ZeroMQ, needs a multiple of 4 bytes)
  • Input as UTF-8 text or hex bytes; view the decoded result as text or hex

For Base64 use the Base64 encoder; for binary digits use Text ↔ Binary.

💡 Tips

  • Two-factor (TOTP) secrets are Base32. Spaces and lowercase are fine when decoding.
  • If the decoded bytes are not text, the result is shown as hex automatically.
  • Z85 needs input whose length is a multiple of 4 bytes.

Frequently Asked Questions

Why use Base58?

It drops look-alike characters (0, O, I, l) and + and /, so it's easy to transcribe and URL-safe. Bitcoin addresses and IPFS hashes use it.

How is Base32 different from Base64?

Base32 uses only uppercase letters and digits 2–7, which is safe where case isn't preserved, but its output is about 60% larger than the input (Base64: about 33%). Base64 is shorter and case-sensitive.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
