XML to JSON Converter

Converts XML to JSON: attributes become @keys, repeated elements become arrays, and numbers/booleans become real value types.

Example

✅ Converted — root <order>

Input — XML input

<?xml version="1.0" encoding="UTF-8"?>
<order id="A-1024" paid="true">
  <customer>Kim &amp; Co.</customer>
  <items>
    <item sku="P-1"><qty>2</qty><price>9.5</price></item>
    <item sku="P-2"><qty>1</qty><price>20</price></item>
  </items>
  <note/>
</order>

Result — JSON output

{
  "order": {
    "@id": "A-1024",
    "@paid": true,
    "customer": "Kim & Co.",
    "items": {
      "item": [
        {
          "@sku": "P-1",
          "qty": 2,
          "price": 9.5
        },
        {
          "@sku": "P-2",
          "qty": 1,
          "price": 20
        }
      ]
    },
    "note": ""
  }
}

What this tool does

To use a SOAP response, an RSS feed or an XML config from JavaScript, JSON is the most convenient shape. The conversion rules are:

  • Attributes become "@name" keys; element text is stored as "#text" when the element also has children or attributes
  • Repeated elements become an array; "Always use arrays" makes single elements arrays too
  • Numbers and true/false become typed values, but values like 007 or 1.50 stay strings so they round-trip unchanged
  • CDATA, entities such as &lt; and the XML declaration are handled; malformed tags are reported with line and column

To go back to XML, use the JSON to XML converter.

💡 Tips

  • For XML whose child structure varies, turn on "Always use arrays" to avoid special cases in your code.
  • If you don't need attributes, "Ignore attributes" keeps the output simple.
  • Code-like values such as ZIP or phone numbers with a leading zero stay strings automatically.

Frequently Asked Questions

What happens to XML namespaces/prefixes?

Prefixes (ns:tag) are kept as part of the key name. Namespace URLs are not resolved.

Does it process DTDs or external entities?

No. The DOCTYPE is ignored and only the five predefined entities and numeric character references are expanded, so XXE-style attacks via external entities are not possible.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
