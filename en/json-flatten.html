JSON Flatten & Unflatten

Flattens nested JSON into single-level keys such as user.address.city, or rebuilds the nested structure from a flat object.

Example

✅ Flattened — 8 value(s)

Input — JSON input

{
  "user": {
    "name": "Kim",
    "emails": ["a@x.com", "b@x.com"],
    "address": { "city": "Seoul", "geo": { "lat": 37.5, "lng": 127 } }
  },
  "active": true,
  "meta": {}
}

Result — Result

{
  "user.name": "Kim",
  "user.emails[0]": "a@x.com",
  "user.emails[1]": "b@x.com",
  "user.address.city": "Seoul",
  "user.address.geo.lat": 37.5,
  "user.address.geo.lng": 127,
  "active": true,
  "meta": {}
}

What this tool does

Translation (i18n) files, environment variables and spreadsheet/CSV exports need a single-level key-value structure. This tool flattens nested JSON and can rebuild it again.

  • Flatten: {"a":{"b":[1,2]}} → {"a.b[0]":1,"a.b[1]":2}
  • Pick the separator (., /, _ …) and array notation (a[0] or a.0)
  • Keep or drop empty objects and arrays
  • Unflatten: consecutive numeric keys (0,1,2…) become arrays, everything else becomes objects

If you only need the paths, the JSON Key Extractor or JSON Pointer tool may be handier.

💡 Tips

  • After flattening you can sort or filter the keys, then use the result as input to restore it.
  • If the separator also appears inside key names, structure can change on restore — choose a character that isn't used in keys, such as /.
  • Object keys that are purely numeric ("0","1") may be rebuilt as arrays.

Frequently Asked Questions

Can I always restore the original after flattening?

Mostly. If key names contain the separator or purely numeric object keys exist, the structure can differ, so pick a safe separator.

How are arrays written?

By default as a[0].b with brackets; you can switch to dot notation like a.0.b.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
