What this tool does

Working with flag fields, bit masks, hashes or network protocols, you often want to verify bit operations in binary without doing it by hand.

  • Input: decimal, 0x hex, 0b binary, 0o octal (underscores and spaces allowed)
  • Operations: AND, OR, XOR, NAND, NOR, XNOR, NOT, left shift, logical/arithmetic right shift, +, −
  • The chosen width (8/16/32/64) reproduces real hardware wrap-around
  • With signed interpretation, results can be negative and arithmetic shifts keep the sign
  • Binary is grouped in nibbles and the number of set bits is reported

💡 Tips

  • To test a bit, compute value AND mask and check for non-zero.
  • To clear a bit use value AND (NOT mask); to flip it use XOR.
  • JavaScript's own bitwise operators are limited to 32 bits, but this tool is exact up to 64 via BigInt.

Frequently Asked Questions

What's the difference between logical and arithmetic shifts?

A logical shift (>>>) fills with zeros; an arithmetic shift (>>) copies the sign bit to keep negatives negative. For unsigned values they're identical.

Why is NOT a large positive number?

In unsigned interpretation, inverting all bits yields a big number within the width. Enable signed mode to see it as -1 and similar.
