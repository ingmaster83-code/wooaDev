What this tool does

Make sure a schema will not be rejected before you send it to a model API. The schema is not uploaded.

  • Targets: OpenAI Structured Outputs (strict), Google Gemini responseSchema and a generic check
  • OpenAI strict: additionalProperties: false on every object, all properties required, unsupported keywords, nesting depth and property-count limits
  • Gemini: keywords outside the supported subset, additionalProperties, $ref differences
  • Auto-convert: optional properties become required + [type, null]; output as a ready-to-use response_format
  • The converted result is re-checked, with object / property / depth statistics

💡 Tips

  • Strict mode has no optional properties. Express a possibly missing value as type: ["string", "null"].
  • Deep schemas with many properties slow responses and may hit limits, so keep only the fields you need.
  • Clear enums and descriptions make the model more likely to fill values correctly.

Frequently Asked Questions

Are the rules up to date?

They follow the public documentation, and support may widen with models and over time. Confirm with a real API call.

What about constraints like minimum or pattern?

Depending on provider and model they may be ignored or rejected. If a warning appears, validate values in your application after receiving the response.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
