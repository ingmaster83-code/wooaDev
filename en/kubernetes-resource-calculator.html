Kubernetes Resource Calculator — requests, limits & QoS

Enter CPU and memory requests and limits per container to get the Pod total, QoS class (Guaranteed / Burstable / BestEffort), nodes needed for the replicas and HPA maximum, and a resources YAML block.

✅ Per Pod: 320m CPU · 352Mi · QoS Burstable

Input — Containers (one per line: name cpuRequest cpuLimit memRequest memLimit, - if unset)

app 250m 500m 256Mi 512Mi
sidecar 50m 100m 64Mi 128Mi
log-agent 20m - 32Mi 64Mi

What this tool does

Resource units (m, Mi, Gi, M) are easy to mix up and mistakes lead to Pending Pods or OOMKilled containers.

  • Input: one container per line — name, CPU request, CPU limit, memory request, memory limit (- when unset)
  • Units: 250m, 0.5, 2 cores; Ki, Mi, Gi, Ti; K, M, G, T; exponent notation (129e6)
  • Calculates the Pod total, replica total, QoS class (a limit without a request means request = limit), Pods per node and nodes needed including the HPA maximum, after the node's allocatable and system share
  • Writes a resources YAML block per container
  • 🚨 warnings for limit < request, missing memory limit, missing CPU request, a high limit/request ratio, Pods bigger than a node and suspicious units

💡 Tips

  • Exceeding a CPU limit throttles; exceeding a memory limit gets the container OOMKilled.
  • The scheduler places Pods by requests: too large leaves nodes idle, too small packs them too densely.
  • Use the Allocatable values from kubectl describe node for the node size.

Frequently Asked Questions

Why does the QoS class matter?

Under node pressure Pods are evicted BestEffort first, then Burstable, then Guaranteed. Make critical services Guaranteed with requests = limits.

What does 250m mean?

1000m is one core, so 250m is a quarter of a core. For memory Mi is a binary unit (1Mi = 1,048,576 bytes) while M is decimal.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
