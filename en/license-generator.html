💡 Tips

  • Save it as a file literally named "LICENSE" (no extension) in your repo root — GitHub auto-detects and displays it.
  • The year can be a range like "2020-2026" if the project has been around a while.
  • For a company or team project, put the org/team name in the author field.

Frequently Asked Questions

Which license should I choose?

MIT or ISC for maximum freedom, Apache 2.0 if you also want explicit patent protection, GPL v3 if you want derivative works to stay open source. When unsure, check choosealicense.com.

Can I use the generated text as-is?

Yes, it's the official open source license text verbatim, with only the author name and year filled in. Save it as a LICENSE file in your project root.

Are inputs stored on a server?

No. All processing happens entirely in your browser and inputs are never sent to a server.
