Config File Diff — Ignores Key Order & Comments

Reads two TOML, INI, .properties, YAML, JSON or .env files as data, so differences in key order, whitespace or comments disappear and only real changes remain.

Example

🔍 Added 1 · Removed 1 · Changed 2

Input — Original config (A)

[server]
host = "localhost"
port = 8080

[database]
url = "postgres://localhost/app"
pool = 5

[features]
beta = false

Input — Changed config (B)

[database]
pool = 10
url = "postgres://localhost/app"

[server]
port = 8080
host = "0.0.0.0"

[logging]
level = "info"

Result — Changes (key order ignored)

Type | Path | Before (A) | After (B)
Changed | $.server.host | "localhost" | "0.0.0.0"
Changed | $.database.pool | 5 | 10
Removed | $.features | {"beta":false} | 
Added | $.logging |  | {"level":"info"}

What this tool does

Comparing environment-specific files (application-dev.properties vs application-prod.properties, config.ini…) with a text diff is noisy because of ordering and whitespace. This tool reads the files in their own format and compares values.

  • Supports TOML, INI, Java .properties, YAML, JSON and .env
  • Ignores section/key order, whitespace and comments; shows additions, removals and changes with paths
  • For INI, .properties and .env, an option treats "8080" and 8080 as equal
  • Optional array-order ignoring
  • Parse errors say whether the problem is in A or B

💡 Tips

  • For dev-vs-prod comparisons, choose .properties and keep "Coerce types" on to cut noise.
  • If the two files use different formats, convert them to the same one with the Config File Converter first.
  • For checking missing variables in .env files, the ENV Diff tool is more convenient.

Frequently Asked Questions

Can I compare different formats (TOML vs YAML) directly?

One format is chosen for both inputs. Convert the other file with the converters first, then compare.

Are files that only differ in comments the same?

Yes. Comments aren't data, so only values are compared.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
