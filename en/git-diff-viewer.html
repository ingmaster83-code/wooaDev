Git Diff Viewer — Make Patches Readable

Paste git diff, git show or .patch / .diff content to get a per-file summary of added and removed lines, renames, new and deleted files, plus a coloured diff with line numbers.

What this tool does

Use it when a long patch arrives in an email or PR description and you have no handy way to read it. The patch is processed only in your browser.

  • Per-file summary: status (modified / added / deleted / renamed % / mode change / binary), added and removed lines, hunk count
  • Changes: coloured diff with old and new line numbers, changed-lines-only view and a file name filter
  • A summary in the style of git diff --stat
  • Warns when a hunk header's line counts disagree with the actual lines (truncated or edited patch)
  • Flags secret files (.env, keys, credentials), trailing whitespace and very large changes of over 1,000 lines

💡 Tips

  • Copy with git diff --no-color; colour escape codes confuse parsing.
  • For a big PR use the file filter to look at the interesting part first.
  • Before applying a patch run git apply --check to find conflicts.

Frequently Asked Questions

Can I compare two texts directly?

This tool reads an existing diff. To compare two texts directly use the Diff Viewer tool.

How are binary changes shown?

The content is not shown; the file appears in the list as binary. Use git diff --stat for size changes.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
