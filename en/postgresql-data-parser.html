PostgreSQL Array & Interval Parser

Converts PostgreSQL array literals such as {1,2,3}, {"a b",NULL} or {{1,2},{3,4}} to JSON and breaks intervals like '1 year 2 mons 3 days 04:05:06' into fields and ISO 8601.

Example

✅ Converted 4 array(s)

Input — PostgreSQL array literals (one per line)

{1,2,3}
{"hello world",NULL,"with \"quote\"","a,b"}
{{1,2},{3,4}}
{apple,banana}

Input — interval values (one per line)

1 year 2 mons 3 days 04:05:06.5
-1 days +02:00:00
P1Y2M3DT4H5M6S
@ 2 hours 30 mins
00:90:00

Result — Results

Input | Status | Dims | Elements | Note
{1,2,3} | ✅ | 1D | 3 | 
{"hello world",NULL,"with \"quote\"",… | ✅ | 1D | 4 | 
{{1,2},{3,4}} | ✅ | 2D | 4 | 
{apple,banana} | ✅ | 1D | 2 |

Result — JSON / normalised

[1,2,3]
["hello world",null,"with \"quote\"","a,b"]
[[1,2],[3,4]]
["apple","banana"]

What this tool does

Array and interval columns exported by psql or CSV arrive as text. Paste them to get structured values.

  • Arrays: quoted elements and escapes, NULL versus "NULL", multi-dimensional, empty arrays and [0:2]= dimension prefixes
  • Element types are guessed: unquoted numbers and t / f become JSON numbers and booleans, the rest strings
  • Warns when sub-arrays of a multi-dimensional array differ in length, which PostgreSQL rejects
  • Intervals: postgres style, SQL standard (@ 2 hours), ISO 8601 (P1Y2M3DT4H5M6S), h:m:s normalisation, ago and fractional units
  • Outputs years, months, days, hours, minutes, seconds, ISO 8601 and an approximate seconds total

💡 Tips

  • An interval stores months (approximated as 30 days), days and time separately, so a flat seconds figure is approximate.
  • Real applications get arrays converted by the driver (pg and others); use this for CSV and log analysis.
  • PostgreSQL quotes string elements that contain commas, spaces or quotes.

Frequently Asked Questions

Is NULL different from "NULL"?

Unquoted NULL is a null value; quoted "NULL" is a string containing the letters NULL.

What is mons in an interval?

Short for months. 12 mons displays as 1 year, and a year converts to 12 months.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
