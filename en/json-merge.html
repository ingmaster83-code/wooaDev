JSON Merge — Deep Merge with Conflict Priority & Array Strategy

Deep-merges an overlay JSON onto a base JSON. Choose which side wins conflicts and how arrays are combined, and review every conflict.

Example

🔀 Merged — 3 conflict(s)/change(s) (B preferred)

Input — Base JSON (A)

{
  "name": "app",
  "port": 3000,
  "db": { "host": "localhost", "user": "root" },
  "plugins": ["auth", "log"]
}

Input — Overlay JSON (B)

{
  "port": 8080,
  "db": { "host": "db.prod", "ssl": true },
  "plugins": ["log", "cache"],
  "debug": null
}

Result — Merged result

{
  "name": "app",
  "port": 8080,
  "db": {
    "host": "db.prod",
    "user": "root",
    "ssl": true
  },
  "plugins": [
    "log",
    "cache"
  ],
  "debug": null
}

Result — Conflicts & changes

Path | A value | B value | Result | Applied
$.port | 3000 | 8080 | 8080 | B
$.db.host | "localhost" | "db.prod" | "db.prod" | B
$.plugins | ["auth","log"] | ["log","cache"] | ["log","cache"] | B

What this tool does

Combining base and per-environment settings with a shallow merge (Object.assign) makes nested objects disappear. This tool deep-merges and shows which value came from which side.

  • Choose B (overlay) or A (keep base) to win conflicts
  • Arrays: replace / concatenate / union (deduplicate) / merge by index
  • Optionally treat null in B as "delete the key" (RFC 7386 JSON Merge Patch)
  • See each conflicting path with the A value, B value and the applied result

If you only want the differences between two documents, use the JSON Diff tool.

💡 Tips

  • To layer user settings over defaults, set A = defaults, B = user values and prefer B.
  • When merging plugin or tag lists, "Union" removes duplicates for you.
  • With the RFC 7386 option, keys set to null in B are removed from the result.

Frequently Asked Questions

What's the difference between a shallow and a deep merge?

A shallow merge only overwrites top-level keys, so a nested object is replaced wholesale. A deep merge combines objects key by key, preserving sub-keys from both sides.

Why are arrays handled by an option?

There's no single right way to merge arrays. You can replace them, concatenate, deduplicate or merge element by element, depending on your use case.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
