💡 Tips

  • Simple mode: Applies the same value to all 4 corners at once.
  • Advanced mode: Set each corner (TL, TR, BL, BR) individually.
  • % unit: Proportional to the element size. Set to 50% for a perfect circle.
  • px unit: Fixed pixel value — consistent roundness regardless of element size.
  • When all 4 values are equal, the output is simplified to a single value like border-radius: 12px.
What happens when I set 4 different values?

CSS applies corners clockwise: border-radius: TL TR BR BL. In advanced mode, each corner is set individually and the code is generated in this format.

Does 50% make a perfect circle?

On a square element, border-radius: 50% creates a perfect circle. On a rectangle, it creates an ellipse.

What is the difference between border-radius and border-top-left-radius?

border-radius is a shorthand property that sets up to 4 corners at once. Individual properties like border-top-left-radius also work. This tool generates the shorthand format.
