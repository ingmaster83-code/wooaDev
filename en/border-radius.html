💡 Tips

  • Simple mode: Applies the same value to all 4 corners at once.
  • Advanced mode: Set each corner (TL, TR, BL, BR) individually.
  • % unit: Proportional to the element size. Set to 50% for a perfect circle.
  • px unit: Fixed pixel value — consistent roundness regardless of element size.
  • When all 4 values are equal, the output is simplified to a single value like border-radius: 12px.

Frequently Asked Questions

Should I use px or % for border-radius?

px sets a fixed radius regardless of element size. % is proportional to the element — 50% on a square creates a perfect circle.

How do I set each corner differently?

Use the advanced mode to set individual values for top-left, top-right, bottom-right, and bottom-left corners.

Is my data sent to a server?

No. All processing happens entirely within your browser — your files are never uploaded to any server. This zero-server architecture keeps your data 100% private, safe for sensitive documents and enterprise security environments.
