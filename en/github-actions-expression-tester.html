GitHub Actions Expression Evaluator

Evaluate expressions used in if: against context JSON such as github, env, matrix, steps and needs. Every sub-expression shows its value and type, following GitHub's rules for case-insensitive comparison, number coercion and falsy values.

Example

✅ Result: true (boolean)

Input — Expression (with or without ${{ … }}; text containing ${{ }} segments works too)

github.ref == 'refs/heads/main' && contains(github.event.head_commit.message, '[deploy]') && !cancelled()

Input — Contexts (JSON: github, env, vars, steps, needs, matrix, inputs, runner, job, secrets …)

{
  "github": {
    "ref": "refs/heads/main",
    "event_name": "push",
    "actor": "octocat",
    "event": { "head_commit": { "message": "Fix bug [deploy]" }, "commits": [ { "message": "a" }, { "message": "b" } ] }
  },
  "env": { "NODE_ENV": "production" },
  "matrix": { "os": "ubuntu-latest", "node": 20 },
  "steps": { "build": { "outcome": "success", "outputs": { "version": "1.2.3" } } },
  "needs": { "test": { "result": "success" } }
}

What this tool does

Check whether an if condition is true without committing and running it. Input never leaves your browser.

  • Syntax: literals (null, booleans, numbers, 0x hex, 'strings' with '' escape), .a.b properties, ['key'], indexes, the object filter .*, ! < <= > >= == != && ||, parentheses
  • Functions: contains, startsWith, endsWith, format ({0} and {{ }}), join, toJSON, fromJSON, hashFiles (placeholder), success, failure, always and cancelled
  • Rules: string comparison ignores case, different types are compared as numbers (null→0, true→1, ''→0, non-numeric strings→NaN), NaN comparisons are false, && and || return operand values
  • Text mixing ${{ }} segments is evaluated per segment and joined; context and function names are case-insensitive
  • A per-sub-expression table (value and type) and a job status selector (success / failure / cancelled)

💡 Tips

  • Comparing a boolean with a string using == such as inputs.dry == 'false' coerces both to numbers and can surprise you.
  • In if:, text after ${{ }} makes the whole value a string that is always true.
  • github.event.commits.*.message gathers a property across array elements, which join can combine.

Frequently Asked Questions

Can results differ from a real runner?

The context values are JSON you provide and may differ from a real run; the evaluation rules follow GitHub's documentation.

Why does hashFiles give no value?

It needs the runner's actual files, so a placeholder string is returned with a note.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
