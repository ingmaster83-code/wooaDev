SVG Optimiser, Checker & Data URI

Paste SVG code to strip editor metadata, comments, unused ids and default attributes and to shorten coordinate precision and colours. Script, on* handlers, foreignObject and external links are found and removed, and you get a preview where scripts cannot run plus a CSS data URI.

What this tool does

Tidy SVGs in the browser without installing svgo. Your code is not uploaded.

  • Cleaning: comments, metadata, Inkscape / Sodipodi attributes, empty groups, unused ids, default attributes and coordinate precision
  • Path minifying: rewrites path data (arc flags, saving separators for negatives and decimals) and shortens colour names, rgb() and #aabbcc
  • Checks: missing viewBox or xmlns, script, on* handlers, foreignObject, external or javascript: links, embedded rasters, accessibility title
  • Output: cleaned SVG (minified or indented), size change with gzip estimate, script-blocked preview, URL-encoded and Base64 CSS data URIs
  • Options: decimal places, keep title / desc, drop width / height, strip risky content

💡 Tips

  • One or two decimals is often enough for icons; fewer digits shrink the file a lot but large shapes may drift.
  • Do not inline untrusted SVG as <svg>; load it with <img>, where scripts do not run.
  • For CSS backgrounds a URL-encoded data URI is usually smaller than Base64.

Frequently Asked Questions

Can the shape change?

Lower precision can cause tiny differences. Check the preview and raise the decimals if needed. Rules inside <style> are left untouched.

Is it the same as svgo?

Only the common cleanup rules are implemented. Advanced steps such as merging paths or applying transforms are not done, so use svgo for large illustrations.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
