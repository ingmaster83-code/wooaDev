HTML Formatter & Structure Checker

Makes squashed or badly indented HTML readable and finds structural problems such as unclosed tags, duplicate ids, images without alt and missing lang or viewport. Minify is included.

What this tool does

Make copied markup or template output readable and catch common mistakes in one go. Input is processed in your browser.

  • Format: block elements on their own lines, inline elements kept together, void elements (br, img) and optional end tags (li, p) handled
  • script, style, pre and textarea content is preserved verbatim
  • Structure checks: unclosed or stray tags, duplicate ids, img without alt, target=_blank without rel=noopener, inline on* attributes, deprecated tags
  • Page checks: DOCTYPE, html lang, title, meta charset and viewport
  • Minify mode and a line-width setting

💡 Tips

  • Whitespace inside pre and textarea matters and is left alone.
  • One space between inline elements can create visible spacing, so check the rendering after minifying.
  • Always give img an alt; use alt="" for decorative images.

Frequently Asked Questions

Browsers render broken HTML, so why check?

The browser's silent repair may differ from your intent, and duplicate ids or missing attributes cause script, accessibility and SEO problems.

Does it handle XHTML or JSX?

It follows plain HTML rules. Self-closing tags (<br />) are understood but JSX-only syntax is not.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
