Security Header Builder — Nginx, Apache, Caddy & helmet

Pick HSTS, X-Content-Type-Options, X-Frame-Options, Referrer-Policy, Permissions-Policy, CORS and COOP / COEP and get the configuration code for your server.

Example

✅ Built 5 header(s)

Result — Security header configuration

# server { … } 또는 location 블록 안에
add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
add_header X-Content-Type-Options "nosniff" always;
add_header X-Frame-Options "DENY" always;
add_header Referrer-Policy "strict-origin-when-cross-origin" always;
add_header Permissions-Policy "camera=(), microphone=(), geolocation=(), interest-cohort=()" always;

Result — Headers applied

Header | Value | Purpose
Strict-Transport-Security | max-age=31536000; includeSubDomains | Makes browsers remember to use HTTPS only
X-Content-Type-Options | nosniff | Disables MIME sniffing
X-Frame-Options | DENY | Clickjacking protection (CSP frame-ancestors can replace it)
Referrer-Policy | strict-origin-when-cross-origin | Limits information leaked via the Referer header
Permissions-Policy | camera=(), microphone=(), geolocation=(), interest-cohort=() | Restricts browser features

What this tool does

When a scanner reports missing headers, this shows which ones to add with which values, as ready-to-paste configuration.

  • Output formats: Nginx add_header, Apache .htaccess, Caddy, Express helmet + cors, Netlify / Cloudflare Pages _headers, plain list
  • Presets (balanced, strict, minimal) and HSTS details (max-age, includeSubDomains, preload)
  • CORS: allowed origin, methods, headers, credentials, with warnings for invalid combinations such as * with credentials
  • Cross-origin isolation (COOP + COEP) with notes on its impact
  • A table explains the purpose of each header

💡 Tips

  • HSTS preload is hard to undo. Make sure every subdomain supports HTTPS first.
  • In Nginx add always to add_header so the headers also appear on 4xx / 5xx responses.
  • CSP is site specific; build it with the CSP Builder.

Frequently Asked Questions

Can CSP replace X-Frame-Options?

Yes, frame-ancestors in CSP is the more flexible modern way. Many sites keep both for older browsers.

Is Access-Control-Allow-Origin: * safe?

Fine for public APIs, but it cannot be used with credentials. Allowing specific origins is safer.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
