Certificate Chain Checker

Paste the certificate bundle a server sends and the tool builds the chain from leaf to root and verifies each signature with its issuer's public key. It reports misordering, missing intermediates, expiry and CA constraint violations.

What this tool does

Check the server's chain when TLS errors appear only in some clients. Certificates never leave your browser.

  • Finds the leaf in the bundle and builds the chain from issuer names and key identifiers (duplicates removed, strays flagged)
  • Signature verification: RSA (PKCS#1 v1.5 SHA-1 / 256 / 384 / 512), ECDSA (P-256 / 384 / 521) and Ed25519 via Web Crypto
  • Checks: bundle order (leaf → intermediate → root), missing intermediate, expiry, CA flag, keyCertSign and pathlen, weak signatures and short keys
  • Leaf SAN against a hostname, custom reference time
  • Does not check whether the root is in a trust store (signature chain only)

💡 Tips

  • A server should send the leaf and intermediates; clients already have the root.
  • Browsers fetch a missing intermediate through AIA, but Android, Java and curl do not and fail.
  • A misordered bundle is rejected by some clients: leaf first, then its issuer.

Frequently Asked Questions

It says the signature does not match.

A different CA certificate with the same name was mixed in, or the leaf was signed with another key; check it pairs with the renewed intermediate.

Does it handle cross-signed roots?

Candidates with the same subject are chosen by AKI. It does no full path discovery, so check complex cross-signing yourself.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
