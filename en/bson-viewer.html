BSON Decoder & Extended JSON Converter

Decodes MongoDB BSON bytes from hex, Base64 or a .bson file into an element table with byte offsets and Relaxed or Canonical Extended JSON. Extended JSON can be encoded back to BSON too.

What this tool does

Open .bson files from mongodump or documents captured on the wire. Files are not uploaded.

  • Input: hex, Base64 or a .bson file (including concatenated mongodump documents)
  • Element table: byte offset, type byte, path, type and value — double, string, document, array, binary, ObjectId, bool, datetime, null, regex, int32, timestamp, int64, decimal128, minKey and maxKey
  • Output style: Relaxed Extended JSON, Canonical Extended JSON, or plain JSON without type information
  • Checks document size and terminator; notes duplicate keys and deprecated types (undefined, symbol, DBPointer)
  • Encode: Extended JSON ($oid, $date, $numberLong …) to BSON bytes

💡 Tips

  • Relaxed is easier to read while Canonical preserves every type; use Canonical when moving data to other tools.
  • The first 4 bytes of an ObjectId are its creation time; the ObjectId tool turns them into a date.
  • JSON numbers become int32 when they fit, int64 within the safe range, otherwise double.

Frequently Asked Questions

How does BSON differ from JSON?

BSON is MongoDB's binary JSON with types JSON lacks: dates, ObjectId, binary, Int64 and Decimal128.

Relaxed versus Canonical Extended JSON?

Canonical tags every number with a type such as $numberInt and round-trips exactly; Relaxed uses plain numbers and ISO dates for readability.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
