💡 Tips

  • X Offset: Positive moves shadow right, negative moves it left.
  • Y Offset: Positive moves shadow down, negative moves it up.
  • Blur: Higher values create softer, more spread-out shadows. 0 = sharp edge.
  • Spread: Positive expands the shadow, negative shrinks it.
  • Inset: Draws the shadow inside the element — great for pressed/sunken effects.
  • Stack multiple shadow layers for richer, more realistic depth effects.
What's the difference between box-shadow and text-shadow?

box-shadow applies to the entire element box and supports inset and spread. text-shadow only applies to the text characters and does not support those parameters.

Does box-shadow affect layout?

No. Unlike outline, box-shadow does not take up space in the document layout. It is purely visual and does not push other elements away.

How do I apply a shadow to only one side?

Use a negative spread value combined with a single-directional offset. For example: box-shadow: 0 4px 6px -4px rgba(0,0,0,0.4) shows a shadow only at the bottom.
