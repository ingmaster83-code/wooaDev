💡 Tips

  • justify-content: Aligns items along the main axis. Horizontal for row, vertical for column.
  • align-items: Aligns items along the cross axis for a single line.
  • align-content: Aligns multiple lines along the cross axis. Only works with flex-wrap: wrap.
  • align-self: Overrides align-items for individual items.
  • gap: Sets spacing between items (both row-gap and column-gap).
What is the difference between Flexbox and Grid?

Flexbox is designed for 1D layouts (either row or column), while Grid handles 2D layouts (rows and columns together). Use Flexbox for navbars and button groups; use Grid for full-page layouts.

What are flex-grow, flex-shrink, and flex-basis?

flex-grow: proportion of remaining space an item takes. flex-shrink: how much an item shrinks when space is limited. flex-basis: default size before growing/shrinking. The shorthand flex: 1 equals flex: 1 1 0%.

Is Flexbox supported in all browsers?

Flexbox is fully supported in all modern browsers (Chrome, Firefox, Safari, Edge). IE11 has partial support with some bugs and may require -ms- prefixes.
