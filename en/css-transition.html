Frequently Asked Questions

What is the difference between transition and animation?

Transition defines a smooth change between two states (e.g., hover on/off). Animation uses keyframes for multi-step, looping effects. Use transition for simple hover effects; use animation for complex sequences.

Should I use will-change with transitions?

Adding will-change: transform can enable GPU acceleration for transform and opacity transitions, improving performance. However, overusing it increases memory consumption, so apply it only where needed.
