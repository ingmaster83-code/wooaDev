What this tool does

When you put long text or JSON into code as a string, handling quotes, backslashes and newlines by hand is tedious and error-prone.

  • Escape: real string → a literal you can paste into code (choose the quote style and whether to include the quotes)
  • Unescape: a literal like "a\nb\u0041" → the real string (\xHH, \u{1F600}, octal and line continuations handled)
  • Targets: JSON, JavaScript (single/double/template), Python, Java & C#, C & C++, SQL (doubled single quotes), MySQL, regex literal
  • "Escape non-ASCII as \uXXXX" handles CJK text and emoji (surrogate pairs)

To check that the result is valid JSON, use the JSON Validator.

💡 Tips

  • To embed multi-line JSON in code, escape with the JSON target and copy it including the quotes.
  • For SQL values, parameter binding is safer than escaping — this tool is for writing literals.
  • Unknown escapes (like \q) are kept as plain characters and counted.

Frequently Asked Questions

Is the JSON output identical to JSON.stringify?

The JSON target follows JSON.stringify rules (\n, \t, \", \\ and control characters as \u00XX). Other languages follow their own literal rules and may differ slightly.

Does SQL escaping prevent SQL injection?

Not reliably. Always use prepared statements with bound parameters. This tool is for hand-written queries or logging values.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
