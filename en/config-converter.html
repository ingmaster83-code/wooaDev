Config File Converter — INI · .properties · plist ↔ JSON

Converts INI, Java .properties and Apple plist (XML) files to JSON, and JSON back to those formats.

What this tool does

Python's configparser (INI), Java/Spring's application.properties and macOS/iOS Info.plist are different config formats. Converting to JSON lets you see the structure at a glance and move it elsewhere.

  • INI: [section], key=value, ; and # comments, key[]=value arrays, [a.b] nested sections
  • .properties: key=value, key:value, line continuations (\), \uXXXX unicode, optional a.b.c dotted-key nesting
  • plist (XML): dict/array/string/integer/real/true/false/date/data (null becomes an empty string)
  • The JSON → INI/.properties/plist direction works too; reuse the result as input to check round trips

For TOML and YAML there are dedicated converters, and .env has the ENV converter.

💡 Tips

  • For Spring's application.properties, enable "dotted keys as nesting" to see a structure like application.yml.
  • Turn on number/boolean typing if INI values should be real numbers and booleans.
  • Non-ASCII text escaped as \uXXXX in .properties is restored to the real characters.

Frequently Asked Questions

Are binary plists supported?

Only the XML format. Convert a binary plist first with `plutil -convert xml1`.

Is there an INI standard?

No formal spec exists, so implementations differ. This tool supports the most common rules: sections, = or :, ; and # comments and quoted values.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
