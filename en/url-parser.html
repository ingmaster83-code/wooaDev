Frequently Asked Questions

Does it handle non-ASCII characters or special symbols in a URL?

Yes, it uses the browser's URL/URLSearchParams APIs, which handle encoding and decoding automatically.

Does adding/removing query params change the original URL?

No. Your original input URL stays untouched — the edited result is shown as a new URL below.

Are inputs stored on a server?

No. All processing happens entirely in your browser and inputs are never sent to a server.
