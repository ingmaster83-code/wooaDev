Protobuf Wire Decoder (No Schema)

Decodes Protobuf binary without a .proto file into field numbers, wire types, several readings of varint and fixed values (signed, zigzag, float) and guessed nested messages and strings. The 5-byte gRPC header can be skipped.

What this tool does

Understand the structure of Protobuf bytes from a log or packet before you have the schema. Data never leaves your browser.

  • Input: hex, Base64 or a file; option to skip the 5-byte gRPC header (compression flag + length)
  • Field table: byte offset, field number (nested as 3.2.1), wire type and possible readings
  • varint: unsigned / int64 / zigzag (sint) / bool candidates; fixed32 / 64: integer, float and double candidates
  • Length-delimited fields are guessed as string, nested message, packed varints or bytes (can be turned off)
  • Repeated field numbers become JSON arrays; groups (wire 3 / 4), truncated data and bad lengths are errors

💡 Tips

  • Without a schema int32, uint32, enum and bool all look like numbers; judge by value range.
  • Negative int32 / int64 values are 10-byte varints; check the int64 candidate for values such as -1.
  • A field that looks like a string may be a coincidence; turn off nested guessing to see the bytes.

Frequently Asked Questions

Can it decode accurately without a schema?

Structure (field numbers and wire types) is exact, but types are guesses; a .proto is needed for exact decoding.

What does field 3.2 mean?

Field 3 is a nested message and 2 is a field inside it.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
