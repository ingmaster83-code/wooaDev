What this tool does

JSON copied from logs, produced by an AI assistant, printed from a Python dict or cut off by a length limit often fails in JSON.parse. This tool reads the structure with a forgiving parser and writes it back as standard JSON.

  • Removes comments (//, /* */, #) and trailing commas; fills in missing commas and colons
  • Converts single-quoted, smart-quoted and bare strings/keys to double-quoted JSON
  • Converts True/False/None, undefined, NaN, Infinity and hex numbers to JSON values
  • Closes unclosed brackets and strings, and strips ```json fences or surrounding prose

Every change is listed in a table, so you can check that nothing was changed in a way you didn't intend.

Frequently Asked Questions

Will repairing change my data?

Only the syntax is fixed. Repairs that require a guess — closing a cut-off string or filling a missing value with null — are all listed in the fix table so you can review them.

What happens with duplicate keys?

Like JSON.parse, only the last value of a repeated key is kept, and the table tells you it happened.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
