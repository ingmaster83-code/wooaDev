What this tool does

Example API keys, invite codes, test data, prize draws — plenty of jobs need randomness. This tool only uses unpredictable cryptographic randomness (crypto.getRandomValues).

  • Random strings: letters+digits, lowercase, uppercase, digits, hex, Base64url, no look-alikes, or your own character set; entropy in bits per string
  • Random integers and decimals: set the range and count, unique draws, decimal places
  • List picking: choose n of the lines you enter (with or without repeats), or shuffle the whole list (Fisher–Yates)
  • Uniform draws without modulo bias

  • If a draw must be provably fair, record the time and input list together with the result.
  • For passwords, the dedicated Password Generator is more convenient.

Frequently Asked Questions

How is this different from Math.random?

Math.random is a predictable pseudo-random generator, unsuitable for security. crypto.getRandomValues uses the operating system's secure source and is unpredictable.

Can I reproduce a result?

Seeded randomness isn't offered. For reproducible test data use the seed option in the JSON Mock Data Generator.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
