What this tool does

Comparing a downloaded ISO, installer or backup with the hash published by its vendor is the most basic integrity check. Files are processed only inside your browser.

  • Calculates MD5, SHA-1, SHA-256, SHA-384, SHA-512 and CRC-32 in one pass
  • Paste the published hash and the tool finds which algorithm matches (spaces and case are ignored)
  • Text mode hashes a string; choose upper or lower case hex
  • Copy the results as a table

💡 Tips

  • For security use SHA-256 or stronger. MD5 and SHA-1 can be forged on purpose and only suit accidental-corruption checks.
  • Fetch the expected hash from a different channel than the download itself (official docs or a signature file).
  • Windows: certutil -hashfile file SHA256. macOS / Linux: shasum -a 256 file gives the same value.

Frequently Asked Questions

Does a matching hash mean the file is safe?

It means the content equals the published release, not that it is free of malware. What matters is whether the source of the hash is trustworthy.

Are checksum and hash the same?

They serve a similar purpose. Checksums like CRC-32 detect transmission errors, while cryptographic hashes such as SHA-256 also resist deliberate tampering.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
