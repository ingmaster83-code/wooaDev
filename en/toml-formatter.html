TOML Formatter & Validator

Validates TOML syntax and rewrites spacing, tables and arrays in one consistent style.

What this tool does

Hand-edited TOML tends to drift in spacing and style. This tool parses the document, validates it, and writes the same content back in a consistent shape.

  • TOML 1.0 validation with line/column error positions
  • Normalises key=value vs key = value spacing and array/inline-table notation
  • Optional key sorting for smaller diffs and fewer merge conflicts
  • Summary of key count, tables, arrays and maximum depth

Note: comments are not preserved when the file is rewritten — for files where comments matter, use it only to validate.

💡 Tips

  • For files edited by several people, such as pyproject.toml, sort keys before committing to keep diffs clean.
  • If you must keep comments, validate here and make edits by hand.
  • To inspect the data as JSON, use the TOML to JSON converter.

Frequently Asked Questions

Does formatting change my values?

No. The document is parsed and the same values are written back, so only the notation is unified. Comments and the original line-break style are lost.

Does it support TOML 1.1 or extensions?

It targets TOML 1.0. Syntax added after 1.0 may be reported as an error.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
