DNS Record Generator & BIND Zone File Editor

Reads a BIND-format zone file, rewrites it in aligned form, adds records, bumps the SOA serial and finds common configuration mistakes.

Example

⚠️ 9 records — 1 item(s) to check

Input — BIND zone file

$ORIGIN example.com.
$TTL 3600
@   IN SOA ns1.example.com. admin.example.com. (
        2026101601 ; serial
        7200       ; refresh
        3600       ; retry
        1209600    ; expire
        3600 )     ; minimum
    IN NS  ns1.example.com.
    IN NS  ns2.example.com.
    IN MX  10 mail.example.com.
@   IN A   203.0.113.10
www IN CNAME @
mail IN A  203.0.113.20
@   IN TXT "v=spf1 mx -all"
ftp IN CNAME www.example.com

What this tool does

Self-hosted BIND, NSD or PowerDNS zone files suffer from parenthesised SOAs, relative vs absolute names and forgotten trailing dots. Paste one and it is parsed, checked and tidied.

  • Supports $ORIGIN, $TTL, multi-line SOA (parentheses), ; comments, blank-owner continuation and A, AAAA, CNAME, MX, NS, TXT, SRV, CAA, PTR…
  • Output: an aligned zone file and a record table
  • Add a record by type, name, value and TTL (TXT values are quoted automatically)
  • SOA serial: keep / +1 / today's date (YYYYMMDDnn)
  • Checks: missing SOA or apex NS, CNAME coexisting with other records, apex CNAME, A/AAAA values, MX form, targets missing a trailing dot, TXT strings over 255 bytes, TTL syntax

💡 Tips

  • The classic mistake is a CNAME target without a trailing dot: the origin is appended, giving www.example.com.example.com.
  • Always bump the SOA serial after editing so secondary servers pick up the change.
  • $INCLUDE and $GENERATE directives are skipped, not interpreted.

Frequently Asked Questions

Why can't the apex have a CNAME?

The apex must carry SOA and NS records, and a CNAME cannot coexist with other records at the same name. Use an A record or your provider's ALIAS/ANAME feature.

What if a TXT value exceeds 255 characters?

One string holds at most 255 bytes, so long values (such as DKIM keys) are split into several quoted strings within the same record.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
