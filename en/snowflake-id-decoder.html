What this tool does

A Snowflake ID is a 64-bit integer with a timestamp in the high bits followed by a worker number and a sequence. From a tweet, Discord message or user ID alone you can tell when it was created.

  • Twitter (X): 41-bit time + 5-bit datacenter + 5-bit worker + 12-bit sequence (epoch 2010-11-04)
  • Discord: epoch 2015-01-01, worker / process / increment; Instagram: 13-bit shard + 10-bit sequence
  • Sonyflake: 10 ms time units + sequence + machine ID; Custom: set your own epoch and bit widths
  • Shows UTC and a time zone of your choice (e.g. Asia/Seoul); analyses one ID per line

💡 Tips

  • Picking the wrong platform gives silly years (1970s or the far future) — try another one.
  • Always treat IDs as strings: JavaScript numbers lose precision. This tool uses BigInt.
  • IDs created within the same millisecond are told apart by the sequence value.

Frequently Asked Questions

Does one ID give the exact creation time?

Yes, to the millisecond. It can't reveal any clock error on the server that generated it.

Why do platforms use different epochs?

A Snowflake stores time since an epoch in 41 bits (about 69 years). Each service picked an epoch near its launch to stretch the usable lifetime.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
