MongoDB Extended JSON (EJSON) Converter

Switches the type markers of Extended JSON exported by mongoexport or Compass — $oid, $date, $numberLong and friends — between Canonical (type-preserving), Relaxed (readable) and plain JSON.

Example

✅ Converted to Relaxed

Input — MongoDB Extended JSON (EJSON)

{
  "_id": {"$oid": "507f1f77bcf86cd799439011"},
  "createdAt": {"$date": {"$numberLong": "1760000000000"}},
  "count": {"$numberInt": "42"},
  "big": {"$numberLong": "9007199254740993"},
  "price": {"$numberDouble": "19.99"},
  "amount": {"$numberDecimal": "12345.6789"},
  "uid": {"$uuid": "123e4567-e89b-12d3-a456-426614174000"},
  "file": {"$binary": {"base64": "aGVsbG8=", "subType": "00"}},
  "re": {"$regularExpression": {"pattern": "^a", "options": "i"}},
  "name": "Kim"
}

Result — Converted

{
  "_id": {
    "$oid": "507f1f77bcf86cd799439011"
  },
  "createdAt": {
    "$date": "2025-10-09T08:53:20Z"
  },
  "count": 42,
  "big": {
    "$numberLong": "9007199254740993"
  },
  "price": 19.99,
  "amount": {
    "$numberDecimal": "12345.6789"
  },

  },
  "file": {
    "$binary": {

Result — Notes

The 64-bit integer 9007199254740993 may lose precision as a JSON number, so $numberLong was kept
In Relaxed form int32 / int64 / double are plain JSON numbers and can no longer be told apart. Use Canonical to preserve types

What this tool does

Removes the confusion about how ObjectIds, dates and 64-bit integers are represented when moving MongoDB data as JSON.

  • Relaxed: integers and doubles as JSON numbers, dates as ISO strings (readable)
  • Canonical: every number as $numberInt / $numberLong / $numberDouble to preserve types
  • Plain JSON: $oid as a string and dates as ISO, dropping the type information
  • Supports $oid, $date, $numberInt / Long / Double / Decimal, $uuid, $binary, $regularExpression, $timestamp, $minKey / $maxKey
  • 64-bit integers beyond JavaScript's safe range stay as $numberLong to keep precision

💡 Tips

  • Use Canonical for migrations and backups where types matter, Relaxed for human-readable logs.
  • Re-importing plain JSON turns ObjectId and dates into strings, so do not use it for imports.
  • mongoimport reads both Canonical and Relaxed.

Frequently Asked Questions

Canonical or Relaxed?

Canonical when another system must receive the exact types; Relaxed for people and API responses.

Why is $numberLong a string?

A 64-bit integer as a JSON number (an IEEE 754 double) loses precision above 9,007,199,254,740,992.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
