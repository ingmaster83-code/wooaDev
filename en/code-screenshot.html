Frequently Asked Questions

Which programming languages are supported?

Syntax highlighting is supported for JavaScript, TypeScript, Python, HTML, CSS, JSON, Bash, and more.

Where can I use the downloaded image?

Anywhere you want to show code visually — Twitter, Instagram, blog posts, or slide decks.

Is the code I enter stored on a server?

No. All processing happens entirely in your browser and the code you enter is never sent to a server.
