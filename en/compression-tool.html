What this tool does

Compress and decompress in the browser with CompressionStream, no server involved. Your data is not uploaded.

  • Operations: compress, decompress, inspect header, compare sizes across formats
  • Formats: gzip, deflate (zlib wrapper), deflate-raw; the format is auto-corrected from magic bytes when decompressing
  • gzip header: modification time, OS, XFL, original file name and comment, CRC-32 and original size (ISIZE)
  • zlib header: window size, level hint, preset dictionary flag and Adler-32, checked against the decompressed result
  • I/O: text, Base64, hex and files (non-text results are shown as Base64 / hex)

💡 Tips

  • If you received an HTTP Content-Encoding: gzip body as Base64, paste it into Decompress.
  • Very short data grows because of headers (gzip 18 B, zlib 6 B); use Compare sizes to check.
  • An integrity mismatch in Inspect header means the data was damaged or truncated in transit.

Frequently Asked Questions

Can I choose the compression level?

The browser CompressionStream has no level option and uses its default. For maximum compression use server-side zlib or 7-Zip.

Does it handle zip or brotli?

Only gzip, deflate and deflate-raw. Zip archives and brotli are different formats and are not covered.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
