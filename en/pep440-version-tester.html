PEP 440 Python Version & Specifier Tester

What this tool does

Use it to see which version pip will pick and how version strings order. Everything runs in your browser.

  • Normalise: 1.0-rc1 → 1.0rc1, 1.0.POST1 → 1.0.post1, 1.0.0 compares equal to 1.0
  • Sort: dev < a < b < rc < final < post, epoch (1!) first, local versions (+ubuntu.1)
  • Specifiers: ==, !=, <=, >=, <, >, ~=, ==1.*, === and comma AND
  • Pre-releases are excluded unless the specifier names one (option to include)
  • Invalid lines are marked in the table and the highest matching version is printed

💡 Tips

  • ~=1.4.2 equals >=1.4.2,==1.4.* so 1.5.0 is not allowed.
  • 1.0 and 1.0.0 are the same version; sorting as strings puts 1.10 before 1.9.
  • To receive pre-releases use pip install --pre or name one in the specifier.

Frequently Asked Questions

Is SemVer the same as PEP 440?

Similar but not identical. PEP 440 has a, b, rc, dev, post, epochs and local versions, and notations like -beta.1 are normalised.

==1.* versus ~=1.0?

==1.* is all of 1.x; ~=1.0 is the same range, while ~=1.0.0 narrows to 1.0.x.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
