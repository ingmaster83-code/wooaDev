What this tool does

When an API call returns 401, check whether the header was built correctly. Decoding happens only in your browser, so pasting a real token does not send it anywhere.

  • Basic: decodes Base64 to user:password and flags problems such as a colon in the username
  • Bearer / JWT: shows the alg header and claims (sub, iss, aud, iat, nbf, exp) as readable times
  • Give a reference time to see 'expires in N min' or 'expired N min ago'
  • Warns about alg=none tokens and tokens without exp
  • Enter user and password to build Authorization: Basic ...

💡 Tips

  • Basic auth is only Base64 encoding, not encryption. Use it over HTTPS only.
  • This tool does not verify signatures. Anyone can read a JWT, so never put secrets in it.
  • If a token seems to have just expired, also suspect clock skew between client and server.

Frequently Asked Questions

What is a bearer token?

Whoever holds the token can use it. A leak is immediately exploitable, which is why HTTPS and short lifetimes matter.

Does it verify the JWT signature?

No. Verification needs the secret or public key. Use this for inspection and expiry checks and verify on the server.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
