CSS Formatter & Linter

Makes compressed CSS readable or minifies it, and finds duplicate properties in a rule, empty rules, !important overuse, unnecessary vendor prefixes and unclosed braces.

.card:hover,.card:focus{transform:translateY(-2px)}
@media (max-width:600px){.card{margin:0;-webkit-transition:all .3s;transition:all .3s}.empty{}}
.btn{padding:4px 8px;&:hover{opacity:.8}}

What this tool does

Use it to read a minified stylesheet or tidy hand-written CSS. Everything is processed in your browser.

  • Format: selector commas on new lines, normalised values and spacing, !important notation, @media condition spacing
  • ; { } inside strings and url() are left alone; nested rules (&:hover) and @-rules are supported
  • Options: alphabetical declaration sort, keep or drop comments, 2 / 4 spaces or tab
  • Lint: duplicate properties, empty rules, four or more !important, unnecessary -webkit- prefixes, property:value errors, unclosed brackets, comments and strings
  • Minify: strips whitespace and comments, the last semicolon and leading zeros (0.5 → .5)

💡 Tips

  • Sorting can reorder intentional fallbacks (writing color twice), so be careful.
  • Many !important declarations usually mean selector specificity needs tidying.
  • Leave vendor prefixes to a build tool such as Autoprefixer.

Frequently Asked Questions

Is a duplicate property always wrong?

No, it is sometimes a deliberate fallback for old browsers. The note only asks you to confirm it is intentional.

Does it handle SCSS or Less?

It targets plain CSS and CSS nesting. Preprocessor features such as variables and mixins are not supported.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
