DynamoDB JSON ↔ Plain JSON Converter

Converts DynamoDB's typed JSON ({"name":{"S":"Kim"},"age":{"N":"31"}}) to plain JSON and back. Supports Item / Items wrappers and the SS, NS, B, L and M types.

Example

✅ Converted

Input — Input JSON

{
  "Item": {
    "pk": {"S": "USER#42"},
    "age": {"N": "31"},
    "active": {"BOOL": true},
    "nick": {"NULL": true},
    "tags": {"SS": ["a", "b"]},
    "scores": {"NS": ["1.5", "2"]},
    "addr": {"M": {"city": {"S": "Seoul"}, "zip": {"S": "04524"}}},
    "history": {"L": [{"S": "x"}, {"N": "7"}]},
    "avatar": {"B": "aGVsbG8="}
  }
}

Result — Converted

{
  "Item": {
    "pk": "USER#42",
    "age": 31,
    "active": true,
    "nick": null,
    "tags": [
      "a",
      "b"
    ],
    "scores": [
      1.5,
      2
    ],
    "addr": {
      "city": "Seoul",
      "zip": "04524"
    },
    "history": [
      "x",
      7
    ],
    "avatar": {
      "$binary": "aGVsbG8="
    }
  }
}

Result — Notes

Sets (SS / NS / BS) become arrays and lose the set property. Binary values are shown as {"$binary": base64}

What this tool does

Turn the output of aws dynamodb get-item / scan or console exports into readable JSON, or turn plain JSON into the format put-item expects.

  • Types: S, N, BOOL, NULL, L, M, SS, NS, B, BS
  • DynamoDB → plain: handles Item, Items wrappers, arrays and single attribute values
  • Plain → DynamoDB: numbers become string N, nested objects M, arrays L (optionally unique string / number arrays as SS / NS sets)
  • Big numbers that would lose precision stay as strings
  • Unknown types or several types in one attribute are reported with the path

💡 Tips

  • Sets (SS / NS) become arrays in plain JSON and the set property is lost.
  • Numbers travel as strings with up to 38 digits, which JavaScript numbers can lose.
  • In SDKs the marshall / unmarshall helpers do the same conversion in code.

Frequently Asked Questions

How are BOOL and NULL written?

As {"BOOL": true} and {"NULL": true}; NULL's value is always true.

What happens to binary (B)?

Base64 strings are shown as {"$binary": …}. When converting back, specify B explicitly.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
