What this tool does

Receiving JSON in Spring or any Java service needs DTO classes. With a sample JSON you can get a first draft immediately.

  • Styles: POJO (private fields + getters/setters), record (Java 16+), Lombok @Data
  • snake_case keys become camelCase fields with Jackson @JsonProperty("is_active") added automatically
  • Arrays → List<T>, integers → Long (or Integer), floats → Double, booleans → Boolean, mixed → Object
  • Nested objects become their own classes; identical shapes are reused
  • Reserved words (class, new…) get a trailing underscore to avoid compile errors

Paste several response samples together for more accurate field types.

💡 Tips

  • If you don't use Jackson, turn off the @JsonProperty option.
  • Records suit immutable DTOs — check that your serializer supports them (Jackson 2.12+).
  • Enter a package to add the declaration at the top.

Frequently Asked Questions

Shouldn't a Boolean getter be isXxx?

For the wrapper type Boolean, JavaBeans uses getXxx. If you need primitive boolean, change the type and rename the getter to isXxx.

What happens with null or missing fields?

Reference types can be null, so wrapper types are used without extra handling. Initialise defaults yourself if needed.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
