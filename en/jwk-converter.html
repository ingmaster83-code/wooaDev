JWK / JWKS ↔ PEM Converter

Converts the JWK or JWKS used for JWT verification into PEM public or private keys and PEM public keys, private keys and certificates into JWK. It computes RFC 7638 thumbprints to use as kid and can select one key by kid.

What this tool does

Use it when a JWT library accepts only PEM or you must publish a JWKS endpoint. Keys never leave your browser.

  • JWK / JWKS → PEM: RSA, EC (P-256, P-384, P-521) and OKP (Ed25519); private keys as PKCS#8, public keys as SPKI
  • PEM → JWK: SPKI, PKCS#8, PKCS#1 (RSA), SEC1 (EC) and certificates (public key extracted), with kid (thumbprint), use and alg
  • RFC 7638 thumbprint (SHA-256, Base64URL) from the required members as lexicographic JSON
  • Select one key from a JWKS by kid; symmetric (oct) keys are noted as having no PEM
  • Warns about private parameters (d), weak RSA and a missing kid

💡 Tips

  • Publish only public keys in a JWKS; fields such as d, p and q mean a private key.
  • kid tells which key signed during rotation; an RFC 7638 thumbprint as kid maps one-to-one to the key.
  • alg is a usage declaration, not part of the key; JWT libraries check it, so set it precisely.

Frequently Asked Questions

What are RSA n and e?

The modulus and public exponent, Base64URL encoded; they are the same values as in the SPKI public key.

Ed25519 does not convert.

The browser must support Ed25519 in Web Crypto (Chrome 137+, Firefox 129+, Safari 17+).

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
