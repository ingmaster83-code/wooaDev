Frequently Asked Questions

Where can I use Markdown tables?

Markdown tables are supported in GitHub README files, GitLab, Notion, Obsidian, VS Code, Discord, and any platform that renders CommonMark or GFM (GitHub Flavored Markdown).

How does column alignment work?

The separator row uses colons to indicate alignment: :--- for left, :---: for center, ---: for right. The generator handles this automatically based on your selection.
