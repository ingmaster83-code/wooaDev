CloudFormation Template Validator

Paste a YAML or JSON template (short-form functions like !Ref supported) to get line-numbered findings on missing resource and parameter references, circular dependencies, condition and mapping references, missing required properties, duplicate Exports, open security groups, public S3, plain-text passwords and end-of-life Lambda runtimes.

Example

⛔ 9 error(s), 2 warning(s) — 5 resource(s)

Input — CloudFormation template (YAML or JSON; short-form functions like !Ref supported)

AWSTemplateFormatVersion: "2010-09-09"
Parameters:
  Env:
    Type: String
    Default: staging
    AllowedValues: [dev, prod]
  DbPassword:
    Type: String
Conditions:
  IsProd: !Equals [!Ref Env, prod]
  Unused: !Equals [!Ref Env, test]
Resources:
  Bucket:
    Type: AWS::S3::Bucket
    Properties:
      AccessControl: PublicRead
      BucketName: !Sub "${Env}-${AWS::Region}-${Missing}"
  Function:
    Type: AWS::Lambda::Function
    DependsOn: Role
    Properties:
      Runtime: python3.8
      Handler: index.handler
      Role: !GetAtt Role.Arn
  Role:
    Type: AWS::IAM::Role
    DependsOn: Function
    Properties:
      ManagedPolicyArns: [!Ref Policy2]
  Sg:
    Type: AWS::EC2::SecurityGroup
    Properties:
      GroupDescription: web
      SecurityGroupIngress:
        - IpProtocol: tcp
          FromPort: 22
          ToPort: 22
          CidrIp: 0.0.0.0/0
  Db:

What this tool does

Find structure, reference and common security problems before a stack rolls back. Your template is not uploaded.

  • Format: YAML / JSON, short-form functions such as !Ref, !GetAtt, !Sub and !If, section names, logical ID rules, resource type format and unknown attributes
  • References: whether Ref, Fn::GetAtt and Fn::Sub (${}) targets exist among resources, parameters and pseudo parameters, DependsOn, Fn::FindInMap mappings and Condition / Fn::If conditions
  • Cycles: circular dependencies in the Ref / GetAtt / DependsOn graph
  • Properties: parameter Type, Default vs AllowedValues and NoEcho, and required properties of common resources (Lambda, IAM Role, EC2, RDS, SQS / SNS policies …)
  • Security and operations: public S3, SSH / RDP open to the world, IAM Action:* on Resource:*, plain-text DB passwords, end-of-life Lambda runtimes, DeletionPolicy on stateful resources and duplicate Export names

💡 Tips

  • Take passwords through a NoEcho parameter or a Secrets Manager dynamic reference {{resolve:secretsmanager:...}}.
  • Logical IDs cannot contain hyphens or underscores; only letters and digits are allowed.
  • Circular dependencies often come from security groups referring to each other through Ref; split the rules into separate resources.

Frequently Asked Questions

Does it replace cfn-lint?

No. It does not check the full schema of each resource type, only structure, references and common properties; also run cfn-lint and a change set before deploying.

Does it handle SAM templates?

SAM templates with Transform get basic structure and reference checks only, since AWS::Serverless::* properties are expanded by SAM.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
