Redis RESP Parser & Command Builder

Parses RESP text or hex from redis-cli --pipe, MONITOR or packet captures into a tree of type (+, -, :, $, *, RESP3 extensions), length and value. It can also build RESP bytes from a command such as SET key value.

What this tool does

Read what commands and replies are in the bytes exchanged with a Redis server. Data never leaves your browser.

  • Input: real line-break text, text with literal \r\n, or hex bytes; LF-only input is corrected to CRLF
  • Types: + simple string, - error, : integer, $ bulk string (including nil -1), * array and RESP3 _ # , ( ! = % ~ > |
  • Tree table (offset, path, type, length, value); arrays that look like commands are summarised as "SET key value"
  • A bulk string length that does not match the data is reported with its position
  • Build: a command with quoted arguments to RESP bytes (byte lengths), with a printf | nc example

💡 Tips

  • A bulk string length counts bytes, not characters; non-ASCII text takes more bytes per character.
  • A pipelined reply is a stream of several values read in order.
  • For redis-cli --pipe bulk loads, save the RESP built here to a file.

Frequently Asked Questions

RESP2 versus RESP3?

RESP3 adds null, boolean, double, map, set and push types and is used on connections negotiated with HELLO 3.

Does LF-only text work?

Yes. RESP uses CRLF, so LF is converted and you are told.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
