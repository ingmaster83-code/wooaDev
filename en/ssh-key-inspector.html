SSH Public Key Inspector & Fingerprint Calculator

Paste id_ed25519.pub, authorized_keys or known_hosts lines to get the key type and size, the same SHA256 fingerprint as ssh-keygen -l and the legacy MD5 fingerprint, with warnings for weak keys (RSA 1024, DSA). Keys can be converted to PEM.

What this tool does

Check which key is registered on a server or GitHub, or which key a fingerprint in a log belongs to. Keys never leave your browser.

  • Input: several public-key lines, authorized_keys options (command=, from=, no-pty …), known_hosts host prefixes and RFC 4716 format
  • Calculates key type and bits, SHA256:… fingerprint (equal to ssh-keygen -lf) and MD5 fingerprint
  • Checks: RSA below 2048, DSA (ssh-dss) retired, duplicate keys, missing comment, type mismatch; shows certificates (-cert-v01) and security keys (sk-)
  • Converts RSA, Ed25519 and ECDSA to PEM SubjectPublicKeyInfo
  • A pasted private key (-----BEGIN OPENSSH PRIVATE KEY-----) is refused with a warning

💡 Tips

  • Compare the SHA256:… value with a server log or your GitHub settings to identify the key.
  • Prefer Ed25519 for new keys; for RSA use 3072 bits or more.
  • A command= option in authorized_keys restricts that key to the given command.

Frequently Asked Questions

May I paste a private key?

No. Never paste private keys anywhere; enter only the public key (.pub). The tool refuses a private key.

Why is there an MD5 fingerprint?

OpenSSH before 6.7 and some devices show MD5 fingerprints; SHA256 is the current standard.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
