Maven ↔ Gradle Dependency Converter

Converts pom.xml <dependency> blocks into Gradle Groovy or Kotlin DSL and Gradle implementation "group:artifact:version" lines into Maven XML. Scopes map to configurations and parts that cannot be converted are flagged.

Example

✅ Converted 3 dependencies to Gradle (Groovy)

Input — Maven <dependency> blocks or Gradle dependency declarations

<dependency>
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-starter-web</artifactId>
  <version>3.3.4</version>
</dependency>
<dependency>
  <groupId>org.projectlombok</groupId>
  <artifactId>lombok</artifactId>
  <version>1.18.34</version>
  <scope>provided</scope>
</dependency>
<dependency>
  <groupId>org.junit.jupiter</groupId>
  <artifactId>junit-jupiter</artifactId>
  <version>5.10.3</version>
  <scope>test</scope>
</dependency>

Result — Converted

dependencies {
    implementation 'org.springframework.boot:spring-boot-starter-web:3.3.4'
    compileOnly 'org.projectlombok:lombok:1.18.34'
    testImplementation 'org.junit.jupiter:junit-jupiter:5.10.3'
}

Result — Dependencies

groupId | artifactId | Version | Scope / configuration
org.springframework.boot | spring-boot-starter-web | 3.3.4 | compile → implementation
org.projectlombok | lombok | 1.18.34 | provided → compileOnly
org.junit.jupiter | junit-jupiter | 5.10.3 | test → testImplementation

What this tool does

Convert dependency declarations in bulk when moving a project between Maven and Gradle. Input is processed in your browser.

  • Input auto-detected: Maven <dependency> XML or Gradle declarations ("g:a:v" and group: / name: / version: maps)
  • Scope mapping: compile → implementation, provided → compileOnly, runtime → runtimeOnly, test → testImplementation
  • Handles classifier, type (such as @aar), exclusions and optional
  • Output: Gradle Groovy, Gradle Kotlin or Maven XML
  • Flags inexact parts (${…} version properties, BOMs, import scope)

💡 Tips

  • Maven compile usually becomes Gradle implementation rather than api; use api only when the type leaks into your library API.
  • A property version such as ${spring.version} has to move to Gradle extra properties or a version catalog.
  • Replace a BOM such as Spring Boot's with Gradle platform().

Frequently Asked Questions

What happens to import-scope dependencies?

dependencyManagement imports are expressed as platform("g:a:v") in Gradle, so they are only reported as notes.

Can I paste a whole pom.xml?

Only the <dependency> blocks are extracted; parent POMs, plugins and profiles are not converted.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
