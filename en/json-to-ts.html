  • Enable Optional (?) to mark all fields as optional
  • Works with JSON arrays at the root level too

Frequently Asked Questions

What happens with null values?

Null values are typed as null. If you want nullable types, use a union: string | null — you can edit the output after generation.

Does it handle deeply nested JSON?

Yes. Each nested object generates its own interface, and the parent interface references it by name. Interface names are derived from the property key (PascalCase).
