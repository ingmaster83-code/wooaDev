💡 Tips

  • Use rem for font sizes to respect the user's browser default and improve accessibility.
  • Use em for spacing that should scale with the component's font size.
  • Use vw/vh for viewport-relative layouts like full-screen sections.

Frequently Asked Questions

What is the difference between em and rem?

em is relative to the parent element's font size; rem is relative to the root () element.

When should I use px vs percent?

Use px for fixed dimensions (borders, icons); use % for fluid layouts that scale with parent element size.

Is my data sent to a server?

No. All processing happens entirely within your browser — your files are never uploaded to any server. This zero-server architecture keeps your data 100% private, safe for sensitive documents and enterprise security environments.
