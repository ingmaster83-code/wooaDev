IP 주소 변환기 — 정수 · 16진수 · 2진수 · IPv6 표기

IPv4·IPv6 주소를 10진 정수, 16진수, 2진수로 바꾸고 IPv4-매핑 IPv6, 6to4, 역방향 DNS 이름까지 한 번에 계산합니다.

사용 예시

✅ 5개 변환

입력 — IP 주소 또는 정수 (한 줄에 하나)

192.168.0.1
3232235521
0xC0A80001
2001:db8::1
::ffff:192.0.2.128

결과 — 변환 결과

입력 | 버전 | 표준 표기 | 10진 정수 | 16진수
192.168.0.1 | IPv4 | 192.168.0.1 | 3232235521 | 0xC0A80001
3232235521 | IPv4 | 192.168.0.1 | 3232235521 | 0xC0A80001
0xC0A80001 | IPv4 | 192.168.0.1 | 3232235521 | 0xC0A80001
2001:db8::1 | IPv6 | 2001:db8::1 | 42540766411282592856903984951653826561 | 0x20010DB8000000000000000000000001
::ffff:192.0.2.128 | IPv6 | ::ffff:c000:280 | 281473902969472 | 0xFFFFC0000280

이 도구로 할 수 있는 일

데이터베이스에 IP를 정수로 저장하거나, 로그에서 16진수 IP를 만났거나, IPv6 표기를 정리해야 할 때 쓰는 변환기입니다.

  • IPv4 ↔ 10진 정수(3232235521) ↔ 16진수(0xC0A80001) ↔ 2진수 ↔ 옥텟별 8진수
  • IPv6: 압축 표기(2001:db8::1)와 전체 표기(0000 채움), 10진/16진 정수
  • IPv4-매핑 IPv6(::ffff:192.0.2.1)에 담긴 IPv4 추출, 6to4 접두어(2002::/16)
  • 역방향 DNS 이름(in-addr.arpa, ip6.arpa) 생성
  • 정수 입력은 IPv4/IPv6 중 어느 쪽으로 읽을지 선택, 옥텟 8진/16진 표기(0300.0250.0.1)도 인식

💡 Tips

  • MySQL에서는 INET_ATON()/INET_NTOA() 함수가 같은 변환을 합니다. 값 검증에 이 도구를 쓰세요.
  • IPv6의 연속된 0 그룹은 가장 긴 구간 하나만 ::로 줄이는 것이 표준(RFC 5952) 표기입니다.
  • 큰 정수(2^32 초과)는 IPv6 주소로 해석됩니다.

자주 묻는 질문

IP를 정수로 바꾸면 어디에 좋은가요?

대역(범위) 검색을 BETWEEN 비교로 빠르게 할 수 있고 저장 공간도 문자열보다 작습니다(IPv4는 4바이트).

::ffff:192.0.2.1 은 무엇인가요?

IPv6 소켓에서 IPv4 연결을 표현하는 IPv4-매핑 주소입니다. 마지막 32비트가 IPv4 주소입니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
