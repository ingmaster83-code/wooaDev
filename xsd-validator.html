XML Schema (XSD) 검증기

XML 과 XSD 를 붙여 넣으면 요소 순서와 출현 횟수, 필수 속성, 단순 타입(정수·날짜·불리언 등)과 패싯(enumeration, pattern, 길이, 범위), ID/IDREF 를 검사해 위치(XPath 경로)와 이유를 알려 줍니다.

사용 예시

⛔ 오류 5개

입력 — 검증할 XML

<?xml version="1.0"?>
<catalog>
  <book id="b1" pages="320">
    <title>XML Basics</title>
    <author>Kim</author>
    <price currency="USD">29.99</price>
    <published>2024-02-30</published>
  </book>
  <book id="b1" pages="0">
    <title>XPath 입문</title>
    <price currency="EUR">18000</price>
    <isbn>123</isbn>
  </book>
</catalog>

입력 — XSD 스키마

<?xml version="1.0"?>
<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema">
  <xs:element name="catalog">
    <xs:complexType>
      <xs:sequence>
        <xs:element name="book" maxOccurs="unbounded">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="title" type="xs:string"/>
              <xs:element name="author" type="xs:string" maxOccurs="3"/>
              <xs:element name="price">
                <xs:complexType>
                  <xs:simpleContent>
                    <xs:extension base="xs:decimal">
                      <xs:attribute name="currency" use="required">
                        <xs:simpleType>
                          <xs:restriction base="xs:string">
                            <xs:enumeration value="USD"/>
                            <xs:enumeration value="KRW"/>
                          </xs:restriction>
…

결과 — 검증 오류

# | 위치 | 오류
1 | /catalog/book[1]/published | 값 "2024-02-30" 이(가) 존재하지 않는 날짜입니다
2 | /catalog/book[2] | ID "b1" 가 중복됩니다
3 | /catalog/book[2] | 속성 pages 값 "0" 이(가) positiveInteger 범위(1 ~ ∞)를 벗어납니다
4 | /catalog/book[2] | 자식 요소 순서·구성이 스키마와 다릅니다: <price> 위치에 <author> 가 와야 합니다
5 | /catalog/book[2]/price | 속성 currency 값 "EUR" 이(가) 허용된 값(USD, KRW)이 아닙니다

결과 — 참고

지원 범위: 요소·속성·complexType(sequence, choice, all, group, 확장/제한)·simpleType(패싯, list, union)·내장 타입·출현 횟수·ID/IDREF. 네임스페이스는 접두사를 무시하고 이름으로만 비교하며 key/unique/keyref, import/include, substitutionGroup 은 검사하지 않습니다

이 도구로 할 수 있는 일

연동용 XML 이 스키마에 맞는지 xmllint 없이 브라우저에서 확인합니다. 파일은 서버로 전송되지 않습니다.

  • 구조: sequence·choice·all·group, minOccurs/maxOccurs, mixed, 빈 요소, 확장·제한(complexContent·simpleContent), 이름 있는 타입과 element ref
  • 오류 위치: /catalog/book[2]/price 같은 XPath 경로와 "자식 요소 순서가 다릅니다: <price> 위치에 <author> 가 와야 합니다" 같은 이유
  • 속성: required·prohibited·fixed·default, 선언되지 않은 속성 오류, anyAttribute
  • 타입: string, 정수군(범위 포함), decimal, boolean, date·dateTime·time·duration, anyURI, hexBinary, base64Binary, NMTOKEN, language, ID/IDREF 등 내장 타입
  • 패싯: enumeration, pattern, length·minLength·maxLength, min/maxInclusive·Exclusive, totalDigits, fractionDigits, list, union

💡 Tips

  • 가장 먼저 나오는 순서 오류가 뒤의 연쇄 오류를 만들 수 있습니다. 위에서부터 고치세요.
  • 날짜는 형식뿐 아니라 존재하는 날짜인지(2월 30일 불가)도 확인합니다.
  • key/unique/keyref, substitutionGroup, import/include 는 지원하지 않습니다. 필요한 경우 전용 도구로 확인하세요.

자주 묻는 질문

네임스페이스가 있는 XML 도 되나요?

접두사를 무시하고 이름으로만 비교합니다. targetNamespace 가 다른 요소 구분이 필요하면 정확한 결과가 아닐 수 있습니다.

XSD 1.1 의 assert 도 되나요?

지원하지 않습니다. XSD 1.0 의 핵심 기능을 대상으로 합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
