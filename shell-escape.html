쉘 이스케이프 변환기 — POSIX · Bash · PowerShell · cmd

공백, 따옴표, $, 백틱, 세미콜론이 든 문자열을 셸에서 하나의 인수로 안전하게 전달하도록 POSIX sh/bash, Bash $'…', fish, PowerShell, cmd.exe 방식으로 한 번에 이스케이프합니다.

사용 예시

✅ 인수 5개를 이스케이프했습니다

입력 — 이스케이프할 문자열 (한 줄 = 인수 하나, 줄바꿈 포함 인수는 아래 옵션 사용)

It's a "quoted" $HOME `value`
plain-word
C:\Program Files\App
hello world; rm -rf /
single\backslash

결과 — 이스케이프 결과

# POSIX sh / bash / zsh
echo 'It'\''s a "quoted" $HOME `value`'
echo plain-word
echo 'C:\Program Files\App'
echo 'hello world; rm -rf /'
echo 'single\backslash'

# Bash $'…'
echo $'It\'s a "quoted" $HOME `value`'
echo plain-word
echo $'C:\\Program Files\\App'
echo $'hello world; rm -rf /'
echo $'single\\backslash'

# POSIX "…"
echo "It's a \"quoted\" \$HOME \`value\`"
echo "plain-word"
echo "C:\\Program Files\\App"
echo "hello world; rm -rf /"
echo "single\\backslash"

# fish
echo 'It\'s a "quoted" $HOME `value`'
echo plain-word
echo 'C:\\Program Files\\App'
echo 'hello world; rm -rf /'
echo 'single\\backslash'

# PowerShell '…'
echo 'It''s a "quoted" $HOME `value`'
echo 'plain-word'
echo 'C:\Program Files\App'
echo 'hello world; rm -rf /'
echo 'single\backslash'

# PowerShell "…"
echo "It's a `"quoted`" `$HOME ``value``"
echo "plain-word"
echo "C:\Program Files\App"
echo "hello world; rm -rf /"
echo "single\backslash"

# cmd.exe
echo "It's a \"quoted\" $HOME `value`"
echo plain-word
echo "C:\Program Files\App"
echo "hello world; rm -rf /"
echo "single\backslash"

# JSON
echo "It's a \"quoted\" $HOME `value`"
echo "plain-word"
echo "C:\\Program Files\\App"
echo "hello world; rm -rf /"
echo "single\\backslash"

결과 — 주의

큰따옴표 안에서는 $ ` \ " ! 가 특수하게 해석됩니다 — 변수 치환을 원하지 않으면 작은따옴표 방식을 쓰세요
이스케이프는 "문자열을 하나의 인수로 안전하게 전달"하는 용도입니다. 사용자 입력으로 셸 명령 문자열을 조립하는 대신, exec 계열 API 에 인수 배열을 넘기세요 (shell=False)
cmd.exe 의 규칙은 프로그램마다 다릅니다(CommandLineToArgvW 기준). % 와 ^ 처리는 .bat 파일 안/밖에서 달라질 수 있습니다

이 도구로 할 수 있는 일

사용자 입력이나 파일 이름을 셸 명령에 넣을 때 잘못 인용하면 명령이 깨지거나 보안 문제가 됩니다. 셸마다 규칙이 달라 한 번에 비교해 줍니다.

  • 대상: POSIX sh/bash/zsh 작은따옴표('It'\''s'), Bash $'…'(ANSI-C), POSIX 큰따옴표, fish, PowerShell 작은/큰따옴표, cmd.exe, JSON
  • 한 줄에 인수 하나씩 여러 개를 처리하거나 줄바꿈이 포함된 전체를 하나의 인수로 처리
  • 명령어 앞부분(예: echo, scp)을 붙여 바로 실행 가능한 형태로 출력
  • 안전한 문자만 있으면 따옴표 없이 그대로, 빈 문자열은 ''
  • NUL 문자, 줄바꿈 제한, 큰따옴표 안의 $·백틱 확장 같은 주의사항 안내

💡 Tips

  • 사용자 입력으로 셸 명령 문자열을 조립하는 대신 execve 계열 API 에 인수 배열을 넘기세요 (Python subprocess shell=False 등).
  • 변수 확장을 원하지 않는다면 큰따옴표보다 작은따옴표 방식이 안전합니다.
  • PowerShell 은 작은따옴표 안에서 ' 를 '' 로 두 번 씁니다.

자주 묻는 질문

작은따옴표 안에 작은따옴표를 어떻게 넣나요?

작은따옴표 안에서는 어떤 이스케이프도 안 되므로 따옴표를 닫고 \' 를 쓴 뒤 다시 여는 'It'\''s' 방식을 씁니다.

cmd.exe 는 왜 결과가 복잡한가요?

cmd.exe 는 자신의 규칙(^, %)과 프로그램별 인수 분해 규칙이 겹쳐 완벽한 인용이 어렵습니다. 가능하면 PowerShell 이나 배열 인수를 쓰세요.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
