cubic-bezier 이징 편집기 · steps()

cubic-bezier(x1, y1, x2, y2) 값이나 ease-out-back 같은 이름을 넣으면 곡선을 그려 보여 주고, 시간별 진행도 표와 transition·@keyframes·Web Animations 코드를 만들어 줍니다.

사용 예시

✅ cubic-bezier(0.34, 1.56, 0.64, 1) (= ease-out-back)

입력 — cubic-bezier(x1, y1, x2, y2) 또는 키워드

cubic-bezier(0.34, 1.56, 0.64, 1)

결과 — CSS

/* ease-out-back */
transition: transform 600ms cubic-bezier(0.34, 1.56, 0.64, 1);

@keyframes move {
  from { transform: translateX(0); }
  to   { transform: translateX(200px); }
}
.box { animation: move 600ms cubic-bezier(0.34, 1.56, 0.64, 1) forwards; }

/* JS (Web Animations API) */
el.animate([{ transform: "translateX(0)" }, { transform: "translateX(200px)" }], { duration: 600, easing: "cubic-bezier(0.34, 1.56, 0.64, 1)", fill: "forwards" });

이 도구로 할 수 있는 일

애니메이션의 느낌은 이징 곡선이 결정합니다. 숫자 네 개가 어떤 움직임이 되는지 곡선과 표로 확인하세요.

  • 입력: cubic-bezier(…), 숫자 네 개, 키워드(ease, ease-in-out), 이징 이름(ease-out-back, ease-in-expo 등 18종), steps(n, jump)
  • 곡선 그래프와 제어점, 지정한 지점 수의 시간별 진행도 표
  • y 가 0~1 밖으로 나가는 오버슈트(탄성)와 예비 동작 감지
  • transition, @keyframes, Web Animations API 코드 생성
  • x1·x2 가 0~1 을 벗어나면 CSS 규격 위반으로 오류

💡 Tips

  • 오버슈트(y > 1)가 있는 곡선은 요소가 목표를 살짝 지나쳤다가 돌아와 탄력 있는 느낌을 줍니다.
  • UI 전환은 150~300ms, 큰 이동은 300~500ms 정도가 자연스럽습니다.
  • 스프라이트 애니메이션이나 타자기 효과에는 steps() 를 쓰세요.

자주 묻는 질문

x 값은 왜 0~1 이어야 하나요?

x 는 시간 축이라 뒤로 돌아가면 한 시각에 값이 여러 개가 되기 때문에 CSS 규격이 0~1 로 제한합니다. y 는 제한이 없습니다.

keyframes 안에서는 어떻게 적용되나요?

animation-timing-function 은 키프레임 구간마다 다시 적용됩니다. 전체 애니메이션에 한 곡선을 쓰려면 구간이 하나여야 합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
