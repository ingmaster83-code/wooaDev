JWK · JWKS ↔ PEM 변환기

JWT 서명 검증에 쓰는 JWK/JWKS 를 PEM(공개키·개인키)으로, 반대로 PEM 공개키·개인키·인증서를 JWK 로 바꿉니다. RFC 7638 지문을 계산해 kid 로 넣을 수 있고 kid 로 한 키만 고를 수도 있습니다.

사용 예시

✅ 키 2개를 PEM 으로 변환

입력 — JWK / JWKS (JSON) 또는 PEM

{
  "keys": [
    {
      "kty": "EC",
      "crv": "P-256",
      "x": "f83OJ3D2xF1Bg8vub9tLe1gHMzV76e8Tus9uPHvRVEU",
      "y": "x_FEzRu9m36HLN_tue659LNpXW6pCyStikYjKIWI5a0",
      "kid": "ec-demo",
      "use": "sig"
    },
    {
      "kty": "OKP",
      "crv": "Ed25519",
      "x": "11qYAYKxCrfVS_7TyWQHOg7hcvPapiMlrwIaaPcHURo",
      "kid": "ed-demo"
    }
  ]
}

결과 — 키 정보

# | kty | 크기 | alg | use | kid | 지문 (RFC 7638) | 상태
1 | EC | EC P-256 | — | sig | ec-demo | oKIywvGUpTVTyxMQ3bwIIeQUudfr_CkLMjCE19ECD-U | 공개키
2 | OKP | OKP Ed25519 | — | — | ed-demo | kPrK_qmxVWaYVA9wwBF6Iuo3vVzz7TxHCTwXBygrS4k | 공개키

이 도구로 할 수 있는 일

JWT 검증 라이브러리가 PEM 만 받거나 JWKS 엔드포인트를 만들어야 할 때 씁니다. 키는 브라우저 밖으로 나가지 않습니다.

  • JWK/JWKS → PEM: RSA, EC(P-256·P-384·P-521), OKP(Ed25519), 개인키는 PKCS#8, 공개키는 SPKI
  • PEM → JWK: SPKI, PKCS#8, PKCS#1(RSA), SEC1(EC), 인증서(공개키 추출), kid(지문)·use·alg 지정
  • RFC 7638 지문(SHA-256, Base64URL) 계산 — 필수 필드를 사전순 JSON 으로 만들어 해시
  • JWKS 에서 kid 로 키 하나만 선택, 대칭키(oct)는 PEM 이 없다고 안내
  • 개인키(d)가 들어 있으면 경고, 약한 RSA·kid 누락 등 점검

함께 쓰면 좋은 도구

🎫JWT 디코더 🔑키 쌍 생성기 (RSA·EC·Ed25519) 🗝️SSH 공개키 검사기 📜인증서 디코더

💡 Tips

  • 공개 JWKS 에는 공개키만 게시하세요. d, p, q 같은 필드가 보이면 개인키입니다.
  • kid 는 키 회전 때 어떤 키로 서명했는지 알려 줍니다. RFC 7638 지문을 kid 로 쓰면 값이 키와 일대일로 대응합니다.
  • alg 는 키가 아니라 사용 선언입니다. JWT 라이브러리는 alg 를 확인하므로 정확히 지정하세요.

자주 묻는 질문

RSA 의 n 과 e 는 무엇인가요?

모듈러스와 공개 지수입니다. Base64URL 로 인코딩되며 SPKI 의 공개키와 같은 값입니다.

Ed25519 가 안 변환돼요.

브라우저가 Web Crypto 의 Ed25519 를 지원해야 합니다(Chrome 137+, Firefox 129+, Safari 17+).

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
