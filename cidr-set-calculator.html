CIDR 집합 계산기 — 병합 · 교집합 · 제외

여러 CIDR 블록을 하나로 합치고, 두 목록의 교집합·합집합·제외를 구하거나 IP가 대역 안에 있는지 확인합니다. IPv4와 IPv6 모두 지원합니다.

사용 예시

✅ 5개 → 12개 CIDR

입력 — CIDR 목록 A (한 줄에 하나, 단일 IP·범위 허용)

10.0.0.0/24
10.0.1.0/24
10.0.2.0/23
192.168.0.0/16
172.16.0.1 - 172.16.0.200

입력 — CIDR 목록 B (교집합·제외·포함 확인용)

10.0.2.0/24
192.168.10.0/24

결과 — 결과 CIDR

10.0.0.0/22
172.16.0.1/32
172.16.0.2/31
172.16.0.4/30
172.16.0.8/29
172.16.0.16/28
172.16.0.32/27
172.16.0.64/26
172.16.0.128/26
172.16.0.192/29
172.16.0.200/32
192.168.0.0/16

결과 — 요약

입력 항목 수: 5
결과 CIDR 수: 12
IPv4 주소 수: 66,760

이 도구로 할 수 있는 일

방화벽, 보안 그룹, nginx allow 목록, 클라우드 IP 대역이 길어지면 겹치거나 인접한 항목을 정리해 개수를 줄여야 할 때가 많습니다.

  • 병합: 겹치거나 맞닿은 블록을 가장 적은 수의 CIDR로 집계 (10.0.0.0/24 + 10.0.1.0/24 → 10.0.0.0/23)
  • 교집합(A∩B), 제외(A−B), 합집합(A∪B): 허용 목록에서 특정 대역만 빼거나 두 목록의 공통부를 찾을 때
  • 포함 여부: B의 각 항목이 A에 전부 들어가는지, 일부만 겹치는지, 전혀 아닌지 검사
  • 입력: CIDR, 단일 IP, "시작 - 끝" 범위, # 주석을 한 줄에 하나씩
  • 결과의 총 주소 수와 CIDR 개수도 함께 표시

💡 Tips

  • 제외(A−B)를 하면 결과가 여러 CIDR로 쪼개질 수 있습니다. 이는 CIDR이 2의 거듭제곱 크기만 표현하기 때문입니다.
  • 클라우드 공급사가 공개하는 IP 목록을 붙여 넣어 병합하면 규칙 수를 크게 줄일 수 있습니다.
  • IPv4와 IPv6가 섞여 있어도 각각 따로 계산합니다.

자주 묻는 질문

병합하면 허용 범위가 넓어지지 않나요?

아니요. 이 도구는 정확히 같은 주소 집합을 가장 적은 CIDR로 다시 표현할 뿐, 새 주소를 추가하지 않습니다.

범위 입력(시작 - 끝)은 어떻게 처리되나요?

범위를 최소 개수의 CIDR로 분해해 다른 항목과 함께 병합합니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
